# مستند فنی: قمر (Qamar)
### پلتفرمی برای همگرایی دانش و داده‌های میان‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که داده‌های پراکنده از حوزه‌های مختلف (از علوم انسانی گرفته تا مهندسی داده) را به هم گره می‌زنند، می‌دانید که بزرگ‌ترین دردسر «زبان مشترک» است. **قمر** دقیقاً برای حل همین مشکل ساخته شده؛ ابزاری که به شما اجازه می‌دهد لایه‌های مختلف اطلاعاتی را بدون گم شدن در پیچیدگی‌های ساختاری، با هم ترکیب کنید.

---

## ۱. چرا قمر؟ (فلسفه پروژه)
قمر صرفاً یک کتابخانه یا فریم‌ورک نیست؛ یک رویکرد است. در دنیای امروز که مرزهای بین علوم کمرنگ شده، ما به سیستمی نیاز داریم که بتواند همزمان با مدل‌های آماری، متون کیفی و ساختارهای گراف‌محور کار کند.

*   **انعطاف‌پذیری بالا:** عدم وابستگی به یک نوع دیتاسِت خاص.
*   **معماری سبک:** طراحی شده برای اجرا در محیط‌های مختلف بدون سربار اضافه.
*   **یکپارچگی:** خروجی‌های استاندارد برای تحلیل‌های بعدی.

---

## ۲. نصب و راه‌اندازی
نصب قمر بسیار سرراست است. برای شروع کار، مطمئن شوید که محیط پایتون شما به‌روز است.

```bash
# نصب از طریق pip
pip install qamar-core

# یا اگر از مخزن اصلی استفاده می‌کنید:
git clone https://github.com/qamar-project/qamar
cd qamar
pip install -r requirements.txt
```

---

## ۳. شروع سریع (Quick Start)
بیایید یک مثال ساده از نحوه تعریف یک "گره میان‌رشته‌ای" با استفاده از قمر ببینیم. این کد به شما کمک می‌کند تا دو حوزه مختلف را به هم متصل کنید:

```python
from qamar import Nexus

# تعریف یک فضای کاری میان‌رشته‌ای
space = Nexus(name="Research_Hub")

# اضافه کردن دیتاست‌های ناهمگون
space.add_node("Data_Science", {"method": "Regression", "confidence": 0.95})
space.add_node("Sociology", {"theory": "Social_Capital", "weight": 0.8})

# ایجاد ارتباط بین دو حوزه
space.link("Data_Science", "Sociology", relation="predictive_model")

print(space.analyze_connections())
```

## ۴. جدول مقایسه‌ای: قمر در برابر روش‌های سنتی

| ویژگی | روش‌های سنتی (Excel/SQL) | قمر (Qamar) |
| :--- | :--- | :--- |
| **انعطاف ساختار** | بسیار سخت (Rigid) | پویا (Dynamic) |
| **تحلیل میان‌رشته‌ای** | دستی و زمان‌بر | بومی (Native) |
| **مقیاس‌پذیری** | محدود به جدول | بسیار بالا (گراف‌محور) |
| **منحنی یادگیری** | متوسط | سریع |

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
قطعاً. معماری قمر به گونه‌ای است که در لایه‌های زیرین از دیتابیس‌های توزیع‌شده پشتیبانی می‌کند.

**آیا نیاز دارم حتماً برنامه‌نویس باشم؟**
دانش پایه‌ای پایتون کمک می‌کند، اما مستندات ما طوری نوشته شده که محققان حوزه‌های علوم انسانی هم بتوانند با کدهای آماده، نیازهای خود را برطرف کنند.

**چگونه می‌توانم در توسعه قمر مشارکت کنم؟**
ما همیشه از PRهای جدید استقبال می‌کنیم. برای شروع به [qamar.website](https://qamar.website) سر بزنید و بخش "Contribution Guidelines" را مطالعه کنید.
