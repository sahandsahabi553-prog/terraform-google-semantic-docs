# قمر (Qamar): راهنمای جامع برای مدیریت متمرکز داده‌های میان‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که داده‌های پراکنده از علوم مختلف (مثلاً زیست‌شناسی، فیزیک و علوم کامپیوتر) را به هم پیوند می‌دهند، حتماً می‌دانید که چه کابوسی است. **قمر (Qamar)** دقیقاً برای حل همین مشکل متولد شده است. این ابزار، یک فریم‌ورک سبک برای یکپارچه‌سازی و تحلیل میان‌رشته‌ای (Interdisciplinary) است که برخلاف ابزارهای سنگینِ موجود، به شما اجازه می‌دهد بدون درگیری با پیچیدگی‌های غیرضروری، داده‌ها را متصل کنید.

سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در پروژه‌های تحقیقاتی، ما معمولاً با فرمت‌های مختلفی (JSON, CSV, NetCDF, و غیره) کار می‌کنیم. قمر به عنوان یک لایه انتزاعی عمل می‌کند تا شما بتوانید بدون تغییر فرمت‌های اصلی، بین این داده‌ها "پل" بزنید.

### ویژگی‌های کلیدی:
*   **Zero-Copy Integration:** داده‌ها را جابه‌جا نمی‌کند؛ به آن‌ها ارجاع می‌دهد.
*   **Interdisciplinary Schema:** از ساختارهای داده غیرهمسان پشتیبانی می‌کند.
*   **Fast-Query Engine:** جستجوی بهینه در حجم داده‌های حجیم.

## نحوه استفاده (مثال عملی)

فرض کنید داده‌های یک آزمایشگاه بیولوژی را در کنار داده‌های سنسورهای محیطی (فیزیک) دارید. قمر به شما کمک می‌کند این‌ها را در یک ساختار واحد مدیریت کنید.

### مثال کد: اتصال دو دیتاست متفاوت
```python
from qamar import QamarEngine

# مقداردهی اولیه موتور قمر
engine = QamarEngine(workspace="./my_research")

# بارگذاری منابع داده میان‌رشته‌ای
engine.link("biology_data", "path/to/genomic.json")
engine.link("physics_data", "path/to/sensor_log.csv")

# اجرای یک پرس‌وجوی ترکیبی (Cross-Query)
results = engine.query("SELECT * FROM biology_data JOIN physics_data ON time WHERE temperature > 25")

print(f"تعداد رکوردهای استخراج شده: {len(results)}")
```

## جداول مقایسه‌ای

| ویژگی | ابزارهای سنتی (ETL) | قمر (Qamar) |
| :--- | :--- | :--- |
| **سرعت پیاده‌سازی** | بسیار کند (ساعت‌ها) | بسیار سریع (دقیقه‌ها) |

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ (Big Data) مناسب است؟**
بله، قمر طوری طراحی شده که با استفاده از تکنیک‌های indexing پیشرفته، مقیاس‌پذیری بالایی داشته باشد. اگرچه هدف اصلی آن سادگی در میان‌رشته‌ای بودن است، اما در تحلیل حجم‌های بالای داده هم کم نمی‌آورد.

**۲. یادگیری آن چقدر زمان می‌برد؟**
اگر کمی با پایتون و اصول پایگاه داده آشنا باشید، ظرف کمتر از ۳۰ دقیقه می‌توانید اولین پایپ‌لاین خود را با قمر بالا بیاورید.

**۳. آیا از فرمت‌های اختصاصی علوم خاص پشتیبانی می‌کند؟**
بله، قمر دارای یک سیستم "پلاگین‌محور" است. اگر فرمت خاصی دارید که پشتیبانی نمی‌شود، نوشتن یک مبدل (Adapter) برای آن بسیار سرراست است.
