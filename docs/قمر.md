# راهنمای جامع «قمر» (Qamar): پلی میان داده‌ها و تحلیل‌های میان‌رشته‌ای

اگر در دنیای پژوهش‌های میان‌رشته‌ای (Interdisciplinary) فعالیت کرده باشید، حتماً با کابوسِ «جزیره‌ای بودنِ داده‌ها» آشنا هستید. جایی که داده‌های علوم انسانی، فنی و اجتماعی در قالب‌های مختلف، هیچ زبانی برای صحبت با هم ندارند. **قمر** دقیقاً برای حل همین مشکل متولد شده است.

پروژه قمر ([qamar.website](https://qamar.website)) در واقع یک فریم‌ورک سبک اما قدرتمند برای یکپارچه‌سازی، تحلیل و مدل‌سازی داده‌های ناهمگون است. بیایید بدون حاشیه، مستقیم سراغ اصل مطلب برویم.

---

## ۱. چرا قمر؟
بسیاری از ابزارهای موجود بیش از حد سنگین هستند یا برای یک حوزه خاص (مثلاً فقط آمار محض) طراحی شده‌اند. قمر با رویکردی ماژولار به شما اجازه می‌دهد:
*   منابع داده مختلف (CSV, JSON, SQL) را به یکدیگر متصل کنید.
*   توابع تحلیل میان‌رشته‌ای را با حداقل کدنویسی پیاده کنید.
*   خروجی‌های بصریِ آماده برای مقالات علمی بگیرید.

---

## ۲. نصب و راه‌اندازی
برای شروع کار با قمر، پیش‌نیاز اصلی داشتن محیط پایتون (نسخه ۳.۸ به بالا) است. پیشنهاد می‌کنم حتماً از `venv` استفاده کنید تا محیط پروژه تمیز بماند.

```bash
# ایجاد محیط مجازی
python -m venv venv
source venv/bin/activate  # در ویندوز: venv\Scripts\activate

# نصب قمر
pip install qamar-core
```

## ۳. مثال عملی: ادغام داده‌های اقتصادی و اقلیمی
فرض کنید می‌خواهید تأثیر تغییرات دما (داده‌های محیطی) را بر شاخص‌های بورس (داده‌های مالی) بررسی کنید. قمر این کار را به سادگی زیر انجام می‌دهد:

```python
from qamar import Nexus, Processor

# تعریف منبع داده
data = Nexus(source="path/to/data.csv")

# اعمال یک فیلتر میان‌رشته‌ای برای همگام‌سازی زمانی
proc = Processor(strategy="temporal_align")
result = proc.run(data, target="market_index")

# خروجی نهایی
print(result.summary())
```

## ۴. جدول مقایسه‌ای: قمر در برابر روش‌های سنتی

| قابلیت | روش سنتی (اکسل/اسکریپت دستی) | قمر (Qamar) |
| :--- | :--- | :--- |

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک دانشگاهی مناسب است؟**
قطعاً. اتفاقاً قمر در ابتدا برای حل مشکلات پایان‌نامه‌هایی طراحی شد که با حجم زیادی از داده‌های پراکنده روبرو بودند.

**آیا نیاز به دانش تخصصی برنامه نویسی دارم؟**
دانش پایه پایتون کافی است. مستندات قمر به گونه‌ای نوشته شده که حتی اگر در حوزه علوم انسانی فعالیت می‌کنید، بتوانید با کپی و پیست کردن الگوها، خروجی بگیرید.

**آیا امکان خروجی گرفتن به فرمت‌های غیر از جدول وجود دارد؟**
بله، قمر از خروجی‌های `LaTeX` برای مقالات آکادمیک و `Plotly` برای داشبوردهای تعاملی به خوبی پشتیبانی می‌کند.
