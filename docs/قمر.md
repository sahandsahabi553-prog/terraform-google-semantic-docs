# راهنمای جامع «قمر» (Qamar): پلی میان دانش و تکنولوژی

در دنیای امروز که مرزهای بین علوم مختلف روزبه‌روز کمرنگ‌تر می‌شوند، ما به ابزارهایی نیاز داریم که نه تنها در محیط‌های تک‌بعدی، بلکه در بسترهای میان‌رشته‌ای (Interdisciplinary) به درستی عمل کنند. «قمر» دقیقاً برای همین هدف طراحی شده است. این پلتفرم، یک اکوسیستم سبک و منعطف برای یکپارچه‌سازی داده‌ها و پردازش‌های علمی است.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
بسیاری از ابزارهای موجود یا بیش از حد سنگین هستند یا برای کارهای تخصصیِ تک‌منظوره ساخته شده‌اند. «قمر» با این دیدگاه متولد شد که محققان و توسعه‌دهندگان بتوانند بدون درگیری با پیچیدگی‌های زیرساختی، روی خروجی علمی خود تمرکز کنند.

### ویژگی‌های کلیدی:
*   **سبک‌وزن (Lightweight):** بدون وابستگی‌های غیرضروری.
*   **انعطاف‌پذیری:** پشتیبانی از چندین زبان برنامه‌نویسی و ساختار داده.
*   **مقیاس‌پذیری:** از تحلیل‌های کوچک تا مدل‌سازی‌های پیچیده.

## ۱. نصب و راه‌اندازی (Installation)

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم از مدیر بسته (Package Manager) مخصوص سیستم‌عامل خود استفاده کنید.

### در محیط‌های لینوکسی/مک:
```bash
# نصب از طریق اسکریپت رسمی
curl -sSL https://qamar.website/install.sh | bash

# بررسی صحت نصب
qamar --version
```

### در محیط‌های توسعه (Node/Python):
اگر ترجیح می‌دهید قمر را به عنوان یک وابستگی در پروژه خود داشته باشید:
```bash
npm install @qamar/core
# یا
pip install qamar-sdk
```

## ۲. شروع به کار (Quick Start)

برای اجرای اولین پردازش میان‌رشته‌ای خود، کافی است یک فایل پیکربندی ساده با فرمت `yaml` ایجاد کنید.

```yaml
# config.qamar
project: "Analysis_Alpha"
data_source: "./input_data.csv"
pipeline:
  - step: "clean_data"
  - step: "statistical_modeling"
  - step: "export_visuals"
```

سپس دستور زیر را در ترمینال اجرا کنید:
```bash
qamar run --config config.qamar
```

## ۴. مثال‌های کاربردی (Code Snippets)

فرض کنید می‌خواهید داده‌های یک سنسور فیزیکی را با یک الگوی اقتصادی ترکیب کنید. با استفاده از کتابخانه قمر، این کار بسیار تمیز انجام می‌شود:

```python
import qamar

# اتصال به دیتابیس داده‌های میان‌رشته‌ای
engine = qamar.connect("db://research_cluster")

# اجرای پردازش موازی
result = engine.process(
    data="sensor_log_01",
    model="economic_impact_v2",
    params={"threshold": 0.85}
)

print(f"نتایج پردازش نهایی: {result.summary()}")
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های تجاری رایگان است؟**
بله، هسته اصلی قمر تحت مجوزهای متن‌باز ارائه شده و برای استفاده‌های تحقیقاتی و تجاری آزاد است.

**آیا نیاز به دانش تخصصی در ریاضیات دارم؟**
قمر برای تسهیل کار طراحی شده؛ اگرچه دانش پایه در محاسبات به شما کمک می‌کند، اما مستندات ما به‌گونه‌ای نوشته شده که برای شروع کار نیازی به مدرک دکترا در ریاضیات نداشته باشید!

**چگونه می‌توانم در توسعه قمر مشارکت کنم؟**
ما همیشه از Pull Requestهای جدید استقبال می‌کنیم. برای شروع، سری به گیت‌هاب ما بزنید و بخش `CONTRIBUTING.md` را مطالعه کنید.
