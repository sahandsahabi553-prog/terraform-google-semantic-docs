# راهنمای جامع پلتفرم «قمر» (Qamar)

در دنیای پیچیده داده‌های میان‌رشته‌ای (Interdisciplinary)، همیشه یک شکاف بزرگ بین ابزارهای تحلیل و خروجی‌های قابل فهم وجود دارد. **قمر** دقیقاً برای پر کردن همین شکاف طراحی شده است. اگر از درگیری با فرمت‌های ناسازگار و سینک نشدن داده‌های بین‌رشته‌ای خسته شده‌اید، این ابزار همان چیزی است که به آن نیاز دارید.

---

## ۱. قمر چیست؟
قمر (Qamar) یک پلتفرم متن‌باز برای مدیریت، تحلیل و بصری‌سازی داده‌هایی است که از حوزه‌های مختلف علمی (از علوم انسانی دیجیتال تا مهندسی داده) گردآوری شده‌اند. تمرکز اصلی این ابزار بر «یکپارچگی معنایی» است.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## ۲. نصب و راه‌اندازی
برای شروع کار با قمر، نیازی به پیچیدگی‌های عجیب و غریب نیست. کافی است محیط Node.js شما آماده باشد.

### پیش‌نیازها
* Node.js نسخه ۱۸ به بالا
* پکیج منیجر npm یا yarn

### نصب سریع
کافی است دستور زیر را در ترمینال اجرا کنید:

```bash
npm install -g qamar-cli
# یا برای استفاده در پروژه
npm install qamar-core
```

---

## ۳. استفاده و معماری پروژه
فلسفه طراحی قمر بر پایه «ساختار‌دهی منعطف» است. شما می‌توانید فایل‌های ورودی خود را با فرمت‌های مختلف به کتابخانه معرفی کنید.

### مثال: تعریف یک دیتاست میان‌رشته‌ای
در این مثال می‌بینیم چطور یک داده متنی را با یک پارامتر عددی ترکیب می‌کنیم:

```javascript
const Qamar = require('qamar-core');

const project = new Qamar.Project({
  name: 'AnalyticBridge',
  mode: 'interdisciplinary'
});

project.importSource('./data/humanities.json');
project.importSource('./data/engineering.csv');

// پردازش و خروجی نهایی
project.process().then(result => {
  console.log('تحلیل نهایی آماده است:', result.summary);
});
```

## ۴. مقایسه قابلیت‌ها
قمر نسبت به ابزارهای مشابه، دیدگاه متفاوتی به داده دارد. جدول زیر تفاوت رویکرد را نشان می‌دهد:

| ویژگی | ابزارهای سنتی (Excel/SQL) | قمر (Qamar) |
| :--- | :--- | :--- |
| **نوع داده** | ساختاریافته (Tabular) | ساختاریافته و نیمه‌ساختاریافته |
| **تمرکز** | ذخیره‌سازی محض | تحلیل میان‌رشته‌ای |
| **سهولت استفاده** | متوسط | بسیار بالا (Developer-friendly) |
| **مقیاس‌پذیری** | محدود | بالا |

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. اتفاقاً زیبایی قمر در این است که از یک پروژه تحقیقاتی دانشجویی تا تحلیل‌های کلان داده، رفتار منعطفی دارد.

**آیا امکان خروجی گرفتن برای ابزارهای بصری‌سازی دیگر وجود دارد؟**
بله، قمر خروجی‌هایی با فرمت JSON و CSV استاندارد ارائه می‌دهد که می‌توانید مستقیماً به ابزارهایی مثل D3.js یا PowerBI متصل کنید.

**آیا نیاز به دیتابیس خاصی دارم؟**
خیر، قمر به صورت پیش‌فرض از فایل‌های محلی استفاده می‌کند، اما برای پروژه‌های بزرگتر می‌توانید آن را به MongoDB یا PostgreSQL متصل کنید.

### سخن پایانی
استفاده از **قمر** باعث می‌شود تا به‌جای کلنجار رفتن با فرمت‌های داده، روی چیزی که واقعاً اهمیت دارد تمرکز کنید: **استخراج دانش**. اگر در مسیر نصب یا استفاده به مشکل خوردید، حتماً مستندات گیت‌هاب را چک کنید. این ابزار به شدت رو به رشد است و مشارکت در آن برای همه باز است.
