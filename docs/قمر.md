# قمر (Qamar): پلی میان داده‌های پراکنده و تحلیل‌های عمیق

در دنیای مدرن، بزرگترین چالش ما کمبود داده نیست؛ بلکه «ارتباط» دادن این داده‌ها به یکدیگر است. **قمر (Qamar)** دقیقاً برای همین هدف طراحی شده است: یک پلتفرم میان‌رشته‌ای (Interdisciplinary) که به شما اجازه می‌دهد لایه‌های مختلف اطلاعات را از حوزه‌های متفاوت (فنی، علمی، اجتماعی) در یک ساختار یکپارچه مدل‌سازی کنید.

اگر از سرگردانی بین ده‌ها ابزار مختلف برای تحلیل سیستم‌های پیچیده خسته شده‌اید، قمر همان حلقه‌ی گمشده‌ای است که به دنبالش بودید.

---

## چرا قمر؟

قمر صرفاً یک کتابخانه یا دیتابیس نیست؛ یک فریم‌ورک برای «فکر کردن» به داده‌هاست. این ابزار به شما کمک می‌کند تا با تعریف روابط بین موجودیت‌های غیرهم‌جنس، الگوهای پنهانی را کشف کنید که در مدل‌های تک‌بعدی کاملاً نادیده گرفته می‌شوند.

### ویژگی‌های کلیدی:
*   **انعطاف‌پذیری بالا:** پشتیبانی از انواع فرمت‌های داده (JSON, CSV, Graph).
*   **معماری میان‌رشته‌ای:** طراحی شده برای پل زدن بین علوم کامپیوتر، آمار و علوم انسانی.
*   **مقیاس‌پذیری:** بهینه‌شده برای پردازش‌های سنگین روی دیتاست‌های بزرگ.

## نصب و راه‌اندازی

برای شروع، نیازی به پیکربندی‌های پیچیده ندارید. قمر به گونه‌ای طراحی شده که با یک دستور ساده در محیط ترمینال شما بالا بیاید.

```bash
# نصب از طریق پکیج منیجر اختصاصی
curl -sSL https://qamar.website/install | sh

# تایید نصب
qamar --version
```

پس از نصب، پیشنهاد می‌کنم محیط کاری خود را با دستور `qamar init` مقداردهی کنید تا ساختار دایرکتوری‌های لازم برای پروژه‌های میان‌رشته‌ای شما ایجاد شود.

## مثال کاربردی: تحلیل همبستگی

فرض کنید می‌خواهید تأثیر نوسانات قیمت یک ارز دیجیتال را بر روی یک شاخص اجتماعی خاص بسنجید. قمر این کار را برای شما ساده می‌کند:

```python
import qamar

# تعریف لایه‌های داده
finance_layer = qamar.load("market_data.csv")
social_layer = qamar.load("social_sentiment.json")

# ایجاد یک مدل میان‌رشته‌ای
model = qamar.Model(name="Market-Social-Correlation")
model.link(finance_layer, social_layer, on="timestamp")

# اجرای تحلیل همبستگی
result = model.analyze(method="pearson")
print(f"ضریب همبستگی: {result.score}")
```
