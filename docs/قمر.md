# راهنمای جامع «قمر» (Qamar): پلی میان دانش و تکنولوژی

در دنیای امروز که مرزهای بین علوم سخت (مثل فیزیک و ریاضی) و علوم نرم (مثل فلسفه و تحلیل داده) روز‌به‌روز کمرنگ‌تر می‌شود، ابزارهایی مثل **قمر (Qamar)** حکم یک پل ارتباطی حیاتی را دارند. قمر یک پلتفرم میان‌رشته‌ای (Interdisciplinary) است که برای ساده‌سازی فرآیندهای پیچیده محاسباتی و مدل‌سازی طراحی شده است.

اگر به دنبال راهی هستید که بدون درگیری با پیچیدگی‌های غیرضروری، تحلیل‌های دقیق علمی را در پروژه‌های خود پیاده کنید، جای درستی آمده‌اید.

---

## ۱. چرا قمر؟
بسیاری از ابزارهای موجود یا بیش از حد مهندسی‌محور هستند و یا فاقد دقت علمی لازم برای کارهای پژوهشی. قمر سعی کرده این تعادل را برقرار کند:
*   **پشتیبانی از کتابخانه‌های چندمنظوره:** امکان اتصال به دیتاسیت‌های علمی.
*   **سرعت بالا:** بهینه‌سازی شده برای محاسبات سنگین.
*   **رابط کاربری مدرن:** برای اینکه خروجی‌ها در گزارش‌های علمی شما واقعاً حرفه‌ای به نظر برسند.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## ۲. نصب و راه‌اندازی
نصب قمر بسیار سرراست است. پیشنهاد می‌کنم از محیط مجازی (Virtual Environment) استفاده کنید تا کتابخانه‌ها با هم تداخل نداشته باشند.

```bash
# نصب از طریق پکیج منیجر
pip install qamar-core

# بررسی صحت نصب
qamar --version
```

اگر از سیستم‌عامل‌های مبتنی بر لینوکس استفاده می‌کنید، احتمالاً نیاز دارید `build-essential` را نیز در سیستم داشته باشید تا کامپایل‌های داخلی به درستی انجام شوند.

---

## ۳. استفاده سریع (Quick Start)
بیایید یک مثال ساده از نحوه فراخوانی داده‌ها در یک محیط چندرشته‌ای را ببینیم. فرض کنید می‌خواهیم خروجی یک مدل را با داده‌های آماری مقایسه کنیم:

```python
from qamar import QModel

# مقداردهی اولیه
model = QModel(dataset="physics_v1")

# اجرای تحلیل داده‌ها
result = model.run(threshold=0.85)

# چاپ خروجی
print(f"نتیجه تحلیل: {result.summary()}")
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های تجاری رایگان است؟**
بله، هسته اصلی قمر تحت مجوزهای متن‌باز عرضه شده است، اما برای استفاده‌های سازمانی در مقیاس بزرگ، بهتر است مستندات مربوط به لایسنس‌های تجاری را در سایت مطالعه کنید.

**آیا می‌توانم کتابخانه‌های شخصی خودم را به قمر اضافه کنم؟**
کاملاً! معماری قمر به شکلی است که می‌توانید ماژول‌های اختصاصی خود را به راحتی از طریق `qamar-plugin-sdk` توسعه دهید.

**در صورت بروز خطای «Connection Timeout» چه کنم؟**
این خطا معمولاً به محدودیت‌های شبکه در ایران مربوط است. توصیه می‌کنم از پروکسی‌های استاندارد استفاده کنید یا مخازن محلی (Local Mirror) را برای دانلود پکیج‌ها تنظیم کنید.
