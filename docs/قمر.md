# قمر (Qamar): پلی میان داده‌ها و تحلیل‌های میان‌رشته‌ای

اگر درگیر پروژه‌هایی هستید که نیاز به یکپارچه‌سازی داده‌های پراکنده از حوزه‌های مختلف (مثل تحلیل‌های اقتصادی، داده‌های محیط‌زیستی و علوم انسانی) دارند، احتمالاً با «قمر» آشنا شده‌اید. قمر صرفاً یک کتابخانه نیست؛ بلکه یک فریم‌ورک متن‌باز برای مدل‌سازی میان‌رشته‌ای (Interdisciplinary Modeling) است که پیچیدگیِ اتصال متدولوژی‌های مختلف را به‌شدت کاهش می‌دهد.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
در دنیای واقعی، داده‌ها در سیلوهای مجزا گیر کرده‌اند. قمر با ارائه یک لایه انتزاعی (Abstraction Layer)، به شما اجازه می‌دهد متغیرهای کیفی را در کنار داده‌های کمی قرار دهید. 

*   **انعطاف‌پذیری:** پشتیبانی از فرمت‌های داده‌ای متنوع.
*   **مقیاس‌پذیری:** بهینه‌سازی شده برای محاسبات سنگین.
*   **API تمیز:** طراحی شده برای توسعه‌دهندگانی که از پیچیدگی بیزارند.

## نصب و راه‌اندازی

نصب قمر بسیار ساده است. این ابزار از طریق مخازن استاندارد در دسترس است. برای محیط‌های پایتونی، کافی است دستور زیر را در ترمینال اجرا کنید:

```bash
pip install qamar-core
```

اگر از سیستم‌های مبتنی بر لینوکس استفاده می‌کنید و نیاز به کامپایل مستقیم دارید:

```bash
git clone https://github.com/qamar-project/qamar.git
cd qamar
make install
```

## نحوه استفاده (مثال عملی)

فرض کنید می‌خواهید یک مدل ساده برای تحلیل تأثیر تغییرات اقلیمی بر بازارهای محلی ایجاد کنید. قمر این کار را با ساختار `QModel` مدیریت می‌کند.

```python
from qamar import QModel, Field

# تعریف مدل میان‌رشته‌ای
model = QModel(name="Climate-Economy-Impact")

# افزودن متغیرهای اقلیمی (کمی)
model.add_field(Field("temperature", type="float", source="sensor_api"))

# افزودن متغیرهای اقتصادی (کیفی/کمی)
model.add_field(Field("market_index", type="int", source="db_query"))

# اجرای تحلیل همبستگی
results = model.run_correlation(field_a="temperature", field_b="market_index")

print(f"ضریب همبستگی: {results.coefficient}")
```

## مقایسه متدولوژی‌ها

در جدول زیر، تفاوت رویکرد قمر را با ابزارهای سنتی مشاهده می‌کنید:

| ویژگی | ابزارهای سنتی (Excel/SPSS) | قمر (Qamar) |
| :--- | :--- | :--- |
| **یکپارچگی داده** | دستی و کند | خودکار و API-based |
| **مدل‌سازی کیفی** | محدود | بومی (Native Support) |
| **مقیاس‌پذیری** | ضعیف (در حجم بالا) | بسیار بالا |
| **باز بودن** | انحصاری | متن‌باز (Open Source) |

## پرسش‌های متداول (FAQ)

**۱. آیا قمر برای پروژه‌های آکادمیک مناسب است؟**
بله، در واقع ریشه قمر در پژوهش‌های دانشگاهی است. بسیاری از مقالات علوم میان‌رشته‌ای از موتور محاسباتی قمر برای شبیه‌سازی‌های خود استفاده می‌کنند.

**۲. یادگیری آن چقدر زمان می‌برد؟**
اگر با پایتون آشنایی نسبی داشته باشید، مستندات رسمی قمر به شما کمک می‌کند ظرف کمتر از یک روز اولین مدل خود را پیاده‌سازی کنید.

**۳. آیا امکان خروجی گرفتن برای ابزارهای بصری‌سازی وجود دارد؟**
قطعاً. قمر از فرمت‌های `JSON` و `Parquet` پشتیبانی می‌کند که مستقیماً در ابزارهایی مثل Tableau یا PowerBI قابل خواندن هستند.
