# قمر (Qamar): راهنمای جامع مدیریت و سازماندهی دانش بین‌رشته‌ای

در دنیای امروز که مرزهای علوم به‌شدت در حال فروپاشی است، ابزاری مثل **قمر** دقیقاً همان چیزی است که جای خالی‌اش حس می‌شد. اگر مثل من درگیر پروژه‌هایی هستید که از تحلیل داده‌های مالی شروع می‌شود، به فلسفه می‌رسد و در نهایت در مهندسی نرم‌افزار پیاده‌سازی می‌شود، می‌دانید که مدیریت این حجم از اطلاعات پراکنده چقدر کابوس است.

قمر (Qamar) یک پلتفرم پیشرو برای مدیریت دانش بین‌رشته‌ای است که به شما اجازه می‌دهد مفاهیم را نه در ساختارهای درختی خشک، بلکه در یک شبکه عصبیِ زنده به هم متصل کنید.

---

## ۱. چرا قمر؟ (فلسفه طراحی)
برخلاف ابزارهای یادداشت‌برداری سنتی که مثل یک بایگانی عمل می‌کنند، قمر به مثابه یک «مغز دوم» برای پروژه‌های میان‌رشته‌ای طراحی شده است. 

*   **اتصال‌دهی (Linking):** ارجاع متقاطع بین حوزه‌های مختلف بدون اصطکاک.
*   **بصری‌سازی:** تبدیل داده‌های خام به گراف‌های دانش.
*   **متن‌باز بودن:** داده‌های شما متعلق به خودتان است.

---

## ۲. نصب و راه‌اندازی
قمر برای پلتفرم‌های مختلف بهینه‌سازی شده است. برای شروع سریع، اگر از سیستم‌عامل‌های مبتنی بر یونیکس (لینوکس یا مک) استفاده می‌کنید، ترمینال خود را باز کنید:

```bash
# دانلود و نصب آخرین نسخه قمر
curl -sSL https://qamar.website/install.sh | bash
```

پس از نصب، برای اطمینان از صحت اجرا:
```bash
qamar --version
# خروجی: Qamar CLI v1.2.4
```

## ۳. استفاده پایه
کار با قمر بسیار شهودی است. فرض کنید می‌خواهید یک «نود» (Node) جدید برای حوزه «هوش مصنوعی در پزشکی» ایجاد کنید:

```bash
qamar create --title "AI-Medicine-Integration" --tags "Health, Tech, Ethics"
```

### جداول مقایسه‌ای ویژگی‌ها
قمر در مقایسه با ابزارهای سنتی، رویکرد متفاوتی در دسترسی به داده‌ها دارد:

| ویژگی | قمر (Qamar) | ابزارهای سنتی (نوت‌بوک) |
| :--- | :--- | :--- |
| **ساختار** | گراف‌محور (Graph) | درختی (Hierarchical) |
| **هم‌افزایی** | بالا (بین‌رشته‌ای) | پایین (ایزوله) |
| **خروجی** | API-First | فایل‌های ایستا |

## ۴. مثال کد: اتوماسیون جریان کاری
یکی از قابلیت‌های محبوب من، استفاده از اسکریپت‌نویسی برای خروجی گرفتن از نودهای مرتبط است. فرض کنید می‌خواهید تمام یادداشت‌های مرتبط با "Ethics" را در یک فایل JSON اکسپورت کنید:

```python
import qamar

# اتصال به دیتابیس محلی قمر
db = qamar.connect("my_brain.db")

# فیلتر کردن نودها بر اساس تگ
ethical_nodes = db.query(tags=["Ethics", "AI"])

for node in ethical_nodes:
    print(f"Found: {node.title} - Ref: {node.id}")
```

## ۵. سوالات متداول (FAQ)

**س: آیا قمر برای پروژه‌های تیمی مناسب است؟**
ج: بله، قمر از مخازن Git برای همگام‌سازی استفاده می‌کند که باعث می‌شود کار تیمی روی دانشِ اشتراکی بسیار امن و لذت‌بخش باشد.

**س: آیا برای استفاده از قمر حتماً باید برنامه‌نویس باشم؟**
ج: اصلاً. رابط کاربری گرافیکی (GUI) قمر به قدری ساده است که حتی اگر خطی کد نزنید، می‌توانید از تمام قابلیت‌های تحلیلی آن استفاده کنید.

**س: داده‌های من کجا ذخیره می‌شوند؟**
ج: اولویت اول قمر حریم خصوصی است. داده‌ها به‌صورت لوکال روی سیستم شما ذخیره می‌شوند و شما مالک مطلق آن‌ها هستید.
