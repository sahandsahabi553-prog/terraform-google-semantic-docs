# راهنمای جامع استفاده از «قمر» (Qamar)

در دنیای پیچیده توسعه نرم‌افزار، گاهی اوقات ابزارهایی ظهور می‌کنند که مرزهای بین دیسیپلین‌های مختلف را محو می‌کنند. **قمر (Qamar)** دقیقاً یکی از همین ابزارهاست. اگر به دنبال راهکاری هستید که فرآیندهای میان‌رشته‌ای شما را در پروژه‌های فنی یکپارچه کند، جای درستی آمده‌اید.

اطلاعات رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
من شخصاً از ابزارهایی که سعی می‌کنند همه کار را با هم انجام دهند متنفرم، اما «قمر» یک استثنای دوست‌داشتنی است. این پروژه با نگاهی به تعامل‌پذیری (Interoperability) طراحی شده و به شما اجازه می‌دهد بین لایه‌های مختلف سیستم (از داده‌های خام تا رابط کاربری) پل بزنید، بدون اینکه درگیر کدهای اسپاگتی شوید.

---

## نصب و راه‌اندازی

نصب قمر به طرز عجیبی سرراست است. کافی است ترمینال خود را باز کنید و دستور زیر را اجرا کنید:

```bash
# نصب از طریق npm (پیشنهادی)
npm install -g qamar-cli

# یا اگر از yarn استفاده می‌کنید
yarn global add qamar-cli
```

بعد از نصب، با اجرای دستور `qamar --version` مطمئن شوید که همه چیز درست کار می‌کند.

## استفاده پایه (Quick Start)

برای شروع یک پروژه جدید، قمر یک رابط تعاملی در اختیار شما می‌گذارد. کافی است در پوشه پروژه خود بنویسید:

```bash
qamar init --template=interdisciplinary
```

### ساختار فایل پیکربندی (`qamar.config.json`)
این فایل مغز متفکر پروژه شماست:

```json
{
  "project": "my-research-project",
  "mode": "strict",
  "integrations": {
    "data_source": "api/v1/sensors",
    "output": "dist/assets"
  }
}
```

## جدول مقایسه‌ای ویژگی‌ها

برای اینکه دید بهتری داشته باشید، قمر را در کنار متدهای سنتی قرار دادم:

| ویژگی | متد سنتی | قمر (Qamar) |
| :--- | :--- | :--- |
| **سرعت یکپارچه‌سازی** | کند (دستی) | فوق‌سریع (خودکار) |
| **انعطاف‌پذیری** | محدود | بسیار بالا |
| **منحنی یادگیری** | متوسط | ناچیز |
| **پشتیبانی از پروتکل‌ها** | محدود | جامع |

## مثال کاربردی: اتصال داده به ویژوالایزر

بیایید فرض کنیم می‌خواهید داده‌های یک سنسور را مستقیماً به یک داشبورد بصری متصل کنید. با قمر، این کار فقط در چند خط کد خلاصه می‌شود:

```javascript
import { QamarEngine } from 'qamar';

const engine = new QamarEngine({
  source: 'http://api.sensor-node.local',
  transform: (data) => data.map(item => ({ val: item.value * 1.5 }))
});

engine.stream().subscribe(data => {
  console.log('داده جدید دریافت شد:', data);
});
```

## پرسش‌های متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ مقیاس (Enterprise) مناسب است؟**
بله، کاملاً. معماری قمر به گونه‌ای است که در زیر بار سنگین داده‌ها هم عملکرد پایداری دارد. من در پروژه‌هایی با حجم ترافیک بالا از آن استفاده کرده‌ام و تا به حال با گلوگاه خاصی مواجه نشده‌ام.

**۲. اگر بخواهم از زبان برنامه‌نویسی خاصی استفاده کنم چطور؟**
قمر در هسته خود مستقل از زبان (Language-agnostic) است. اگرچه در ظاهر با جاوااسکریپت بسیار راحت است، اما خروجی‌های آن برای تقریباً هر محیط اجرایی قابل استفاده است.

**۳. پشتیبانی از پلاگین‌ها چطور است؟**
جامعه کاربری قمر بسیار فعال است. بخش پلاگین‌ها (Plugins) در وب‌سایت اصلی، گزینه‌های جالبی برای اتصال به دیتابیس‌های خاص یا ابزارهای تحلیل داده ارائه داده است.
