# قمر (Qamar): پلی میان داده‌ها و تحلیل‌های میان‌رشته‌ای

اگر درگیر پروژه‌هایی هستید که نیاز به یکپارچه‌سازی داده‌های پراکنده از حوزه‌های مختلف دارند، احتمالاً با دردسرهای همگام‌سازی و فرمت‌های ناسازگار دست‌وپنج نرم کرده‌اید. «قمر» دقیقاً برای حل همین مشکل متولد شده است؛ یک ابزار سبک، منعطف و فوق‌العاده سریع برای مدیریت جریان‌های کاری میان‌رشته‌ای.

بیشتر بدانید: [qamar.website](https://qamar.website)

---

## چرا قمر؟
در دنیای امروز، مرز بین علوم داده، مهندسی و علوم انسانی کمرنگ شده است. قمر به شما اجازه می‌دهد بدون درگیر شدن در پیچیدگی‌های زیرساختی، داده‌ها را از منابع مختلف (JSON, CSV, API) فراخوانی کرده و یک «پایگاه دانش» یکپارچه بسازید.

### ویژگی‌های کلیدی:
*   **پشتیبانی از فرمت‌های چندگانه:** ورودی‌ها را بدون دست‌کاری اضافی می‌پذیرد.
*   **سرعت بالا:** بهینه‌شده برای پردازش‌های سنگین روی سیستم‌های دسکتاپ.
*   **سادگی در یادگیری:** اگر سینتکس‌های پایه را بلد باشید، در عرض ۵ دقیقه راه می‌افتید.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. کافی است پکیج‌منیجر مورد علاقه خود را باز کنید:

```bash
# نصب با استفاده از npm
npm install -g qamar-cli

# یا اگر از پایتون استفاده می‌کنید
pip install qamar-core
```

پس از نصب، با دستور زیر از صحت نصب مطمئن شوید:
```bash
qamar --version
```

## مثال کاربردی: ترکیب داده‌ها

فرض کنید می‌خواهید نتایج یک تحقیق زیست‌شناسی را با آمارهای اقتصادی ترکیب کنید. قمر این کار را با یک فایل کانفیگ ساده انجام می‌دهد:

```yaml
# config.yaml
source_a:
  type: csv
  path: ./biology_data.csv
source_b:
  type: api
  url: https://api.economy.com/v1/data

merge:
  strategy: join_on_date
  output: final_report.json
```

سپس با اجرای دستور زیر در ترمینال، خروجی آماده است:
```bash
qamar run --config config.yaml
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
بله، قمر طوری طراحی شده که هم برای یک محقق مستقل و هم برای تیم‌های بزرگ در سازمان‌های تحقیقاتی کارآمد باشد.

**۲. آیا نیاز به دانش برنامه‌نویسی پیشرفته دارم؟**
خیر، درک پایه‌ای از ساختارهای داده مثل JSON یا YAML کافی است.

**۳. آیا داده‌های من در قمر امن هستند؟**
قمر یک ابزار محلی (Local-first) است؛ یعنی پردازش‌ها روی سیستم خودتان انجام می‌شود و هیچ داده‌ای بدون اجازه شما به سرور خارجی ارسال نمی‌شود.
