# راهنمای جامع «قمر»: ابزاری برای مدیریت ساختاریافته داده‌های میان‌رشته‌ای

اگر درگیر پروژه‌هایی هستید که مرزهای علوم داده، مدیریت محتوا و تحلیل‌های پیچیده را جابه‌جا می‌کنند، احتمالاً با چالش همیشگی «داده‌های پراکنده» دست‌ و پنجه نرم کرده‌اید. **قمر (Qamar)** دقیقاً برای همین ساخته شده است؛ یک فریم‌ورک سبک اما قدرتمند برای یکپارچه‌سازی و مدیریت داده‌های میان‌رشته‌ای که به شما اجازه می‌دهد بدون درگیری با پیچیدگی‌های زیرساختی، روی تحلیل‌های خود تمرکز کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (نگاهی از دید توسعه‌دهنده)

بیشتر ابزارهای موجود یا بیش از حد سنگین هستند (مثل پایگاه‌داده‌های بزرگ سازمانی) یا بیش از حد ساده (مثل فایل‌های CSV). قمر در نقطه بهینه ایستاده است. استفاده از آن مثل کار با یک کتابخانه محلی است که به شما اجازه می‌دهد داده‌های غیرمتجانس (Unstructured) را با منطق ساختاریافته ترکیب کنید.

### ویژگی‌های کلیدی:
*   **انعطاف‌پذیری بالا:** پشتیبانی از انواع فرمت‌های داده.
*   **سرعت:** بهینه‌شده برای پردازش‌های سریع در محیط‌های تحقیقاتی.
*   **یکپارچگی:** رابط کاربری خط فرمان (CLI) ساده و یکپارچه.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. اگر از سیستم‌های مبتنی بر یونیکس (لینوکس یا مک) استفاده می‌کنید، کافیست دستور زیر را در ترمینال خود اجرا کنید:

```bash
# نصب از طریق اسکریپت رسمی
curl -sSL https://qamar.website/install.sh | bash
```

پس از نصب، با دستور زیر از درستی نصب مطمئن شوید:

```bash
qamar --version
```

## شروع به کار (Usage)

اولین قدم، ایجاد یک پروژه جدید است. قمر از ساختار دایرکتوری‌های استاندارد استفاده می‌کند تا همه چیز مرتب بماند.

```bash
# ایجاد پروژه جدید
qamar init my-research-project

# ورود به دایرکتوری
cd my-research-project

# افزودن یک منبع داده جدید
qamar add source --url "data-link-or-path"
```

### یک مثال ساده
فرض کنید می‌خواهید داده‌های یک مطالعه میان‌رشته‌ای در حوزه محیط‌زیست و اقتصاد را ترکیب کنید. ساختار فایل پیکربندی شما در `qamar.yaml` به این شکل خواهد بود:

```yaml
project: "Eco-Econ-Study"
version: "1.0.0"
sources:
  - name: "climate-data"
    type: "csv"
    path: "./raw/climate.csv"
  - name: "market-data"
    type: "json"
    path: "./raw/market.json"
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. حتی اگر تنها یک پروژه تحقیقاتی ساده دارید، استفاده از قمر باعث می‌شود داده‌هایتان به شکلی استاندارد ذخیره شود که در آینده به‌راحتی قابل توسعه باشد.

**۲. آیا می‌توانم خروجی‌های قمر را در پایتون استفاده کنم؟**
بله، قمر یک API بسیار ساده برای فراخوانی داده‌ها در محیط‌های پایتونی ارائه می‌دهد. کافیست از کتابخانه `pyqamar` استفاده کنید.

**۳. پشتیبانی از فرمت‌های حجیم چگونه است؟**
قمر از مکانیزم‌های Streaming استفاده می‌کند تا حتی در صورت کار با فایل‌های چند گیگابایتی، رم سیستم شما اشغال نشود.

## سخن پایانی
قمر یک ابزار «همه کاره» نیست؛ بلکه ابزاری است که در کاری که انجام می‌دهد — یعنی مدیریت داده‌های میان‌رشته‌ای — بهترین است. اگر در کارهای خود با داده‌های پراکنده سروکار دارید، پیشنهاد می‌کنم همین امروز آن را نصب کنید و خروجی کارتان را با روش‌های قدیمی مقایسه کنید. تفاوت را همان لحظه حس خواهید کرد.
