# راهنمای جامع کار با «قمر» (Qamar)

اگر در دنیای توسعه نرم‌افزار و پروژه‌های میان‌رشته‌ای (Interdisciplinary) فعالیت می‌کنید، احتمالاً بارها با چالش یکپارچه‌سازی داده‌های ناهمگون دست‌ و پنجه نرم کرده‌اید. **قمر** دقیقاً برای حل همین مشکل طراحی شده است؛ ابزاری که پل میان سیستم‌های مختلف است و اجازه می‌دهد بدون درگیری با پیچیدگی‌های زیرساختی، داده‌ها را بین محیط‌های مختلف جابه‌جا و پردازش کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
در پروژه‌هایی که ترکیبی از علوم داده، مهندسی نرم‌افزار و تحلیل‌های آماری هستند، ابزارهای سنتی معمولاً کم می‌آورند. قمر با رویکرد "Agile-Integration" سعی می‌کند گلوگاه‌های ارتباطی را حذف کند.

### ویژگی‌های کلیدی:
*   **پشتیبانی چندزبانه:** به راحتی با پایتون، Node.js و حتی اسکریپت‌های Bash هماهنگ می‌شود.
*   **سرعت بالا:** استفاده از معماری مبتنی بر Event-loop برای کاهش تاخیر.
*   **مقیاس‌پذیری:** از یک اسکریپت ساده لوکال تا زیرساخت‌های توزیع‌شده.

## نصب و راه‌اندازی

برای شروع، کافی است ابزار را از طریق پکیج‌منیجر مورد علاقه‌تان نصب کنید.

### پیش‌نیازها
*   Node.js نسخه ۱۸ به بالا
*   Python 3.9+ (برای ماژول‌های تحلیلی)

### دستور نصب
```bash
# نصب از طریق npm
npm install -g @qamar/cli

# بررسی نصب
qamar --version
```

## شروع سریع (Quick Start)

بعد از نصب، برای مقداردهی اولیه یک پروژه، کافیست در ریشه پوشه پروژه خود دستور زیر را بزنید:

```bash
qamar init --template=interdisciplinary
```

این دستور یک ساختار استاندارد ایجاد می‌کند که شامل پیکربندی‌های لازم برای اتصال به دیتابیس‌ها و سرویس‌های خارجی است.

### مثال کد: اتصال یک سرویس ساده
در اینجا قطعه کدی را می‌بینید که خروجی یک آنالیز آماری را به یک API خارجی ارسال می‌کند:

```javascript
const qamar = require('@qamar/core');

async function syncData() {
  const data = await qamar.fetchSource('sensor_log_01');
  const processed = qamar.transform(data, 'normalize');
  
  await qamar.push(processed, {
    target: 'cloud_dashboard',
    retry: true
  });
}

syncData().catch(console.error);
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. من شخصاً در پروژه‌های شخصی‌ام که فقط شامل چند اسکریپت ساده بودند از قمر استفاده کردم تا از شرِ نوشتن کدهای تکراری برای هندل کردن خطاها خلاص شوم.

**۲. چگونه می‌توانم پلاگین اختصاصی بنویسم؟**
قمر از یک معماری ماژولار استفاده می‌کند. کافی است یک کلاس بنویسید که اینترفیس `QamarPlugin` را پیاده‌سازی کند. مستندات بخش SDK در وب‌سایت برای این کار عالی است.

**۳. آیا امنیت داده‌ها در قمر تضمین شده است؟**
قمر هیچ دیتایی را در سرورهای خودش ذخیره نمی‌کند (Self-hosted). تمام پردازش‌ها روی ماشین خودتان انجام می‌شود. این برای پروژه‌های حساس که نیاز به محرمانگی دارند، حیاتی است.
