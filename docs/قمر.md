# راهنمای جامع پلتفرم «قمر» (Qamar)

در دنیای پیچیده داده‌ها و محاسبات بین‌رشته‌ای، همیشه جای خالی ابزاری که بتواند پل میان علوم مختلف باشد حس می‌شد. «قمر» دقیقاً همان قطعه گمشده‌ای است که به ما اجازه می‌دهد داده‌های پراکنده را در یک ساختار منسجم و تحلیل‌پذیر گرد هم بیاوریم.

اگر به دنبال راهکاری هستید که فراتر از چارچوب‌های خشکِ نرم‌افزارهای کلاسیک عمل کند، به جای درستی آمده‌اید.

---

## چرا قمر؟ (فلسفه پروژه)
قمر یک ابزار صرفاً فنی نیست؛ بلکه یک اکوسیستم برای پژوهشگران، توسعه‌دهندگان و متخصصانی است که نیاز دارند پارامترهای متغیر را در حوزه‌های مختلف (از فیزیک گرفته تا علوم اجتماعی) مدل‌سازی کنند.

*   **انعطاف‌پذیری بالا:** همخوانی با کتابخانه‌های استاندارد علوم داده.
*   **عملکرد بهینه:** استفاده از موتورهای پردازش سریع برای محاسبات سنگین.
*   **سادگی در یادگیری:** منحنی یادگیری ملایم بدون قربانی کردن قدرت.

---

## شروع کار: نصب و راه‌اندازی

برای شروع، نیازی به پیچیدگی‌های عجیب و غریب نیست. کافی است محیط پایتون خود را آماده داشته باشید.

### نصب از طریق pip
سریع‌ترین راه برای وارد کردن قمر به پروژه خود:

```bash
pip install qamar-lib
```

### نیازمندی‌های سیستم
پیش از شروع، مطمئن شوید که نسخه‌ی پایتون شما بالاتر از ۳.۹ است. برای نصب در محیط‌های مجازی (Venv) همیشه پیشنهاد می‌کنم از دستور زیر استفاده کنید:

```bash
python -m venv venv
source venv/bin/activate  # در لینوکس و مک
venv\Scripts\activate     # در ویندوز
```

## استفاده عملیاتی

فرض کنید می‌خواهید یک مدل اولیه برای تحلیل داده‌های بین‌رشته‌ای خود بسازید. کد زیر یک مثال مینیمال از نحوه پیاده‌سازی یک `QamarNode` است:

```python
from qamar import QamarNode

# تعریف یک گره جدید برای پردازش داده
node = QamarNode(name="DataParser", engine="fast")

# اضافه کردن یک منبع داده
node.connect("https://api.qamar.website/v1/stream")

# اجرای تحلیل
results = node.run(params={"threshold": 0.85})
print(f"خروجی نهایی: {results}")
```

**۳. آیا امکان استفاده از قمر در محیط‌های آفلاین وجود دارد؟**
بله، هسته مرکزی کتابخانه نیازی به اتصال دائم ندارد، مگر برای بروزرسانی‌های خاص پکیج‌ها.
