# راهنمای جامع پلتفرم «قمر» (Qamar)

اگر درگیر پروژه‌های میان‌رشته‌ای (Interdisciplinary) باشید، احتمالاً می‌دانید که بزرگترین کابوس، مدیریت داده‌های پراکنده بین حوزه‌های مختلف است. «قمر» دقیقاً برای حل همین مشکل طراحی شده؛ یک پلتفرم منعطف که اجازه می‌دهد داده‌های علمی، فنی و هنری را بدون درگیری با پیچیدگی‌های دیتابیس‌های سنتی، به هم متصل کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در دنیای واقعی، داده‌ها ایزوله نیستند. یک مهندس سازه ممکن است به داده‌های هواشناسی نیاز داشته باشد و یک طراح گرافیک به خروجی‌های سنسورهای اینترنت اشیاء. قمر به عنوان یک «لایه پیونددهنده» عمل می‌کند تا این شکاف‌های بین‌رشته‌ای را پر کند.

### ویژگی‌های کلیدی
* **Schema-less:** نگران تغییر ساختار داده‌هایتان نباشید.
* **API-First:** هر چیزی که در پنل می‌بینید، یک اندپوینت اختصاصی دارد.
* **سرعت بالا:** بهینه‌سازی شده برای پردازش‌های بلادرنگ.

## نصب و راه‌اندازی

برای شروع کار، ساده‌ترین راه استفاده از CLI اختصاصی قمر است. مطمئن شوید که `Node.js` نسخه ۱۸ به بالا روی سیستم شما نصب است.

```bash
# نصب پکیج به صورت سراسری
npm install -g @qamar/cli

# ایجاد پروژه جدید
qamar init my-project
```

پس از اجرای دستورات بالا، یک فایل `qamar.config.js` در دایرکتوری شما ایجاد می‌شود که می‌توانید تنظیمات اتصال به دیتابیس و کلیدهای API را در آن مدیریت کنید.

## نحوه استفاده (مثال عملی)

فرض کنید می‌خواهید داده‌های یک سنسور محیطی را به یک اپلیکیشن تحلیل آماری وصل کنید. با قمر، این کار فقط چند خط کد نیاز دارد:

```javascript
const Qamar = require('@qamar/sdk');

const client = new Qamar({ apiKey: 'YOUR_API_KEY' });

// ارسال داده‌های میان‌رشته‌ای
async function syncData() {
  const result = await client.push('environmental-data', {
    temperature: 24.5,
    humidity: 40,
    timestamp: Date.now(),
    source: 'sensor-alpha'
  });
  
  console.log('داده با موفقیت ثبت شد:', result.id);
}

syncData();
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ مقیاس (Enterprise) مناسب است؟**
بله، معماری توزیع‌شده قمر اجازه می‌دهد تا میلیون‌ها رکورد را بدون افت کیفیت پردازش کنید.

**۲. آیا داده‌های من در قمر امن هستند؟**
امنیت اولویت ماست. تمامی داده‌ها در حالت استراحت (At-rest) رمزنگاری می‌شوند و دسترسی‌ها از طریق توکن‌های JWT کنترل می‌شود.

**۳. آیا امکان خروجی گرفتن برای نرم‌افزارهای تخصصی مثل MATLAB یا R وجود دارد؟**
قطعاً. شما می‌توانید با استفاده از `Qamar API` به راحتی داده‌ها را به فرمت CSV یا JSON تبدیل کرده و در نرم‌افزارهای تحلیل آماری وارد کنید.
