# قمر (Qamar): راهکار جامع برای مدیریت داده‌های بین‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که نیاز به ترکیب داده‌های علمی، تحلیل‌های آماری و خروجی‌های بصری در یک محیط واحد دارند، احتمالاً می‌دانید که چقدر زود همه چیز به یک آشفتگی غیرقابل مدیریت تبدیل می‌شود. **قمر (Qamar)** دقیقاً برای حل همین معضل متولد شده است؛ ابزاری که مرز بین علوم داده، تحلیل‌های فنی و مستندسازی را از بین می‌برد.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه پروژه)
اکثر ابزارهای موجود یا بیش از حد "برنامه‌نویس‌محور" هستند یا در محیط‌های آکادمیک گم می‌شوند. قمر یک رویکرد **Interdisciplinary** (بین‌رشته‌ای) دارد. هدف این است که شما بتوانید بدون درگیری با پیکربندی‌های پیچیده، داده‌های خام خود را به خروجی‌های معنادار تبدیل کنید.

### ویژگی‌های کلیدی:
*   **یکپارچگی چندزبانه:** پشتیبانی بومی از Python، R و Julia.
*   **خروجی متمرکز:** تبدیل نتایج به مستندات Markdown یا PDF در لحظه.
*   **مدیریت وابستگی‌ها:** بدون نیاز به درگیری با `pip` یا `conda` برای هر پروژه کوچک.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. اگر روی سیستم‌عامل‌های مبتنی بر یونیکس (macOS یا Linux) هستید، با یک دستور ساده کار تمام است:

```bash
# نصب از طریق اسکریپت رسمی
curl -sSL https://qamar.website/install.sh | bash

# بررسی صحت نصب
qamar --version
```

برای ویندوز، پیشنهاد می‌کنم از طریق `WSL2` اقدام کنید تا بهترین عملکرد را در پردازش داده‌ها داشته باشید.

## شروع به کار (Usage)

بعد از نصب، کافی است یک محیط کاری جدید ایجاد کنید. قمر ساختار پروژه شما را به صورت خودکار مدیریت می‌کند:

```bash
# ایجاد پروژه جدید
qamar init my-research-project

# اجرای تحلیل روی یک فایل داده
qamar run analysis.qm
```

### یک مثال ساده از ساختار فایل `.qm`

در قمر، ما از بلوک‌های منطقی استفاده می‌کنیم. به این مثال نگاه کنید که چطور یک دیتاست را بارگذاری و فیلتر می‌کند:

```qamar
# بارگذاری دیتاست
data = load("sensor_data.csv")

# تحلیل بین‌رشته‌ای (فیزیک و آمار)
result = data.filter(threshold > 0.85)
    .calculate_mean()
    .export("results.json")

print(result)
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ با داده‌های حجیم مناسب است؟**
بله، هسته پردازشی قمر به گونه‌ای طراحی شده که داده‌ها را به صورت Stream پردازش می‌کند، نه اینکه همه را در RAM بارگذاری کند.

**۲. آیا می‌توانم خروجی‌ها را به صورت وب‌سایت منتشر کنم؟**
دقیقاً. با دستور `qamar deploy` می‌توانید مستندات و نتایج خود را مستقیماً به عنوان یک وب‌سایت استاتیک در اختیار همکاران‌تان قرار دهید.

**۳. آیا برای استفاده از قمر باید برنامه‌نویس باشم؟**
خیر. با اینکه درک پایه از منطق برنامه‌نویسی کمک می‌کند، اما زبان قمر به شدت به زبان طبیعی نزدیک است و برای محققان غیرفنی نیز طراحی شده است.
