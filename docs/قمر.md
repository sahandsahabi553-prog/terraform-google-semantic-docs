# راهنمای جامع استفاده از «قمر» (Qamar)

اگر در دنیای توسعه سیستم‌های توزیع‌شده و پردازش میان‌رشته‌ای فعالیت می‌کنید، احتمالاً بارها با چالش «اتصال قطعات نامتجانس» به یکدیگر روبرو شده‌اید. **قمر (Qamar)** دقیقاً برای حل همین مشکل طراحی شده است؛ یک فریم‌ورک سبک و در عین حال قدرتمند برای مدیریت جریان‌های کاری (Workflows) در پروژه‌هایی که مرزهای علوم داده، مهندسی نرم‌افزار و زیرساخت را در می‌نوردند.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (نگاهی از دید یک توسعه‌دهنده)

من همیشه از ابزارهای سنگین که نیاز به کانفیگ‌های هزارخطی دارند بیزار بوده‌ام. قمر با این فلسفه ساخته شده که «باید کار کند، سریع و بدون دردسر». این ابزار به شما اجازه می‌دهد منطق تجاری خود را از پیچیدگی‌های پروتکل‌های ارتباطی جدا کنید.

### ویژگی‌های کلیدی:
*   **انعطاف‌پذیری بالا:** پشتیبانی از چندین زبان برنامه‌نویسی.
*   **پایداری:** مکانیزم داخلی برای مدیریت خطاها و بازگشت (Retry Logic).
*   **مقیاس‌پذیری:** طراحی شده برای خوشه‌های کوچک تا محیط‌های ابری بزرگ.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. بسته به محیطی که در آن کار می‌کنید، کافیست دستور زیر را در ترمینال خود اجرا کنید:

```bash
# نصب از طریق اسکریپت خودکار
curl -sSL https://qamar.website/install.sh | bash

# یا اگر با Node.js کار می‌کنید
npm install -g qamar-cli
```

بعد از نصب، با اجرای دستور `qamar --version` مطمئن شوید که همه‌چیز در مسیر درست قرار دارد.

## استفاده از قمر: یک مثال عملی

فرض کنید می‌خواهید داده‌هایی را از یک سنسور سخت‌افزاری بگیرید، آن‌ها را تحلیل کنید و در نهایت در یک پایگاه داده ذخیره کنید. قمر این جریان را به شکل زیر مدیریت می‌کند:

```python
from qamar import QamarFlow

# تعریف جریان کاری
flow = QamarFlow(name="sensor-data-pipeline")

@flow.step
def fetch_data():
    return {"temp": 24.5, "status": "ok"}

@flow.step
def analyze(data):
    if data['temp'] > 20:
        return "High alert"
    return "Normal"

# اجرای جریان
if __name__ == "__main__":
    result = flow.run()
    print(f"Result: {result}")
```

## مقایسه با ابزارهای مشابه

برای اینکه دید بهتری داشته باشید، جدول زیر تفاوت قمر را با سایر ابزارهای متداول نشان می‌دهد:

| ویژگی | قمر (Qamar) | ابزارهای سنتی (مثل Celery) | راه‌حل‌های ابری |
| :--- | :---: | :---: | :---: |
| **سهولت نصب** | بسیار ساده | متوسط | سخت |
| **مصرف منابع** | ناچیز | بالا | بسیار بالا |
| **کاربرد میان‌رشته‌ای** | عالی | ضعیف | متوسط |

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. من حتی برای اسکریپت‌های ساده اتوماسیون شخصی هم از آن استفاده می‌کنم چون مدیریت خطاها را بسیار تمیزتر از `try-except`های تو در تو انجام می‌دهد.

**۲. آیا قمر از پروتکل‌های خاصی پشتیبانی می‌کند؟**
قمر بر پایه REST و gRPC بنا شده است، بنابراین اگر سرویسی دارید که با این‌ها حرف می‌زند، قمر با آن سازگار است.

**۳. چگونه می‌توانم در توسعه آن مشارکت کنم؟**
به مخزن گیت‌هاب ما در وب‌سایت سر بزنید. ما همیشه از Pull Request‌هایی که به بهبود عملکرد یا مستندات کمک کنند، استقبال می‌کنیم.
