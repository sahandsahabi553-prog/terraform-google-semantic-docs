# مستند فنی: «قمر» (Qamar)
### پلتفرمی برای همگرایی دانش‌های میان‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که مرز بین علوم داده، زیرساخت‌های وب و تحلیل‌های پیچیده را هدف قرار می‌دهند، احتمالاً می‌دانید که بزرگ‌ترین چالش، «یکپارچگی» است. **قمر** (Qamar) دقیقاً برای حل همین مشکل ساخته شده است. این ابزار به شما اجازه می‌دهد تا داده‌های میان‌رشته‌ای را بدون درگیری با پیچیدگی‌های غیرضروری، تحلیل و ارائه کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا از قمر استفاده کنیم؟
در دنیای امروز، دیگر نمی‌توان علوم را در سیلوهای مجزا نگه داشت. قمر با رویکردی ماژولار، به شما اجازه می‌دهد خروجی‌های خود را از متغیرهای ریاضی تا مدل‌های رفتاری، در یک بستر واحد مدیریت کنید.

*   **سرعت بالا:** بهینه‌سازی شده برای پردازش‌های سنگین.
*   **انعطاف‌پذیری:** پشتیبانی از چندین زبان برنامه‌نویسی و فرمت داده.
*   **سادگی:** رابط کاربری که به جای گیج کردن شما، روی نتیجه تمرکز دارد.

---

## ۱. نصب و راه‌اندازی

نصب قمر بسیار سرراست است. بسته به محیط کاری خود، یکی از روش‌های زیر را انتخاب کنید.

### نصب از طریق مدیر بسته (Node.js)
اگر در محیط توسعه وب هستید، ساده‌ترین راه استفاده از `npm` است:

```bash
npm install @qamar/core --save
```

### نصب از طریق پایتون
برای کسانی که با علوم داده کار می‌کنند، کتابخانه پایتون قمر در دسترس است:

```bash
pip install qamar-sdk
```

---

## ۲. شروع سریع (Quick Start)

بعد از نصب، برای شروع اولین پروژه، کافی است یک نمونه اولیه ایجاد کنید. در اینجا مثالی از نحوه فراخوانی یک ماژول داده‌محور در قمر آورده شده است:

```javascript
const Qamar = require('@qamar/core');

const project = new Qamar.Project({
    name: 'Research-Alpha',
    mode: 'interdisciplinary'
});

project.init().then(() => {
    console.log("پروژه با موفقیت راه‌اندازی شد!");
});
```

## ۴. پرسش‌های متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. با وجود اینکه برای مقیاس‌های بزرگ طراحی شده، اما سبک بودن هسته آن باعث می‌شود برای پروژه‌های شخصی و تحقیقاتی کوچک نیز عالی عمل کند.

**آیا امکان خروجی گرفتن به فرمت‌های دیگر وجود دارد؟**
بله، قمر به صورت بومی از خروجی‌های JSON، CSV و حتی نمودارهای تعاملی HTML پشتیبانی می‌کند.

**آیا مستندات بیشتری برای توسعه‌دهندگان وجود دارد؟**
حتماً. پیشنهاد می‌کنم بخش `Docs` در [سایت اصلی](https://qamar.website) را چک کنید؛ آنجا مثال‌های پیشرفته‌تری برای کار با APIهای اختصاصی پیدا خواهید کرد.
