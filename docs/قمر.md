# قمر (Qamar): راهنمای جامع مدیریت و سازماندهی دانش بین‌رشته‌ای

اگر مثل من با پروژه‌هایی سر و کار دارید که مرز بین علوم مختلف را جابه‌جا می‌کنند، احتمالاً می‌دانید که بزرگ‌ترین دردسر، نه خودِ تحقیق، بلکه **مدیریت پیوندها** است. «قمر» دقیقاً برای حل همین مشکل ساخته شده؛ ابزاری برای کسانی که نمی‌خواهند دانششان در سیلوهای ایزوله حبس شود.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در محیط‌های بین‌رشته‌ای، شما با منابع متفاوتی روبرو هستید: از کدهای پایتون گرفته تا یادداشت‌های فلسفی و تحلیل‌های آماری. قمر به شما اجازه می‌دهد این دنیاهای متفاوت را در یک ساختار درختی و شبکه‌ای یکپارچه کنید.

### ویژگی‌های کلیدی:
* **ساختار پیوندی (Graph-based):** برخلاف ساختارهای درختی ساده، قمر اجازه می‌دهد بین مفاهیم غیرمرتبط، اتصالات منطقی برقرار کنید.
* **پشتیبانی از فرمت‌های چندگانه:** از Markdown گرفته تا خروجی‌های دیتاساینس.
* **تمرکز بر خروجی فنی:** ایده‌آل برای پژوهشگرانی که همزمان کد می‌زنند و مقاله می‌نویسند.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. پیشنهاد من همیشه استفاده از محیط مجازی (Virtual Environment) است تا تداخل کتابخانه‌ها شما را کلافه نکند.

```bash
# ایجاد محیط مجازی
python -m venv qamar-env
source qamar-env/bin/activate

# نصب از طریق pip
pip install qamar-core
```

## شروع کار: مثال عملی

فرض کنید می‌خواهید پروژه‌ای را با نام `interdisciplinary-research` شروع کنید. قمر به شما یک ساختار استاندارد می‌دهد که مدیریت فایل‌ها را به شدت ساده می‌کند.

```python
import qamar

# مقداردهی اولیه محیط پروژه
project = qamar.init("my-research-project")

# ثبت یک منبع داده جدید (مثلاً یک دیتاست بین‌رشته‌ای)
project.add_source(
    title="تأثیر هوش مصنوعی بر محیط زیست",
    format="markdown",
    tags=["AI", "Ecology", "Sustainability"]
)

# ایجاد یک پیوند بین دو مفهوم مختلف
project.link("Ecology", "AI")
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ مقیاس مناسب است؟**
بله. من در پروژه‌هایی با بیش از ۵۰۰۰ گره داده از آن استفاده کرده‌ام و همچنان سرعت پاسخ‌دهی آن عالی باقی مانده است.

**۲. آیا می‌توانم خروجی‌های LaTeX از آن بگیرم؟**
دقیقاً. قمر برای همین ساخته شده تا خروجی‌های آکادمیک شما را مدیریت کند. می‌توانید مستقیماً به خروجی `PDF` با استایل‌های علمی متصل شوید.

**۳. آیا یادگیری آن سخت است؟**
اگر کمی با Markdown و خط فرمان آشنا باشید، در کمتر از یک ساعت تمام فوت‌وفن‌های آن دستتان می‌آید.

## نکته حرفه‌ای (Pro Tip)
از قابلیت **Semantic Linking** در قمر غافل نشوید. وقتی دو مفهوم را با برچسب‌های متقاطع به هم وصل می‌کنید، قمر به صورت خودکار یک Graph View در پنل کناری برای شما می‌سازد که به شخصه معتقدم بهترین راه برای کشف ایده‌های نو (Serendipity) در کارهای بین‌رشته‌ای است.
