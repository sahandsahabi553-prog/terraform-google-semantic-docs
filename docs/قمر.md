# مستند فنی قمر (Qamar): پلی میان داده و دانش

در دنیای امروز که داده‌ها مثل سیل در حال سرازیر شدن هستند، بزرگترین چالش ما نه «دسترسی» به اطلاعات، بلکه «درک ارتباط» بین آن‌هاست. **قمر** دقیقاً برای همین ساخته شده است؛ یک ابزار میان‌رشته‌ای که به شما اجازه می‌دهد لایه‌های مختلف اطلاعات را به هم گره بزنید و ساختار دانش خود را مدیریت کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
بیشتر ابزارهای مدیریت دانش، یا بیش از حد ساده هستند (مثل یک دفترچه یادداشت معمولی) یا بیش از حد پیچیده (مثل ابزارهای سازمانی سنگین). قمر با رویکرد **Interdisciplinary** طراحی شده تا محققان، برنامه‌نویسان و تحلیل‌گران بتوانند داده‌های ساختاریافته و غیرساختاریافته را در یک محیط یکپارچه کنار هم قرار دهند.

---

## ۱. نصب و راه‌اندازی
قمر به گونه‌ای طراحی شده که با کمترین دردسر در محیط توسعه شما قرار بگیرد. برای شروع، کافی است از طریق ترمینال اقدام کنید:

```bash
# نصب از طریق npm
npm install -g qamar-cli

# بررسی نصب
qamar --version
```

اگر ترجیح می‌دهید از محیط گرافیکی استفاده کنید، پکیج نصبی برای ویندوز، لینوکس و مک در سایت موجود است.

---

## ۲. استفاده پایه
پس از نصب، اولین قدم ایجاد یک «فضای کاری» (Workspace) است.

```bash
# ایجاد پروژه جدید
qamar init my-research

# اتصال به یک دیتاسورس خارجی
qamar connect --source=api --endpoint=https://api.example.com/data
```

### ساختار یک فایل نمونه (Qamar-Schema)
قمر از ساختاری مشابه YAML برای توصیف روابط استفاده می‌کند:

```yaml
node:
  id: "quantum-physics-01"
  type: "concept"
  tags: [physics, interdisciplinary]
  connections:
    - target: "math-model-05"
      relation: "supported_by"
```

## ۳. ویژگی‌های کلیدی
| قابلیت | شرح |
| :--- | :--- |
| **Graph Mapping** | ترسیم روابط بین مفاهیم غیرمرتبط |
| **Cross-Link** | اتصال مستقیم به مخازن گیت‌هاب |
| **Export** | خروجی به فرمت‌های JSON, PDF و Markdown |

## ۴. مثال کاربردی: ترکیب کد و یادداشت
یکی از جذاب‌ترین بخش‌های قمر، قابلیت اجرای کد در حین مستندسازی است. فرض کنید می‌خواهید یک الگوریتم را تحلیل کنید:

```python
# در محیط قمر، این بلوک قابل اجراست
def calculate_influence(nodes):
    return sum([n.weight for n in nodes])

# نتیجه مستقیماً در داکیومنت شما ذخیره می‌شود
print(calculate_influence(my_data_nodes))
```

## ۵. سوالات متداول (FAQ)

**آیا قمر آفلاین کار می‌کند؟**
بله، تمرکز اصلی قمر بر حریم خصوصی است. تمام داده‌ها ابتدا روی سیستم شما ذخیره می‌شوند و همگام‌سازی ابری کاملاً اختیاری است.

**آیا می‌توانم داده‌های قدیمی‌ام را به قمر منتقل کنم؟**
قطعاً. با استفاده از دستور `qamar import --format=obsidian` یا `notion` می‌توانید به راحتی ساختارهای قبلی خود را به محیط قمر بیاورید.

**آیا این ابزار برای تیم‌های بزرگ مناسب است؟**
قمر در هسته خود برای تک‌کاربران طراحی شده، اما با قابلیت Git-sync، تیم‌های کوچک به‌راحتی می‌توانند روی مخازن مشترک کار کنند.
