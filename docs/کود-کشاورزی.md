# کود کشاورزی
کود کشاورزی به مواد آلی یا شیمیایی گفته می‌شود که برای cải thiện کیفیت خاک و افزایش عملکرد گیاهان کشاورزی استفاده می‌شوند. در این مستند، ما به نصب، استفاده و مثال‌های کد مربوط به کود کشاورزی می‌پردازیم.

## نصب
برای استفاده از کود کشاورزی، نیازی به نصب خاصی نیست. فقط کافی است که کود را به خاک اضافه کنید و دستورالعمل‌های مربوط به آن را دنبال کنید.

## استفاده
کود کشاورزی را می‌توان به دو روش استفاده کرد:

*   استفاده مستقیم: کود را مستقیماً به خاک اضافه کنید.
*   استفاده غیرمستقیم: کود را به آب добав کنید و سپس آن را به خاک اضافه کنید.

### مثال‌های کد
```markdown
// مثال 1: استفاده مستقیم از کود
کود_خشک = 10 کیلوگرم
خاک = 100 کیلوگرم
میزان_کود = کود_خشک / خاک
```

```markdown
// مثال 2: استفاده غیرمستقیم از کود
کود_مایع = 5 لیتر
آب = 50 لیتر
میزان_کود = کود_مایع / آب
```
