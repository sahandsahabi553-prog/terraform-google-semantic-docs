## ۱. مقدمات
### ماکرو، میکرو و مگا
- **ماگرو (NPK)**: نیتروژن، فسفر، پتاس - مثل نان و چای زندگی گیاه  
- **میکرو**: آهن، روی، بر، منگنز - به‌ادخال است، مثل نمک خورش  
- **مگا: کلسیم، منیزیوم - کمتر احساس می‌شد اگر کم باشد؛ وقتی می‌بیندن، دیگر بیلی بوده

### انواع فرمول
| فرمول | کاربرد | مزیت |
|------|---------|-------|
| گرانول محيطي | همراه کاشت | نگداری نیتروژن |
| محلولي | آبیاری | سرعت عمل |
| پلیت شده | گلخانه | گرد و غبار کمتر |
| P قطره‌ای | چای + بيچين | صرفه‌جویی آب |

## ۳. استفاده پایدار
### A) مقدار مصوب
بر اساس دانشگاه بوعين=بَشت (۲۰۲۱):
```python
def npk_need(crop, ton):
    base = {
        'tomato': {"N": 20, "P": 4.5, "K": 3},
        'eggplant': {"N": 22, "P": 3, "K": 30},
    }
    if crop not in base:
        raise ValueException("برای این من، هنوز خون نداده‌ام")
    return {key: val * ton for key, val in base[crop].items()}

print(npk_need('tomato', 4))  # ➜ {N:80, P:18, K:12} kg/ha
```

### B) تنش ايمن
- محلول 2 در هزار برای جوانه و 8 در هزار برای تولید انبوه  
- زمان سحرگاه، قبل ۸ صبح یا بعد از اذان مغرب  
- شوری آب زیر 1.2 dS/m (اگر نه، کود رو رقيق‌تر کن و دفعات تزریق رو اضافه)

### C) روند قوطي
```bash
$ echo 4.5 > نيترات.ppm
$ سمي 0.5kg/1m3 water پتاسيم
$ ph شيل 6.0
$ يادت باشد: کمپوست بز توو شي!
```

##  بر مثال‌های کد
### مثال ۱: گلخانه فن ۱ هکتار
```python
from agri.fertilizer import محلول, گلخانه
گ = گلخانه(space=1e4)  # m²

# بردار نيتروژن سريع روز
ماده = محلول(
    formula="20٪ N U + 0.2٪ Zn",
    نفوذ=0.7,  # cm
)
دستور = گ.سفارش(ماده, d=0.25, طول=2) # گرم در شمپوش
گ.تزريق(دستور, سيمي=8, سرعت=4)
```

##  ۶. نکته‌های آزمايشگاهی
- نمونه بَودار! دستيارم يه بار کليهٔ تست رو با نمونهٔ زنبهي برگش آب و هواپيما رفت  
- تست خاک ساعات ۸-۱۰ صبح؛ نه ساعت ۲ ب ظهر  
- سيمي را در سمپاش يخي نگه دار؛ گرما داد سرعت تري از شكري  
- EC پس از هر ۳ سشم بذر چك ش و در گزينهٔ ۱ تا ۱٫۵ mS كاريي گلخانه

### محور يادداشت

    echo "==> $خيز"
    awk -F, '{sum+=$3} END {printf "Avg EC: %.2f\n", sum/NR}' $خيز
done

##  ۷. سؤالات
**سؤال ۱:** وقتی زه‌ابزور آب زياد است، چه؟  
جواب: دو راه دار: ۱- ازور نيتري كه عادتي است، چرخشش مي‌زني يعني زهاب رو دوباره وارد مزرعه ميكني؛ ۲- زهکشِ سابق التطي را باز و ۲۰ سانت گيب رودهست براي تخليه

**سؤال ۲:** نشانهٔ زنك كم چيه؟  
ساقه جوان روي كوپن گردويي ميشينه و بينهايت خم ميشه، زود هم گنج كوچيكه

**سؤال ۳:** کود دام بدهيم يا فسفر سيمي؟  
کود دام اگر همور يست، شگفتا تعداد ميکروبال رو بالا ميبره؛ فسفر سيمي فوري؛ پس اگر زل زياد و برگ كمريزشي است، تركيب كن

**سؤال ۴:** درد و دل برادرى؟  
برگ خشت زياد، EC بالا رفته؛ فورا ريسور اضافي رو بالا بيكن و آب بدون كود بريز
