> این مستند برای توسعه‌دهندگانی طراحی شده که قصد دارند سیستم توصیه‌ی کود را با API ما یکپارچه کنند. اگر تازه‌کار هستید، پیشنهاد می‌کنم ابتدا بخش «مفاهیم پایه» را با دقت بخوانید؛ چون یک بار در فصل بهار، به‌خاطر اشتباه در همین پارامترها، ۳۰۰ هکتار گندم سوخت و حاصل خوبی نداد!

## نصب و راه‌اندازی
1. مخزن را کلون کنید یا فایل `wheel` را از [PyPI](https://pypi.org/project/kalatak-fertilizer/) نصب کنید:
   ```bash
   pip install kalatak-fertilizer==2.3.1
   ```

2. فایل `.env` بسازید و کلید خود را داخلش قرار دهید:
   ```env
   KALATAK_API_KEY=kt_live_7sBG64x...
   ```

3. تست سریع:
   ```python
   from kalatak_fertilizer import recommend
   print(recommend(crop='gandom', area=10, growth_stage='tillering'))
   ```
   اگر خروجی «200 OK» دیدید، همه چیز مرتبه!

## دریافت کلید API
به [پنل توسعه‌دهندگان کلاتک](https://kalatakco.com/dashboard) بروید و در بخش «کود کشاورزی» یک کلید زنده بسازید. کلید آزمایشی رایگان است ولی محدودیت ۱۰۰ درخواست در روز دارد. برای کشاورزان خوزستان پیشنهاد می‌کنم همین طرح رایگان بگیرید، چون معمولاً نیاز روزانه‌تان را پوشش می‌دهد.

## پارامترهای ورودی
| پارامتر         | نوع    | واحد | محدوده‌ی مجاز | توضیحات |
|----------------|--------|------|---------------|---------|
| crop           | string | -    | ['gandom', 'jo', 'ذرت', 'کلزا', 'چغندر'] | انگلیسی یا فارسی |
| cultivar       | string | -    | اختیاری | مثلاً «pishgam» برای گندم |
| area           | float  | هکتار | 0.1..5000 | مساحت قطعه |
| growth_stage   | string | -    | ['tillering', 'stem_extension', 'flowering', 'grain_filling'] | مرحله‌ی رشد |
| soil_test.n    | float  | mg/kg | 0..200 | نیتروژن قابل جذب |
| soil_test.p    | float  | mg/kg | 0..70 | فسفر قابل جذب |
| soil_test.k    | float  | mg/kg | 0..600 | پتاسیم تبادلی |
| soil_test.ph   | float  | -    | 4.5..9.0 | pH خاک |
| soil_test.ec   | float  | dS/m | 0..8 | شوری |
| irrigation_type| string | -    | ['drip', 'sprinkler', 'basin', 'rainfed'] | نوع آبیاری |
| region         | string | -    | ISO-3166-2 | مثلاً «kermanshah» |

## کد نمونه
### پایتون
```python
from kalatak_fertilizer import FertilizerClient
import os

client = FertilizerClient(api_key=os.getenv("KALATAK_API_KEY"))

req = {
    "crop": "gandom",
    "area": 30,
    "growth_stage": "flowering",
    "soil_test": {"n": 10, "p": 5, "k": 180, "ph": 7.9, "ec": 2.1},
    "irrigation_type": "sprinkler",
    "region": "isfahan"
}

resp = client.recommend(req)
for rec in resp["data"]["recommendations"]:
    print(f"{rec['fertilizer']}: {rec['rate_kg_per_ha']} kg/ha")
```

### cURL
```bash
curl -X POST https://api.kalatakco.com/v1/fertilizer/recommend \
  -H "Authorization: Bearer kt_live_7sBG64x..." \
  -H "Content-Type: application/json" \
  -d '{
        "crop": "کلزا",
        "area": 5,
        "growth_stage": "stem_extension",
        "soil_test": {"n": 20, "p": 9, "k": 250, "ph": 7.2, "ec": 1.1}
      }'
```

## جدول compatiblity انواع خاک
| نوع خاک | pH مناسب | EC مجاز (dS/m) | کود پیشنهادی N | ملاحظات |
|---------|----------|----------------|------------------|----------|
| لومی    | 6.5-7.5  | <2             | اوره             | بهترین راندمان |
| شنی     | 6.0-7.0  | <1.5           | نیترات آمونیوم | زهکشی بالاست، نیتروژن سریع‌الاثر لازم دارد |
| رسی     | 7.0-8.0  | <3             | اوره + سولفات آمونیوم | احتمال ثابت ماندن کود بالاست؛ نصف در زمان کاشت + نصف در صورت غرقاب |
| آهکی    | 7.5-8.5  | <2.5           | سولفات آمونیوم | pH بالا باعث ثابت ماندن فسفر می‌شود؛ از کودهای حاوی اسید فسفریک استفاده شود |

## سوالات متداول
**س ۱) آیا می‌توانم از واحد اینترنشنال (پوند در هر آکر) استفاده کنم؟**  
خیر، فعلاً فقط kg/ha پشتیبانی می‌شود. اگر واقعاً لازم دارید، کتابخانه‌ی `agunit` را نصب کنید؛ تبدیلش می‌کند. ولی به‌تجربه گفته باشم، تبدیل دستی را با ضریب ۸۹/۰ در ذهن داشته باشید.

**س ۲) مرحله‌ی رشد رو اشتباه فرستادم؛ قبول می‌کنید؟**  
API idempotent است؛ فقط کافی‌ست دوباره با stage درست صدا بزنید. هیچ هزینه‌ی اضافی نمی‌خورید.

**س ۳) چرا توصیه‌ی منفی (صفر کود) می‌دهد؟**  
وقتی ph بالای ۸ یا EC بالای ۴ است، سیستم احتیاط می‌کند و نیتروژن را صفر پیشنهاد می‌دهد تا گیاه دچار شوک نشود. می‌توانید با تیک `force_positive` در query رفتارش را تغییر دهید، ولی مسئولیتش با خودتان!

**س ۴) آیا از کود زیستی هم پشتیبانی می‌شود؟**  
در نسخه‌ی ۲.۴ (اواخر تابستان) قابلیت «ریزیوبیوم» اضافه می‌شود. الان فقط کودهای شیمیایی داریم.
