## ⚙️ مشخصات فنی ظروف

هر ظرف تولید شده در کارگاه ما، یک «سند» منحصر‌به‌فرد است. در اینجا جدولی از ویژگی‌های فنی محصولات آورده شده است:

| ویژگی | توضیحات |
| :--- | :--- |
| **متریال** | مواد اولیه طبیعی (سفال/سرامیک/چوب درجه یک) |
| **تکنیک ساخت** | کاملاً دست‌ساز (Handcrafted) |
| **پایداری** | مقاوم در برابر حرارت استاندارد آشپزخانه |
| **شخصی‌سازی** | قابلیت سفارش طرح‌های اختصاصی |
