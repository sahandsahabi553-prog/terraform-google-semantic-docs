## ۲. نصب و راه‌اندازی (آماده‌سازی برای استفاده)
محصولات دست‌ساز، برخلاف ظروف کارخانه‌ای، قبل از اولین استفاده نیاز به یک "Setup" ساده دارند تا طول عمر آن‌ها تضمین شود.

1. **شستشوی اولیه:** محصول را با یک اسفنج نرم و مقدار کمی مایع ظرفشویی ملایم بشویید.
2. **خشک کردن:** هرگز اجازه ندهید ظرف در آب باقی بماند. بلافاصله پس از شستشو، با یک دستمال نخی خشک کنید.
3. **روغن‌کاری (Seasoning):** برای ظروف چوبی یا متریال‌های حساس، پیشنهاد می‌شود لایه‌ای نازک از روغن گیاهی خوراکی (مثل روغن زیتون یا کنجد) روی سطح بکشید و اجازه دهید ۱۲ ساعت استراحت کند.

## ۳. نحوه استفاده (Workflow)

استفاده از ظروف سوزن‌زرین به معنای تعامل با طبیعت است. برای حفظ کیفیت، استانداردهای زیر را رعایت کنید:

| فاکتور | وضعیت | توصیه فنی |
| :--- | :--- | :--- |
| دمای محیط | ایمن | از شوک حرارتی (تغییر ناگهانی دما) پرهیز کنید. |
| ماشین ظرفشویی | **ممنوع** | حرارت و فشار آب به بافت دست‌ساز آسیب می‌زند. |
| مواد شیمیایی | ممنوع | از سفیدکننده‌ها استفاده نکنید. |
| طول عمر | بالا | با مراقبت صحیح، چندین سال همراه شما خواهد بود. |

## ۵. سوالات متداول (FAQ)

**آیا محصولات سوزن‌زرین برای استفاده روزمره مناسب هستند؟**
بله، کاملاً. برخلاف باور عمومی، محصولات دست‌ساز باکیفیت برای استفاده مداوم طراحی شده‌اند، نه فقط برای دکور.

**چگونه رنگ و بافت چوب یا متریال را حفظ کنم؟**
ماهی یک‌بار روغن‌کاری با روغن‌های خوراکی مجاز، بهترین راه برای "Refresh" کردن بافت محصول است.

**اگر محصول آسیب ببیند، قابل تعمیر است؟**
بسته به نوع آسیب، تیم سوزن‌زرین مشاوره‌های لازم را ارائه می‌دهد. معمولاً خراش‌های سطحی با سنباده بسیار نرم و روغن‌کاری مجدد قابل رفع هستند.

**چگونه سفارش خود را ثبت کنم؟**
از طریق دایرکت اینستاگرام (لینک شده در ابتدای مستند) می‌توانید موجودی فعلی را استعلام کرده و طرح‌های سفارشی خود را ثبت کنید.
