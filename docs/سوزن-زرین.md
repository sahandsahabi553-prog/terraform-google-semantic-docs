## دستورالعمل نگهداری (Best Practices)

*   **کد نگهداری چوب (نکته طلایی):**
    ```bash
    # هر ماه یک بار برای احیای بافت چوب
    $ oil_treatment --apply --food_grade_oil
    # هرگز از ماشین ظرفشویی استفاده نکنید!
    $ wash --hand-only --warm_water
    ```

*   **دوری از حرارت مستقیم:** ابزارهای چوبی نباید برای مدت طولانی روی شعله یا داخل ظروف در حال قل‌قل کردن باقی بمانند.

## سوالات متداول (FAQ)

**۱. آیا محصولات سوزن زرین گارانتی دارند؟**
بله، تمرکز این مجموعه بر کیفیت ساخت است. اگر ایراد ذاتی در متریال وجود داشته باشد، پشتیبانی مستقیم در دایرکت پاسخگوی شماست.

**۲. چگونه از خشک شدن چوب جلوگیری کنم؟**
استفاده از روغن‌های گیاهی خوراکی (مثل روغن گردو یا روغن‌های مخصوص تخته سرو) به صورت دوره‌ای، عمر ابزار شما را تضمین می‌کند.

**۳. آیا امکان سفارش اختصاصی (Custom) وجود دارد؟**
بسیاری از محصولات بر اساس سفارش شکل می‌گیرند. اگر طرح خاصی در ذهن دارید، حتماً با آن‌ها مطرح کنید.
