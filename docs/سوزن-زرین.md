# راهنمای فنی و مستندات «سوزن زرین» (Golden Needle)
## هنر ظرافت در صنایع‌دستی آشپزخانه

«سوزن زرین» فراتر از یک نام تجاری، نمادی از دقت در طراحی و پیوند میان هنر سنتی و کاربرد مدرن در محیط آشپزخانه است. این مستند به بررسی نحوه تعامل با این محصولات و استانداردهای نگهداری آن‌ها می‌پردازد.

---

### ۱. مقدمه: فلسفه طراحی
در دنیای تولیدات انبوه، ما در «سوزن زرین» به دنبال بازگشت به ریشه هستیم. هر قطعه، حاصل ساعت‌ها کار دست است که نه تنها برای زیبایی، بلکه برای «عملکرد بهینه» طراحی شده است.

*   **اصالت:** استفاده از متریال باکیفیت و پایدار.
*   **دوام:** طراحی شده برای استفاده روزمره، نه فقط دکوراسیون.
*   **ارگونومی:** توجه به راحتی کاربر در هنگام آشپزی یا سرو.

---

### ۲. نصب و راه‌اندازی (آماده‌سازی اولیه)
برخلاف محصولات صنعتی، ظروف دست‌ساز نیازمند یک «مرحله تثبیت» هستند تا طول عمر آن‌ها تضمین شود.

1.  **شستشوی اولیه:** محصول را با آب ولرم و شوینده بسیار ملایم بشویید. از اسکاچ‌های زبر خودداری کنید.
2.  **تثبیت با روغن (برای محصولات چوبی):** اگر محصول شما از چوب ساخته شده، پیشنهاد می‌کنم برای بار اول آن را با روغن گیاهی خوراکی (مانند روغن زیتون یا کنجد) چرب کنید و بگذارید ۲۴ ساعت بماند.
3.  **خشک کردن:** همیشه پس از شستشو، سطح محصول را با یک پارچه نخی نرم کاملاً خشک کنید.

### ۴. مثال‌های کاربردی (نحوه استفاده)

```python
    if item.is_dirty():
        wash_gently(item)
    
    if item.material == "wood":

    avoid_dishwasher(item)
    return "Longevity Guaranteed"
```
