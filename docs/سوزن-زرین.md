# مستند فنی: سوزن زرین (Golden Needle)
**هنرِ دست، دقتِ صنعت**

«سوزن زرین» فراتر از یک نام، مجموعه‌ای است از ظروف آشپزخانه دست‌ساز که با وسواس و عشق طراحی شده‌اند. ما در اینجا معتقدیم که هر ظرف، روایتی از هنرِ اصیل است که باید با استانداردهای فنی دقیق، به خانه‌های شما راه پیدا کند.

## ۱. فلسفه طراحی
هر قطعه از محصولات ما، حاصل ترکیب تکنیک‌های سنتی و ارگونومی مدرن است. ما در «سوزن زرین» از متریال‌های پایدار استفاده می‌کنیم تا علاوه بر زیبایی، دوام و کارایی بی‌نظیری را در محیط آشپزخانه ارائه دهیم.

## ۲. راهنمای نصب و راه‌اندازی (نگهداری اولیه)
محصولات دست‌ساز نیاز به «آب‌بندی» و مراقبت اولیه دارند تا طول عمر آن‌ها تضمین شود.

1. **شستشوی اولیه:** محصول را با آب ولرم و شوینده ملایم بشویید.
2. **خشک کردن:** بلافاصله پس از شستشو، با یک دستمال نخی نرم کاملاً خشک کنید.
3. **روغن‌کاری (برای ظروف چوبی):**
   - از روغن‌های خوراکی (ترجیحاً روغن گردو یا روغن معدنی گرید غذایی) استفاده کنید.
   - لایه‌ای نازک روی سطح بزنید و اجازه دهید ۲۴ ساعت جذب شود.

## ۴. مثال عملی: استفاده در چیدمان (Workflow)

برای داشتن یک میز پذیرایی حرفه‌ای با ظروف سوزن زرین، می‌توانید طبق این الگوریتم عمل کنید:

```javascript
// الگوریتم چیدمان میز پذیرایی
const tableSetting = {
  centerpiece: "کاسه سرامیکی سوزن زرین",
  accessories: ["قاشق چوبی دست‌ساز", "رانر کتان"],
  maintenance: "پس از اتمام، با دستمال نمناک پاک شود"
};

function setupTable(items) {
  items.forEach(item => {
    console.log(`در حال قرار دادن ${item} در جایگاه اصلی...`);
  });
}

setupTable(tableSetting.accessories);
```
