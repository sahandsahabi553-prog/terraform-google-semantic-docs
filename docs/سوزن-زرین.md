# مستند فنی: سوزن زرین (Sozane Zarin)
### هنرِ تلفیق سنت و مدرنیته در ابزارهای آشپزخانه

## ۱. چرا سوزن زرین؟
سوزن زرین مجموعه‌ای از ظروف دست‌ساز آشپزخانه است که تمرکز اصلی آن بر متریال‌های طبیعی و ارگونومیِ کاربردی است. برخلاف محصولات کارخانه‌ای، هر قطعه توسط دستان هنرمند تراشیده و پرداخت می‌شود.

*   **اصالت:** هر محصول شناسنامه بصری منحصر به فرد خود را دارد.
*   **پایداری:** استفاده از متریال‌های تجدیدپذیر.
*   **ارگونومی:** طراحی شده بر اساس فرم دست انسان برای استفاده‌های طولانی‌مدت.

## ۲. نصب و راه‌اندازی (آماده‌سازی اولیه)
برخلاف ابزارهای دیجیتال، این «سخت‌افزارها» نیاز به نصب ندارند، اما برای طول عمر حداکثری، یک پروسه «کانفیگ اولیه» یا همان روغن‌کاری ضروری است.

### مراحل آماده‌سازی:
1.  **شستشوی ملایم:** ظرف را با آب ولرم و مقدار بسیار کمی مایع ظرفشویی بشویید.
2.  **خشک کردن:** حتماً با یک پارچه نخی خشک کنید. هرگز اجازه ندهید در مجاورت هوا به صورت خیس باقی بماند.
3.  **روغن‌کاری (Deployment):** با استفاده از روغن‌های خوراکی (مثل روغن گردو یا زیتون تصفیه شده)، سطح چوب را ماساژ دهید تا اشباع شود.

```bash
# پروسه نگهداری دوره‌ای (شبه‌کد)
function maintain_sozane_zarin(product) {
    if (product.is_dry()) {
        apply_food_grade_oil(product);
        wait_for_absorption(24_hours);
        polish_with_cloth(product);
    }
}
```

## ۴. پرسش‌های متداول (FAQ)

**س: آیا این ظروف در ماشین ظرفشویی قابل شستشو هستند؟**
پاسخ: **اکیداً خیر.** حرارت بالا و فشار آب ماشین ظرفشویی باعث «تنش حرارتی» در بافت چوب شده و منجر به ترک خوردن آن می‌شود. همیشه با دست بشویید.

**س: چرا رنگ ظرف بعد از مدتی تغییر می‌کند؟**
پاسخ: این یک رفتار طبیعی (Natural Behavior) است. واکنش چوب به روغن‌های موجود در غذا و نور محیط، باعث ایجاد یک پتینه (Patina) زیبا روی سطح کار می‌شود که ارزش آن را بالاتر می‌برد.

**س: چگونه می‌توانم سفارش دهم؟**
