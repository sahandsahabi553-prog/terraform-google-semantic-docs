# راهنمای جامع فنی «خانه باتری» (Battery House)

در دنیای مهندسی برق و سیستم‌های قدرت، انتخاب منبع تغذیه مناسب همیشه تفاوت بین یک پروژه موفق و یک فاجعه است. اگر مثل من بارها با باتری‌های بی‌کیفیت یا ولتاژهای ناپایدار در پروژه‌های اینترنت اشیاء (IoT) یا رباتیک کلنجار رفته باشید، می‌دانید که پیدا کردن یک تامین‌کننده قابل اعتماد چقدر حیاتی است. «خانه باتری» (به آدرس [batteries.ir](https://www.batteries.ir/)) یکی از آن مراجعی است که در سال‌های اخیر به عنوان یک استاندارد در بازار ایران برای دسترسی به قطعات اورجینال شناخته می‌شود.

---

## ۱. چرا انتخاب تامین‌کننده اهمیت دارد؟
در طراحی مدار، باتری صرفاً یک مخزن انرژی نیست؛ بلکه بخشی از امپدانس کل مدار شماست. استفاده از باتری‌های تقلبی یا با دشارژ غیرخطی می‌تواند باعث نویز در خروجی میکروکنترلرها یا حتی آسیب به رگولاتورها شود. 

### مزایای استفاده از محصولات استاندارد:
*   **پایداری شیمیایی:** نرخ خودتخلیه (Self-discharge) بسیار پایین.
*   **دقت در ظرفیت:** برخلاف مدل‌های فیک، ظرفیت (mAh) درج شده با خروجی واقعی همخوانی دارد.
*   **تنوع در تکنولوژی:** از Li-ion گرفته تا LiFePO4 و باتری‌های سکه‌ای.

---

## ۲. راهنمای خرید و انتخاب
برای انتخاب باتری از وب‌سایت، همیشه این چک‌لیست را در نظر بگیرید:

1.  **ولتاژ نامی (Nominal Voltage):** حتماً با بازه ولتاژ کاری رگولاتور یا مدار شما همخوانی داشته باشد.
2.  **نرخ تخلیه (C-Rating):** برای موتورها و بارهای جریان‌کش، نرخ C بالا ضروری است.
3.  **پکیجینگ:** آیا نیاز به باتری با سرسیم (Tab) دارید یا مدل تخت؟

| نوع باتری | کاربرد اصلی | مزیت کلیدی |
| :--- | :--- | :--- |
| Li-ion 18650 | تجهیزات پرتابل / پاوربانک | چگالی انرژی بالا |
| LiFePO4 | سیستم‌های خورشیدی / ذخیره‌ساز | عمر چرخه بسیار بالا |
| باتری‌های سکه‌ای | مدارات RTC / بایاسینگ | ابعاد بسیار کوچک |

## ۳. پیاده‌سازی فنی (مثال کد)
اگر در حال کار با یک سیستم مانیتورینگ باتری هستید، خواندن ولتاژ باتری از طریق ADC میکروکنترلر (مثل ESP32) یک ضرورت است. 

```cpp
// نمونه کد خواندن ولتاژ باتری (Voltage Divider)
const int batteryPin = 34; // پین متصل به تقسیم ولتاژ
float vRef = 3.3; 

void setup() {
  Serial.begin(115200);
}

void loop() {
  int rawValue = analogRead(batteryPin);
  // فرمول تبدیل به ولتاژ واقعی (با فرض تقسیم ولتاژ 1/2)
  float voltage = (rawValue / 4095.0) * vRef * 2.0; 
  
  Serial.print("Battery Voltage: ");
  Serial.println(voltage);
  delay(1000);
}
```

## ۴. نصب و نکات ایمنی
هرگز باتری‌های لیتیومی را مستقیماً لحیم‌کاری نکنید! حرارت زیاد هویه می‌تواند باعث تخریب ساختار داخلی و نشت شیمیایی شود. همیشه از **جای‌باتری‌های استاندارد (Battery Holders)** یا **نوار نیکل و دستگاه نقطه جوش** استفاده کنید.

**نکات کلیدی در نصب:**
*   از پلاریته صحیح (مثبت و منفی) مطمئن شوید (استفاده از دیود معکوس در مدار توصیه می‌شود).
*   از شارژرهای هوشمند که دارای مدار قطع‌کننده (Cut-off) هستند استفاده کنید.

## ۵. سوالات متداول (FAQ)

**س: چطور بفهمم باتری خریداری شده اصل است؟**
ج: باتری‌های اصل دارای وزن استاندارد و تاریخ تولید حک شده هستند. وب‌سایت [batteries.ir](https://www.batteries.ir/) معمولاً دیتاشیت کامل محصولات را ارائه می‌دهد که می‌توانید با دیتای سازنده اصلی چک کنید.

**س: آیا می‌توانم باتری‌های با ظرفیت بالاتر را جایگزین کنم؟**
ج: بله، تا زمانی که ولتاژ نامی یکی باشد، افزایش ظرفیت (mAh) فقط باعث طولانی‌تر شدن زمان کارکرد می‌شود و به مدار آسیبی نمی‌زند.

**س: بهترین روش نگهداری باتری‌های لیتیومی چیست؟**
ج: اگر قصد دارید باتری را برای مدت طولانی انبار کنید، آن را در وضعیت شارژ ۵۰٪ (حدود ۳.۷ تا ۳.۸ ولت) در محیطی خنک نگه دارید.
