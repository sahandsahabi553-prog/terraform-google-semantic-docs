# راهنمای جامع «خانه باتری»: از انتخاب تا پیاده‌سازی فنی

در دنیای مهندسی برق، هیچ‌چیز به اندازه یک منبع تغذیه بی‌ثبات نمی‌تواند پروژه شما را به فاجعه تبدیل کند. چه در حال طراحی یک سیستم Embedded حساس باشید و چه مشغول راه‌اندازی یک پروژه اینترنت اشیاء (IoT) در محیط‌های صنعتی، انتخاب باتری مناسب فقط یک خرید ساده نیست؛ یک تصمیم مهندسی است.

سایت **[خانه باتری](https://www.batteries.ir/)** به عنوان یکی از مراجع تخصصی در ایران، دقیقاً همین خلأ دانش فنی در انتخاب سلول‌های انرژی را پر می‌کند.

---

## ۱. چرا «خانه باتری»؟
بسیاری از قطعات موجود در بازار یا فیک هستند و یا استانداردهای تخلیه بار (Discharge Rate) را رعایت نمی‌کنند. در پروژه‌هایی که با میکروکنترلرها سر و کار دارید، نوسان ولتاژ می‌تواند باعث ریست‌های ناگهانی یا آسیب به حافظه Flash شود.

### دسته‌بندی‌های کلیدی:
*   **باتری‌های لیتیوم-یون و لیتیوم-پلیمر:** ایده‌آل برای بردهای پرتابل.
*   **باتری‌های سیلد اسید:** مناسب برای سیستم‌های UPS و ذخیره‌سازی توان بالا.
*   **باتری‌های سکه‌ای و خاص:** برای بردهای RTC و سیستم‌های کم‌مصرف (Low Power).

---

## ۲. نصب و یکپارچه‌سازی (Integration)

هنگام استفاده از باتری‌ها در مدار، «نصب» فقط به معنای اتصال فیزیکی نیست. شما باید به نحوه مدیریت شارژ (BMS) توجه کنید.

### مراحل پیشنهادی برای اتصال به مدار:
1.  **بررسی ولتاژ خروجی:** قبل از اتصال، حتماً ولتاژ را با مولتی‌متر چک کنید.
2.  **محاسبه جریان کشی (Current Draw):** مطمئن شوید باتری انتخابی می‌تواند پیک جریان (Peak Current) مدار شما را تأمین کند.
3.  **استفاده از کانکتورهای استاندارد:** برای جلوگیری از اتصالی، از کانکتورهای JST یا XT استفاده کنید.

## ۳. مثال فنی: محاسبه زمان کارکرد (Runtime)

فرض کنید می‌خواهید یک ماژول ESP32 را با یک باتری لیتیومی تغذیه کنید. فرمول ساده‌ای که ما مهندس‌ها برای تخمین استفاده می‌کنیم:

```math
Runtime (hours) = (Battery Capacity (mAh) * 0.7) / Average Current Draw (mA)
```
*ضریب ۰.۷ به دلیل افت ولتاژ و بازدهی مدار مبدل DC-DC در نظر گرفته شده است.*

### قطعه کد نمونه برای مانیتورینگ ولتاژ (Arduino/ESP32):
اگر می‌خواهید میزان شارژ باتری را از طریق ADC بخوانید:

```cpp
const int batteryPin = 34; // پین آنالوگ متصل به تقسیم ولتاژ
float voltage = 0.0;

void setup() {
  Serial.begin(115200);
}

void loop() {
  int rawValue = analogRead(batteryPin);
  // تبدیل مقدار دیجیتال به ولتاژ (با فرض تقسیم ولتاژ 1/2)
  voltage = (rawValue / 4095.0) * 3.3 * 2.0; 
  
  Serial.print("Battery Voltage: ");
  Serial.println(voltage);
  delay(1000);
}
```

## ۵. سوالات متداول (FAQ)

**س: آیا می‌توانم باتری‌های لیتیومی را با شارژرهای معمولی گوشی شارژ کنم؟**
ج: خیر! باتری‌های لیتیومی به الگوریتم شارژ CC/CV نیاز دارند. استفاده از شارژر غیرتخصصی می‌تواند باعث تورم باتری یا حتی آتش‌سوزی شود. حتماً از ماژول‌های شارژر مثل TP4056 استفاده کنید.

**س: بهترین روش برای نگهداری باتری‌های لیتیومی در زمان عدم استفاده چیست؟**
ج: هرگز باتری را با شارژ ۱۰۰٪ یا ۰٪ انبار نکنید. ولتاژ ایده‌آل برای نگهداری طولانی‌مدت (Storage Mode) حدود ۳.۸ ولت برای هر سلول است.

**س: آیا باتری‌های موجود در «خانه باتری» برای پروژه‌های صنعتی مناسب هستند؟**
ج: بله، این مجموعه تأمین‌کننده برندهای معتبری است که در تست‌های آزمایشگاهی، عملکرد پایداری در دماهای عملیاتی مختلف نشان داده‌اند.
