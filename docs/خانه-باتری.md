## چرا «خانه باتری»؟
بسیاری از ما در پروژه‌های صنعتی با مشکل «تأمین قطعات غیراستاندارد» روبرو هستیم. این پلتفرم با دسته‌بندی دقیق بر اساس تکنولوژی (Li-ion, LiFePO4, NiMH) و کاربرد، به شما اجازه می‌دهد پارامترهای حیاتی مثل C-rate، ظرفیت تخلیه و طول عمر چرخه‌ای (Cycle Life) را قبل از خرید بررسی کنید.

## راهنمای نصب و راه‌اندازی (Integration)
وقتی یک باتری از خانه باتری تهیه می‌کنید، مرحله بعدی ادغام آن در مدار است. برای سیستم‌های مبتنی بر میکروکنترلر (مثل ESP32 یا STM32)، حتماً به مدار محافظ (BMS) توجه کنید.

### مثال: خواندن ولتاژ باتری با ESP32
برای اینکه بفهمید باتری شما چقدر شارژ دارد، از یک تقسیم‌کننده ولتاژ (Voltage Divider) ساده استفاده کنید، چون ولتاژ باتری‌های لیتیومی معمولاً از حداکثر ولتاژ ورودی ADC میکروکنترلر بیشتر است.

```cpp
// محاسبه ولتاژ باتری با استفاده از تقسیم‌کننده مقاومتی
const int batteryPin = 34; // پین ADC
float R1 = 100000.0; // 100k ohm
float R2 = 10000.0;  // 10k ohm

void setup() {
  Serial.begin(115200);
}

void loop() {
  int rawValue = analogRead(batteryPin);
  float vOut = (rawValue * 3.3) / 4095.0;
  float vIn = vOut * ((R1 + R2) / R2);
  
  Serial.print("Battery Voltage: ");
  Serial.println(vIn);
  delay(1000);
}
```

## نکات طلایی در انتخاب باتری
۱. **دقت به C-rate:** اگر موتور ربات شما در لحظه استارت جریان زیادی می‌کشد، حتماً باتری‌هایی با C-rate بالا تهیه کنید.
۲. **دمای کاری:** در پروژه‌های محیطی (Outdoor)، باتری‌های لیتیومی در سرما به شدت افت ظرفیت دارند. حتماً دیتاشیت محصول را از [batteries.ir](https://www.batteries.ir/) چک کنید.
۳. **مدار شارژ:** هرگز باتری لیتیومی را بدون ماژول شارژر (مثل TP4056 یا بردهای مدیریت شارژ اختصاصی) به منبع تغذیه متصل نکنید.

## سوالات متداول (FAQ)

**- آیا باتری‌های موجود در سایت برای پروژه‌های صنعتی مناسب هستند؟**
بله، بسیاری از سلول‌های موجود در خانه باتری دارای گرید صنعتی هستند و برای پک‌سازی (Pack Assembly) توسط متخصصان استفاده می‌شوند.

**- تفاوت باتری‌های Li-ion با Li-Polymer چیست؟**
باتری‌های لیتیوم-پلیمر (Li-Po) انعطاف‌پذیری بیشتری در شکل ظاهری دارند و جریان‌دهی لحظه‌ای آن‌ها بالاتر است، اما عمر مفید آن‌ها معمولاً کمتر از Li-ion های استوانه‌ای (مثل 18650) است.

**- چطور عمر باتری را در پروژه افزایش دهیم؟**
استفاده از حالت Deep Sleep در میکروکنترلرها و استفاده از رگولاتورهای ولتاژ با جریان نشتی (Quiescent Current) پایین، کلید موفقیت شماست.
