# راهنمای جامع «خانه باتری»: از انتخاب تا پیاده‌سازی فنی

در دنیای مهندسی برق و سیستم‌های مبتنی بر انرژی، دسترسی به قطعات باکیفیت و استاندارد نه تنها یک مزیت، بلکه یک ضرورت برای جلوگیری از شکست پروژه است. وب‌سایت [خانه باتری](https://www.batteries.ir/) به عنوان یکی از مراجع تخصصی در ایران، بستری را فراهم کرده که در آن از باتری‌های لیتیوم-یون گرفته تا سلول‌های خورشیدی و تجهیزات جانبی، با مشخصات فنی دقیق ارائه می‌شوند.

در این مستند، نگاهی فنی به نحوه تعامل با این زیرساخت و استفاده از قطعات در پروژه‌های سخت‌افزاری می‌اندازیم.

## ۱. چرا انتخاب قطعه درست حیاتی است؟

بسیاری از دوستان در پروژه‌های اینترنت اشیاء (IoT) یا رباتیک، به دلیل استفاده از باتری‌های غیر استاندارد با افت ولتاژ ناگهانی یا سوختن مدارات در زمان پیک جریان مواجه می‌شوند. در خانه باتری، دسته‌بندی‌ها به گونه‌ای است که می‌توانید بر اساس **ظرفیت (Capacity)**، **ولتاژ (Voltage)** و **نرخ تخلیه (Discharge Rate)** فیلتر کنید.

### جداول مشخصات کلیدی برای انتخاب
پیش از خرید، همیشه این پارامترها را با دیتاسیت (Datasheet) ماژول خود چک کنید:

| پارامتر | واحد | اهمیت فنی |
| :--- | :--- | :--- |
| Nominal Voltage | V | انطباق با مدار رگولاتور |
| Capacity | mAh | محاسبه طول عمر پروژه |
| Max Discharge | A | جلوگیری از داغ شدن سلول |
| Chemistry | - | پایداری شیمیایی (Li-ion vs LiFePO4) |

## ۲. نصب و پیاده‌سازی (Integration)

زمانی که باتری یا قطعه مورد نظر را از خانه باتری تهیه کردید، مرحله نصب نیازمند رعایت استانداردهای ایمنی است. برای اتصال باتری‌های لیتیومی به بردهای میکروکنترلر (مانند ESP32 یا STM32)، حتماً از ماژول‌های شارژ و محافظ (BMS) استفاده کنید.

### مثال کد: خواندن ولتاژ باتری با ADC
اگر می‌خواهید سطح شارژ باتری را در پروژه خود مانیتور کنید، می‌توانید از یک مدار تقسیم ولتاژ ساده (Voltage Divider) استفاده کنید:

```cpp
// کد نمونه برای خواندن ولتاژ باتری در آردوینو/ESP32
const int batteryPin = 34; // پین ADC
float vRef = 3.3; 

void setup() {
  Serial.begin(115200);
}

void loop() {
  int rawValue = analogRead(batteryPin);
  // فرمول محاسبه ولتاژ با توجه به مقاومت‌های تقسیم ولتاژ
  float voltage = (rawValue / 4095.0) * vRef * 2.0; 
  
  Serial.print("Battery Voltage: ");
  Serial.println(voltage);
  delay(1000);
}
```

## ۳. نکات طلایی در استفاده
1. **لحیم‌کاری:** هرگز مستقیم روی بدنه باتری‌های لیتیومی لحیم نزنید! حرارت بالا باعث تخریب لایه‌های داخلی می‌شود. حتماً از باتری‌های دارای **Tab** (سرپوش فلزی) استفاده کنید.
2. **دمای عملیاتی:** باتری‌ها را در محیط‌های محصور که دمای بالای ۴۵ درجه دارند قرار ندهید؛ این کار نرخ خودتخلیه (Self-discharge) را به شدت افزایش می‌دهد.
3. **تطبیق جریان:** اگر موتور DC دارید، مطمئن شوید باتری انتخابی شما نرخ دشارژ (C-rating) کافی برای استارت موتور را تامین می‌کند.

## ۴. پرسش‌های متداول (FAQ)

**سؤال: آیا باتری‌های موجود در خانه باتری برای پهپادها مناسب هستند؟**
پاسخ: بله، اما باید حتماً به نرخ دشارژ (مثلاً 20C یا بالاتر) توجه کنید. باتری‌های معمولی لیتیوم-یون برای پهپادها مناسب نیستند و باید از سری‌های Li-Po استفاده کنید.

**سؤال: عمر مفید یک سلول ۱۸۶۵۰ چقدر است؟**
پاسخ: به صورت استاندارد، پس از ۵۰۰ تا ۸۰۰ سیکل شارژ و دشارژ، ظرفیت باتری به حدود ۸۰٪ ظرفیت اولیه می‌رسد.

**سؤال: چگونه می‌توانم دیتاسیت دقیق یک قطعه را پیدا کنم؟**
پاسخ: در سایت [batteries.ir](https://www.batteries.ir/)، برای اکثر محصولات کدهای فنی درج شده است. با جستجوی مدل دقیق در گوگل همراه با عبارت "Datasheet"، می‌توانید نمودارهای تخلیه و منحنی شارژ آن را مشاهده کنید.
