# راهنمای جامع «خانه باتری»: از انتخاب تا پیاده‌سازی

در دنیای تجهیزات الکترونیک، پیدا کردن یک منبع مطمئن که هم تنوع کالایی بالایی داشته باشد و هم مشاوره تخصصی ارائه دهد، همیشه چالش‌برانگیز است. وب‌سایت [خانه باتری](https://www.batteries.ir/) یکی از آن مراجع قدیمی و کاردرست بازار است که اگر با بردهای الکترونیکی، سیستم‌های UPS یا پروژه‌های DIY سر و کار دارید، حتماً باید در بوک‌مارک‌های مرورگرتان باشد.

این مستند فنی برای کمک به مهندسان و تکنسین‌ها جهت استفاده بهینه از منابع این مجموعه تدوین شده است.

## ۱. چرا «خانه باتری»؟
تفاوت این مجموعه با فروشگاه‌های عمومی قطعات الکترونیک در تخصصی بودن آن است. برخلاف فروشگاه‌های قطعات که باتری را فقط به عنوان یک کالای جانبی می‌بینند، در اینجا با دیتاسیت‌های دقیق، تست‌های جریان‌دهی و تنوع شیمیایی (Li-ion, LiFePO4, NiMH و غیره) روبرو هستید.

### دسته‌بندی‌های کلیدی برای مهندسان:
*   **باتری‌های صنعتی:** مناسب برای اینورترها و سیستم‌های خورشیدی.
*   **پک‌های سفارشی:** اگر پروژه خاصی دارید، امکان سفارش ساخت پک با BMS اختصاصی وجود دارد.
*   **تجهیزات تست:** شارژرهای هوشمند و دشارژرهای قابل برنامه‌ریزی.

## ۲. نصب و راه‌اندازی (راهنمای عملیاتی)
وقتی یک باتری لیتیومی یا پک باتری را از خانه باتری تهیه می‌کنید، رعایت پروتکل‌های ایمنی و نصب اولین قدم است.

### مراحل نصب استاندارد:
1.  **بررسی ولتاژ اولیه:** همیشه قبل از اتصال به مدار، ولتاژ را با مولتی‌متر چک کنید. (تلرانس مجاز نباید بیش از ۰.۰۵ ولت باشد).
2.  **تنظیم BMS:** اگر پک باتری دارید، مطمئن شوید سیم‌های بالانسر به درستی روی کانکتور نشسته باشند.
3.  **لحیم‌کاری یا نقطه‌جوش:** **هرگز** روی بدنه باتری‌های لیتیومی لحیم‌کاری مستقیم نکنید! از ابزارهای نقطه‌جوش (Spot Welder) استفاده کنید.

## ۳. مثال کاربردی: اتصال پک باتری به میکروکنترلر
فرض کنید می‌خواهید یک پک باتری ۳.۷ ولت لیتیوم-پلیمری را به یک برد ESP32 متصل کنید. باید یک مدار محافظ برای جلوگیری از دشارژ بیش از حد (Deep Discharge) در نظر بگیرید.

```cpp
// کد ساده برای مانیتورینگ ولتاژ باتری با استفاده از ADC
const int batteryPin = 34; // پین آنالوگ متصل به تقسیم ولتاژ
float voltage = 0.0;

void setup() {
  Serial.begin(115200);
}

void loop() {
  int rawValue = analogRead(batteryPin);
  // تبدیل مقدار ADC به ولتاژ (با در نظر گرفتن مقاومت‌های تقسیم ولتاژ)
  voltage = (rawValue * 3.3 / 4095.0) * 2; 
  
  if (voltage < 3.2) {
    Serial.println("هشدار: شارژ باتری کم است!");
  }
  delay(1000);
}
```

## ۵. سوالات متداول (FAQ)

**س: آیا باتری‌های موجود در سایت برای پروژه‌های پهپاد مناسب هستند؟**
ج: بله، اما حتماً به نرخ دشارژ (C-Rating) دقت کنید. برای پهپادها باید مدل‌های High-Drain انتخاب کنید.

**س: آیا امکان مشاوره برای طراحی BMS اختصاصی دارم؟**
ج: بله، تیم فنی خانه باتری در بخش پروژه‌های سفارشی، مشاوره خوبی برای انتخاب مدار محافظ مناسب بر اساس نوع سلول‌های شما ارائه می‌دهند.

**س: تفاوت باتری‌های اصلی و کپی را چطور تشخیص دهیم؟**
ج: بهترین راه، بررسی وزن باتری و تست ظرفیت (Capacity Test) با دستگاه‌های دشارژر است. باتری‌های بی‌کیفیت معمولاً در تست ظرفیت، عددی بسیار کمتر از لیبل روی باتری را نشان می‌دهند.
