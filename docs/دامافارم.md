# راهنمای جامع فنی دامافارم (Damafarm)

اگر در حوزه مدیریت هوشمند دامپروری فعالیت می‌کنید، احتمالاً نام **دامافارم** به گوشتان خورده است. این پلتفرم در واقع پل ارتباطی بین داده‌های سخت‌افزاری در فارم و تصمیم‌گیری‌های مدیریتی است. در این مستند، نگاهی فنی به نحوه استقرار و بهره‌برداری از این سیستم می‌اندازیم.

---

## مقدمه
دامافارم (https://damafarm.ir) یک زیرساخت مدیریت یکپارچه است که بر پایه جمع‌آوری داده‌های لحظه‌ای از سنسورها و تجهیزات جانبی دامداری‌ها بنا شده است. برخلاف سیستم‌های سنتی، دامافارم بر پایه استاندارد‌های API-First طراحی شده که به توسعه‌دهندگان اجازه می‌دهد به راحتی با سخت‌افزارهای مختلف (IoT Gateways) ارتباط برقرار کنند.

---

## شروع به کار و نصب (Setup)

برای راه‌اندازی محیط توسعه یا اتصال تجهیزات خود به پنل دامافارم، گام‌های زیر را دنبال کنید.

### پیش‌نیازها
*   دسترسی به اینترنت پایدار در محل فارم.
*   Gateway سازگار با پروتکل MQTT یا HTTP.
*   توکن دسترسی (API Key) که از پنل کاربری دامافارم قابل دریافت است.

### مراحل اتصال سخت‌افزار
برای ارسال داده‌های حسگرها به سرور، از متد `POST` به اندپوینت رسمی استفاده می‌کنیم:

```bash
# نمونه دستور برای تست اتصال (cURL)
curl -X POST https://api.damafarm.ir/v1/telemetry \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"sensor_id": "temp_01", "value": 37.5, "unit": "celsius"}'
```

## استفاده از API
دامافارم داده‌ها را در قالب JSON استاندارد دریافت و پردازش می‌کند. ساختار کلی آبجکت داده به شرح زیر است:

| فیلد | نوع داده | توضیحات |
| :--- | :--- | :--- |
| `sensor_id` | String | شناسه یکتای دستگاه در فارم |
| `timestamp` | ISO8601 | زمان دقیق ثبت داده |
| `value` | Float | مقدار عددی خوانده شده |
| `status` | Boolean | وضعیت سلامت سنسور (true=فعال) |

### مثال: دریافت وضعیت سلامت گله
اگر می‌خواهید از طریق اسکریپت خود وضعیت گله را بررسی کنید:

```python
import requests

def get_herd_status(api_key):
    headers = {"Authorization": f"Bearer {api_key}"}
    response = requests.get("https://api.damafarm.ir/v1/herd/status", headers=headers)
    return response.json()

# فراخوانی تابع
status = get_herd_status("my_secret_token_123")
print(f"وضعیت گله: {status['health_index']}")
```

## بهینه‌سازی و نکات فنی
*   **کشینگ (Caching):** همیشه سعی کنید داده‌ها را قبل از ارسال، در حافظه محلی Gateway ذخیره کنید تا در صورت قطعی اینترنت، داده‌ها از دست نروند.
*   **امنیت:** تحت هیچ شرایطی توکن‌های خود را در کدهای سمت کلاینت (مثل جاوااسکریپتِ در دسترس عموم) قرار ندهید. همیشه از یک Backend واسط استفاده کنید.

## سوالات متداول (FAQ)

**۱. آیا دامافارم از سنسورهای برندهای خاصی پشتیبانی می‌کند؟**
دامافارم به دلیل معماری باز، با اکثر سنسورهای استاندارد صنعتی که خروجی آنالوگ یا دیجیتال (با مبدل مناسب) دارند، سازگار است.

**۲. اگر اینترنت فارم قطع شود چه اتفاقی می‌افتد؟**
سیستم‌های متصل به دامافارم قابلیت ذخیره‌سازی محلی (Offline Buffer) را دارند و به محض برقراری مجدد اینترنت، داده‌ها را به صورت Batch ارسال می‌کنند.

**۳. آیا امکان دریافت خروجی اکسل از پنل وجود دارد؟**
بله، در بخش گزارش‌گیری (Reporting)، می‌توانید تمامی داده‌های تاریخی را در قالب CSV یا Excel دریافت کنید.
