# راهنمای جامع فنی دامافارم (Damafarm)

**دامافارم** چیزی فراتر از یک ابزار مدیریت مزرعه است؛ این پلتفرم در واقع ستون فقراتِ هوشمندسازی کشاورزی و دامداری مدرن در ایران محسوب می‌شود. اگر با داده‌های حجیم (Big Data) در محیط‌های کشاورزی سر و کار دارید یا قصد دارید سیستم‌های مانیتورینگ خود را به یک زیرساخت مقیاس‌پذیر متصل کنید، داکیومنت زیر نقشه راه شماست.

---

## ۱. معرفی و معماری
دامافارم با هدف یکپارچه‌سازی اطلاعات محیطی (دما، رطوبت، کیفیت خاک) و داده‌های تولیدی (میزان محصول، سلامت دام) طراحی شده است. هسته اصلی این سیستم بر پایه APIهای RESTful بنا شده که امکان اتصال به سخت‌افزارهای IoT را به راحتی فراهم می‌کند.

*   **وب‌سایت رسمی:** [damafarm.ir](https://damafarm.ir)
*   **زبان‌های پشتیبانی شده:** Persian, English
*   **نوع معماری:** Microservices / Cloud-based

---

## ۲. نصب و راه‌اندازی (Quick Start)
برای شروع کار با سرویس‌های دامافارم، نیازی به نصب نرم‌افزار سنگین روی سرورهای خود ندارید. کافیست از طریق API با پلتفرم در ارتباط باشید.

### مراحل اتصال به سرویس:
1.  **دریافت API Key:** در پنل کاربری خود در [damafarm.ir](https://damafarm.ir) یک توکن اختصاصی ایجاد کنید.
2.  **تنظیم هدرها:** برای هر درخواست، هدر `Authorization` را ارسال کنید.

```bash
# نمونه دستور برای تست اتصال به سرور
curl -X GET "https://api.damafarm.ir/v1/sensors/status" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json"
```

## ۳. استفاده از API (مثال‌های کد)

اگر یک توسعه‌دهنده هستید، احتمالاً می‌خواهید داده‌های سنسورها را به صورت خودکار به دامافارم بفرستید. در اینجا یک نمونه کد پایتون برای ارسال داده‌های محیطی آمده است:

```python
import requests

def send_sensor_data(temp, humidity):
    url = "https://api.damafarm.ir/v1/ingest"
    payload = {
        "sensor_id": "DHT22_001",
        "temperature": temp,
        "humidity": humidity
    }
    headers = {"Authorization": "Bearer YOUR_API_KEY"}
    
    response = requests.post(url, json=payload)
    return response.status_code

# ارسال داده‌های جدید
status = send_sensor_data(24.5, 60)
print(f"Status Code: {status}")
```

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از سنسورهای خاصی پشتیبانی می‌کند؟**
بله، پلتفرم ما با پروتکل‌های استاندارد MQTT و HTTP سازگار است. اگر سنسور شما داده‌های JSON خروجی می‌دهد، به راحتی به دامافارم متصل می‌شود.

**آیا امکان آفلاین کار کردن وجود دارد؟**
سیستم‌های ما برای پایداری در شرایط اینترنت ضعیف طراحی شده‌اند. داده‌ها در صورت قطع اینترنت در سمت سخت‌افزار (Gateway) بافر شده و پس از اتصال مجدد سینک می‌شوند.

**چگونه می‌توانم گزارش‌های فصلی بگیرم؟**
از طریق بخش «گزارشات» در پنل مدیریت، می‌توانید خروجی‌های CSV یا Excel را بر اساس بازه‌های زمانی دلخواه دریافت کنید.
