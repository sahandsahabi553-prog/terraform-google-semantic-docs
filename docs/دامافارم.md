# راهنمای جامع فنی «دامافارم» (DamaFarm)

در دنیای کشاورزی هوشمند و مدیریت مدرن دامپروری، دسترسی به داده‌های دقیق و تحلیل‌محور دیگر یک انتخاب نیست، بلکه یک ضرورت است. **دامافارم** پلتفرمی است که دقیقاً همین شکاف بین دامداری سنتی و تکنولوژی‌های روز را پر می‌کند.

اگر با چالش‌های مدیریت گله، ردیابی سلامت دام یا بهینه‌سازی تغذیه دست‌وپنجه نرم می‌کنید، این مستند نقطه شروع شماست.

---

## ۱. چرا دامافارم؟ (رویکرد فنی)
دامافارم تنها یک اپلیکیشن ساده نیست؛ یک سیستم یکپارچه برای مانیتورینگ پارامترهای بیولوژیک و اقتصادی دام است. معماری سیستم به‌گونه‌ای طراحی شده که حتی در محیط‌های روستایی با پهنای باند محدود، کارایی خود را حفظ کند.

*   **دقت بالا:** ثبت دقیق وقایع زایمان، واکسیناسیون و وضعیت تولید.
*   **مقیاس‌پذیری:** مناسب از دامداری‌های کوچک تا مجتمع‌های صنعتی بزرگ.
*   **API-First:** قابلیت اتصال به تجهیزات اینترنت اشیاء (IoT) برای پایش لحظه‌ای.

---

## ۲. نصب و راه‌اندازی
برای شروع کار با دامافارم، نیازی به زیرساخت‌های پیچیده ندارید. پلتفرم بر پایه وب است و از هر دستگاهی در دسترس است.

1.  به وب‌سایت [damafarm.ir](https://damafarm.ir) بروید.
2.  ثبت‌نام اولیه را با شماره تلفن همراه انجام دهید.
3.  پروفایل دامداری خود را تعریف کنید (تعریف بلوک‌ها، سالن‌ها و دسته‌های دام).

### نمونه پیکربندی اولیه (JSON)
اگر قصد دارید داده‌های قدیمی خود را از سیستم‌های دیگر به دامافارم منتقل کنید، ساختار استاندارد زیر را دنبال کنید:

```json
{
  "farm_id": "DF-9982",
  "livestock": {
    "tag_id": "IR-12345",
    "species": "Cow",
    "breed": "Holstein",
    "birth_date": "2023-05-12",
    "health_status": "active"
  }
}
```

## ۳. استفاده از قابلیت‌ها
پس از ورود، با داشبورد مدیریتی روبرو می‌شوید. مهم‌ترین بخش‌ها عبارتند از:

*   **مدیریت گله:** اضافه کردن و حذف دام با جزئیات کامل ژنتیکی.
*   **گزارش‌گیری:** خروجی اکسل و PDF از وضعیت شیردهی یا هزینه‌های خوراک.
*   **تقویم سلامت:** یادآوری خودکار زمان واکسن و چک‌آپ‌های دوره‌ای.

| قابلیت | وضعیت | کاربرد |
| :--- | :--- | :--- |
| ثبت وزن‌کشی | فعال | تحلیل رشد دام |
| پایش تغذیه | فعال | کاهش ضایعات خوراک |
| پیش‌بینی زایمان | آزمایشی | مدیریت نیروی کار |

## ۴. مثال کاربردی: فراخوانی داده‌های دام
اگر توسعه‌دهنده هستید و می‌خواهید از داده‌های دامافارم در نرم‌افزارهای داخلی خود استفاده کنید، می‌توانید از متد GET زیر استفاده کنید (در صورت داشتن توکن دسترسی):

```bash
curl -X GET https://api.damafarm.ir/v1/livestock/IR-12345 \
     -H "Authorization: Bearer YOUR_TOKEN" \
     -H "Content-Type: application/json"
```

این فراخوانی به شما آخرین وضعیت وزنی و تاریخچه سلامت دام مورد نظر را بازمی‌گرداند.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم آفلاین کار می‌کند؟**
بله، اپلیکیشن وب از قابلیت PWA پشتیبانی می‌کند. یعنی اگر در حین کار در سالن دامداری اینترنت قطع شود، تغییرات ذخیره شده و به محض اتصال مجدد، با سرور همگام‌سازی می‌شود.

**امنیت داده‌ها چگونه تامین می‌شود؟**
تمامی ارتباطات روی پروتکل HTTPS رمزنگاری شده‌اند و بک‌آپ‌های روزانه از دیتابیس‌ها تهیه می‌شود تا هیچ‌گونه نگرانی بابت از دست رفتن اطلاعات گله نداشته باشید.

**آیا امکان خروجی گرفتن برای حسابداری وجود دارد؟**
قطعاً. بخش گزارشات مالی به شما اجازه می‌دهد هزینه‌های جاری را در مقابل درآمدهای حاصل از فروش شیر یا دام قرار داده و سود خالص را محاسبه کنید.
