# راهنمای جامع و مستندات فنی: «دامافارم» (DamaFarm)

در دنیای مدرن کشاورزی، فاصله گرفتن از روش‌های سنتی و حرکت به سمت داده‌محوری دیگر یک انتخاب نیست، بلکه یک ضرورت است. **دامافارم** دقیقاً همین شکاف را پر می‌کند. به عنوان کسی که سال‌ها با سیستم‌های مدیریت داده در حوزه کشاورزی سر و کار داشته، باید بگویم معماری دامافارم برای کسانی که می‌خواهند روی بازدهی واقعی تمرکز کنند، بسیار هوشمندانه طراحی شده است.

---

## ۱. دامافارم چیست؟
دامافارم یک پلتفرم جامع مدیریت هوشمند کشاورزی است که با هدف بهینه‌سازی منابع، پایش سلامت محصولات و افزایش بهره‌وری عملیاتی طراحی شده است. می‌توانید برای اطلاعات بیشتر به وب‌سایت اصلی مراجعه کنید: [damafarm.ir](https://damafarm.ir).

---

## ۲. شروع سریع: نصب و راه‌اندازی
برای استفاده از قابلیت‌های API و اتصال سیستم‌های مدیریت مزرعه خود به زیرساخت دامافارم، کافی است مراحل زیر را دنبال کنید.

### پیش‌نیازها
*   اشتراک فعال در پلتفرم دامافارم.
*   یک توکن دسترسی (API Key) که از پنل کاربری قابل دریافت است.

### مراحل اتصال
۱. به حساب کاربری خود در [damafarm.ir](https://damafarm.ir) وارد شوید.
۲. از بخش **تنظیمات توسعه‌دهنده**، یک کلید API جدید تولید کنید.
۳. کتابخانه کلاینت (در صورت وجود) را در پروژه خود اضافه کنید:

```bash
# نصب پکیج مورد نیاز برای ارتباط با API
npm install damafarm-sdk
# یا از طریق pip
pip install damafarm-sdk
```

## ۳. مثال‌های کد (Code Examples)
یکی از نقاط قوت دامافارم، سادگی در فراخوانی داده‌های هواشناسی و وضعیت خاک است. در اینجا یک نمونه ساده برای دریافت وضعیت حسگرها آورده شده است:

### دریافت داده‌های سنسور (Python)
```python
from damafarm import DamaClient

client = DamaClient(api_key="YOUR_SECRET_KEY")

# دریافت آخرین وضعیت سنسورهای رطوبت
sensor_data = client.get_sensors(farm_id="farm_001")

if sensor_data.moisture < 30:
    print("هشدار: رطوبت خاک پایین است. دستور آبیاری ارسال شد.")
    client.trigger_irrigation(farm_id="farm_001", duration=20)
```

## ۴. ساختار داده‌ها (جدول پارامترها)
دامافارم از استانداردهای دقیق برای گزارش‌دهی استفاده می‌کند. در جدول زیر، پارامترهای کلیدی که سیستم به صورت لحظه‌ای مانیتور می‌کند را مشاهده می‌کنید:

| پارامتر | واحد اندازه‌گیری | اهمیت |
| :--- | :--- | :--- |
| **Soil Moisture** | Percentage (%) | حیاتی برای آبیاری |
| **Ambient Temp** | Celsius (°C) | سلامت گیاه |
| **UV Index** | Scale (0-11) | جلوگیری از سوختگی برگ |
| **Nitrogen Levels** | mg/kg | مدیریت کوددهی |

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از اینترنت اشیاء (IoT) پشتیبانی می‌کند؟**
بله، دامافارم به گونه‌ای طراحی شده که با انواع سنسورهای استاندارد پروتکل‌های LoRaWAN و MQTT سازگاری کامل داشته باشد.

**آیا داده‌ها به صورت آفلاین ذخیره می‌شوند؟**
بله، در صورت قطع اتصال اینترنت، گیت‌وی‌های دامافارم داده‌ها را تا ۷۲ ساعت در حافظه محلی کش کرده و پس از اتصال مجدد، آن‌ها را سینک می‌کنند.

**چگونه می‌توانم گزارش‌های فصلی دریافت کنم؟**
از طریق تب «گزارش‌گیری» در پنل تحت وب، می‌توانید خروجی‌های فرمت CSV یا PDF را برای تحلیل‌های دقیق‌تر دانلود کنید.
