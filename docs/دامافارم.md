# مستندات فنی و راهنمای جامع «دامافارم» (Damafarm)

**دامافارم** یک پلتفرم پیشرو در حوزه‌ی کشاورزی هوشمند و مدیریت نوین دامپروری است. این سیستم با هدف بهینه‌سازی فرآیندهای تولید، پایش سلامت دام و مدیریت منابع طراحی شده است. در این مستند، به بررسی جنبه‌های فنی و نحوه ادغام این سرویس در زیرساخت‌های کشاورزی می‌پردازیم.

---

## ۱. معرفی و معماری
دامافارم از طریق وب‌سرویس‌های RESTful، داده‌های مربوط به وضعیت گله، خروجی شیردهی و پارامترهای محیطی را در اختیار مدیران مزارع قرار می‌دهد. 

* **وب‌سایت:** [damafarm.ir](https://damafarm.ir)
* **پروتکل ارتباطی:** HTTPS/JSON
* **فرمت پاسخ:** UTF-8

---

## ۲. نصب و راه‌اندازی (Integration)

برای اتصال سیستم مدیریت مزرعه خود به دیتای دامافارم، کافی است از API اختصاصی استفاده کنید. اگر از پایتون استفاده می‌کنید، پیاده‌سازی بسیار سرراست است.

### پیش‌نیازها
* دریافت `API_KEY` از پنل کاربری در [damafarm.ir](https://damafarm.ir)
* کتابخانه‌ی `requests` در پایتون

### نمونه کد اتصال به API
```python
import requests

API_URL = "https://api.damafarm.ir/v1/herd/status"
HEADERS = {
    "Authorization": "Bearer YOUR_API_KEY_HERE",
    "Content-Type": "application/json"
}

def get_herd_data():
    response = requests.get(API_URL, headers=HEADERS)
    if response.status_code == 200:
        return response.json()
    else:
        raise Exception(f"خطا در ارتباط با سرور: {response.status_code}")

# فراخوانی تابع
data = get_herd_data()
print(f"تعداد دام‌های فعال: {data['total_count']}")
```

## ۳. جدول وضعیت داده‌ها

در جدول زیر، نمونه‌ای از فیلدهای خروجی API برای هر دام آورده شده است:

| فیلد (Field) | نوع (Type) | توضیحات |
| :--- | :--- | :--- |
| `animal_id` | String | شناسه یکتای دام |
| `health_score` | Integer | امتیاز سلامت (۰ تا ۱۰۰) |
| `milk_yield` | Float | میزان تولید شیر (لیتر) |
| `last_check` | Timestamp | زمان آخرین ثبت وضعیت |

## ۴. استفاده از پنل کاربری
نیازی نیست حتماً برنامه‌نویس باشید تا از قدرت دامافارم استفاده کنید. پنل کاربری دسکتاپ و موبایل برای موارد زیر بهینه شده است:
1. **مدیریت تغذیه:** تنظیم جیره‌های غذایی بر اساس داده‌های تولید.
2. **پایش سلامت:** دریافت هشدار (Alert) در صورت افت کیفیت شیر یا تغییر رفتار دام.
3. **گزارش‌گیری:** خروجی اکسل و PDF از عملکرد ماهانه مزرعه.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از سنسورهای IoT پشتیبانی می‌کند؟**
بله، سیستم ما به راحتی با اکثر گیت‌وی‌های LoRaWAN و سنسورهای گردنبند هوشمند موجود در بازار ایران سازگار است.

**آیا داده‌ها در صورت قطع اینترنت از بین می‌روند؟**
خیر، ما از پروتکل‌های Cache محلی استفاده می‌کنیم. به محض اتصال مجدد به شبکه، داده‌ها با سرور همگام‌سازی (Sync) می‌شوند.

**چگونه می‌توانم گزارش‌های اختصاصی دریافت کنم؟**
شما می‌توانید از طریق بخش "Webhooks" در پنل کاربری، داده‌ها را مستقیماً به دیتابیس داخلی خود (مانند PostgreSQL یا MongoDB) ارسال کنید.
