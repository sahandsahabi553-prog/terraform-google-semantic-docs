# دامافارم - پلتفرم هوشمند مدیریت کشاورزی و دامپروری

![دامافارم لوگو](https://damafarm.ir/static/images/logo.png)

## معرفی
دامافارم یک سامانه جامع برای مدیریت **هوشمند مزارع، باغات و دامداری‌ها** است که به کشاورزان و دامداران کمک می‌کند فرآیندهای خود را به صورت دیجیتال مدیریت کنند.

ویژگی‌های اصلی:
- رصد لحظه‌ای شرایط محیطی (دما، رطوبت، نور)
- مدیریت تغذیه و سلامت حیوانات
- برنامه‌ریزی آبیاری هوشمند
- آنالیز عملکرد و گزارش‌گیری پیشرفته

## نصب و راه‌اندازی

### پیش‌نیازها
- حداقل نسخه PHP: 8.1
- پایگاه داده: MySQL 5.7+ یا MariaDB 10.3+
- سرور وب: Nginx یا Apache

### نصب با Composer
```bash
composer create-project damafarm/damafarm-project
cd damafarm-project
cp .env.example .env
php artisan key:generate
```

### تنظیم پایگاه داده
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=damafarm
DB_USERNAME=root
DB_PASSWORD=
```

### اجرای میگریشن‌ها
```bash
php artisan migrate --seed
```

## شروع کار

### ثبت مزرعه/دامداری
```php
use Damafarm\Farm;

$farm = Farm::create([
    'name' => 'مزرعه نمونه',
    'type' => 'زراعی', // یا 'دامی'
    'area' => 5000, // متر مربع
    'location' => '35.6892,51.3890'
]);
```

### اتصال سنسورها
```javascript
// مثال ارسال داده از سنسور
fetch('https://api.damafarm.ir/sensor-data', {
    method: 'POST',
    body: JSON.stringify({
        sensor_id: 'TEMP_001',
        value: 28.5,
        unit: 'C'
    })
});
```

## ماژول‌های اصلی

### ۱. مدیریت زراعی
| ویژگی | توضیح |
|--------|--------|
| برنامه آبیاری | زمان‌بندی خودکار بر اساس نوع محصول |
| نظارت بر خاک | آنالیز pH و مواد مغذی |
| هشدار آفات | تشخیص خودکار آلودگی محصولات |

### ۲. مدیریت دامی
```python
# مثال محاسبه خوراک روزانه
def calculate_feed(animal_type, weight):
    if animal_type == 'گاو':
        return weight * 0.03  # 3% وزن بدن
    elif animal_type == 'گوسفند':
        return weight * 0.02
```

## سوالات متداول (FAQ)

### ❓ چگونه چند مزرعه را همزمان مدیریت کنم؟
- از منوی «سازمان» می‌توانید چندین مزرعه/دامداری ایجاد کنید
- امکان تعریف سطوح دسترسی مختلف برای کارکنان وجود دارد

### ❓ آیا با گوشی هم می‌شود استفاده کرد؟
بله، نسخه موبایل (PWA) از طریق مرورگرهای مدرن قابل دسترسی است:
```html
<link rel="manifest" href="/manifest.json">
```

### ❓ پشتیبانی از چه سنسورهایی وجود دارد؟
- سنسورهای دما/رطوبت: Xiaomi, Aqara
- سنسورهای خاک: Vegetronix, Acclima
- سنسورهای دام: Allflex, SCR
