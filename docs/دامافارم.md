# مستندات فنی و راهنمای جامع داما‌فارم (Damafarm)

**دسترسی به پلتفرم:** [damafarm.ir](https://damafarm.ir)

داما‌فارم یک زیرساخت مدرن برای هوشمندسازی کشاورزی و مدیریت داده‌محور مزارع است. اگر در حال خواندن این مستند هستید، احتمالاً به دنبال راهکاری برای بهینه‌سازی مصرف آب، پایش سلامت محصولات یا خودکارسازی فرآیندهای گلخانه‌ای خود هستید. در ادامه، نگاهی فنی به نحوه استقرار و تعامل با اکوسیستم داما‌فارم خواهیم داشت.

---

## ۱. معماری سیستم
داما‌فارم بر پایه یک معماری توزیع‌شده بنا شده که داده‌ها را از سنسورهای محیطی (IoT) دریافت کرده و پس از پردازش در لایه Cloud، دستورات لازم را به عملگرها (Actuators) ارسال می‌کند.

### اجزای اصلی:
*   **Edge Gateway:** دریافت داده‌های خام از سنسورهای خاک و هوا.
*   **Data Lake:** ذخیره‌سازی سری‌های زمانی (Time-series) برای تحلیل‌های آماری.
*   **API Gateway:** نقطه اتصال برای توسعه‌دهندگان جهت دریافت گزارش‌ها.

---

## ۲. شروع سریع و نصب
برای شروع کار با سرویس‌های ابری داما‌فارم، نیازی به نصب نرم‌افزار سنگین ندارید. با این حال، اگر قصد دارید سیستم‌های خود را با API ما یکپارچه کنید، مراحل زیر را دنبال کنید.

### نصب کتابخانه کلاینت (Python)
برای تعامل با دیتای مزرعه خود، می‌توانید از SDK رسمی ما استفاده کنید:

```bash
pip install damafarm-sdk
```

### تنظیمات اولیه
پس از دریافت `API_KEY` از پنل کاربری در [damafarm.ir](https://damafarm.ir)، آن را در محیط پروژه خود ست کنید:

```python
import damafarm

client = damafarm.Client(api_key="YOUR_SECRET_KEY")

# دریافت آخرین وضعیت رطوبت خاک
status = client.get_sensor_data(sensor_id="soil_moisture_01")
print(f"Current Humidity: {status.value}%")
```

## ۳. مثال کاربردی: خودکارسازی آبیاری
یکی از چالش‌های اصلی، تنظیم دقیق زمان آبیاری است. در اینجا نمونه کدی برای فعال‌سازی شیر برقی در صورتی که رطوبت از حد مجاز کمتر شود، آورده شده است:

```python
THRESHOLD = 30.0

def manage_irrigation():
    data = client.get_sensor_data("soil_moisture_01")
    if data.value < THRESHOLD:
        client.trigger_actuator("valve_01", action="ON")
        print("Irrigation started.")
    else:
        client.trigger_actuator("valve_01", action="OFF")
```

## ۴. مشخصات فنی سنسورها
جدول زیر برخی از استانداردهای پشتیبانی شده توسط سخت‌افزارهای داما‌فارم را نشان می‌دهد:

| سنسور | دامنه اندازه‌گیری | دقت | پروتکل ارتباطی |
| :--- | :--- | :--- | :--- |
| رطوبت خاک | ۰ تا ۱۰۰٪ | ±۲٪ | RS485 |
| دما | -۴۰ تا +۸۵ درجه | ±۰.۵ | I2C |
| تابش خورشیدی | ۰ تا ۲۰۰۰ W/m² | ±۵٪ | Analog (4-20mA) |

## ۵. سوالات متداول (FAQ)

**آیا داما‌فارم در مناطق بدون اینترنت پرسرعت کار می‌کند؟**
بله، گیت‌وی‌های داما‌فارم با استفاده از پروتکل‌های کم‌مصرف (مانند LoRaWAN) طراحی شده‌اند و حتی با پهنای باند بسیار محدود نیز داده‌ها را به سرور منتقل می‌کنند.

**آیا امکان خروجی گرفتن از داده‌ها برای اکسل وجود دارد؟**
قطعاً. در پنل کاربری، بخشی به نام "Export Data" وجود دارد که به شما خروجی‌های CSV و JSON با فرمت استاندارد برای تحلیل‌های نرم‌افزاری ارائه می‌دهد.

**امنیت داده‌های مزرعه من چقدر تضمین شده است؟**
تمام ارتباطات بین سخت‌افزار و سرور از طریق پروتکل TLS 1.3 رمزنگاری می‌شود. ما به حریم خصوصی داده‌های کشاورزان تعهد کامل داریم.
