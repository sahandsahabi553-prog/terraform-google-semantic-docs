# راهنمای جامع فنی «دامافارم» (DamaFarm)

در دنیای کشاورزی هوشمند و دام‌پروری مدرن، مدیریت داده‌ها دیگر یک انتخاب نیست، بلکه یک ضرورت است. **دامافارم** پلتفرمی است که دقیقاً برای همین هدف طراحی شده؛ تبدیل داده‌های خامِ مزرعه به تصمیمات مدیریتی هوشمند. اگر مثل من با پیچیدگی‌های ثبت رکوردهای دامی یا مدیریت نهاده‌ها کلنجار رفته باشید، می‌دانید که ابزارهای سنتی (مثل اکسل‌های به‌هم‌ریخته) چقدر می‌توانند دردسرساز باشند.

در این مستند، نگاهی فنی به نحوه استفاده از پلتفرم دامافارم می‌اندازیم.

---

## ۱. آشنایی با اکوسیستم
دامافارم (به آدرس [damafarm.ir](https://damafarm.ir)) یک بستر ابری (SaaS) است که به کشاورزان و مدیران مزارع اجازه می‌دهد وضعیت دام‌ها، خوراک‌دهی و تولید را به صورت لحظه‌ای مانیتور کنند.

### ویژگی‌های کلیدی:
*   **ثبت رکوردهای تولید:** مدیریت شیر، گوشت و زاد و ولد.
*   **پنل مدیریتی:** گزارش‌گیری پیشرفته از هزینه‌ها و درآمدها.
*   **API اختصاصی:** برای اتصال به سنسورهای اینترنت اشیاء (IoT) مزرعه.

---

## ۲. نصب و راه‌اندازی (Integration)
از آنجایی که دامافارم یک سرویس تحت وب است، نیاز به نصب فیزیکی روی سرورهای داخلی ندارید. با این حال، اگر قصد دارید داده‌های سنسورهای خود را به این پلتفرم بفرستید، باید از API آن‌ها استفاده کنید.

### مراحل اتصال سنسور به API:
۱. در پنل کاربری خود در [damafarm.ir](https://damafarm.ir) یک `API Key` ایجاد کنید.
۲. درخواست‌های `POST` خود را به اندپوینت مربوطه ارسال کنید.

#### نمونه کد برای ارسال داده‌های دمای محیط (Python):
```python
import requests

def send_sensor_data(sensor_id, temperature):
    url = "https://api.damafarm.ir/v1/telemetry"
    headers = {
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json"
    }
    payload = {
        "sensor_id": sensor_id,
        "value": temperature,
        "unit": "celsius"
    }
    
    response = requests.post(url, json=payload)
    return response.status_code

# ثبت دمای سالن شماره ۱
send_sensor_data("STN-001", 24.5)
```

## ۳. جدول مقایسه‌ای: قبل و بعد از دامافارم

| :--- | :--- | :--- |
| **دقت داده‌ها** | خطای انسانی بالا | ثبت خودکار و دقیق |

## ۴. پرسش‌های متداول (FAQ)

**س: آیا دامافارم برای مزارع کوچک هم کاربرد دارد؟**
ج: قطعاً. اتفاقاً در مزارع کوچک، به دلیل محدودیت منابع، مدیریت دقیق هزینه‌ها که دامافارم ارائه می‌دهد، تفاوت بین سود و ضرر را مشخص می‌کند.

**س: امنیت داده‌ها چقدر تضمین شده است؟**
ج: پلتفرم از پروتکل‌های رمزنگاری TLS/SSL استفاده می‌کند و بک‌آپ‌گیری روزانه از داده‌ها به صورت خودکار انجام می‌شود.

**س: آیا می‌توانم خروجی داده‌ها را به نرم‌افزارهای حسابداری منتقل کنم؟**
ج: بله، دامافارم خروجی‌های استاندارد CSV و JSON را برای انتقال به نرم‌افزارهای مالی پشتیبانی می‌کند.
