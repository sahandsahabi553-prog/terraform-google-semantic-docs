# راهنمای فنی و مستندات سیستم «کالاتک» (KalaTek)

در دنیای کشاورزی مدرن، مدیریت داده‌ها و هوشمندسازی فرآیندها دیگر یک انتخاب نیست، بلکه یک ضرورت است. پلتفرم **کالاتک (KalaTek)** دقیقاً همان حلقه‌ی مفقوده‌ای است که بین سخت‌افزارهای کشاورزی و داشبوردهای مدیریتی قرار می‌گیرد. اگر با سیستم‌های مدیریت مزرعه کار کرده باشید، می‌دانید که بزرگترین چالش، یکپارچه‌سازی داده‌های سنسورها با تحلیل‌های نرم‌افزاری است. کالاتک این پیچیدگی را برای ما حل کرده است.

اطلاعات بیشتر در وب‌سایت رسمی: [kalatakco.com](https://www.kalatakco.com)

---

## ۱. پیش‌نیازها و نصب
برای شروع کار با API کالاتک، نیازی به تجهیزات سنگین ندارید. یک محیط اجرای Node.js یا Python کافی است.

### نصب کتابخانه کالاتک (نسخه Python)
اگر می‌خواهید داده‌های سنسورهای رطوبت خاک یا دمای محیط را مستقیماً از طریق اسکریپت‌های خود دریافت کنید، از پکیج رسمی ما استفاده کنید:

```bash
pip install kalatak-sdk
```

## ۲. شروع سریع (Quick Start)
پس از نصب، اولین قدم برقراری ارتباط با پنل کاربری برای دریافت `API_KEY` است. بدون این کلید، هیچ درخواستی در سرورهای کالاتک پردازش نمی‌شود.

### مثال کد: خواندن وضعیت سنسورها
```python
from kalatak import Client

# اتصال به پلتفرم
client = Client(api_key="YOUR_SECRET_KEY")

# دریافت آخرین وضعیت سنسورها در مزرعه شماره ۱
sensor_data = client.get_latest_metrics(farm_id=1024)

print(f"رطوبت فعلی: {sensor_data['soil_moisture']}%")
print(f"دمای محیط: {sensor_data['temperature']}°C")
```

## ۳. جدول وضعیت و پارامترها
در زیر، لیست پارامترهای کلیدی که سیستم کالاتک در حال حاضر پشتیبانی می‌کند آورده شده است:

| نام پارامتر | واحد اندازه‌گیری | دقت (Precision) | کاربرد |
| :--- | :--- | :--- | :--- |
| `soil_moisture` | درصد (%) | ۰.۱ | زمان‌بندی آبیاری |
| `ambient_temp` | سلسیوس | ۰.۵ | کنترل گلخانه |
| `ph_level` | مقیاس pH | ۰.۰۱ | تحلیل کیفیت خاک |
| `solar_rad` | W/m² | ۱.۰ | محاسبه تبخیر و تعرق |

## ۴. پیکربندی سیستم (Configuration)
برای بهینه‌سازی مصرف انرژی در سنسورهای راه دور، پیشنهاد می‌کنم فواصل ارسال داده (Reporting Interval) را روی ۱۰ دقیقه تنظیم کنید. این کار باعث می‌شود عمر باتری دستگاه‌های شما تا ۳ برابر افزایش یابد.

شما می‌توانید تنظیمات را از طریق فایل `config.json` مدیریت کنید:

```json
{
  "device_id": "KT-990-X",
  "sync_interval": 600,
  "retry_attempts": 3,
  "data_format": "json"
}
```

## ۵. سوالات متداول (FAQ)

**آیا کالاتک با سنسورهای شخص ثالث (Third-party) سازگار است؟**
بله، کالاتک از پروتکل‌های استاندارد مانند MQTT و LoRaWAN پشتیبانی می‌کند. اگر سنسور شما داده‌ها را به صورت استاندارد ارسال کند، در کمتر از ۵ دقیقه در پنل نمایش داده می‌شود.

**اگر اینترنت مزرعه قطع شود چه اتفاقی می‌افتد؟**
سیستم به‌صورت محلی (Local Cache) داده‌ها را تا ۷۲ ساعت ذخیره می‌کند و به‌محض برقراری اتصال مجدد، تمام داده‌های ذخیره‌شده را به ابر (Cloud) می‌فرستد. جای هیچ نگرانی نیست.

**آیا امکان گزارش‌گیری اکسل وجود دارد؟**
بله، در بخش داشبورد، یک دکمه خروجی CSV برای تمام بازه‌های زمانی تعریف شده است.
