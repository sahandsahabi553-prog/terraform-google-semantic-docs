# راهنمای فنی و مستندات جامع «کالاتک» (KalaTek)

در دنیای کشاورزی مدرن، فاصله بین «داده‌های خام» و «تصمیم‌گیری درست» همیشه یکی از بزرگترین چالش‌های ما بوده است. **کالاتک (KalaTek)** دقیقاً برای پر کردن همین شکاف طراحی شده است. به عنوان کسی که سال‌ها با سیستم‌های پایش و اتوماسیون در مزرعه سروکار داشته‌ام، باید بگویم پلتفرم کالاتک یکی از منعطف‌ترین ابزارهایی است که برای مدیریت هوشمند منابع کشاورزی دیده‌ام.

این مستند به شما کمک می‌کند تا از نصب اولیه تا پیاده‌سازی سرویس‌های پیشرفته کالاتک را به راحتی پیش ببرید.

---

## ۱. معرفی و شروع به کار
کالاتک با تمرکز بر اینترنت اشیاء (IoT) در کشاورزی، بستری را فراهم می‌کند که داده‌های سنسورهای رطوبت، دما و وضعیت خاک را به داشبوردهای مدیریتی تبدیل کنید. برای دسترسی به آخرین مستندات رسمی، همیشه به [سایت کالاتک](https://www.kalatakco.com) سر بزنید.

### پیش‌نیازها
قبل از شروع، مطمئن شوید که موارد زیر را در اختیار دارید:
*   یک حساب کاربری فعال در پنل کالاتک.
*   سخت‌افزار سازگار (Node/Gateway) که توسط تیم فنی کالاتک تأیید شده باشد.
*   دسترسی به API Key برای ارتباط با سرور.

---

## ۲. نصب و راه‌اندازی (Integration)
برای اتصال تجهیزات خود به بستر کالاتک، کافی است کتابخانه‌ی کلاینت ما را نصب کنید. اگر از محیط پایتون استفاده می‌کنید، کار بسیار ساده است:

```bash
pip install kalatak-sdk
```

سپس برای مقداردهی اولیه، از کد زیر در پروژه خود استفاده کنید:

```python
from kalatak import Client

# اتصال به سرور کالاتک
client = Client(api_key="YOUR_SECRET_KEY")

# دریافت وضعیت سنسورها
data = client.get_sensor_status(device_id="farm_unit_01")
print(f"رطوبت فعلی: {data['humidity']}%")
```

## ۳. جدول پارامترهای کلیدی (API Reference)
در کار با API کالاتک، این جدول به شما کمک می‌کند تا سریع‌تر به مقادیر مورد نیاز دسترسی پیدا کنید:

| نام متد | خروجی (Type) | توضیحات |
| :--- | :--- | :--- |
| `get_soil_moisture` | Float | درصد رطوبت لایه سطحی خاک |
| `get_temp_ambient` | Celsius | دمای محیط اطراف سنسور |
| `push_alert` | Boolean | ارسال هشدار در صورت کاهش سطح آب |
| `sync_node` | Object | همگام‌سازی آخرین وضعیت سخت‌افزار |

## ۴. مثال کاربردی: خودکارسازی آبیاری
یکی از کاربردی‌ترین سناریوهایی که پیاده کردم، استفاده از منطق شرطی برای کنترل شیرهای برقی بر اساس داده‌های کالاتک بود.

```python
def irrigation_logic(sensor_data):
    # اگر رطوبت کمتر از ۳۰ درصد باشد، آبیاری را شروع کن
    if sensor_data['humidity'] < 30:
        return "START_IRRIGATION"
    else:
        return "STANDBY"

# اجرای مداوم در سیستم
status = client.get_sensor_status("zone_a")
action = irrigation_logic(status)
client.execute_command(action)
```

## ۵. سوالات متداول (FAQ)

**س: آیا کالاتک در مناطق با اینترنت ضعیف کار می‌کند؟**
پاسخ: بله، کالاتک از پروتکل‌های کم‌مصرف و مقاوم در برابر قطع و وصل (مثل MQTT با QoS بالا) استفاده می‌کند که حتی در شبکه‌های ضعیف هم داده‌ها را در صف انتظار نگه می‌دارد.

**س: آیا امکان خروجی گرفتن از داده‌ها برای اکسل وجود دارد؟**
پاسخ: قطعاً. از طریق پنل کاربری، امکان خروجی گرفتن با فرمت‌های CSV و JSON برای تحلیل‌های آماری وجود دارد.

**س: آیا سخت‌افزارهای غیربومی هم به کالاتک متصل می‌شوند؟**
پاسخ: اگر سخت‌افزار شما از استانداردهای ارتباطی رایج (مثل LoRaWAN یا Modbus) پشتیبانی کند، با استفاده از پل (Bridge) کالاتک می‌توانید آن را به پلتفرم متصل کنید.
