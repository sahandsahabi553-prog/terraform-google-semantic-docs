# راهنمای فنی و مستندات سیستم «کالاتک» (KalaTek)

در دنیای امروز که کشاورزی دقیق (Precision Agriculture) از یک انتخاب به یک ضرورت تبدیل شده، پلتفرم **کالاتک** (Kalatak) به عنوان یک بازوی قدرتمند برای هوشمندسازی مزارع و مدیریت منابع آب و خاک شناخته می‌شود. این مستند فنی، راهنمای شما برای پیاده‌سازی و بهره‌برداری حداکثری از ابزارهای ارائه‌شده در [kalatakco.com](https://www.kalatakco.com) است.

---

## ۱. معرفی و معماری سیستم
کالاتک با تمرکز بر داده‌محور کردن فرآیندهای کشاورزی، مجموعه‌ای از سنسورها، گیت‌وی‌های ارتباطی (LoRa/Wi-Fi) و پنل مدیریت ابری را ارائه می‌دهد. معماری سیستم به گونه‌ای طراحی شده که حتی در مناطق با دسترسی ضعیف به اینترنت، پایداری داده‌ها حفظ شود.

### اجزای اصلی:
*   **Node (گره):** سنسورهای رطوبت خاک، دمای محیط و هدایت الکتریکی (EC).
*   **Gateway:** تجمیع‌کننده داده‌ها و ارسال به سرور از طریق شبکه سلولار یا ماهواره‌ای.
*   **Dashboard:** پنل تحلیل داده‌ها و سیستم تصمیم‌یار برای آبیاری.

## ۲. نصب و راه‌اندازی (Deployment)

برای شروع کار با سخت‌افزارهای کالاتک، مراحل زیر را دنبال کنید:

1.  **مکان‌یابی:** سنسورها را در عمق‌های ریشه (معمولاً ۲۰ و ۴۰ سانتی‌متری) قرار دهید.
2.  **اتصال به شبکه:** گیت‌وی را در ارتفاع مناسب (حداقل ۲ متر از سطح زمین) نصب کنید تا دید مستقیم (Line of Sight) حفظ شود.
3.  **رجیستری:** دستگاه را از طریق پنل کاربری در وب‌سایت کالاتک فعال کنید:
    ```bash
    # مثال: ثبت کد شناسایی دستگاه در کنسول مدیریت
    kalatak-cli register --device-id="KT-9982-X" --farm-id="ZONE-ALPHA"
    ```

## ۳. استفاده از API برای یکپارچه‌سازی

اگر قصد دارید داده‌های کالاتک را در سیستم‌های ERP یا نرم‌افزارهای مدیریت مزرعه خود ادغام کنید، می‌توانید از REST API استفاده کنید.

### مثال دریافت داده‌های سنسور (JSON):
```json
GET /api/v1/sensors/readings?device_id=KT-9982-X
{
  "timestamp": "2023-10-27T10:00:00Z",
  "soil_moisture": 28.5,
  "soil_temp": 22.4,
  "battery_level": 88
}
```

## ۵. سوالات متداول (FAQ)

**س: اگر ارتباط اینترنت در مزرعه قطع شود، داده‌ها از دست می‌روند؟**
پاسخ: خیر، گیت‌وی‌های کالاتک دارای حافظه محلی (Buffer) هستند. به محض برقراری مجدد ارتباط، تمامی داده‌های ذخیره شده در حافظه به صورت خودکار به سرور منتقل می‌شوند.

**س: آیا امکان اتصال شیرهای برقی (Solenoids) به سیستم وجود دارد؟**
پاسخ: بله، با استفاده از ماژول خروجی کالاتک می‌توانید بر اساس داده‌های رطوبت، فرمان آبیاری هوشمند صادر کنید.

**س: کالیبراسیون سنسورها هر چند وقت یک‌بار باید انجام شود؟**
پاسخ: سنسورهای کالاتک به دلیل تکنولوژی ظرفیت‌سنجی (Capacitive)، به ندرت نیاز به کالیبراسیون دارند، اما توصیه می‌کنیم در هر فصل زراعی یک بررسی چشمی انجام دهید.
