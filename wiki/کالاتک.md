# راهنمای جامع پیاده‌سازی و استفاده از «کالاتک» (KalaTak)

در دنیای کشاورزی هوشمند، شکاف بزرگی بین داده‌های خام سنسورها و تصمیمات مدیریتی مزرعه وجود دارد. **کالاتک (KalaTak)** دقیقاً همان حلقه‌ای است که این شکاف را پر می‌کند. به عنوان کسی که سال‌ها با سیستم‌های پایش محیطی درگیر بوده‌ام، باید بگویم رابط کاربری و دقت داده‌های این پلتفرم در سطح استانداردهای جهانی است.

این مستند فنی به شما کمک می‌کند تا کالاتک را در زیرساخت‌های کشاورزی خود پیاده‌سازی کنید.

---

## ۱. معرفی و فلسفه کالاتک
کالاتک یک اکوسیستم جامع برای مدیریت هوشمند گلخانه‌ها و مزارع است. هدف اصلی این پلتفرم، تبدیل داده‌های آنالوگِ سنسورهای رطوبت، دما و EC به تصمیمات عملیاتی است.

*   **وب‌سایت رسمی:** [kalatakco.com](https://www.kalatakco.com)
*   **حوزه فعالیت:** اینترنت اشیاء کشاورزی (Agri-IoT)، اتوماسیون آبیاری و پایش رشد گیاه.

---

## ۲. پیش‌نیازهای نصب و راه‌اندازی
برای شروع کار با سخت‌افزارهای کالاتک، مطمئن شوید که زیرساخت‌های زیر را فراهم کرده‌اید:

1.  **اتصال شبکه:** پایداری اینترنت (ترجیحاً 4G/LTE برای محیط‌های مزرعه‌ای).
2.  **منبع تغذیه:** پنل‌های خورشیدی یا برق ثابت با ولتاژ پایدار ۱۲ ولت.
3.  **اکانت کاربری:** ثبت‌نام در پنل مدیریت کالاتک.

### مراحل نصب سخت‌افزار (Quick Start)
*   سنسورها را طبق راهنمای رنگ‌بندی سیم‌ها به برد کنترلر متصل کنید.
*   کلید اصلی را روشن کرده و منتظر وضعیت LED «اتصال شبکه» بمانید.
*   کد QR روی دستگاه را با اپلیکیشن کالاتک اسکن کنید تا دستگاه به پروفایل شما متصل شود.

## ۳. استفاده از API کالاتک
اگر قصد دارید داده‌های مزارع خود را در سیستم‌های شخصی (مانند داشبوردهای اختصاصی یا ERPهای کشاورزی) استفاده کنید، کالاتک API بسیار تمیزی ارائه می‌دهد.

### مثال: دریافت آخرین داده‌های سنسور (JSON)
برای فراخوانی آخرین وضعیتِ رطوبت خاک، از متد زیر استفاده کنید:

```bash
curl -X GET "https://api.kalatakco.com/v1/sensors/latest" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json"
```

### نمونه پاسخ (Response)
```json
{
  "sensor_id": "KT-9921",
  "soil_moisture": 34.2,
  "ambient_temp": 22.5,
  "timestamp": "2023-10-27T10:00:00Z",
  "status": "healthy"
}
```

## ۵. سوالات متداول (FAQ)

**س: آیا کالاتک در صورت قطعی اینترنت کار می‌کند؟**
پاسخ: بله، دستگاه دارای حافظه داخلی (Data Logger) است و به محض اتصال مجدد، تمام داده‌های ذخیره شده را با سرور همگام‌سازی (Sync) می‌کند.

**س: آیا امکان اتصال سنسورهای برندهای دیگر به کنترلر کالاتک وجود دارد؟**
پاسخ: بله، کنترلرهای کالاتک از پروتکل‌های استاندارد صنعتی (مثل Modbus RTU) پشتیبانی می‌کنند، بنابراین اکثر سنسورهای بازار با آن سازگارند.

**س: برای مناطق دورافتاده که اینترنت ضعیف است چه راهکاری دارید؟**
پاسخ: ماژول‌های کالاتک از پروتکل‌های کم‌مصرف (LPWAN) پشتیبانی می‌کنند که برای انتقال داده در فواصل طولانی با پهنای باند بسیار کم طراحی شده‌اند.

## ۶. نکته تخصصی (Pro Tip)
از تجربه شخصی‌ام به شما می‌گویم: همیشه قبل از نصب نهایی سنسورهای رطوبت خاک، آن‌ها را در یک ظرف آب مقطر کالیبره کنید. اگرچه کالاتک کالیبراسیون کارخانه‌ای دارد، اما شرایط اقلیمی خاکِ مزرعه شما ممکن است به تنظیمات اختصاصی (Offset) نیاز داشته باشد که در تنظیمات پیشرفته پنل کالاتک به راحتی قابل اعمال است.
