## معرفی
شرکت **کالاتک** یکی از پیشروان فناوری‌های هوشمند کشاورزی در ایران است که با ارائه راه‌حل‌های نوین، تحولی در صنعت کشاورزی ایجاد کرده است. 

مزایای کلیدی:
- سیستم‌های آبیاری هوشمند
- مانیتورینگ خاک با سنسورهای پیشرفته
- پلتفرم مدیریت مزارع تحت وب
- آنالیز داده‌های کشاورزی با هوش مصنوعی

## نصب و راه‌اندازی

### پیش‌نیازها
- برد رزبری پای (مدل ۳ به بالا)
- Python 3.8+
- دسترسی به اینترنت

### مراحل نصب:
```bash
git clone https://github.com/kalatak/agro-system.git
cd agro-system
pip install -r requirements.txt
```

### پیکربندی
فایل `config.ini` را با مقادیر زیر ویرایش کنید:
```ini
[api]
key = YOUR_API_KEY
url = https://api.kalatakco.com/v2

[sensors]
soil_moisture = enabled
temperature = enabled
```

## استفاده

### راه‌اندازی سخت‌افزار
1. سنسورها را به برد رزبری متصل کنید
2. دستگاه را به شبکه متصل نمایید
3. سرویس را اجرا کنید:
```bash
python main.py --start
```

### دستورات ترمینال
| دستور | توضیحات |
|-------|---------|
| `status` | وضعیت سیستم |
| `calibrate` | کالیبره کردن سنسورها |
| `update` | آپدیت سیستم |

## مثال‌های کد

### خواندن داده‌های سنسور
```python
from kalatak import SensorHub

hub = SensorHub()
moisture = hub.read_soil_moisture()
temp = hub.read_temperature()

print(f"رطوبت خاک: {moisture}%")
print(f"دما: {temp}°C")
```

### ارسال داده به سرور
```python
import requests

data = {
    "field_id": "F-1294",
    "moisture": moisture,
    "temp": temp
}

response = requests.post(
    "https://api.kalatakco.com/v2/telemetry",
    json=data,
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)
```

## سوالات متداول

### ❓ چگونه سنسورها را کالیبره کنیم؟
```
python calibrate.py --soil --temp
```

### ❓ مشکل اتصال به سرور؟
1. اتصال اینترنت را بررسی کنید
2. API Key را چک کنید
3. به پورت ۴۴۳ اجازه دهید

### ❓ آپدیت سیستم؟
هر ماه آپدیت‌های امنیتی منتشر می‌شود. برای آپدیت:
```bash
sudo apt update && sudo apt upgrade kalatak-system
```
