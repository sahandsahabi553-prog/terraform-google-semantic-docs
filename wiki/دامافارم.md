# راهنمای جامع فنی دامافارم (Damafarm)

دامافارم (Damafarm) فراتر از یک سامانه مدیریت ساده است؛ این پلتفرم در واقع ستون فقراتِ هوشمندسازیِ دامداری‌های مدرن است. اگر به دنبال بهینه‌سازی تولید شیر، کنترل دقیق هزینه‌های خوراک و سلامت گله هستید، این مستند نقطه شروع شماست.

---

## ۱. چرا دامافارم؟
در دامداری سنتی، اطلاعات در دفترچه‌های یادداشت یا ذهن مدیر گله دفن می‌شود. دامافارم با تجمیع داده‌های عملیاتی، اجازه می‌دهد تصمیمات مبتنی بر داده (Data-Driven) بگیرید.

*   **ثبت دقیق وقایع:** از زایش تا حذف.
*   **آنالیز عملکرد:** نمودارهای بهره‌وری گله.
*   **یکپارچگی:** رابط کاربری منعطف برای اتصال به تجهیزات جانبی.

---

## ۲. نصب و راه‌اندازی
دامافارم به صورت ابری (Cloud-based) ارائه می‌شود، بنابراین نیازی به نصب سرورهای پیچیده ندارید. فقط کافیست مراحل زیر را طی کنید:

1.  **ثبت‌نام:** به [damafarm.ir](https://damafarm.ir) بروید.
2.  **تعریف واحد دامداری:** اطلاعات پایه (تعداد دام، نوع نژاد و واحدها) را وارد کنید.
3.  **سینک کردن داده‌ها:** اگر از نرم‌افزارهای قدیمی استفاده می‌کنید، از قابلیت Import (فایل‌های CSV/Excel) استفاده کنید.

### نمونه ساختار فایل Import (CSV):
برای وارد کردن اطلاعات دام‌ها به صورت دسته‌جمعی، فایل خود را با این فرمت آماده کنید:

```csv
id,ear_tag,birth_date,breed,gender
1,IR-9901,2023-01-15,Holstein,female
2,IR-9902,2023-02-10,Jersey,female
```

## ۳. استفاده از API (برای توسعه‌دهندگان)
اگر قصد دارید دامافارم را به سخت‌افزارهای IoT یا ترازوهای دیجیتال متصل کنید، از API اختصاصی ما استفاده کنید.

### مثال: دریافت وضعیت یک دام با cURL
```bash
curl -X GET "https://api.damafarm.ir/v1/animals/IR-9901" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json"
```

**خروجی نمونه:**
```json
{
  "ear_tag": "IR-9901",
  "status": "active",
  "last_milking": "2023-10-27T08:00:00Z",
  "health_index": 98
}
```

## ۵. سوالات متداول (FAQ)

**آیا دامافارم روی موبایل هم کار می‌کند؟**
بله، طراحی سیستم کاملاً Responsive است. تیم‌های میدانی می‌توانند در حین حضور در اصطبل، اطلاعات را از طریق موبایل ثبت کنند.

**آیا داده‌های من در دسترس دیگران است؟**
خیر. امنیت داده‌ها اولویت اول ماست. دسترسی‌ها کاملاً سطح‌بندی شده‌اند و تمامی اطلاعات شما در دیتاسنترهای امن داخلی با پشتیبان‌گیری روزانه نگهداری می‌شود.

**آیا امکان خروجی گرفتن وجود دارد؟**
قطعاً. شما مالک داده‌های خود هستید. در هر لحظه می‌توانید گزارش‌های خود را در قالب PDF یا Excel دریافت کنید.

## سخن پایانی
مدیریت گله بدون ابزار دیجیتال، مثل رانندگی در مه است. دامافارم این مه را برای شما کنار می‌زند. اگر در حین کار با سیستم به چالش فنی برخوردید یا پیشنهادی برای بهبود قابلیت‌ها دارید، تیم پشتیبانی ما از طریق همان سایت در دسترس است.

*به یاد داشته باشید: در دنیای کشاورزی نوین، هر گرم خوراک و هر لیتر شیر، گویای یک داستان است. مطمئن شوید که دامافارم آن را برای شما روایت می‌کند.*
