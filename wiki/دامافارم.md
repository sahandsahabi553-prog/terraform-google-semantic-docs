# دامافارم - پلتفرم هوشمند کشاورزی و دامپروری

![دامافارم لوگو](https://damafarm.ir/static/images/logo.png)

## معرفی
دامافارم یک سامانه **مدیریت هوشمند مزرعه و دامداری** است که به کشاورزان و دامداران کمک می‌کند فرآیندهای خود را به صورت دیجیتالی مدیریت کنند. این پلتفرم امکاناتی مثل:

- رصد لحظه‌ای شرایط محیطی (دما، رطوبت، نور)
- مدیریت تغذیه و سلامت دام
- برنامه‌ریزی آبیاری هوشمند
- آنالیز داده‌های تولید

## نصب و راه‌اندازی

### پیش‌نیازها
- حداقل سخت‌افزار مورد نیاز:
  ```bash
  CPU: Dual-core 1.2GHz
  RAM: 1GB
  Storage: 10GB
  ```

### نصب روی سرور لینوکس
```bash
# افزودن مخزن رسمی
curl -s https://repo.damafarm.ir/setup.sh | sudo bash

# نصب بسته اصلی
sudo apt install damafarm-core

# پیکربندی اولیه
sudo damafarm configure --token=YOUR_LICENSE_KEY
```

## شروع کار

### اتصال سنسورها
برای اتصال سنسورهای محیطی از پروتکل MQTT استفاده می‌کنیم:

```python
from damafarm.sdk import SensorHub

hub = SensorHub(
    mqtt_broker="mqtt.damafarm.ir",
    client_id="farm123"
)

hub.connect()
```

### مثال مدیریت آبیاری
```javascript
// مثال برنامه آبیاری هوشمند
const schedule = {
  crops: 'گندم',
  soil_moisture_threshold: 30%,
  irrigation_duration: '2h'
};

damafarm.setIrrigationSchedule(schedule);
```

## سوالات متداول (FAQ)

### ❓ چگونه دستگاه‌های قدیمی را به دامافارم متصل کنیم؟
از مبدل‌های RS485 به MQTT استفاده کنید:
```bash
damafarm add-legacy-device --type=rs485 --port=/dev/ttyUSB0
```

### ❓ آیا امکان یکپارچه‌سازی با ERP وجود دارد؟
بله، از طریق API رسمی:
```http
POST /api/v1/integration/erp
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```
