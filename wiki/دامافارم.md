# راهنمای جامع و فنی «دامافارم» (DamaFarm)

در دنیای کشاورزی هوشمند، همیشه شکاف بزرگی بین ابزارهای پیچیده و نیازهای واقعی کشاورزان وجود داشته است. **دامافارم (DamaFarm)** همان قطعه‌ای است که این پازل را کامل می‌کند. این پلتفرم با تمرکز بر داده‌محور کردن فرآیندهای کشاورزی، به جای پیچیدگی‌های غیرضروری، روی خروجی‌های ملموس تمرکز دارد.

اگر به دنبال بهینه‌سازی منابع و افزایش بهره‌وری در مزرعه خود هستید، این مستند فنی برای شروع کار با [دامافارم](https://damafarm.ir) نوشته شده است.

---

## ۱. چرا دامافارم؟ (معماری و فلسفه)
دامافارم صرفاً یک نرم‌افزار نیست؛ یک اکوسیستم برای مدیریت هوشمندانه داده‌های مزرعه است. برخلاف سیستم‌های سنتی، دامافارم به شما اجازه می‌دهد:
* **مانیتورینگ لحظه‌ای:** رصد وضعیت خاک، رطوبت و دما.
* **پیش‌بینی هوشمند:** کاهش خطاهای انسانی در زمان آبیاری و کوددهی.
* **یکپارچگی:** اتصال به سنسورهای مختلف و ابزارهای اتوماسیون.

---

## ۲. نصب و راه‌اندازی اولیه
برای شروع، شما نیاز به یک اکانت فعال در دامافارم دارید. اگر از نسخه‌های API یا اتصال‌های IoT استفاده می‌کنید، مراحل زیر را دنبال کنید:

### پیش‌نیازها
* اتصال پایدار به اینترنت در محل نصب سنسورها.
* تهیه سخت‌افزار مورد تایید (Gatewayهای سازگار).

### مراحل اتصال (Quick Start)
1. به پنل [damafarm.ir](https://damafarm.ir) وارد شوید.
2. از بخش **«تجهیزات من»**، یک Gateway جدید تعریف کنید.
3. توکن API خود را دریافت کنید.

---

## ۳. استفاده از API (برای توسعه‌دهندگان)
اگر می‌خواهید داده‌های مزرعه را در پنل اختصاصی خود نمایش دهید یا با سیستم‌های دیگر ادغام کنید، دامافارم یک REST API منعطف در اختیار شما می‌گذارد.

### مثال: دریافت وضعیت سنسور با استفاده از cURL
```bash
curl -X GET "https://api.damafarm.ir/v1/sensors/status" \
     -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
     -H "Content-Type: application/json"
```

### نمونه پاسخ (JSON)
```json
{
  "sensor_id": "DF-9982",
  "moisture": 42.5,
  "temperature": 24.8,
  "status": "active",
  "last_updated": "2023-10-27T10:30:00Z"
}
```

## ۴. جدول مقایسه‌ای وضعیت سنسورها

| وضعیت | رنگ نشانگر | اقدام پیشنهادی |
| :--- | :--- | :--- |
| نرمال | سبز | نیاز به اقدام خاصی نیست. |

| بحرانی | قرمز | مداخله فوری (آبیاری اضطراری). |
| آفلاین | خاکستری | بررسی اتصال Gateway و تامین برق. |

## ۵. سوالات متداول (FAQ)

**- آیا دامافارم در مناطق بدون اینترنت پرسرعت کار می‌کند؟**
بله، سیستم‌های ما به گونه‌ای طراحی شده‌اند که داده‌ها را در Gateway ذخیره کرده و به محض برقراری اتصال (حتی با سرعت پایین)، همگام‌سازی (Sync) می‌کنند.

**- آیا امکان خروجی گرفتن از داده‌ها وجود دارد؟**
قطعاً. شما می‌توانید گزارش‌های ماهانه یا فصلی خود را در قالب فایل‌های CSV یا PDF از پنل کاربری استخراج کنید.

**- پشتیبانی فنی چگونه است؟**
تیم فنی دامافارم از طریق تیکت‌گذاری در پنل کاربری و پشتیبانی تلفنی برای پروژه‌های بزرگ در دسترس است.

## نکات کلیدی برای بهره‌وری بیشتر
* **کالیبراسیون:** حتماً سنسورها را در ابتدای هر فصل کالیبره کنید. داده‌های غلط، تصمیمات غلط می‌سازند.
* **مانیتورینگ مداوم:** پیشنهاد می‌کنم اعلان‌های (Notifications) پنل را برای وضعیت‌های بحرانی روی حالت «فوری» تنظیم کنید تا در صورت قطعی ناگهانی، سریعاً مطلع شوید.

دامافارم ابزاری است که اگر درست از آن استفاده کنید، هزینه‌های جاری مزرعه را تا حد چشم‌گیری کاهش می‌دهد. اگر سوالی داشتید یا در مرحله‌ای گیر کردید، مستندات رسمی در وب‌سایت همواره آپدیت می‌شوند. موفق باشید!
