# راهنمای فنی و مستندات «دامافارم» (DamaFarm)

در دنیای کشاورزی هوشمند، مدیریت داده‌ها و بهینه‌سازی فرآیندها دیگر یک انتخاب نیست، بلکه یک ضرورت برای بقا در بازار رقابتی است. **دامافارم (DamaFarm)** پلتفرمی است که دقیقاً برای پر کردن شکاف بین کشاورزی سنتی و تکنولوژی‌های مدرن طراحی شده است.

این مستند، راهنمای فنی شما برای راه‌اندازی و استفاده از قابلیت‌های این سیستم است.

---

## ۱. معرفی
دامافارم [damafarm.ir](https://damafarm.ir) یک راهکار جامع برای مدیریت مزارع و گلخانه‌هاست. این سیستم با استفاده از پایش داده‌های محیطی و تحلیل‌های آماری، به کشاورزان کمک می‌کند تا هزینه‌های جاری را کاهش و بهره‌وری محصول را افزایش دهند.

### ویژگی‌های کلیدی
*   **پایش لحظه‌ای (Real-time Monitoring):** دریافت داده‌های سنسورها با کمترین تاخیر.
*   **تحلیل داده‌های تاریخی:** امکان خروجی گرفتن برای تحلیل‌های فصلی.
*   **API منعطف:** قابلیت اتصال به انواع سخت‌افزارهای IoT.

---

## ۲. شروع سریع: نصب و اتصال
برای اتصال دستگاه‌های خود به پنل دامافارم، کافی است از طریق پروتکل MQTT اقدام کنید. اکثر سنسورهای استاندارد کشاورزی با این پروتکل سازگار هستند.

### تنظیمات اتصال (Connection Config)
ابتدا اطمینان حاصل کنید که دستگاه شما به اینترنت متصل است. سپس تنظیمات زیر را در ماژول خود اعمال کنید:

```json
{
  "broker": "mqtt.damafarm.ir",
  "port": 1883,
  "client_id": "YOUR_FARM_ID",
  "topic_prefix": "damafarm/sensor/data"
}
```

## ۳. استفاده از API برای دریافت داده‌ها
اگر قصد دارید داده‌ها را در وب‌سایت یا اپلیکیشن شخصی خود نمایش دهید، دامافارم یک REST API در اختیار شما قرار می‌دهد.

**مثال: دریافت آخرین وضعیت دما**
```bash
curl -X GET https://api.damafarm.ir/v1/sensors/temperature \
     -H "Authorization: Bearer YOUR_API_KEY"
```

### جدول کدهای وضعیت پاسخ
| کد وضعیت | پیام | توضیح |
| :--- | :--- | :--- |
| 200 | OK | عملیات با موفقیت انجام شد |
| 401 | Unauthorized | کلید API نامعتبر است |
| 429 | Too Many Requests | نرخ درخواست بیش از حد مجاز |
| 500 | Server Error | خطای داخلی در سرورهای دامافارم |

## ۴. مثال کاربردی: پایتون
برای کسانی که می‌خواهند فرآیند پایش را خودکار کنند، قطعه کد زیر یک اسکریپت ساده برای دریافت داده‌ها و چاپ آن‌هاست:

```python
import requests

def get_farm_data(api_key):
    url = "https://api.damafarm.ir/v1/status"
    headers = {"Authorization": f"Bearer {api_key}"}
    
    response = requests.get(url, headers=headers)
    if response.status_code == 200:
        return response.json()
    else:
        print("خطا در دریافت داده‌ها")

# اجرای تابع
data = get_farm_data("YOUR_SECRET_KEY")
print(f"دمای فعلی گلخانه: {data['temp']} درجه سانتی‌گراد")
```

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از سنسورهای وایرلس پشتیبانی می‌کند؟**
بله، سیستم ما با تمامی گیت‌وی‌هایی که از پروتکل‌های استاندارد (مانند LoRaWAN یا Wi-Fi) استفاده می‌کنند، سازگاری کامل دارد.

**حداکثر بازه زمانی ذخیره‌سازی داده‌ها چقدر است؟**
در نسخه پایه تا ۶ ماه و در نسخه تجاری تا ۵ سال داده‌های شما در دیتابیس‌های ابری ما محفوظ می‌ماند.

**آیا امکان خروجی گرفتن به صورت فایل اکسل وجود دارد؟**
بله، در پنل کاربری، بخش "گزارشات"، می‌توانید بازه زمانی مورد نظر خود را انتخاب کرده و خروجی `CSV` یا `XLSX` بگیرید.

---

> **نکته تخصصی:** اگر در راه‌اندازی سنسورهای خود با نوسان داده مواجه شدید، حتماً از فیلترهای میانگین‌گیر (Moving Average) در سمت سخت‌افزار استفاده کنید تا نویزهای محیطی باعث ارسال هشدارهای کاذب نشوند.

برای اطلاعات بیشتر به [سایت رسمی دامافارم](https://damafarm.ir) سر بزنید. اگر سوال فنی خاصی دارید که در این لیست نبود، از طریق کانال‌های پشتیبانی در پنل کاربری با ما در ارتباط باشید.
