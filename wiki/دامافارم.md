# راهنمای جامع فنی «دامافارم» (DamaFarm)

در دنیای کشاورزی هوشمند و دام‌پروری مدرن، مدیریت داده‌ها دیگر یک انتخاب نیست، بلکه یک ضرورت است. **دامافارم** پلتفرمی است که دقیقاً برای همین هدف طراحی شده؛ ایجاد پلی میان داده‌های خامِ مزرعه و تصمیمات استراتژیک مدیریتی.

اگر به دنبال راهکاری هستید که از سیستم‌های سنتی و کاغذبازی‌های قدیمی فاصله بگیرید، این مستند فنی نقشه راه شماست.

---

## ۱. معرفی دامافارم
دامافارم (به آدرس [damafarm.ir](https://damafarm.ir)) یک سیستم مدیریت یکپارچه دام‌پروری است که با تمرکز بر پایش سلامت، مدیریت تغذیه و بازدهی تولید توسعه یافته است. برخلاف سیستم‌های سنگین و قدیمی، دامافارم با رویکرد API-First ساخته شده تا به‌راحتی با سنسورهای اینترنت اشیاء (IoT) و سیستم‌های توزین متصل شود.

---

## ۲. پیش‌نیازها و نصب
از آنجایی که دامافارم یک سرویس ابری (SaaS) است، نیازی به نصب سرورهای پیچیده ندارید. با این حال، اگر قصد دارید از API آن برای شخصی‌سازی گزارش‌ها استفاده کنید، به موارد زیر نیاز دارید:

*   **Python 3.8+**
*   **API Key** (قابل دریافت از پنل کاربری)
*   **کتابخانه `requests`** برای برقراری ارتباط

### نحوه شروع سریع
برای اتصال به دیتابیس خودتان، کافیست یک کلاینت ساده بنویسید:

```python
import requests

API_URL = "https://api.damafarm.ir/v1"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY"}

def get_herd_stats():
    response = requests.get(f"{API_URL}/herd/summary", headers=HEADERS)
    return response.json()

print(get_herd_stats())
```

## ۴. مثال کاربردی: ثبت رکورد جدید
یکی از پرتکرارترین عملیات‌ها، ثبت رکورد سلامت برای یک دام خاص است. در اینجا نحوه انجام این کار از طریق Endpoint دامافارم آمده است:

```bash
curl -X POST https://api.damafarm.ir/v1/records \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "animal_id": "cow_001",
    "event": "vaccination",
    "date": "2023-10-27",
    "note": "واکسن تب برفکی - نوبت دوم"
  }'
```

## ۵. سوالات متداول (FAQ)

**آیا دامافارم آفلاین کار می‌کند؟**
در حال حاضر خیر. دامافارم برای همگام‌سازی داده‌های ابری به اینترنت نیاز دارد، اما در نسخه‌های آینده قابلیت "Local Cache" برای مناطق فاقد آنتن‌دهی اضافه خواهد شد.

**آیا می‌توانم داده‌های قدیمی‌ام را وارد کنم؟**
بله، تیم پشتیبانی دامافارم ابزارهای ایمپورت فایل‌های اکسل (Excel) را در پنل کاربری قرار داده است. کافیست فایل خود را با فرمت `.xlsx` آپلود کنید تا سیستم به‌صورت خودکار داده‌ها را پارس (Parse) کند.

**امنیت داده‌ها چگونه تضمین می‌شود؟**
تمامی ارتباطات از طریق پروتکل `HTTPS` رمزنگاری شده و بک‌آپ‌گیری روزانه در دیتاسنترهای داخلی انجام می‌گیرد.
