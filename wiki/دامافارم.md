# مستندات فنی و راهنمای جامع «دامافارم» (Damafarm)

**دامافارم** پلتفرمی است که دقیقاً برای پر کردن شکاف بین دانش سنتی کشاورزی و فناوری‌های مدرنِ داده‌محور طراحی شده. اگر با مدیریت مزارع هوشمند سر و کار داشته باشید، احتمالاً می‌دانید که بزرگترین چالش، «تفسیر داده» است، نه خودِ داده. دامافارم اینجاست تا این پیچیدگی را به یک داشبورد ساده و کاربردی تبدیل کند.

---

## ۱. چرا دامافارم؟ (دیدگاه فنی)
در دنیای کشاورزی هوشمند (Smart Agriculture)، ما با انبوهی از سنسورها (IoT) روبرو هستیم. دامافارم به عنوان یک لایه میان‌افزار (Middleware)، داده‌ها را از سنسورهای رطوبت، دما و EC خاک دریافت کرده و با تحلیل‌های اقلیمی ترکیب می‌کند.

*   **وب‌سایت رسمی:** [damafarm.ir](https://damafarm.ir)
*   **مزیت کلیدی:** قابلیت یکپارچه‌سازی با سیستم‌های آبیاری هوشمند.

---

## ۲. نصب و راه‌اندازی اولیه
برای شروع کار با زیرساخت‌های دامافارم، ابتدا باید دستگاه‌های خود را به پنل متصل کنید. روند کار بسیار سرراست است:

### مراحل اتصال سنسورها:
1.  **ثبت‌نام:** در سایت [damafarm.ir](https://damafarm.ir) یک حساب کاربری ایجاد کنید.
2.  **تعریف مزرعه:** یک بلوک جدید در پنل کاربری تعریف کنید (مختصات جغرافیایی دقیق بسیار مهم است).
3.  **اتصال API:** اگر از سخت‌افزارهای شخصی‌سازی شده استفاده می‌کنید، از کلید API اختصاصی خود برای ارسال داده‌ها استفاده کنید.

---

## ۳. استفاده از API (برای توسعه‌دهندگان)
اگر می‌خواهید داده‌های سنسورهای مزرعه خود را به صورت خودکار به سرورهای دامافارم ارسال کنید، می‌توانید از متد `POST` استفاده کنید.

**نمونه کد ارسال داده (Python):**

```python
import requests

url = "https://api.damafarm.ir/v1/sensor/push"
payload = {
    "farm_id": "FARM_123",
    "sensor_type": "soil_moisture",
    "value": 42.5,
    "timestamp": "2023-10-27T10:00:00Z"
}

headers = {"Authorization": "Bearer YOUR_API_KEY"}

response = requests.post(url, json=payload)
print(f"Status Code: {response.status_code}")
```

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از سخت‌افزارهای غیرایرانی هم پشتیبانی می‌کند؟**
بله، سیستم‌های دامافارم کاملاً ماژولار هستند. اگر پروتکل ارتباطی سنسور شما استاندارد باشد (مثل MQTT یا HTTP)، به راحتی با API ما هماهنگ می‌شود.

**داده‌ها در کجا ذخیره می‌شوند؟**
تمام داده‌های مزرعه شما در سرورهای ابری امن با پشتیبان‌گیری روزانه نگهداری می‌شوند تا در صورت بروز مشکل در سخت‌افزار، تاریخچه کشت شما از بین نرود.

**آیا امکان خروجی گرفتن (Export) از داده‌ها وجود دارد؟**
قطعاً. شما می‌توانید گزارش‌های فصلی را در قالب فایل‌های `CSV` یا `JSON` از پنل مدیریت دانلود کنید تا در نرم‌افزارهای آماری تحلیل کنید.
