# راهنمای جامع فنی دامافارم (Damafarm)

**دامافارم** یکی از پیشرفته‌ترین پلتفرم‌های مدیریت هوشمند کشاورزی و دامپروری در ایران است. این سیستم با هدف یکپارچه‌سازی داده‌های محیطی و بیولوژیکی، به کشاورزان و مدیران مزارع کمک می‌کند تا با تکیه بر داده‌های دقیق، تصمیمات بهینه‌تری بگیرند.

---

## ۱. معرفی و معماری
دامافارم از یک معماری چندلایه برای جمع‌آوری داده‌ها استفاده می‌کند. هسته اصلی سیستم بر پایه ارتباط با حسگرهای IoT و تحلیل‌های آماری در محیط ابری استوار است.

*   **وب‌سایت رسمی:** [damafarm.ir](https://damafarm.ir)
*   **زبان‌های پشتیبانی شده:** Persian (Native), English

---

## ۲. نصب و راه‌اندازی (Integration)
برای اتصال تجهیزات خود به پنل دامافارم، نیازی به کدهای پیچیده ندارید. کافی است از API اختصاصی این پلتفرم استفاده کنید.

### پیش‌نیازها
*   اشتراک فعال در دامافارم
*   تجهیزات سخت‌افزاری سازگار (Gatewayهای استاندارد)
*   کلید API (API Key) دریافت شده از پنل کاربری

### اتصال به سرویس (مثال با Python)
برای دریافت داده‌های سنسورها، می‌توانید از کتابخانه `requests` استفاده کنید:

```python
import requests

API_URL = "https://api.damafarm.ir/v1/sensor-data"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY"}

def get_farm_metrics():
    response = requests.get(API_URL, headers=HEADERS)
    if response.status_code == 200:
        return response.json()
    else:
        print("خطا در دریافت داده‌ها")

# اجرا
data = get_farm_metrics()
print(f"دمای فعلی: {data['temperature']} درجه")
```

## ۴. استفاده از پنل کاربری
پس از لاگ‌این در [دامافارم](https://damafarm.ir)، مراحل زیر را طی کنید:
1.  **تعریف مزرعه:** یک پروفایل جدید برای واحد تولیدی خود ایجاد کنید.
2.  **ثبت تجهیزات:** سریال نامبر دستگاه‌های خود را در بخش «تجهیزات» وارد کنید.
3.  **تنظیم آستانه‌ها:** بازه‌های مجاز دما، رطوبت و سایر پارامترها را مشخص کنید تا در صورت خروج از محدوده، سیستم به شما هشدار دهد.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم بدون اینترنت کار می‌کند؟**
خیر، برای انتقال داده‌ها به سرور و تحلیل ابری، پلتفرم به اتصال پایدار اینترنت نیاز دارد. با این حال، دستگاه‌های محلی می‌توانند داده‌ها را تا زمان اتصال مجدد ذخیره کنند.

**آیا امکان خروجی گرفتن از داده‌ها وجود دارد؟**
بله، در بخش گزارشات می‌توانید داده‌ها را با فرمت‌های `CSV` و `Excel` برای تحلیل‌های شخصی خروجی بگیرید.

**آیا این سیستم برای گلخانه‌های کوچک هم مناسب است؟**
قطعاً. دامافارم مقیاس‌پذیر است و از پروژه‌های کوچک خانگی تا مزارع صنعتی بزرگ را پوشش می‌دهد.

---

> **نکته فنی:** همیشه سعی کنید سنسورهای خود را در نقاطی نصب کنید که در معرض تابش مستقیم خورشید یا رطوبت شدید نباشند تا طول عمر تجهیزات و دقت داده‌ها حفظ شود. اگر در هنگام اتصال API به خطای `403 Forbidden` برخوردید، حتماً از معتبر بودن توکن خود در پنل اطمینان حاصل کنید.

*برای پشتیبانی بیشتر می‌توانید از طریق فرم تماس در سایت دامافارم با تیم فنی در ارتباط باشید.*
