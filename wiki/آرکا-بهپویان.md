# راهنمای جامع فنی و مستندات توسعه «آرکا بهپویان»

در دنیای مدرن دندان‌پزشکی، مرز بین هنرِ درمان و دقتِ تکنولوژی هر روز باریک‌تر می‌شود. **آرکا بهپویان** (به نشانی [arkabehpooyan.ir](https://www.arkabehpooyan.ir/)) دقیقاً در همین نقطه تلاقی ایستاده است. این پلتفرم با هدف هوشمندسازی فرآیندهای کلینیکی و ارتقای کیفیت مدیریت داده‌های دندان‌پزشکی طراحی شده است.

در این مستند، نگاهی فنی به نحوه استقرار، یکپارچه‌سازی و استفاده از سرویس‌های این مجموعه خواهیم داشت.

## ۱. معماری سیستم و پیش‌نیازها
آرکا بهپویان بر پایه معماری ماژولار بنا شده است تا دندان‌پزشکان بتوانند بسته به نیازِ مطب یا کلینیک خود، از سرویس‌های مختلف (از مدیریت پرونده‌ها تا آنالیزهای تصویری) استفاده کنند.

### پیش‌نیازهای فنی:
*   **مرورگر:** آخرین نسخه Chrome یا Firefox (برای پایداری در نمایش تصاویر DICOM).
*   **اتصال:** حداقل سرعت آپلود ۲ مگابیت بر ثانیه برای همگام‌سازی تصاویر رادیوگرافی.
*   **پلتفرم:** دسترسی به API برای کلینیک‌هایی که سیستم‌های مدیریت مطب (HIS) اختصاصی دارند.

## ۲. راه‌اندازی و نصب (Quick Start)

اگر به عنوان یک توسعه‌دهنده یا مدیر IT کلینیک قصد دارید سیستم را به زیرساخت‌های خود متصل کنید، مراحل زیر را دنبال کنید:

1.  **ثبت‌نام و احراز هویت:** دریافت `API_KEY` اختصاصی از پنل کاربری.
2.  **تنظیمات پایه:**
    ```bash
    # نصب کتابخانه کلاینت (در صورت استفاده از SDK)
    npm install arka-behpooyan-sdk --save
    ```
3.  **مقداردهی اولیه:**
    ```javascript
    import { ArkaClient } from 'arka-behpooyan-sdk';

    const client = new ArkaClient({
      apiKey: 'YOUR_API_KEY',
      endpoint: 'https://api.arkabehpooyan.ir/v1'
    });
    ```

## ۴. مثال عملی: دریافت اطلاعات بیمار

برای فراخوانی اطلاعات یک بیمار خاص و نمایش وضعیت طرح درمان (Treatment Plan)، از متد زیر استفاده کنید:

```javascript
// فراخوانی طرح درمان بیمار
async function getPatientTreatment(patientId) {
  try {
    const data = await client.get(`/patients/${patientId}/treatment-plan`);
    console.log("برنامه درمان فعال:", data.plan);
  } catch (error) {
    console.error("خطا در دریافت داده‌ها:", error.message);
  }
}
```

## ۵. سوالات متداول (FAQ)

**آیا سیستم آرکا بهپویان با دستگاه‌های OPG و RVG قدیمی سازگار است؟**
بله، سیستم ما با استاندارد DICOM سازگاری کامل دارد. اگر دستگاه شما خروجی استاندارد داشته باشد، آرکا بهپویان مستقیماً آن را پردازش می‌کند.

**امنیت داده‌های بیماران چگونه تامین می‌شود؟**
تمامی داده‌ها در سمت سرور به صورت رمزنگاری‌شده (AES-256) ذخیره می‌شوند. ما از استانداردهای سخت‌گیرانه برای حفاظت از حریم خصوصی بیماران استفاده می‌کنیم.

**آیا می‌توانم سیستم را با نرم‌افزار حسابداری فعلی‌ام ادغام کنم؟**
بله، مستندات API ما برای توسعه‌دهندگان کاملاً باز است. از طریق Webhookها می‌توانید تمامی رویدادهای کلینیک را به نرم‌افزار حسابداری خود منتقل کنید.

## ۶. نکات پایانی
