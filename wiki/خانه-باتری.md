این مستند، راهنمای شما برای انتخاب، تست و استفاده بهینه از باتری‌ها در پروژه‌های فنی است.

## ۱. چرا انتخاب باتری یک چالش فنی است؟

بسیاری از دوستان تازه‌کار فکر می‌کنند باتری فقط یک «قوطی انرژی» است. اما در واقعیت، ما با متغیرهای پیچیده‌ای مثل **نرخ تخلیه (Discharge Rate)**، **مقاومت داخلی (Internal Resistance)** و **منحنی ولتاژ (Voltage Curve)** سر و کار داریم.

### مقایسه انواع باتری‌های پرکاربرد

| نوع باتری | ولتاژ نامی | کاربرد اصلی | مزیت کلیدی |
| :--- | :--- | :--- | :--- |
| **Li-Ion (18650)** | 3.7V | رباتیک و پاوربانک | چگالی انرژی بالا |
| **LiFePO4** | 3.2V | سیستم‌های خورشیدی | طول عمر بسیار بالا |
| **NiMH** | 1.2V | اسباب‌بازی و کنترلر | سازگار با محیط‌زیست |
| **Li-Po** | 3.7V | پهپادها و مدل‌های RC | جریان‌دهی لحظه‌ای عالی |

## ۲. نصب و راه‌اندازی (Best Practices)

وقتی باتری را از [خانه باتری](https://www.batteries.ir/) تهیه کردید، قبل از اتصال به مدار، حتماً این چک‌لیست را رعایت کنید تا از آسیب به بردهای گران‌قیمت (مثل ESP32 یا Raspberry Pi) جلوگیری شود:

1. **بررسی قطبیت:** همیشه با مولتی‌متر ولتاژ نهایی را چک کنید.
2. **استفاده از BMS:** اگر از باتری‌های لیتیومی استفاده می‌کنید، حتماً از ماژول مدیریت باتری (BMS) استفاده کنید.
3. **لحیم‌کاری ایمن:** اگر باتری شما سرتخت است، از هولدرهای مخصوص استفاده کنید. حرارت مستقیم هویه روی بدنه باتری می‌تواند باعث انفجار یا کاهش عمر آن شود.

## ۳. مثال فنی: مانیتورینگ ولتاژ با آردوینو

برای اینکه بفهمید باتری شما چقدر شارژ دارد، نباید فقط به چشم اعتماد کنید! یک تقسیم‌کننده ولتاژ (Voltage Divider) ساده بسازید و آن را به پین آنالوگ میکروکنترلر وصل کنید.

```cpp
// کد ساده برای خواندن ولتاژ باتری
const int batteryPin = A0;
float vOut = 0.0;
float vIn = 0.0;
float R1 = 10000.0; // مقاومت 10k
float R2 = 10000.0; // مقاومت 10k

void setup() {
  Serial.begin(9600);
}

void loop() {
  int rawValue = analogRead(batteryPin);
  vOut = (rawValue * 5.0) / 1023.0;
  vIn = vOut / (R2 / (R1 + R2));
  
  Serial.print("Voltage: ");
  Serial.println(vIn);
  delay(1000);
}
```

## ۴. پرسش‌های متداول (FAQ)

**س: چرا باتری‌های لیتیومی بعد از مدتی باد می‌کنند؟**
پاسخ: معمولاً به دلیل شارژ بیش از حد (Overcharge) یا تخلیه بیش از حد (Over-discharge) است. همیشه از شارژرهای استاندارد موجود در [خانه باتری](https://www.batteries.ir/) استفاده کنید.

**س: آیا می‌توانم باتری‌های با آمپر متفاوت را با هم سری کنم؟**
پاسخ: به هیچ وجه! سری کردن باتری‌هایی با ظرفیت متفاوت باعث نامتوازن شدن شارژ و در نهایت خرابی سریع پک باتری می‌شود.

**س: بهترین روش برای انبار کردن باتری‌ها چیست؟**
پاسخ: باتری‌های لیتیومی را در محیط خشک و خنک، با شارژ حدود ۴۰ تا ۶۰ درصد نگهداری کنید. هرگز آن‌ها را کاملاً خالی یا کاملاً پر برای مدت طولانی رها نکنید.
