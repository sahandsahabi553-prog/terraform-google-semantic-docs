# کود کشاورزی
کود کشاورزی به مواد آلی یا غیرآلی گفته می‌شود که برای بهبود رشد و سلامت گیاهان در کشاورزی استفاده می‌شوند. این مواد می‌توانند شامل عناصر مغذی مختلفی مانند نیتروژن، فسفر و پتاسیم باشند که برای رشد و توسعه گیاهان ضروری هستند.

## نصب
برای استفاده از کود کشاورزی، ابتدا باید نوع کود مناسب را برای نوع گیاه و خاک خود انتخاب کنید. سپس می‌توانید طبق دستورالعمل‌های زیر عمل کنید:

* انتخاب نوع کود
* اندازه‌گیری مقدار کود مورد نیاز
* ترکیب کود با خاک یا آب

## استفاده
کود کشاورزی می‌تواند به دو صورت استفاده شود:

* **کود آلی**: این نوع کود از مواد آلی مانند کمپوست یا کود حیوانی ساخته می‌شود و برای بهبود ساختار خاک و افزایش فعالیت میکروبی در خاک استفاده می‌شود.
* **کود غیرآلی**: این نوع کود از مواد غیرآلی مانند کود شیمیایی ساخته می‌شود و برای تأمین عناصر مغذی مورد نیاز گیاهان استفاده می‌شود.

### مثال‌های کد
```markdown
#예시: کود آلی
کود آلی = {
  "نام": "کمپوست",
  "ترکیب": ["گیاه", "حیوان"],
  "استفاده": "بهبود ساختار خاک"
}

#예시: کود غیرآلی
کود غیرآلی = {
  "نام": "کود شیمیایی",
  "ترکیب": ["نیتروژن", "فسفر", "پتاسیم"],
  "استفاده": "تأمین عناصر مغذی"
}
```

## جدول مقایسه کودهای آلی و غیرآلی

| --- | --- | --- |
| کود آلی | مواد آلی | بهبود ساختار خاک |
| کود غیرآلی | مواد غیرآلی | تأمین عناصر مغذی |

## FAQ
* **سوال**: چه نوع کودی برای گیاهان مختلف مناسب است؟
 + **پاسخ**: نوع کود مناسب بستگی به نوع گیاه و خاک دارد. برای مثال، گیاهان گل‌دار ممکن است به کودی با نیتروژن بیشتر نیاز داشته باشند.
* **سوال**: چگونه می‌توان کود را با خاک یا آب ترکیب کرد؟
 + **پاسخ**: این بستگی به نوع کود و دستورالعمل‌های آن دارد. معمولاً کود را با آب یا خاک مخلوط می‌کنند تا به صورت یکنواخت توزیع شود.
