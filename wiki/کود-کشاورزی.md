## مقدمه
کود کشاورزی مکمل غذایی گیاهه؛ درست مثل ویتامین برای آدم. اگه کم بدی، رشد می‌کنه ولی محصول‌دهی پایین میاد؛ اگه زیاد بریزی، نه‌تنها گیاه می‌سوزه بلکه خاک رو هم شور می‌کنه. هدف از این داک، کمک به شماست تا بدون نیاز به کارشناس، خودتون دوز مناسب رو حساب و اجرا کنید.

## انواع کود‌ها

### ۱. کود‌های آلی (Organics)
- **کود دامی پوسیده**  
- کمپوست سبزی‌و‌میوه  
- کرم‌کود (Vermicompost)  
- مزایا: بهبود ساختمان خاک، آزادسازی آهسته عناصر  
- معایب: حجم بالا، تجزیه کُند، احتمال انتقال علف‌هرز یا بیماری

### ۲. کود‌های شیمیایی (Granular & Water-Soluble)
| نوع | N | P | K | کاربرد اصلی |
|-----|---|---|---|-------------|
| اوره | 46 | 0 | 0 | محرک رشد سبزینگی |
| سوپر‌فسفات | 0 | 20 | 0 | ریشه‌دهی قوی |
| سولفات‌پتاسیم | 0 | 0 | 50 | افزایش کیفیت و مقاومت به خشکی |
| کامل ۲۰-۲۰-۲۰ | 20 | 20 | 20 | تهیه‌مطلب سرعت بالا در گلخانه |

### ۳. کود‌های زیستی (Biofertilizers)
- ازوباکتر، ریزوبیوم، باسیلوس  
- قارچ میکوریزا  
- نیاز به دمای خاک ۱۵ تا ۲۸ °C و رطوبت ۶۰٪ ظرفیت مزرعه

## نصب و آماده‌سازی سیستم تزریق

### A. ابزار لازم
- منبع تزریق (تانک پلی‌اتیلن ۵۰۰ تا ۱۰۰۰ L)  
- همزن مکانیکی یا برقی (±۳۰۰ rpm)  
- شیر‌ تاجی برنجی ۱/۲ اینچ  
- فلومتر دیجیتال (۰–۱۰۰ L min⁻¹)  
- شیلنگ تزئینی UV-Resistant  
- فیلتر ۱۲۰ مِش در مسیر خروجی

### B. مراحل نصب
1. تانک رو روی سکویی ۶۰ cm ارتفاع قرار بدید تا گرانش باز هم کمک کنه.  
2. ورودی آب سالم (EC<0.6) رو به پایین‌ترین نقطه تانک وصل کنید.  
3. همزن رو ۱۵° زاویه بزنید تا چرخش محوری ایجاد بشه.  
4. فلومتر رو **بعد از فیلتر** نصب کنید تا ذرات کود باعث گرفتگی حسگر نشه.  
5. خروجی نهایی رو به لوله اصلی آبیاری قطره‌ای یا بارانی متصل کنید.

## محاسبه دوز دقیق

### فرمول کلاسیک
```math
Q = (C × A × I) / (10 × ρ)
```
- Q: مقدار کود خالص (kg)  
- C: غلظت مورد نیاز در محلول (g L⁻¹)  
- A: مساحت مزرعه (m²)  
- I: مقدار آبدهی (mm)  
- ρ: چگالی کود (برای اوره ≈ 1.32 g cm⁻³)

### مثال عملی
**سناریو:** ۱ هکتار گوجه‌فرنگی گلخانه‌ای، نیاز به محلول ۲ g L⁻¹ کود کلاسیک ۲۰-۲۰-۲۰. آبیاری قطره‌ای، ۸ mm آبدهی.

```
Q = (2 × 10 000 × 8) / (10 × 0.75) ≈ ۲۱۳۳ kg
```

> نکته: چون کود کامل گرانوله، عملاً ۲.۱۳ کیسه ۲۵ کیلویی برابر با ۵۳ کیلوگرم کود خشک برای کل سیکل می‌خواید.

## کدنویسی برای اتوماسیون تغذیه

### زبان Python + Raspberry Pi
```python
import time
from gpiozero import OutputDevice
import board
import busio
import adafruit_ads1x15.ads1115 as ADS
from adafruit_ads1x15.analog_in import AnalogIn

# پین‌‌های خروجی
valve_water = OutputDevice(17)   # شیر آب
valve_fert  = OutputDevice(27) # شیر کود
agitator    = OutputDevice(22) # همزن

# ADC خواندن EC سنسور
i2c = busio.I2C(board.SCL, board.SDA)
ads = ADS.ADS1115(i2c)
chan = AnalogIn(ads, ADS.P0)

def read_ec():
    # تبدیل ولتاژ به هدایت الکتریکی (mS cm⁻¹)
    return chan.voltage * 2.1

def fertigation_cycle(target_ec=2.2, duration_min=30):
    agitator.on()
    valve_water.on()
    start = time.time()
    while (time.time() - start) < duration_min*60:
        if read_ec() < target_ec - 0.1:
            valve_fert.on()
        elif read_ec() > target_ec + 0.1:
            valve_fert.off()
        time.sleep(5)
    valve_water.off(); valve_fert.off(); agitator.off()

if __name__ == '__main__':
    fertigation_cycle()
```

> خروجی رو می‌تونید با MQTT به ThingsBoard بفرستید تا ریموت مانیتور داشته باشید؛ من توی مزرعه کویرم با این روش ۲۳٪ کود کمتری مصرف کردم.

## نکات کلیدی ایمنی
1. **همیشه** عینک و دستکش نیتریل بزنید؛ اوره روی پوست به اسید اوریک تبدیل می‌شه و خارش شدید میاره.  
2. محلول‌های غلیظ رو توی ظرف فلزی نریزید؛ فسفات‌ها با آهن ترکیب رسوبی ایجاد می‌کنن و باعث گرفتگی.  
3. کود زیستی رو با آب کلردار (نیتریت <۰.۵ ppm) مخلوط نکنید؛ کلر باکتری‌ها رو از بین می‌بره.  
4. قبل از ذخیره در انبار، رطوبت نسبی رو زیر ۶۰٪ نگه دارید؛ گرانول‌های نیترات در رطوبت بالا سفت می‌شن و دیگه حل نمی‌شن.  
5. در تانکر تزریق، فضای خالی حداقل ۱۰٪ برای انبساط نگه دارید؛ گرمای روز می‌تونه فشار داخلی رو بالا ببره.

## سؤالات متداول (FAQ)

**س1:** چرا برگ‌های خیارم زرد شد ولی کود کامل دادم؟  
**ج1:** احتمالاً pH خاک بالای ۷.۸ هست و آهن قفل شده. از کلات آهن ۶٪ محلول‌پاشی ۲ g L⁻¹ استفاده کنید.

**س2:** می‌تونم اوره رو با سم قارچ‌کش تانک میکس کنم؟  
**ج2:** اکثر قارچ‌کش‌ها (به‌ویژه بنومیل) در pH بالا تجزیه می‌شن؛ اگه pH محلول زیر ۶.۵ هست و تانک رو فوری مصرف می‌کنید، مشکلی نداره ولی تست سازگاری رو فراموش نکنید.

**س3:** چه ساعتی از روز بهترین زمان تزریقِ محلوله؟  
**ج3:** ساعت ۵ تا ۷ صبح؛ هم تبخیر کمتره هم فرصت جذب قبل از اوج نور رو دارید.

**س4:** آیا کود دامی خام می‌ریزید یا باید کمپوست بشه؟  
**ج4:** به‌هیچ‌وجه خام نریزید؛ NH₄⁺ به NH₃ تبدیل می‌شه و ریشه رو می‌سوزونه. حداقل ۶ ماه بی‌هوازی یا ۳ ماه هوازی (چرخش هفتگی) کمپوست کنید.

**س5:** برای سبزی‌های برگی (کاهو، اسفناج) چه کودی پیشنهاد می‌کنید؟  
**ج5:** ۸۰٪ نیاز نیتروژن رو از کود دامی پوسیده + ۲۰٪ از نیترات کلسیم در سه مرحله‌ی ساقه‌دهی بدهید؛ پتاسیم بالا باعث تلخی برگ می‌شه.
