## مقدمه: چرا کود؟
خاک ایران تقریباً ۸۰٪ از عناصر اصلی رو از دست داده. من تو مناطق جنوبی فارس دیدم حتی با وجود آب کافی، برگ درخت خرما به‌خاطر فقر روی نمی‌وهه! کود صرفاً «تقویت» نیست؛ جایگزین‌کردن ذخیره‌ایِ خاکه که طی ۵۰ سال از دست رفته.

### اعداد کلیدی
| عنصر | میانگین در خاک ایران (ppm) | حد مطلوب (ppm) |
|------|----------------------------|----------------|
| نیتروژن کل | 0.05 | 0.15 |
| فسفر قابل جذب | 3.2 | 15 |
| پتاسیم مبادله‌ای | 120 | 250 |

## انواع کودها
### ۱. کودهای آلی (ORG)
- کمپوست: حداقل ۶ ماه پوسیده
- کود دامی پوسیده: نسبت C/N زیر ۲۰
- کود سبز: عدس، شبدر، ماش

### ۲. کودهای شیمیایی (MIN)
| نوع | فرمول | درصد عنصر | کاربرد اصلی |
|-----|--------|-----------|-------------|
| اوره | CO(NH₂)₂ | ۴۶٪ N | سرعت بالا |
| سوپر فسفات | Ca(H₂PO₄)₂ | ۲۰٪ P₂O₅ | ریشه‌زایی |
| سولفات پتاسیم | K₂SO₄ | ۵۰٪ K₂O | میوه‌دهی |

### ۳. کودهای زیستی (BIO)
- ازتوباکتر، سودوموناس، باسیلوس
- قارچ‌های میکوریزا برای جذب فسفر

## مثال‌های کدی: محاسبهٔ نیاز نیتروژن گندم
### تابع رشد پتانسیل (logistic)
```python
def lgc(t, t0=50, k=0.15, ymax=12):
    """t: روز بعد از کاشت"""
    return ymax / (1 + np.exp(-k*(t - t0)))
```

### الگوریتم تفکیک در سه مرحله
```python
def split_n(total, sow_date):
    t1 = sow_date + timedelta(days=60)   # tillering
    t2 = sow_date + timedelta(days=120) # shooting
    t3 = sow_date + timedelta(days=180)  # heading
    w1 = 0.45 * lgc(60)
    w2 = 0.35 * lgc(120)
    w3 = 0.20 * lgc(180)
    wt = w1 + w2 + w3
    return {
        "tillering": round(total * w1/wt, 1),
        "shooting":  round(total * w2/wt, 1),
        "heading":   round(total * w3/wt, 1)
    }
```

### یکپارچه‌سازی با Weather API
```python
def adjust_by_rain(split_dict, forecast):
    """اگه بارش هفتهٔ آینده > ۲۰mm ۱۰٪ کاهش"""
    if forecast.precip_7d > 20:
        split_dict["tillering"] *= 0.9
    return {k: round(v, 1) for k, v in split_dict.items()}
```

## نکات ایمنی و محیط‌زیست
- فاصله با آب‌های سطحی حداقل ۲۰m
- استفاده از ضدجوشک‌های فروکروم در کارخانه → کاهش کروم شش‌ظرفیتی
- **قاعدهٔ 4R**:
  1. Right source
  2. Right rate
  3. Right time
  4. Right place

| آلاینده | حد مجاز خروجی (mg/L) | روش حذف |
|---------|----------------------|----------|
| نیترات | 45 | دنیترification با کربن |
| فسفر کل | 2 | انعقاد FeCl₃ |

## عیب‌یابی و خطایابی
### مشکل: زردشدن نوک برگ بعد کوددهی
**علت احتمالی:** آمونیوم toxicity
**راه‌حل سریع:** آبدهی سنگین + کلسیم نیترات

### مشکل: رسوب و گرفتگی درراه آبیاری قطره‌ای
**علت:** کود فسفاته + آب با pH>8
**راه‌حل:** اسیدسولفونیک ۶۵% تا pH=6

### لاگ خطای API

  "detail": "soil_test.K must be <= 600 mg/kg"

## سوالات متداول
1. **آیا می‌تونم کود آلی و شیمیایی رو هم‌زمان بدم؟**  
   بله، ولی اگه کود دامی تازه دارید، حداقل ۲ هفته فاصله بندازید تا چسبندگی کود شیمیایی به‌هم نخوره.

2. **چرا کود کامل ده‌ده‌ده (NPK 10-10-10) توصیه نمی‌شه؟**  
   چون خاک ما معمولاً فقیر فسفره؛ دادن اون ۱۰٪ اضافه باعث قفل شدن روی و آهن می‌شه.

3. **تفاوت اوره و نیترات آمونیم چیه؟**  
   اوره ارزون‌تره ولی نیاز به آنزیم یوراز داره که توی دمای زیر ۱۲° فعال نیست؛ بهار زود همراه بذر کاری نریزید.

4. **چقدر زود می‌تونم پس از کوددهی محصول بچینم؟**  
   برای کودهای شیمیایی حداقل ۲ تا ۳ آبیاری تا عمق ۳۰cm؛ برای کود زیستی ۱۰ روز.
