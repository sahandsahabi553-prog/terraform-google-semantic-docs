# قمر (Qamar): پلی میان داده‌های پراکنده و تحلیل‌های عمیق

در دنیای امروز، مشکل ما کمبود داده نیست؛ مشکل «جزیره‌ای بودن» داده‌هاست. ما با انبوهی از یادداشت‌ها، قطعه‌کدها، مقالات علمی و تحلیل‌های شخصی روبرو هستیم که هیچ ارتباط ارگانیکی با هم ندارند. **قمر** دقیقاً برای حل همین معضل ساخته شده است. این ابزار نه فقط یک پلتفرم برای ذخیره‌سازی، بلکه یک اکوسیستم بین‌رشته‌ای (Interdisciplinary) است که به شما اجازه می‌دهد بین مفاهیم حوزه‌های مختلف، پل‌های منطقی بزنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر متفاوت است؟

بیشتر ابزارهای مدیریت دانش (KM) مثل یک انبار عمل می‌کنند. قمر مثل یک «مغز دوم» عمل می‌کند. اگر روی یک پروژه هوش مصنوعی کار می‌کنید که نیاز به درک عمیق از ریاضیات محض یا فلسفه ذهن دارد، قمر به شما کمک می‌کند این نقاط را به هم متصل کنید.

### ویژگی‌های کلیدی:
* **ساختار مبتنی بر گراف (Graph-based):** به جای پوشه‌بندی سنتی، از روابط بین یادداشت‌ها استفاده می‌کند.
* **پشتیبانی بومی از فرمول‌های ریاضی و کد:** عالی برای کارهای مهندسی و آکادمیک.
* **محیط مینیمال و متمرکز:** برای اینکه غرق در تنظیمات نشوید.

## نصب و راه‌اندازی

قمر به گونه‌ای طراحی شده که با ابزارهای مدرن شما همخوانی داشته باشد. اگر از کاربران لینوکس یا مک هستید، کار با آن بسیار لذت‌بخش است.

### پیش‌نیازها
مطمئن شوید که نسخه‌ی نود (Node.js) شما به‌روز است:
```bash
node -v # پیشنهاد می‌شود نسخه 18 به بالا باشد
```

### نصب از طریق CLI
بهترین راه برای شروع کار با نسخه توسعه‌دهنده، استفاده از دستور زیر است:

```bash
npm install -g @qamar/cli
qamar init my-project
cd my-project
qamar start
```

## مثال کاربردی: ایجاد یک رابطه بین‌رشته‌ای

فرض کنید می‌خواهید یک یادداشت درباره «نظریه اطلاعات» بنویسید و آن را به «فلسفه زبان» وصل کنید. ساختار فایل Markdown شما در قمر به شکل زیر خواهد بود:

```markdown
---
id: info-theory-01
tags: [math, philosophy]
links: [lang-philosophy-05]
---

# نظریه اطلاعات شانون

در اینجا به بررسی آنتروپی می‌پردازیم. طبق فرمول شانون:
$$ H(X) = -\sum_{i=1}^{n} P(x_i) \log_2 P(x_i) $$

این مفهوم شباهت عجیبی به [[lang-philosophy-05]] دارد که در آن معنا را ناشی از کاهش عدم قطعیت می‌دانیم.
```

## سوالات متداول (FAQ)

**۱. آیا داده‌های من در قمر خصوصی باقی می‌مانند؟**
بله، قمر بر مبنای فایل‌های محلی (Local-first) طراحی شده است. هیچ سروری به محتوای شما دسترسی ندارد مگر اینکه خودتان بخواهید آن را همگام‌سازی (Sync) کنید.

**۲. آیا می‌توانم داده‌هایم را از Obsidian وارد کنم؟**
قطعا. قمر از فرمت Markdown استاندارد استفاده می‌کند؛ بنابراین کافی است پوشه یادداشت‌های خود را در قمر باز کنید.

**۳. قمر برای چه کسانی مناسب است؟**
برای پژوهشگران، دانشجویان دکتری، توسعه‌دهندگان نرم‌افزار و نویسندگانی که با حجم عظیمی از اطلاعات متناقض یا چند‌رشته‌ای سر و کار دارند.
