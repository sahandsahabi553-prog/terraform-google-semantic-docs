# راهنمای جامع پلتفرم «قمر» (Qamar)

در دنیای پیچیده داده‌های میان‌رشته‌ای (Interdisciplinary)، همیشه بزرگترین چالش، «پل زدن» بین حوزه‌های مختلف است. وقتی صحبت از تحلیل داده‌های متنی یا ساختارهای دانش‌محور می‌شود، اکثر ابزارها یا بیش از حد تخصصی هستند و یا آنقدر ساده که عملاً کارایی ندارند. اینجا جایی است که **قمر** وارد می‌شود.

قمر یک بستر هوشمند برای مدیریت و تحلیل داده‌های چندوجهی است که طراحی شده تا شکاف بین علوم انسانی و مهندسی داده را پر کند.

---

## ۱. چرا قمر؟ (فلسفه پروژه)
پروژه قمر ([qamar.website](https://qamar.website)) صرفاً یک کتابخانه یا ابزار نیست؛ یک رویکرد است. اگر شما درگیر پروژه‌هایی هستید که در آن‌ها متن‌های کلاسیک، داده‌های ساختاریافته و تحلیل‌های آماری در هم تنیده شده‌اند، قمر برای شما ساخته شده.

### ویژگی‌های کلیدی:
*   **انعطاف‌پذیری:** پشتیبانی از فرمت‌های داده‌ای متنوع.
*   **سرعت:** بهینه‌سازی شده برای پردازش‌های سنگین روی متون بزرگ.
*   **یکپارچگی:** رابط کاربری (API) تمیز که به راحتی در پایپ‌لاین‌های موجود شما می‌نشیند.

---

## ۲. نصب و راه‌اندازی (Quick Start)

برای شروع، نیازی به پیچیدگی‌های عجیب نیست. اگر پایتون ۳.۹ به بالا دارید، کافیست از `pip` استفاده کنید. 

```bash
# نصب پکیج اصلی
pip install qamar-core

# تأیید نصب
qamar --version
```

اگر می‌خواهید روی پروژه‌های بزرگ کار کنید، پیشنهاد می‌کنم حتماً یک محیط مجازی (Virtual Environment) بسازید تا کتابخانه‌های جانبی دچار تداخل نشوند.

## ۳. نحوه استفاده (مثال عملی)

فرض کنید می‌خواهید یک مجموعه داده متنی را تحلیل کنید و ارتباط بین مفاهیم را استخراج کنید. قمر این کار را به ساده‌ترین شکل ممکن انجام می‌دهد:

```python
from qamar import Analyzer

# مقداردهی اولیه
engine = Analyzer(source="data_corpus.json")

# اجرای تحلیل چندگانه
results = engine.process(method="interdisciplinary_link")

# خروجی گرفتن
for link in results.top_connections(limit=5):
    print(f"ارتباط پیدا شد: {link.subject} -> {link.object}")
```

## ۴. پرسش‌های متداول (FAQ)

**س: آیا قمر برای زبان‌های غیر از فارسی هم کاربرد دارد؟**
پاسخ: بله، ساختار اصلی قمر زبان‌مستقل است، اما در تحلیل‌های معنایی (Semantic Analysis)، بهینه‌سازی‌های خاصی برای زبان فارسی دارد.

**س: آیا می‌توانم قمر را به پایگاه داده SQL متصل کنم؟**
پاسخ: قطعاً. قمر از طریق `Connectors` به راحتی به PostgreSQL و MongoDB متصل می‌شود. کافیست در فایل تنظیمات، رشته اتصال (Connection String) را وارد کنید.

**س: محدودیت حجم داده چقدر است؟**
پاسخ: به دلیل معماری توزیع‌یافته، محدودیت خاصی وجود ندارد و بیشتر به توان سخت‌افزاری سرور شما بستگی دارد.
