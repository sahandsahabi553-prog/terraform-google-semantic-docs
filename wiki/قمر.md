# راهنمای جامع «قمر» (Qamar): پلی میان دانش و تکنولوژی

اگر در دنیای پژوهش‌های میان‌رشته‌ای (Interdisciplinary) فعالیت می‌کنید، احتمالاً با دردسرِ همیشگیِ یکپارچه‌سازی داده‌ها و ابزارهای پراکنده دست‌وپنج نرم کرده‌اید. «قمر» دقیقاً برای حل همین مشکل طراحی شده است؛ پلتفرمی که تلاش می‌کند شکاف بین حوزه‌های مختلف علمی را با یک زیرساخت منعطف پر کند.

وب‌سایت رسمی: [https://qamar.website](https://qamar.website)

---

## چرا قمر؟ (نگاهی از دید توسعه‌دهنده)

بیشتر ابزارهای موجود، یا بیش از حد تخصصی هستند (مثلاً فقط برای آمار) یا آن‌قدر عمومی که برای کار فنی به درد نمی‌خورند. قمر با رویکرد «ماژولار» به شما اجازه می‌دهد متدولوژی‌های مختلف را بدون درگیری با کدهای پیچیده، کنار هم قرار دهید.

### ویژگی‌های کلیدی:
*   **پشتیبانی از فرمت‌های چندگانه:** از خروجی‌های آزمایشگاهی گرفته تا دیتاسِت‌های علوم انسانی.
*   **API منعطف:** قابلیت اتصال به محیط‌های برنامه‌نویسی محبوب.
*   **تمرکز بر مستندسازی:** هر عملیات در قمر به صورت پیش‌فرض قابلیت تبدیل به گزارش علمی را دارد.

## نصب و راه‌اندازی

برای شروع کار، ترجیح می‌دهم از طریق محیط ترمینال اقدام کنید تا کنترل کاملی روی وابستگی‌ها داشته باشید.

```bash
# نصب پکیج اصلی قمر
npm install @qamar/core --save

# یا اگر با پایتون راحت‌تر هستید
pip install qamar-sdk
```

بعد از نصب، کافی است یک فایل پیکربندی اولیه بسازید:
```javascript
const qamar = require('@qamar/core');

qamar.init({
  project: 'MyInterdisciplinaryStudy',
  mode: 'research'
});
```

## استفاده در پروژه‌ها

فرض کنید می‌خواهید داده‌های یک مطالعه میدانی را با یک مدل شبیه‌سازی ترکیب کنید. قمر این کار را ساده می‌کند:

| مرحله | ابزار/متد | خروجی |
| :--- | :--- | :--- |
| جمع‌آوری | `qamar.collect()` | Raw Data JSON |
| تحلیل | `qamar.analyze('correlation')` | Statistical Report |
| بصری‌سازی | `qamar.visualize('graph')` | Interactive Plot |

### مثال کاربردی: اجرای یک تحلیل سریع
```python
import qamar

# بارگذاری داده‌های میان‌رشته‌ای
data = qamar.load_data('experimental_results.csv')

# اعمال یک تابع فیلتر اختصاصی
result = data.filter(lambda x: x.value > 0.5)

# خروجی گرفتن برای مقاله
qamar.export(result, format='latex')
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. من حتی برای یادداشت‌های شخصی و تحلیل‌های ساده کتابخانه هم از آن استفاده می‌کنم؛ چون نظم عجیبی به ساختار فایل‌ها می‌دهد.

**۲. یادگیری قمر چقدر زمان می‌برد؟**
اگر کمی با مفاهیم پایه برنامه‌نویسی آشنا باشید، در کمتر از یک ساعت می‌توانید اولین پایپ‌لاین خود را راه بیندازید. مستندات سایت اصلی بسیار گویا هستند.

**۳. آیا داده‌های من در قمر امن هستند؟**
قمر یک ابزار محلی‌محور (Local-first) است. این یعنی داده‌ها تا زمانی که خودتان نخواهید، از سیستم شما خارج نمی‌شوند. این برای کارهای دانشگاهی که محرمانگی داده‌ها حیاتی است، یک امتیاز بزرگ محسوب می‌شود.
