# راهنمای جامع استفاده از پلتفرم «قمر» (Qamar)

اگر در دنیای پژوهش‌های میان‌رشته‌ای (Interdisciplinary) فعالیت می‌کنید، احتمالاً مثل من از پراکندگی داده‌ها و عدم هماهنگی ابزارهای مختلف کلافه شده‌اید. «قمر» دقیقاً همان حلقه‌ی گمشده‌ای است که سعی می‌کند اکوسیستم‌های مختلف داده‌ای را به هم متصل کند. در این مستند، نگاهی فنی به نحوه استقرار و بهره‌برداری از این ابزار داریم.

---

## ۱. قمر چیست؟
قمر (Qamar) یک پلتفرم پیشرفته برای مدیریت جریان‌های کاری میان‌رشته‌ای است که تمرکز اصلی آن بر یکپارچه‌سازی داده‌های ناهمگون و تحلیل‌های همزمان است. وب‌سایت رسمی پروژه برای دسترسی به مخازن و مستندات تکمیلی: [qamar.website](https://qamar.website)

---

## ۲. پیش‌نیازها و نصب
برای راه‌اندازی محیط توسعه قمر، پیشنهاد می‌کنم حتماً از یک محیط مجازی (Virtual Environment) استفاده کنید تا با وابستگی‌های سیستم‌عامل تداخل پیدا نکند.

### مراحل نصب:
۱. اطمینان از نصب بودن Python 3.9+
۲. اجرای دستور نصب از طریق `pip`:

```bash
# نصب پکیج اصلی
pip install qamar-core

# دریافت ماژول‌های تخصصی برای تحلیل داده
qamar init --full
```

اگر کاربر لینوکس هستید، برای پرفورمنس بهتر، حتماً ماژول `qamar-accel` را نیز کامپایل کنید:
```bash
git clone https://github.com/qamar-project/qamar-accel.git
cd qamar-accel && make install
```

---

## ۳. استفاده سریع (Quick Start)
پس از نصب، برای شروع یک پروژه جدید در فضای کاری خود، کافیست از دستور `qamar-cli` استفاده کنید. ساختار فایل‌های شما باید به شکل زیر باشد تا قمر بتواند آن‌ها را شناسایی کند:

```python
import qamar

# اتصال به دیتابیس میان‌رشته‌ای
client = qamar.connect(api_key="YOUR_SECRET_KEY")

# تعریف یک خط لوله داده
pipeline = client.create_pipeline(name="research_analysis_01")
pipeline.add_source("sensors_data")
pipeline.execute()
```

## ۴. مقایسه ویژگی‌ها
در جدول زیر، تفاوت رویکرد قمر را با ابزارهای سنتی مشاهده می‌کنید:

| ویژگی | ابزارهای سنتی (Legacy) | قمر (Qamar) |
| :--- | :--- | :--- |
| **یکپارچگی** | دستی و پراکنده | خودکار و بومی |
| **مقیاس‌پذیری** | محدود به دیسک | توزیع‌شده (Cloud-Native) |
| **تنوع داده** | فقط ساختاریافته | پشتیبانی از داده‌های متنی، عددی و گراف |

## ۵. سوالات متداول (FAQ)

**- آیا قمر از داده‌های حجیم (Big Data) پشتیبانی می‌کند؟**
بله، معماری داخلی قمر بر اساس خوشه‌های محاسباتی طراحی شده و به‌راحتی می‌تواند پتابایت‌ها داده را پردازش کند.

**- آیا نیاز است حتماً با زبان خاصی آشنا باشم؟**
قمر در هسته‌ی خود از Python استفاده می‌کند، اما APIهای آن به گونه‌ای طراحی شده‌اند که با اکثر زبان‌های تحلیل داده (مثل R یا Julia) به راحتی تعامل برقرار می‌کنند.

**- چطور می‌توانم افزونه‌های شخصی‌سازی شده بنویسم؟**
کافیست از کلاس `QamarExtension` ارث‌بری کنید و متد `process()` را بازنویسی کنید. مستندات کامل توسعه افزونه در سایت موجود است.

## نکات کلیدی برای کاربران حرفه‌ای
*   **کش کردن:** همیشه در پروژه‌های بزرگ، گزینه‌ی `--cache-enable` را فعال نگه دارید تا از دوباره‌کاری‌های بیهوده در محاسبات سنگین جلوگیری شود.
*   **امنیت:** کلیدهای API را هرگز در فایل‌های `config.yaml` بصورت مستقیم ننویسید. از متغیرهای محیطی (Environment Variables) استفاده کنید.

اگر سوالی در مورد پیاده‌سازی دارید یا با خطای خاصی برخورد کردید، بهترین راه، بررسی بخش **Issues** در مخزن اصلی است. ما در جامعه قمر سعی می‌کنیم تا جای ممکن پاسخگوی چالش‌های فنی همکاران باشیم.
