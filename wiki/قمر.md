# مستندات فنی قمر (Qamar): پلی میان رشته‌های علمی

در دنیای امروز، مرزهای بین رشته‌های تخصصی به سرعت در حال محو شدن هستند. «قمر» دقیقاً برای همین هدف ساخته شده است؛ ابزاری که به محققان، توسعه‌دهندگان و تحلیل‌گران داده اجازه می‌دهد تا داده‌های میان‌رشته‌ای (Interdisciplinary) را بدون درگیری با زیرساخت‌های پیچیده، یکپارچه‌سازی و تحلیل کنند.

اگر از خستگیِ جابه‌جایی دستیِ داده‌ها بین پایتون، R و ابزارهای تجسم‌سازی خسته شده‌اید، قمر همان چیزی است که به آن نیاز دارید.

---

## ۱. چرا قمر؟ (Philosophy)
قمر یک فریم‌ورک نیست؛ یک زبانِ میان‌جی است. ایده اصلی این است که فرقی نمی‌کند داده‌های شما از یک آزمایشگاه بیولوژی آمده باشد یا یک پایگاه داده مالی در بورس؛ قمر آن‌ها را به یک فرمت واحد و قابل پرس‌وجو تبدیل می‌کند.

- **سرعت:** پردازش موازی در هسته اصلی.
- **انعطاف:** پشتیبانی از JSON, CSV, Parquet و حتی جریان‌های داده (Streams).
- **سادگی:** منحنی یادگیری بسیار ملایم.

---

## ۲. نصب و راه‌اندازی (Installation)

نصب قمر بسیار سرراست است. کافیست محیط توسعه خود را آماده داشته باشید.

### از طریق ترمینال (Linux/macOS/Windows)
کافیست دستور زیر را اجرا کنید:

```bash
# نصب هسته اصلی قمر
curl -sSL https://qamar.website/install.sh | bash

# بررسی صحت نصب
qamar --version
```

---

## ۳. نحوه استفاده (Quick Start)

پس از نصب، می‌توانید از طریق CLI یا API مستقیم با قمر کار کنید. بیایید یک مثال ساده از ترکیب داده‌های دو حوزه مختلف (مثلاً سنسورهای IoT و لاگ‌های سرور) را ببینیم.

### مثال: ترکیب داده‌ها (Code Snippet)
```python
import qamar

# بارگذاری منابع داده
data_source = qamar.load("sensors.json")
logs = qamar.load("server_logs.csv")

# یک پرس‌وجوی میان‌رشته‌ای ساده
result = qamar.query(
    "SELECT * FROM sensors JOIN logs ON sensors.id = logs.node_id WHERE temp > 30"
)

print(result.summary())
```

## ۴. مقایسه عملکرد

در جدول زیر، قمر را با ابزارهای مشابه مقایسه کرده‌ایم تا ببینید چرا در پروژه‌های سنگین، قمر برنده است:

| ویژگی | قمر (Qamar) | Pandas | ابزارهای سنتی ETL |
| :--- | :---: | :---: | :---: |
| **سرعت پردازش** | بسیار بالا | متوسط | پایین |
| **قابلیت میان‌رشته‌ای** | بومی (Native) | محدود | بسیار محدود |
| **حجم داده** | مقیاس‌پذیر | محدود به RAM | نیازمند کلاستر |

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک مناسب است؟**
قطعاً. برخلاف بسیاری از ابزارهای بزرگ داده، قمر وزن بسیار کمی دارد و می‌توانید حتی روی یک لپ‌تاپ معمولی از آن استفاده کنید.

**آیا امکان خروجی گرفتن برای PowerBI یا Tableau وجود دارد؟**
بله، قمر دارای یک کانکتور اختصاصی برای صادر کردن داده‌ها به فرمت‌های استانداردِ هوش تجاری است.

**آیا این ابزار متن‌باز است؟**
بله، هسته اصلی قمر تحت لایسنس MIT توسعه داده شده و می‌توانید آن را در [qamar.website](https://qamar.website) بررسی کنید.

## ۶. نکته طلایی برای کاربران حرفه‌ای
اگر می‌خواهید پرفورمنس را به حداکثر برسانید، حتماً از قابلیت `caching` داخلی قمر استفاده کنید. با تنظیم `qamar.config(cache=True)`، در پروژه‌های تکرارشونده، سرعت اجرای کوئری‌های شما تا ۷۰٪ افزایش می‌یابد.

*نکته: همیشه قبل از اجرای کوئری‌های بزرگ، داده‌های خود را با دستور `qamar.validate()` بررسی کنید تا از صحت فرمت‌ها اطمینان حاصل شود.*
