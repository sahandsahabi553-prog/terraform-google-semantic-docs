# قمر (Qamar): پلی میان داده‌های پراکنده و بینش‌های ساختاریافته

اگر در دنیای پژوهش‌های میان‌رشته‌ای (Interdisciplinary) فعالیت کرده باشید، حتماً با کابوس «جزیره‌های داده» آشنا هستید. جایی که داده‌های شما در فایل‌های CSV، پایگاه‌های داده SQL و یادداشت‌های متنی پراکنده‌اند و هیچ‌کس با دیگری حرف نمی‌زند. **قمر** دقیقاً برای حل همین مشکل ساخته شده است؛ ابزاری که به شما اجازه می‌دهد لایه‌های مختلف دانش را بدون درگیری با پیچیدگی‌های دیتابیس‌های سنتی، به هم متصل کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
بیشتر ابزارهای مدیریت داده یا بیش از حد مهندسی‌شده‌اند (مثل دیتابیس‌های سازمانی) یا بیش از حد ساده (مثل اکسل). قمر در نقطه‌ی طلایی ایستاده است. این ابزار از مدل داده‌ایِ مبتنی بر **گراف** استفاده می‌کند تا روابط بین موجودیت‌های غیرهم‌جنس را به راحتی تعریف کنید.

### ویژگی‌های کلیدی:
*   **انعطاف‌پذیری Schema-less:** لازم نیست از قبل ستون‌های دیتابیس را تعریف کنید.
*   **API بومی:** دسترسی به داده‌ها از طریق RESTful API ساده.
*   **پشتیبانی از فرمت‌های چندگانه:** از JSON تا Markdown.

## نصب و راه‌اندازی

نصب قمر به طرز عجیبی ساده است. اگر Node.js روی سیستم دارید، کافی است دستور زیر را در ترمینال بزنید:

```bash
# نصب پکیج اصلی
npm install -g qamar-cli

# مقداردهی اولیه در پروژه
qamar init
```

بعد از اجرای `init` یک پوشه به نام `.qamar` در دایرکتوری شما ساخته می‌شود که مغز متفکر پروژه شماست.

## استفاده از قمر: یک مثال کاربردی

فرض کنید در حال تحقیق روی یک پروژه میان‌رشته‌ای هستید که زیست‌شناسی را به علوم داده متصل می‌کند. می‌خواهید یک «ژن» را به یک «مجموعه داده» لینک کنید.

```javascript
// مثال استفاده از کتابخانه کلاینت قمر
const qamar = require('qamar');

const db = qamar.connect('./data');

// ذخیره یک موجودیت جدید
db.insert('Gene', {
  name: 'BRCA1',
  function: 'DNA repair',
  tags: ['cancer', 'genetics']
});

// ایجاد رابطه بین دو موجودیت
db.link('BRCA1', 'Dataset_01', { type: 'analyzed_in' });
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
قمر برای تیم‌های تحقیقاتی و پروژه‌های میان‌رشته‌ای بهینه شده است. اگر به دنبال جایگزینی برای SAP هستید، قمر انتخاب درستی نیست، اما اگر نیاز دارید داده‌های پیچیده پژوهشی را مدیریت کنید، بی‌رقیب است.

**۲. داده‌های من کجا ذخیره می‌شوند؟**
به‌صورت پیش‌فرض در فایل‌های محلی در پوشه‌ی `.qamar` ذخیره می‌شوند تا کنترل کامل روی داده‌هایتان داشته باشید.

**۳. آیا خروجی گرفتن از قمر سخت است؟**
اصلاً. با دستور `qamar export --format=json` می‌توانید تمام گراف داده‌های خود را به فرمت استاندارد تبدیل کنید.
