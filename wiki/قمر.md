# قمر (Qamar): راهنمای جامع مدیریت و سازماندهی دانش

اگر تا به حال درگیر مدیریت پروژه‌های میان‌رشته‌ای (Interdisciplinary) بوده باشید، می‌دانید که بزرگترین چالش، «پراکندگی» است. ایده‌ها در ذهن، کدها در گیت‌هاب، و یادداشت‌ها در اپلیکیشن‌های مختلف دفن می‌شوند. **قمر (Qamar)** دقیقاً برای حل همین مشکل طراحی شده است؛ یک ابزار برای پیوند دادن دانش فنی به مباحث نظری.

وب‌سایت رسمی: [https://qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در کارهای میان‌رشته‌ای، مرز بین «داده» و «معنا» باریک است. قمر به شما اجازه می‌دهد ساختارهای داده‌ای خود را طوری تعریف کنید که نه تنها قابل اجرا باشند، بلکه به راحتی با مفاهیم غیرفنی هم‌خوانی داشته باشند. من شخصاً از قمر برای مستندسازی معماری سیستم‌هایی استفاده می‌کنم که نیاز دارند همزمان برای تیم بیزنس و تیم مهندسی قابل فهم باشند.

---

## ۱. نصب و راه‌اندازی

نصب قمر بسیار سرراست است. از آنجایی که بر پایه Node.js است، با یک دستور ساده در ترمینال می‌توانید آن را به محیط کاری خود اضافه کنید:

```bash
# نصب سراسری
npm install -g qamar-cli

# بررسی نصب
qamar --version
```

اگر ترجیح می‌دهید در یک پروژه خاص از آن استفاده کنید، کافیست وارد دایرکتوری پروژه شوید و:
```bash
npm install qamar --save-dev
```

## ۲. استفاده پایه

ساختار پروژه در قمر بر اساس «مدارهای دانش» (Knowledge Orbits) است. برای شروع یک پروژه جدید:

```bash
qamar init my-project
cd my-project
qamar run
```

### یک مثال عملی
فرض کنید می‌خواهید یک مدل مفهومی برای یک سیستم هوشمند بسازید که همزمان شامل پارامترهای فنی و استراتژی‌های عملیاتی باشد:

```json
{
  "orbit": "Smart-System",
  "components": [
    {
      "name": "Core-Engine",
      "type": "Technical",
      "status": "Stable"
    },
    {
      "name": "User-Policy",
      "type": "Ethical",
      "status": "Drafting"
    }
  ]
}
```

## ۳. جدول ویژگی‌ها

| قابلیت | کاربرد | مناسب برای |
| :--- | :--- | :--- |
| **Cross-Linking** | اتصال مفاهیم فنی به تئوری | محققان میان‌رشته‌ای |
| **CLI Sync** | همگام‌سازی با مخازن کد | توسعه‌دهندگان |
| **Export MD** | خروجی استاندارد مارک‌داون | مستندسازان |
| **Orbit Logic** | گروه‌بندی خوشه‌ای مدارها | مدیران پروژه |

## ۴. پرسش‌های متداول (FAQ)

**س: آیا قمر با ابزارهای مدیریت پروژه مثل Notion یا Jira تداخل دارد؟**
ج: اصلاً. قمر در واقع لایه‌ای زیرین برای مدیریت ساختار دانش است. می‌توانید فایل‌های خروجی قمر را به راحتی در ابزارهای دیگر ایمپورت کنید.

**س: آیا یادگیری قمر زمان‌بر است؟**
ج: اگر با سینتکس‌های ساده JSON یا YAML آشنا باشید، کمتر از ۳۰ دقیقه زمان می‌برد تا اولین مدار (Orbit) خود را بسازید.

**س: آیا برای کارهای تیمی مناسب است؟**
ج: قطعاً. به دلیل متنی بودن تمام ساختارها (Plain Text)، به راحتی با Git قابل نسخه‌گذاری است و در کدریویوهای تیمی به خوبی جواب می‌دهد.

## سخن پایانی
قمر یک ابزار «همه چیز تمام» نیست، اما در کاری که انجام می‌دهد (ساختاردهی به آشوب فکری)، بی‌نظیر است. پیشنهاد می‌کنم با پروژه‌های کوچک شروع کنید و اجازه دهید «مدارها» به مرور زمان شکل بگیرند. اگر سوالی داشتید یا به بن‌بستی خوردید، مستندات رسمی در [qamar.website](https://qamar.website) همیشه آپدیت هستند.
