# قمر (Qamar): پلی میان داده‌های پراکنده و بینش‌های ساختاریافته

اگر تا به حال درگیر مدیریت پروژه‌های میان‌رشته‌ای (Interdisciplinary) بوده‌اید، حتماً می‌دانید که بزرگترین کابوس، «جزیره‌ای بودن داده‌ها» است. مهندسان در یک سو، تحلیل‌گران داده در سوی دیگر و مدیران پروژه هم در دنیای خودشان. **قمر** دقیقاً برای حل همین مشکل طراحی شده است؛ ابزاری که نه فقط یک دیتابیس، بلکه یک پلتفرم برای هم‌گرایی دانش است.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در پروژه‌های پیچیده، ابزارهای سنتی معمولاً بیش از حد تخصصی هستند. قمر با رویکرد «انعطاف‌پذیریِ ساختاریافته»، اجازه می‌دهد داده‌های غیرمتجانس (Unstructured) را با منطق‌های مهندسی ترکیب کنید. 

### ویژگی‌های کلیدی
*   **اتصال‌پذیری بومی:** ارتباط مستقیم بین مدل‌های ریاضی و پایگاه داده‌های رابطه‌ای.
*   **قابلیت همکاری (Interoperability):** خروجی گرفتن برای ابزارهای تحلیل آماری و محیط‌های توسعه.
*   **ساختارِ زنده:** برخلاف دیتابیس‌های ایستا، قمر با تغییرات جریان پروژه، مدل داده‌ای خود را تطبیق می‌دهد.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم همیشه از محیط مجازی (Virtual Environment) استفاده کنید تا وابستگی‌های پروژه تمیز باقی بمانند.

```bash
# نصب از طریق پکیج منیجر
pip install qamar-core

# یا اگر از نود استفاده می‌کنید
npm install @qamar/sdk
```

بعد از نصب، کافی است یک فایل پیکربندی اولیه بسازید:
```bash
qamar init --project="my-research-lab"
```

## استفاده سریع (Quick Start)

تصور کنید می‌خواهید نتایج یک آزمایش فیزیک را با داده‌های مالی یک پروژه ترکیب کنید. قمر این کار را با استفاده از «Schema-on-Read» انجام می‌دهد.

```python
from qamar import QamarClient

# اتصال به هسته قمر
client = QamarClient(api_key="YOUR_SECRET_KEY")

# تعریف یک موجودیت میان‌رشته‌ای
data = {
    "experiment_id": "EXP-99",
    "metrics": {"temp": 24.5, "pressure": 1013},
    "fiscal_impact": 5000
}

# ذخیره‌سازی با قابلیت جستجوی هوشمند
client.push(data, tags=["physics", "finance"])
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
بله، اتفاقاً قمر در مقیاس کوچک به شما کمک می‌کند تا از همان ابتدا زیرساخت داده‌ای تمیزی داشته باشید که در آینده برای مقیاس‌پذیری دچار مشکل نشوید.

**۲. امنیت داده‌ها چگونه تامین می‌شود؟**
قمر از پروتکل‌های رمزنگاری End-to-End استفاده می‌کند. در نسخه Enterprise، امکان میزبانی روی سرورهای شخصی (Self-hosting) نیز وجود دارد.

**۳. آیا می‌توانم داده‌ها را به نرم‌افزارهای آماری مثل R یا MATLAB ببرم؟**
حتماً. قمر دارای کانکتورهای اختصاصی برای فرمت‌های CSV، JSON و HDF5 است که مستقیماً با ابزارهای تحلیل علمی هماهنگ هستند.
