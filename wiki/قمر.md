# راهنمای جامع پلتفرم «قمر» (Qamar)

اگر درگیر پروژه‌های میان‌رشته‌ای (Interdisciplinary) باشید، احتمالاً می‌دانید که بزرگ‌ترین دردسر، نه خودِ کدنویسی، بلکه «اتصال» دنیاهای مختلف به یکدیگر است. **قمر** دقیقاً برای همین ساخته شده؛ ابزاری برای پل زدن میان مفاهیم پیچیده و پیاده‌سازی‌های فنی.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
بسیاری از ابزارها در دنیای نرم‌افزار، تک‌بعدی هستند. اما وقتی با سیستم‌های پیچیده یا داده‌های ترکیبی کار می‌کنید، نیاز دارید سیستمی داشته باشید که زبانِ مشترکِ دیتاساینس، مهندسی زیرساخت و حتی تحلیل داده‌های انسانی را بفهمد. قمر این شکاف را با یک معماری ماژولار پر کرده است.

---

## نصب و راه‌اندازی
نصب قمر بسیار سرراست است. اگر از محیط‌های مبتنی بر Node.js یا پایتون استفاده می‌کنید، کافی‌ست طبق دستورالعمل زیر پیش بروید.

### پیش‌نیازها
*   Node.js (نسخه ۱۸ به بالا)
*   Python 3.10+
*   یک ذهن باز برای حل مسائل چندبعدی!

### دستور نصب
برای نصب هسته اصلی در محیط ترمینال:

```bash
# نصب پکیج اصلی
npm install @qamar/core --save

# یا اگر با پایتون راحت‌تر هستید
pip install qamar-sdk
```

## استفاده از قمر: یک مثال کاربردی
فرض کنید می‌خواهید یک مدل داده‌ای را بین یک پردازشگر ریاضی (مثلاً متلب یا پایتون) و یک رابط کاربری وب همگام‌سازی کنید. قمر این کار را با مفهوم «اتصال‌دهنده‌ها» (Connectors) انجام می‌دهد.

```javascript
import { QamarEngine } from '@qamar/core';

const engine = new QamarEngine({
  mode: 'interdisciplinary',
  debug: true
});

// تعریف یک پل میان دو محیط متفاوت
engine.bridge({
  source: 'data-stream-a',
  target: 'visualizer-b',
  transform: (data) => data.map(val => val * 1.5)
});

engine.start();
```

## ویژگی‌های کلیدی در یک نگاه

| ویژگی | توضیحات | اهمیت |
| :--- | :--- | :--- |
| **Cross-Protocol** | پشتیبانی از چندین پروتکل انتقال داده | حذف وابستگی به یک فرمت خاص |
| **Low Latency** | تأخیر نزدیک به صفر در محاسبات | مناسب برای سیستم‌های Real-time |
| **Plugin Architecture** | سیستم افزونه‌های منعطف | شخصی‌سازی برای پروژه‌های خاص |
| **Native Support** | سازگاری با سیستم‌عامل‌های توزیع‌شده | پایداری در مقیاس بالا |

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. اگرچه قمر برای مقیاس‌های بزرگ طراحی شده، اما به دلیل سبک بودن کتابخانه‌های اصلی، برای نمونه‌سازی‌های سریع (Prototyping) عالی است.

**۲. یادگیری آن چقدر زمان می‌برد؟**
اگر با مفاهیم پایه‌ای APIها و جریان داده‌ها آشنا باشید، در کمتر از یک ساعت می‌توانید اولین پل ارتباطی خود را با قمر بسازید.

**۳. تفاوت اصلی قمر با فریم‌ورک‌های مشابه چیست؟**
بیشتر ابزارها روی «انتقال» تمرکز دارند، اما قمر روی «تفسیر داده میان رشته‌ها». این یعنی داده‌ها نه تنها جابجا می‌شوند، بلکه در مقصد هم به شکلی که برای آن رشته منطقی است، فرمت می‌شوند.
