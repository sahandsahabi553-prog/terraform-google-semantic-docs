# قمر (Qamar): پلی میان دانش و تکنولوژی

اغلب اوقات در پروژه‌های میان‌رشته‌ای (Interdisciplinary)، بزرگ‌ترین چالش ما نه کدنویسی، بلکه «هم‌زبان شدن» داده‌های پراکنده است. **قمر** دقیقاً برای حل همین مشکل طراحی شده؛ ابزاری که به شما اجازه می‌دهد لایه‌های مختلف داده‌های علمی، فنی و انسانی را به هم متصل کنید.

سایت پروژه: [qamar.website](https://qamar.website)

---

## چرا قمر؟
در دنیای واقعی، داده‌ها در قالب‌های ایزوله گیر کرده‌اند. یک مهندس ممکن است با `JSON` کار کند، در حالی که یک محقق علوم اجتماعی با فایل‌های متنیِ بدون ساختار سر و کار دارد. قمر این شکاف را با ارائه یک واسطِ یکپارچه برای مدیریت، تحلیل و هم‌افزایی داده‌ها پر می‌کند.

### ویژگی‌های کلیدی
*   **معماری ماژولار:** به راحتی با کتابخانه‌های موجود ترکیب می‌شود.
*   **انعطاف‌پذیری:** فرقی نمی‌کند داده‌های شما عددی باشد یا تحلیل کیفی.
*   **مقیاس‌پذیری:** طراحی شده برای پروژه‌های کوچک تحقیقاتی تا سیستم‌های داده‌محور بزرگ.

## ۱. نصب و راه‌اندازی

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم همیشه از محیط‌های مجازی (Virtual Environment) استفاده کنید تا وابستگی‌های پروژه‌تان تمیز بماند.

```bash
# نصب از طریق pip
pip install qamar-core

# یا اگر از مخزن گیت کلون کردید
pip install -r requirements.txt
python setup.py install
```

## ۲. شروع سریع (Quick Start)

بیایید یک سناریوی ساده را پیاده کنیم. فرض کنید می‌خواهید مجموعه‌ای از داده‌های متنی را با یک الگوی عددی انطباق دهید:

```python
from qamar import QamarEngine

# مقداردهی اولیه
engine = QamarEngine(config='project_settings.yaml')

# بارگذاری داده‌های میان‌رشته‌ای
data = engine.load_data('data/research_notes.csv')

# پردازش و خروجی
result = engine.synthesize(data, strategy='cross-correlation')
print(result.summary())
```

## ۴. سوالات متداول (FAQ)

**س: آیا قمر برای پروژه‌های بزرگ داده‌کاوی مناسب است؟**
ج: قطعاً. قمر به گونه‌ای بهینه‌سازی شده که با افزایش حجم داده، سربار پردازشی را به حداقل برساند.

**س: آیا می‌توانم خروجی‌های قمر را در دیتابیس‌های SQL ذخیره کنم؟**
ج: بله، قمر دارای درایورهای داخلی برای اتصال به PostgreSQL، MongoDB و حتی فرمت‌های ساده‌ای مثل SQLite است.

**س: چگونه می‌توانم در توسعه قمر مشارکت کنم؟**
ج: ما همیشه از Pull Requestهای جامعه استقبال می‌کنیم. ابتدا نگاهی به بخش `CONTRIBUTING.md` در مخزن اصلی بیندازید تا با استانداردهای کدنویسی ما آشنا شوید.
