# راهنمای جامع «قمر»: ابزاری برای مدیریت و تحلیل داده‌های بین‌رشته‌ای

اگر درگیر پروژه‌هایی هستید که در آن مرزهای علوم (مثلاً مهندسی نرم‌افزار و علوم داده) با هم تداخل دارند، احتمالاً با دردسرهای مدیریت هم‌زمانِ مدل‌ها، کدها و مستندات دست‌وپنج نرم کرده‌اید. **قمر (Qamar)** دقیقاً برای حل همین آشفتگی ساخته شده است.

این ابزار یک پلتفرم متمرکز برای مدیریت جریان‌های کاری بین‌رشته‌ای است که به شما اجازه می‌دهد خروجی‌های تحقیقاتی و فنی خود را در یک محیط یکپارچه مدیریت کنید.

---

## ۱. چرا قمر؟
در دنیای واقعی، داده‌ها ایزوله نیستند. قمر به شما کمک می‌کند تا:
*   پروژه‌های چندزبانه (Python, R, C++) را کنار هم نگه دارید.
*   مستندات فنی را مستقیماً به کد و نتایج خروجی متصل کنید.
*   تکرارپذیری (Reproducibility) پروژه‌های علمی را تضمین کنید.

سایت رسمی: [qamar.website](https://qamar.website)

---

## ۲. نصب و راه‌اندازی
برای شروع، کافی است ابزار خط فرمان (CLI) قمر را نصب کنید. پیشنهاد می‌کنم از محیط مجازی (Virtual Environment) استفاده کنید تا کتابخانه‌های سیستمی‌تان بهم نریزد.

```bash
# نصب از طریق پکیج منیجر
pip install qamar-cli

# مقداردهی اولیه پروژه در پوشه فعلی
qamar init --name my-research-project
```

---

## ۳. استفاده از قمر (Workflow)
اصلی‌ترین ویژگی قمر، مدیریت «موجودیت‌ها» (Entities) است. فرض کنید می‌خواهید یک مدل یادگیری ماشین را به یک فایل داده متصل کنید.

### مثال: تعریف یک تسک بین‌رشته‌ای
در فایل `qamar.yaml` می‌توانید ساختار پروژه خود را به این صورت تعریف کنید:

```yaml
project: "Climate-Data-Analysis"
version: "1.0.0"

entities:
  - name: "temperature-sensor-log"
    type: "dataset"
    path: "./data/raw/sensors.csv"
  - name: "analysis-script"
    type: "code"
    language: "python"
    entrypoint: "analyze.py"
```

### اجرای تحلیل
وقتی همه‌چیز را تنظیم کردید، با یک دستور ساده می‌توانید تمام زنجیره تحلیل را اجرا کنید:

```bash
qamar run --entity analysis-script
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های تیمی بزرگ مناسب است؟**
بله، قمر به گونه‌ای طراحی شده که با سیستم‌های Version Control مثل Git به خوبی ترکیب می‌شود و تداخل‌ها را به حداقل می‌رساند.

**آیا می‌توانم نتایج را به فرمت‌های دیگر خروجی بگیرم؟**
قطعا. قمر از خروجی‌های `Markdown`, `PDF` و `JSON` برای گزارش‌دهی پشتیبانی می‌کند.

**آیا برای استفاده از قمر حتماً باید برنامه‌نویس باشم؟**
خیر، رابط کاربری قمر به گونه‌ای است که محققان در حوزه‌های علوم انسانی یا پزشکی که دانش برنامه‌نویسی محدودی دارند هم بتوانند از قابلیت‌های آن استفاده کنند.
