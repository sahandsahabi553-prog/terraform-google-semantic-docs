# راهنمای جامع «قمر»: ابزاری برای مدیریت داده‌های میان‌رشته‌ای

اگر درگیر پروژه‌هایی هستید که مرزهای علوم داده، تحلیل‌های آماری و مستندسازی فنی را جابه‌جا می‌کنند، احتمالاً با چالش «پراکندگی منابع» دست‌وپنج نرم کرده‌اید. **قمر (Qamar)** دقیقاً برای همین ساخته شده است؛ یک فریم‌ورک سبک اما قدرتمند که به شما کمک می‌کند داده‌های ناهمگون را در یک ساختار منسجم و قابل‌اعتماد مدیریت کنید.

سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه پروژه)

در دنیای امروز، داده‌ها دیگر در فایل‌های CSV ساده خلاصه نمی‌شوند. ما با ترکیب داده‌های سنسورها، متون ادبی، معادلات فیزیکی و خروجی‌های برنامه‌نویسی سروکار داریم. قمر به جای اینکه شما را مجبور به استفاده از نرم‌افزارهای سنگین و بسته کند، یک لایه انتزاعی ایجاد می‌کند تا بتوانید جریان داده (Data Pipeline) خود را به‌صورت کد مدیریت کنید.

### ویژگی‌های کلیدی:
*   **پشتیبانی از متادیتاهای پیچیده:** مدیریت تگ‌ها در سطوح تو در تو.
*   **خروجی چندمنظوره:** تبدیل آنی به فرمت‌های JSON، Markdown و PDF.
*   **یکپارچگی با ابزارهای علمی:** هماهنگی کامل با کتابخانه‌های پایتون.

---

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. کافی است محیط پایتون خود را آماده داشته باشید و دستور زیر را در ترمینال وارد کنید:

```bash
# نصب از طریق pip
pip install qamar-core

# تأیید نصب
qamar --version
```

اگر از کاربران لینوکس هستید، پیشنهاد می‌کنم برای عملکرد بهتر، وابستگی‌های C را از طریق `apt` بروزرسانی کنید.

---

## استفاده اولیه

فرض کنید می‌خواهید یک مجموعه داده مربوط به یک آزمایش فیزیک را در سیستم قمر ثبت کنید. ساختار فایل کانفیگ شما در قمر به این صورت خواهد بود:

```yaml
project: "Quantum-Analysis-01"
author: "Research-Team"
version: 1.0.2

data_source:
  type: "sensor"
  path: "./data/raw_input.csv"
  format: "float64"
```

### اجرای عملیات پردازش
برای اجرای پردازش روی داده‌ها، کافی است از دستور `process` استفاده کنید:

```python
from qamar import Engine

# بارگذاری پروژه
q = Engine.load("./config.yaml")

# اجرای تحلیل روی داده‌ها
results = q.run_analysis(method="linear_regression")

print(f"Analysis complete: {results.summary}")
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک مناسب است؟**
قطعاً. اتفاقاً استفاده از قمر در پروژه‌های کوچک باعث می‌شود از همان ابتدا استانداردهای لازم را رعایت کنید و در آینده برای گسترش پروژه دچار مشکل نشوید.

**۲. فایل‌های خروجی قمر در چه فرمتی ذخیره می‌شوند؟**
به‌صورت پیش‌فرض از فرمت‌های متنی ساختاریافته (مثل YAML یا JSON) استفاده می‌شود تا با ابزارهای کنترل ورژن مثل Git سازگاری کامل داشته باشند.

**۳. آیا امکان اتصال به پایگاه‌داده‌های SQL وجود دارد؟**
بله، قمر دارای کانکتورهای داخلی برای SQLite و PostgreSQL است که در مستندات پیشرفته به آن پرداخته‌ایم.
