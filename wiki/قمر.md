# قمر (Qamar): پلی میان داده‌های پراکنده و بینش‌های ساختاریافته

اگر درگیر پروژه‌های میان‌رشته‌ای (Interdisciplinary) باشید، احتمالاً با کابوس «جزیره‌های داده» آشنا هستید. وضعیتی که در آن بخشی از اطلاعات شما در یک پایگاه داده SQL است، بخش دیگر در فایل‌های CSV خاک می‌خورد و تحلیل‌های نهایی هم در یک Notebook پایتون دفن شده‌اند. **قمر** دقیقاً برای حل همین مشکل طراحی شده است؛ ابزاری که هدفش یکپارچه‌سازی جریان داده‌ها در محیط‌های پژوهشی و فنی است.

بیشتر بدانید: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در پروژه‌های میان‌رشته‌ای، ما اغلب با «عدم تجانس» داده‌ها روبرو هستیم. قمر به شما اجازه می‌دهد بدون درگیری با زیرساخت‌های پیچیده، لایه‌های مختلف داده را به هم متصل کنید. 

### ویژگی‌های کلیدی:
*   **اتصال‌پذیری بومی:** پشتیبانی از فرمت‌های مختلف بدون نیاز به تبدیل‌های دستی.
*   **معماری سبک:** برخلاف سیستم‌های سنگین ETL، قمر روی سرعت توسعه تمرکز دارد.
*   **انعطاف‌پذیری:** مناسب برای رشته‌های فنی، علوم انسانی دیجیتال و تحلیل‌های آماری.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. کافی است ابزار مدیریت پکیج مورد علاقه خود را باز کنید. من شخصاً استفاده از `pip` را در یک `virtual environment` توصیه می‌کنم تا تداخل وابستگی‌ها پیش نیاید.

```bash
# نصب سریع
pip install qamar-cli

# بررسی صحت نصب
qamar --version
```

اگر از کاربران لینوکس یا macOS هستید، قمر به راحتی با `Homebrew` هم سازگار است:
```bash
brew install qamar-project/tap/qamar
```

## استفاده عملیاتی

فرض کنید می‌خواهید یک مجموعه داده از سنسورهای محیطی را با گزارش‌های متنی ترکیب کنید. قمر این کار را با استفاده از فایل‌های پیکربندی `.qamar` ساده می‌کند.

### مثال کد: تعریف یک Pipeline
یک فایل با نام `pipeline.yaml` ایجاد کنید:

```yaml
source:
  type: csv
  path: ./data/sensors.csv
transform:
  - operation: filter
    column: temperature
    threshold: 25
output:
  type: json
  destination: ./output/filtered_data.json
```

سپس با یک دستور ساده پردازش را اجرا کنید:
```bash
qamar run --config pipeline.yaml
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ (Big Data) مناسب است؟**
قمر برای مدیریت جریان‌های کاری میان‌رشته‌ای بهینه‌سازی شده است. اگر حجم داده‌های شما در حد ترابایت است، ممکن است نیاز به تنظیمات خاصی در بخش Memory Allocation داشته باشید، اما برای اکثر پروژه‌های پژوهشی و مهندسی عالی عمل می‌کند.

**۲. آیا می‌توانم افزونه (Plugin) شخصی برای آن بنویسم؟**
بله، قمر دارای یک معماری ماژولار است. کافی است در دایرکتوری `plugins` اسکریپت پایتون خود را قرار دهید تا در زنجیره پردازش شما شناسایی شود.

**۳. آیا داده‌های من در جایی آپلود می‌شوند؟**
خیر. قمر یک ابزار Local-first است. تمام پردازش‌ها روی سیستم خودتان انجام می‌شود و هیچ داده‌ای از محیط کاری شما خارج نمی‌شود. این برای پروژه‌هایی که داده‌های حساس یا محرمانه دارند، حیاتی است.
