# راهنمای جامع «قمر»: ابزاری برای مدیریت و تحلیل داده‌های بین‌رشته‌ای

در دنیای امروز که مرز بین علوم مختلف (از فیزیک و ریاضی گرفته تا علوم انسانی و تحلیل داده) روز‌به‌روز کمرنگ‌تر می‌شود، نیاز به ابزاری داریم که بتواند این دنیای پیچیده را به هم پیوند بزند. «قمر» دقیقاً با همین هدف متولد شده است؛ یک پلتفرم منعطف برای مدل‌سازی و تحلیل داده‌های بین‌رشته‌ای.

اگر از دست ابزارهای سنگین و غیرقابل‌انعطاف خسته شده‌اید، قمر همان چیزی است که جای خالی‌اش را در محیط کاری‌تان حس می‌کردید.

---

## ۱. چرا قمر؟ (فلسفه طراحی)
بیشتر ابزارها برای یک حوزه خاص (مثلاً فقط آمار یا فقط مدیریت پروژه) ساخته شده‌اند. قمر با رویکرد **Interdisciplinary** طراحی شده تا بتوانید داده‌های ناهمگون را در یک ساختار یکپارچه مدیریت کنید.

*   **انعطاف‌پذیری بالا:** ساختار داده‌ها محدود به جداول خشک نیست.
*   **سرعت:** طراحی شده برای پردازش‌های سریع بدون درگیری با سربارهای اضافی.
*   **متن‌باز و شفاف:** همه چیز زیر نظر شماست.

---

## ۲. نصب و راه‌اندازی
برای شروع، کافی است محیط نود.جی‌اس (Node.js) را روی سیستم خود داشته باشید. قمر به سادگی از طریق NPM قابل نصب است.

```bash
# نصب قمر به صورت جهانی
npm install -g qamar-cli

# بررسی نصب موفقیت‌آمیز
qamar --version
```

اگر ترجیح می‌دهید در پروژه خود از آن استفاده کنید:
```bash
npm install qamar-core --save
```

## ۳. استفاده سریع (Quick Start)
فرض کنید می‌خواهید یک مدل داده برای پیوند دادن «داده‌های اقلیمی» و «تولیدات کشاورزی» ایجاد کنید. قمر این کار را به راحتی انجام می‌دهد.

### مثال کد: تعریف یک مدل پایه
```javascript
const qamar = require('qamar-core');

const myProject = new qamar.Project('Climate-Agro-Link');

myProject.addDataEntry({
  id: 'region_01',
  metrics: {
    temp: 24.5,
    rainfall: 120,
    yield: 4500
  },
  tags: ['agriculture', 'climate-data']
});

console.log(myProject.summary());
```

## ۵. سوالات متداول (FAQ)

**س: آیا برای استفاده از قمر حتماً باید برنامه‌نویس باشم؟**
ج: نه لزوماً. رابط کاربری گرافیکی ما به زودی منتشر می‌شود، اما در حال حاضر برای بهره‌وری حداکثری، کمی دانش جاوااسکریپت به شما قدرت فوق‌العاده‌ای می‌دهد.

**س: آیا داده‌های من در قمر امن هستند؟**
ج: کاملاً. قمر در هسته خود به صورت «محلی» (Local-first) کار می‌کند. یعنی داده‌ها در سیستم خودتان باقی می‌مانند مگر اینکه خودتان بخواهید آن‌ها را در فضای ابری همگام‌سازی کنید.

**س: برای پروژه‌های بزرگ دانشگاهی مناسب است؟**
ج: بله، ساختار ماژولار قمر دقیقاً برای مدیریت حجم بالای داده‌های پژوهشی که از منابع مختلف می‌آیند، بهینه‌سازی شده است.
