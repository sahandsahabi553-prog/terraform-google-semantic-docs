# راهنمای جامع فنی: «قمر» (Qamar)

اگر در دنیای توسعه سیستم‌های توزیع‌شده یا پروژه‌های میان‌رشته‌ای فعالیت می‌کنید، احتمالاً با چالش همگام‌سازی و مدیریت داده‌های ناهمگون دست‌وپنج نرم کرده‌اید. **قمر (Qamar)** دقیقاً برای حل همین گره‌های کور طراحی شده است. این ابزار نه فقط یک کتابخانه، بلکه یک فریم‌ورک برای اتصال دنیای داده‌های حجیم به تحلیل‌های بلادرنگ است.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در پروژه‌های اخیرم، متوجه شدم که اکثر ابزارها یا برای مقیاس‌پذیری ساخته شده‌اند یا برای سادگیِ کدنویسی. قمر با رویکرد **Interdisciplinary** سعی می‌کند پلی بین مهندسی نرم‌افزار و تحلیل‌های ریاضیاتی برقرار کند.

### ویژگی‌های کلیدی
*   **Zero-latency Sync:** همگام‌سازی داده‌ها با کمترین سربار ممکن.
*   **Type-safe Schemas:** جلوگیری از خطاهای زمان اجرا با سیستم تایپ‌گذاری سخت‌گیرانه.
*   **Cross-platform:** اجرا روی هر زیرساختی که از محیط‌های مدرن پشتیبانی می‌کند.

## ۱. نصب و راه‌اندازی

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم همیشه از آخرین نسخه پایدار استفاده کنید تا با تغییرات API غافل‌گیر نشوید.

```bash
# نصب از طریق پکیج منیجر اصلی
npm install @qamar/core --save

# یا اگر با پایتون کار می‌کنید
pip install qamar-sdk
```

بعد از نصب، برای مقداردهی اولیه محیط پروژه، دستور زیر را اجرا کنید:

```bash
qamar init --config=production
```

## ۲. استفاده پایه (Quick Start)

برای شروع، باید یک `QamarInstance` ایجاد کنید. این نمونه (Instance) قلب تپنده پروژه شما خواهد بود.

```javascript
import { Qamar } from '@qamar/core';

const qm = new Qamar({
  endpoint: 'https://api.qamar.website',
  apiKey: process.env.QAMAR_KEY
});

// اتصال به جریان داده‌های میان‌رشته‌ای
qm.connect('data-stream-01').then(() => {
  console.log("اتصال با موفقیت برقرار شد!");
});
```

## ۴. مثال کاربردی: پردازش میان‌رشته‌ای

فرض کنید می‌خواهید داده‌های حسگرهای محیطی را با تحلیل‌های آماری ترکیب کنید. قمر این کار را با استفاده از `Pipeline` ساده می‌کند:

```python
from qamar import Pipeline

def process_data(payload):
    # تحلیل میان‌رشته‌ای داده‌ها
    result = payload.normalize() * 0.75
    return result

pipe = Pipeline(source="sensor_nodes")
pipe.pipe(process_data).subscribe(on_data=print)
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک مناسب است؟**
بله، اگرچه قدرت اصلی قمر در مقیاس‌های بزرگ مشخص می‌شود، اما به دلیل سبک بودن کتابخانه، در پروژه‌های کوچک هم بدون ایجاد سربار اضافه، مدیریت داده‌ها را برایتان لذت‌بخش می‌کند.

**در صورت قطع اتصال چه اتفاقی می‌افتد؟**
قمر دارای یک سیستم داخلی `Auto-Retry` با استراتژی `Exponential Backoff` است. یعنی خودش بعد از چند ثانیه تلاش می‌کند دوباره وصل شود بدون اینکه کل برنامه کرش کند.

**چگونه می‌توانم با تیم توسعه قمر در ارتباط باشم؟**
بهترین راه مراجعه به [qamar.website](https://qamar.website) و بررسی مستندات بخش کامیونیتی است. همیشه پیشنهاد می‌کنم قبل از باز کردن Issue در گیت‌هاب، ابتدا داکیومنت‌ها را مرور کنید.
