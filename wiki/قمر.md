# راهنمای جامع کار با «قمر» (Qamar)

اگر در دنیای توسعه نرم‌افزار و پروژه‌های میان‌رشته‌ای فعالیت کرده باشید، حتماً با چالش همگام‌سازی داده‌ها بین محیط‌های مختلف مواجه شده‌اید. **قمر** همان قطعه گمشده‌ای است که پیچیدگی‌های اتصال زیرساخت‌های پراکنده را برای ما حل می‌کند. 

این ابزار فراتر از یک کتابخانه ساده است؛ در واقع یک اکوسیستم کوچک برای مدیریت جریان داده در پروژه‌هایی است که ترکیبی از علوم داده، وب و سیستم‌های توزیع‌شده هستند.

---

## ۱. چرا قمر؟ (فلسفه طراحی)
بسیاری از ابزارها فقط برای یک محیط خاص (مثلاً فقط Node.js یا فقط Python) بهینه شده‌اند. قمر با رویکرد «چند‌زبانه و میان‌رشته‌ای» طراحی شده تا بتوانید بدون درگیری با پروتکل‌های سنگین، داده‌ها را جابه‌جا کنید.

*   **سبک و سریع:** سربار (Overhead) بسیار ناچیز.
*   **انعطاف‌پذیر:** پشتیبانی عالی از JSON و باینری.
*   **مستندات زنده:** همگام با تغییرات جدید.

---

## ۲. نصب و راه‌اندازی

نصب قمر به دلیل سادگی ساختار، کمتر از یک دقیقه زمان می‌برد. بسته به محیط کاری خود، یکی از روش‌های زیر را انتخاب کنید:

### برای محیط‌های Node.js:
```bash
npm install qamar-core --save
```

### برای محیط‌های Python:
```bash
pip install qamar-lib
```

---

## ۳. مثال عملی: اولین ارتباط

فرض کنید می‌خواهید یک پیام را بین دو سرویس مختلف جابه‌جا کنید. ساختار کلی کد در قمر به این صورت است:

```javascript
// مثال در محیط Node.js
const Qamar = require('qamar-core');

const node = new Qamar.Node({ port: 3000 });

node.on('data', (payload) => {
    console.log('داده جدید دریافت شد:', payload);
});

node.broadcast({ message: "سلام از دنیای قمر!" });
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
بله، قمر به گونه‌ای طراحی شده که در زیرساخت‌های کلاسترینگ به خوبی رفتار می‌کند. هرچند پیشنهاد می‌کنم برای مقیاس‌های بسیار بزرگ، مستندات مربوط به `Qamar-Cluster` را مطالعه کنید.

**آیا نیاز به دیتابیس خاصی دارم؟**
خیر، قمر در سطح پروتکل ارتباطی عمل می‌کند و کاملاً دیتابیس-آگنوستیک (Database Agnostic) است.

**پشتیبانی از پروتکل‌های امنیتی به چه صورت است؟**
قمر از لایه TLS به صورت پیش‌فرض پشتیبانی می‌کند. برای فعال‌سازی آن کافی است در فایل تنظیمات، مسیر گواهی‌های SSL خود را معرفی کنید.
