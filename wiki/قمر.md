# راهنمای جامع «قمر»: پلی میان دنیای داده و هنر

اگر تا به حال درگیر مدیریت پروژه‌های میان‌رشته‌ای (Interdisciplinary) بوده‌اید، حتماً می‌دانید که بزرگ‌ترین دردسر، نه خودِ تکنولوژی، بلکه «اتصال» دنیای محاسبات به دنیای مفاهیم انتزاعی است. «قمر» دقیقاً برای حل همین چالش طراحی شده است. این ابزار، یک فریم‌ورک سبک اما قدرتمند است که به شما اجازه می‌دهد جریان‌های کاری (Workflows) پیچیده را بدون درگیری با پیچیدگی‌های غیرضروری، پیاده‌سازی کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (نگاهی از دیدگاه توسعه‌دهنده)

بیشتر ابزارهای موجود یا بیش از حد مهندسی‌شده‌اند (Over-engineered) یا آن‌قدر ساده که برای پروژه‌های جدی به کار نمی‌آیند. قمر در نقطه تعادل ایستاده است. استفاده از آن حس نوشتن کدهای تمیز و ماژولار را می‌دهد.

### ویژگی‌های کلیدی:
*   **انعطاف‌پذیری بالا:** مناسب برای ترکیب علوم داده، طراحی بصری و مهندسی سیستم.
*   **پایداری:** معماری آن به‌گونه‌ای است که حتی در پردازش‌های سنگین، کم نمی‌آورد.
*   **سهولت در یادگیری:** یادگیری آن شبیه به فراگیری یک زبان جدید است که قواعدش از همان ابتدا منطقی به نظر می‌رسد.

## نصب و راه‌اندازی

نصب قمر ساده‌تر از آن است که فکرش را می‌کنید. اگر از سیستم‌عامل‌های مبتنی بر یونیکس (لینوکس یا مک) استفاده می‌کنید، تنها با اجرای یک دستور ساده در ترمینال، همه‌چیز آماده است:

```bash
# نصب قمر از طریق مخزن رسمی
curl -sSL https://qamar.website/install.sh | bash
```

پس از اتمام نصب، برای اطمینان از درستی فرآیند، دستور زیر را وارد کنید:
```bash
qamar --version
```

## استفاده سریع: اولین پروژه

برای اینکه ببینید قمر چگونه کار می‌کند، یک مثال کلاسیک از یک جریان پردازش داده-هنر را بررسی می‌کنیم. فرض کنید می‌خواهیم داده‌های ورودی را بگیریم و خروجی بصری تولید کنیم.

```python
import qamar

# تعریف یک گره پردازشی ساده
@qamar.node
def process_data(input_stream):
    return [x * 1.5 for x in input_stream]

# اجرای جریان
pipeline = qamar.Pipeline(source="data_source.json")
pipeline.add(process_data)
pipeline.run()
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
قطعاً. معماری ماژولار قمر اجازه می‌دهد که پروژه‌ها را به قطعات کوچک‌تر تقسیم کرده و به‌صورت جداگانه توسعه دهید.

**۲. اگر با خطایی مواجه شدم، کجا می‌توانم کمک بگیرم؟**
مستندات موجود در [qamar.website](https://qamar.website) بسیار جامع هستند. همچنین می‌توانید در مخزن گیت‌هاب پروژه، Issue ثبت کنید.

**۳. آیا قمر از کتابخانه‌های خارجی پشتیبانی می‌کند؟**
بله، قمر به‌گونه‌ای طراحی شده که با اکوسیستم‌های رایج پایتون و جاوا اسکریپت کاملاً سازگار است. هیچ محدودیتی در استفاده از کتابخانه‌های محبوب ندارید.
