# مستندات فنی: قمر (Qamar)
**پلتفرمی برای همگرایی دانش و داده**

---

## مقدمه
اگر در حوزه‌های میان‌رشته‌ای (Interdisciplinary) کار کرده باشید، حتماً با دردسر «جزیره‌های داده» آشنا هستید. «قمر» دقیقاً برای حل همین مشکل متولد شده است؛ ابزاری که به شما اجازه می‌دهد بین مفاهیم پیچیده، داده‌های خام و خروجی‌های پژوهشی، ارتباطی ارگانیک و زنده برقرار کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
بیشتر ابزارها یا برای برنامه‌نویس‌ها هستند یا برای محقق‌های علوم انسانی. قمر پل میان این دو است. من شخصاً وقتی روی پروژه‌هایی کار می‌کنم که نیاز به تحلیل داده‌های متنی در کنار مدل‌سازی ریاضی دارند، از قمر استفاده می‌کنم چون ساختار آن به جای محدود کردن کاربر، به جریان فکری او جهت می‌دهد.

---

## نصب و راه‌اندازی

برای شروع، نیازی به پیچیدگی‌های عجیب و غریب نیست. قمر طوری طراحی شده که با استانداردهای وب مدرن همخوانی داشته باشد.

### پیش‌نیازها
*   Node.js نسخه ۱۸ به بالا
*   یک ادیتور متن (پیشنهاد من VS Code است)

### نصب سریع
کافیست در ترمینال خود دستور زیر را اجرا کنید:

```bash
npm install @qamar/core --save
```

سپس برای مقداردهی اولیه محیط کاری:

```bash
npx qamar init --project-type interdisciplinary
```

## نحوه استفاده (مثال عملی)

فرض کنید می‌خواهید یک «گره دانش» (Knowledge Node) تعریف کنید که داده‌های یک فایل JSON را به یک متن تحلیلی متصل می‌کند.

```javascript
import { QamarNode } from '@qamar/core';

const myResearchNode = new QamarNode({
  title: "تحلیل همبستگی داده‌های اقلیمی و اقتصادی",
  tags: ["Climate-Change", "Economics"],
  content: "در این بخش، اثرات تغییرات دما بر بازارهای محلی را بررسی می‌کنیم."
});

// اتصال به منبع داده
myResearchNode.linkSource("./data/climate_stats.json");

myResearchNode.publish();
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ دانشگاهی مناسب است؟**
بله، ساختار ماژولار قمر اجازه می‌دهد تا پروژه‌های چند هزار صفحه‌ای را بدون افت سرعت مدیریت کنید.

**۲. آیا داده‌های من در قمر امن هستند؟**
قمر در هسته خود بر پایه "Local-first" طراحی شده است. یعنی فایل‌ها در سیستم خودتان ذخیره می‌شوند و کنترل کامل دست شماست.

**۳. آیا باید حتماً برنامه‌نویس باشم؟**
نه لزوماً. رابط گرافیکی قمر برای کسانی که نمی‌خواهند درگیر کدنویسی شوند هم امکانات کاملی ارائه می‌دهد. اما اگر کمی با سینتکس آشنا باشید، قدرت واقعی قمر را در اتوماسیون جریان کاری‌تان حس خواهید کرد.
