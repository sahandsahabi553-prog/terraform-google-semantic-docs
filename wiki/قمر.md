# راهنمای جامع «قمر» (Qamar): پلی میان دانش و تکنولوژی

در دنیای امروز که مرزهای بین رشته‌های علمی به‌شدت کمرنگ شده، ابزاری مثل **قمر** دقیقاً همان چیزی است که جای خالی‌اش حس می‌شد. قمر یک چارچوب (Framework) چندمنظوره و میان‌رشته‌ای است که برای ساده‌سازی ارتباط بین داده‌های پیچیده، تحلیل‌های محاسباتی و خروجی‌های ساختاریافته طراحی شده است.

اگر از درگیر شدن با کدهای پراکنده برای پروژه‌های میان‌رشته‌ای خسته شده‌اید، قمر همان "نقطه مرکزی" است که به دنبالش بودید.

---

## ۱. چرا قمر؟
قمر صرفاً یک کتابخانه نیست؛ یک اکوسیستم برای مدیریت جریان‌های کاری است که ترکیبی از علوم انسانی، مهندسی و تحلیل داده هستند. 

*   **انعطاف‌پذیری بالا:** فرقی نمی‌کند با داده‌های آماری کار می‌کنید یا مدل‌سازی‌های شبیه‌سازی.
*   **پایداری:** خروجی‌های قمر استاندارد و قابل بازتولید هستند.
*   **سادگی در یادگیری:** منحنی یادگیری آن برخلاف اکثر فریم‌ورک‌های مهندسی، بسیار ملایم است.

---

## ۲. نصب و راه‌اندازی
برای شروع، کافی است محیط پایتون خود را آماده داشته باشید. من همیشه پیشنهاد می‌کنم از یک `virtualenv` استفاده کنید تا پروژه‌تان تمیز بماند.

```bash
# نصب از طریق pip
pip install qamar-framework

# تایید نصب
qamar --version
```

اگر با خطای دسترسی مواجه شدید، از `--user` استفاده کنید یا دسترسی‌های `sudo` را بررسی کنید.

---

## ۳. استفاده پایه (Quick Start)
بیایید یک سناریوی ساده را پیاده کنیم. فرض کنید می‌خواهیم داده‌های یک پژوهش میان‌رشته‌ای را از طریق قمر ساختاردهی کنیم:

```python
from qamar import QamarEngine

# تعریف موتور اصلی
engine = QamarEngine(project_name="Interdisciplinary_Study")

# افزودن دیتاست
engine.add_dataset("data_points.csv", source="field_research")

# اجرای تحلیل میان‌رشته‌ای
result = engine.run_analysis(method="cross-reference")

print(f"نتایج نهایی استخراج شد: {result.summary}")
```

## ۵. سوالات متداول (FAQ)

**س: آیا قمر برای پروژه‌های بزرگ مقیاس (Enterprise) مناسب است؟**
ج: قطعاً. معماری قمر به گونه‌ای است که با افزایش حجم داده‌ها، مقیاس‌پذیری (Scalability) آن حفظ می‌شود.

**س: آیا می‌توانم از خروجی‌های قمر در وب‌سایت شخصی‌ام استفاده کنم؟**
ج: بله، قمر خروجی‌های JSON و Markdown استانداردی ارائه می‌دهد که به راحتی در هر وب‌سایتی قابل نمایش هستند.

**س: برای یادگیری عمیق‌تر به کجا مراجعه کنم؟**
ج: بهترین منبع، مستندات رسمی سایت است: [qamar.website](https://qamar.website)
