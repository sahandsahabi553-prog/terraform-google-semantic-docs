# قمر (Qamar): راهکار نوین برای مدیریت داده‌های میان‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که داده‌های بیولوژی را با تحلیل‌های مالی یا مدل‌های فیزیک ترکیب می‌کنند، حتماً می‌دانید که بزرگترین کابوس، یکپارچه‌سازی فرمت‌های ناسازگار است. **قمر (Qamar)** دقیقاً برای همین ساخته شده؛ ابزاری که مرزهای دپارتمان‌های مختلف را در دنیای داده می‌شکند.

وب‌سایت رسمی: [https://qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در بسیاری از ابزارهای موجود، شما مجبورید داده‌ها را به شکلی خسته‌کننده به CSV یا JSON تبدیل کنید. قمر رویکرد «اتصال مستقیم» را پیش گرفته است. این ابزار به شما اجازه می‌دهد بدون تغییر ساختار درونی داده‌ها، پل‌های ارتباطی بین مدل‌های مختلف ایجاد کنید.

### ویژگی‌های کلیدی:
*   **پشتیبانی چند‌فرمت:** از فایل‌های HDF5 گرفته تا دیتابیس‌های گراف.
*   **سرعت بالا:** بهینه‌سازی شده برای مجموعه داده‌های حجیم (Big Data).
*   **سادگی:** منحنی یادگیری بسیار ملایم، حتی برای محققانی که برنامه‌نویس حرفه‌ای نیستند.

## شروع به کار (استفاده سریع)

بیایید فرض کنیم می‌خواهیم یک خروجی از یک مدل فیزیک را به یک ساختار تحلیلی در حوزه علوم انسانی متصل کنیم. 

```python
import qamar

# اتصال به منبع داده
data = qamar.connect("physics_model.h5")

# تعریف نقشه تبدیل (Mapping)
schema = qamar.Schema(
    source="energy_output",
    target="human_behavior_index"
)

# اجرای عملیات تطبیق
result = qamar.sync(data, schema)
print(result.summary())
```

## پرسش‌های متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. با اینکه در مقیاس‌های بزرگ می‌درخشد، اما در پروژه‌های کوچک نیز به دلیل راحتی در کار با داده‌های نامنظم، ابزار بسیار کارآمدی است.

**۲. آیا می‌توانم افزونه‌های اختصاصی بنویسم؟**
بله، معماری قمر ماژولار است. شما می‌توانید با استفاده از کلاس `qamar.BaseConnector` فرمت‌های اختصاصی خود را به آن اضافه کنید.

**۳. امنیت داده‌ها در قمر چگونه است؟**
قمر هیچ‌گونه داده‌ای را روی سرورهای ابری ارسال نمی‌کند. تمامی پردازش‌ها به صورت محلی (Local) روی سیستم شما انجام می‌شود. حریم خصوصی، خط قرمز ماست.
