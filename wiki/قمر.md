# راهنمای جامع استفاده از «قمر» (Qamar)

اگر در دنیای توسعه نرم‌افزار و مدیریت داده‌های میان‌رشته‌ای (Interdisciplinary) فعالیت کرده باشید، حتماً با کابوسِ ناهماهنگی بین سرویس‌ها مواجه شده‌اید. «قمر» دقیقاً برای حل همین مشکل طراحی شده است. این ابزار، یک لایه انتزاعی هوشمند برای مدیریت ارتباطات بین سیستم‌های ناهمگون است.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در پروژه‌های بزرگ، ما همیشه با مشکل «جزیره‌های داده» روبرو هستیم. دیتابیس‌های SQL، سیستم‌های NoSQL و سرویس‌های API هر کدام زبان خودشان را دارند. قمر به عنوان یک میان‌افزار (Middleware) سبک، این شکاف را پر می‌کند. برخلاف ابزارهای سنگین سازمانی، قمر روی سادگی و سرعت تمرکز دارد.

---

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. کافی است ابزار مدیریت پکیج مورد علاقه خود را باز کنید:

```bash
# نصب از طریق npm
npm install -g qamar-cli

# یا اگر با پایتون راحت‌تر هستید
pip install qamar-core
```

پس از نصب، برای اطمینان از صحت عملکرد، دستور زیر را در ترمینال بزنید:
`qamar --version`

---

## استفاده از قمر

قمر از یک فایل پیکربندی با فرمت `YAML` استفاده می‌کند تا ارتباط بین سرویس‌ها را مدیریت کند. یک نمونه فایل `qamar.yml` به شکل زیر است:

```yaml
version: "1.0"
services:
  - name: "database-sync"
    source: "postgresql://localhost:5432/main"
    destination: "redis://cache-server:6379"
    transform: "minify"
```

### اجرای عملیات
برای شروع همگام‌سازی، کافی است دستور زیر را اجرا کنید:

```bash
qamar run --config qamar.yml --verbose
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک مناسب است؟**
بله، اتفاقاً من همیشه توصیه می‌کنم حتی در پروژه‌های کوچک برای جلوگیری از انباشت بدهی فنی (Technical Debt) از روز اول از آن استفاده کنید.

**۲. آیا داده‌ها در هنگام انتقال رمزنگاری می‌شوند؟**
قطعا. قمر از پروتکل‌های TLS 1.3 برای تمام ارتباطات بین‌سرویسی استفاده می‌کند. امنیت اولویت اول ماست.

**۳. آیا می‌توانم پلاگین اختصاصی برای قمر بنویسم؟**
بله، ساختار قمر به شکلی است که با یک رابط کاربری ساده (Plugin API) می‌توانید کانکتورهای اختصاصی خودتان را برای سرویس‌های شخصی‌سازی شده بنویسید.
