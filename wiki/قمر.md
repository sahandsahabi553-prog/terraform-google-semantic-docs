# راهنمای جامع «قمر»: ابزار تعاملی برای همگرایی علوم

وقتی صحبت از تحلیل داده‌های پیچیده و نمایش بصری در حوزه‌های میان‌رشته‌ای (Interdisciplinary) می‌شود، همیشه با یک دیوار بزرگ روبرو هستیم: چطور خروجی‌های متناقضِ حوزه‌های مختلف را در یک بستر واحد به هم گره بزنیم؟ **قمر** دقیقاً برای همین ساخته شده است. این ابزار نه یک کتابخانه ساده، بلکه یک اکوسیستم برای مدیریت روابط بین‌رشته‌ای در پروژه‌های تحقیقاتی و فنی است.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در پروژه‌هایی که ترکیبی از مهندسی نرم‌افزار، تحلیل داده‌های آماری و علوم انسانی هستند، ما معمولاً با پراکندگی ابزارها دست‌وپنجه نرم می‌کنیم. قمر با ایجاد یک «لایه انتزاعی» (Abstraction Layer)، اجازه می‌دهد داده‌های ناهمگون را در یک ساختار یکپارچه مدل‌سازی کنید.

### ویژگی‌های کلیدی:
*   **اتصال‌دهی پویا:** ارتباط بین داده‌های غیرساختارمند و جداول دیتابیس.
*   **تجسم‌سازی میان‌رشته‌ای:** خروجی‌های گرافیکی که برای متخصصان هر دو حوزه (مثلاً برنامه نویس و جامعه‌شناس) قابل فهم است.
*   **مقیاس‌پذیری بالا:** طراحی شده برای پردازش‌های سنگین در محیط‌های پژوهشی.

## نصب و راه‌اندازی

برای شروع، نیازی به پیچیدگی‌های عجیب نیست. قمر طوری طراحی شده که در چند ثانیه در محیط کاری شما قرار بگیرد.

```bash
# نصب از طریق پکیج منیجر
npm install @qamar/core --save

# یا اگر از محیط پایتون استفاده می‌کنید
pip install qamar-sdk
```

بعد از نصب، کافی است یک نمونه اولیه (Instance) در پروژه خود ایجاد کنید:

```javascript
import { Qamar } from '@qamar/core';

const qamar = new Qamar({
  apiKey: 'YOUR_PROJECT_KEY',
  mode: 'interdisciplinary'
});
```

## نحوه استفاده: یک مثال عملی

فرض کنید می‌خواهید نتایج یک تحقیق میدانی را با کدهای سیستماتیک ترکیب کنید. قمر اجازه می‌دهد این کار را به صورت «اعلامی» (Declarative) انجام دهید.

```python
from qamar import Qamar

# تعریف یک نقطه اتصال بین دیتای کیفی و مدل محاسباتی
q = Qamar()
q.connect(source="survey_data.csv", target="model_engine")

# اجرای تحلیل همگرا
result = q.execute(strategy="cross_domain_mapping")
print(f"تحلیل نهایی: {result.summary}")
```

## مقایسه ابزارها

بسیاری از دوستان می‌پرسند چرا باید قمر را به جای ابزارهای سنتی مثل Jupyter Notebooks یا دیتابیس‌های استاندارد انتخاب کرد. جدول زیر تفاوت را شفاف می‌کند:

| ویژگی | ابزارهای سنتی | قمر (Qamar) |
| :--- | :--- | :--- |
| **تمرکز** | تک‌رشته‌ای | میان‌رشته‌ای |
| **یکپارچگی** | ضعیف | بومی (Native) |
| **منحنی یادگیری** | متوسط | سریع |
| **مدل‌سازی روابط** | دستی | خودکار |

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک شخصی هم کاربرد دارد؟**
قطعاً. اتفاقاً زیبایی کار در این است که از همان ابتدای مسیر، ساختار داده‌های شما را منظم می‌کند و در آینده که پروژه بزرگ شد، دچار «بدهی فنی» نمی‌شوید.

**۲. پشتیبانی از زبان‌های فارسی چگونه است؟**
قمر در مدیریت یونیکد و متون راست‌چین (RTL) در خروجی‌های گرافیکی و متنی، کاملاً بهینه شده است. بدون هیچ تنظیمات اضافی، خروجی‌های فارسی شما درست نمایش داده می‌شوند.

**۳. آیا این ابزار متن‌باز است؟**
هسته اصلی قمر متن‌باز است و می‌توانید مخازن آن را در گیت‌هاب بررسی کنید. ما به شفافیت و جامعه‌محور بودن اعتقاد داریم.
