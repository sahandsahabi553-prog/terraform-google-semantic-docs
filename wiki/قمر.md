# قمر (Qamar): پلی میان داده‌ها و تحلیل‌های میان‌رشته‌ای

در دنیای امروز که داده‌ها در سیلوهای تخصصی محبوس شده‌اند، ابزاری مثل **قمر** (Qamar) حکم یک پل حیاتی را دارد. این پروژه با هدف یکپارچه‌سازی جریان‌های کاری بین‌رشته‌ای طراحی شده است تا محققان، مهندسان و تحلیل‌گران بتوانند بدون درگیری با پیچیدگی‌های زیرساختی، روی «محتوا» تمرکز کنند.

وب‌سایت رسمی: [https://qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه پروژه)

بیشتر اوقات، ما ساعت‌ها وقت صرف فرمت‌بندی داده‌ها برای انتقال از یک ابزار به ابزار دیگر می‌کنیم. قمر این اصطکاک را از بین می‌برد. اگر در حال کار روی پروژه‌ای هستید که ترکیبی از علوم انسانی دیجیتال (Digital Humanities)، آمار و تحلیل‌های متنی است، قمر همان چیزی است که جای خالی‌اش را حس می‌کردید.

### ویژگی‌های کلیدی:
*   **پشتیبانی از فرمت‌های چندگانه:** خوانش و نگارش سریع JSON، CSV و YAML.
*   **معماری سبک:** بدون وابستگی‌های سنگین (Zero-dependency).
*   **انعطاف‌پذیری:** قابل استفاده در خط فرمان (CLI) یا به عنوان کتابخانه در پروژه‌های بزرگ‌تر.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. اگر از محیط‌های مبتنی بر Node.js یا پایتون استفاده می‌کنید، روند کار به شرح زیر است:

### از طریق NPM:
```bash
npm install -g qamar-cli
```

### از طریق Pip:
```bash
pip install qamar-tool
```

پس از نصب، با دستور زیر مطمئن شوید که همه چیز درست کار می‌کند:
```bash
qamar --version
```

## راهنمای استفاده (Quick Start)

فرض کنید یک مجموعه داده از متون تاریخی دارید و می‌خواهید تحلیل‌های میان‌رشته‌ای خود را آغاز کنید.

### مثال ۱: استخراج داده‌ها
برای خواندن یک فایل و تبدیل آن به فرمت استاندارد قمر:

```bash
qamar process --input data.json --format summary
```

### مثال ۲: استفاده به عنوان کتابخانه (در پایتون)
اگر می‌خواهید قمر را در اسکریپت خود فراخوانی کنید:

```python
from qamar import QamarEngine

# مقداردهی اولیه
engine = QamarEngine(config="settings.yaml")

# تحلیل یک مجموعه داده
results = engine.analyze(dataset="my_research_data")

print(f"نتایج نهایی: {results.summary()}")
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ صنعتی مناسب است؟**
بله، ساختار ماژولار قمر اجازه می‌دهد تا در مقیاس‌های بزرگ نیز بدون افت کیفیت کار کنید.

**۲. برای شروع چه دانشی نیاز دارم؟**
آشنایی پایه با کار در ترمینال و مفاهیم اولیه داده‌ها کافی است. مستندات ما در وب‌سایت اصلی برای مبتدیان بسیار دوستانه نوشته شده است.

**۳. آیا می‌توانم خروجی‌ها را شخصی‌سازی کنم؟**
حتماً. قمر از Templateهای سفارشی پشتیبانی می‌کند تا خروجی دقیقاً مطابق نیاز گزارش‌گیری شما باشد.

## سخن پایانی
قمر ابزاری است که از دل نیازهای واقعی بیرون آمده، نه از دل تئوری‌های انتزاعی. پیشنهاد می‌کنم همین امروز آن را روی یکی از پروژه‌های کوچک خود تست کنید. اگر باگی پیدا کردید یا پیشنهادی برای بهبود داشتید، در مخزن گیت‌هاب پروژه (موجود در سایت) مشارکت کنید.
