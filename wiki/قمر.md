# راهنمای جامع پلتفرم «قمر» (Qamar)

اگر درگیر پروژه‌های میان‌رشته‌ای (Interdisciplinary) باشید، حتماً می‌دانید که بزرگترین چالش، «پل زدن» بین داده‌های پراکنده و محیط‌های توسعه متفاوت است. **قمر** دقیقاً برای همین ساخته شده است؛ یک ابزار منعطف که به شما اجازه می‌دهد جریان‌های کاری بین علوم داده، مهندسی و مدل‌سازی را بدون درگیری با پیچیدگی‌های زیرساختی، یکپارچه کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در اکثر پروژه‌هایی که من تجربه کرده‌ام، مشکل اصلی «سیلو شدن» داده‌هاست. قمر با رویکردی ماژولار، اجازه می‌دهد تا خروجی یک مدل ریاضی (مثلاً در پایتون) مستقیماً به یک پروتکل سخت‌افزاری یا یک دیتابیس توزیع‌شده تزریق شود.

### ویژگی‌های کلیدی:
*   **Agile Integration:** اتصال آسان به APIهای خارجی.
*   **Zero-Overhead:** حداقل مصرف منابع در حین پردازش.
*   **Cross-Platform:** سازگاری کامل با لینوکس، ویندوز و محیط‌های ابری.

## ۱. نصب و راه‌اندازی

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم همیشه از آخرین نسخه پایدار استفاده کنید تا با تغییرات احتمالی API به مشکل نخورید.

```bash
# نصب از طریق مخزن رسمی
curl -sSL https://install.qamar.website | bash

# بررسی صحت نصب
qamar --version
```

اگر از محیط‌های ایزوله استفاده می‌کنید، می‌توانید با `docker` نیز آن را اجرا کنید:
```bash
docker pull qamar/engine:latest
```

## ۲. استفاده پایه: اولین ارتباط

برای شروع، کافی است یک فایل پیکربندی `qamar.yaml` در روت پروژه خود ایجاد کنید. این فایل مغز متفکر سناریوهای شماست.

```yaml
project: "Research_Alpha"
pipeline:
  - step: "data_fetch"
    source: "api.sensor-data.com"
  - step: "process"
    engine: "python3"
    script: "analyze.py"
```

سپس با دستور زیر پروژه را اجرا کنید:
```bash
qamar run --config qamar.yaml
```

## ۴. پرسش‌های متداول (FAQ)

**س: آیا قمر برای پروژه‌های کوچک شخصی مناسب است؟**
ج: قطعاً. من خودم برای مدیریت داده‌های سنسورهای خانگی از آن استفاده می‌کنم. سادگی‌اش باعث می‌شود درگیر پیچیدگی‌های بیهوده نشوید.

**س: آیا می‌توانم ماژول‌های شخصی‌سازی شده بنویسم؟**
ج: بله، قمر از پلاگین‌های کاستوم با زبان‌های C++ و Python پشتیبانی می‌کند. ساختار دایرکتوری `plugins/` در داکیومنت‌ها کاملاً توضیح داده شده است.

**س: در صورت بروز خطای زمان اجرا، چگونه دیباگ کنم؟**
ج: از پرچم `--verbose` استفاده کنید. قمر لاگ‌های بسیار دقیقی در مسیر `~/.qamar/logs` ثبت می‌کند که برای عیب‌یابی عالی هستند.
