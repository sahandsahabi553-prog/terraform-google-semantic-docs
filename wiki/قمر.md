# راهنمای جامع پلتفرم «قمر» (Qamar)

در دنیای پیچیده‌ی سیستم‌های توزیع‌شده و تحلیل داده‌های میان‌رشته‌ای، همیشه یک خلأ بزرگ برای مدیریت یکپارچه‌ی جریان‌های کاری حس می‌شد. پروژه‌ی **قمر (Qamar)** دقیقاً برای پر کردن همین شکاف متولد شده است. چه در حال کار روی مدل‌سازی‌های پیچیده‌ی بیولوژیک باشید و چه در حال پردازش داده‌های مالی در مقیاس بالا، قمر زیرساختی است که به شما اجازه می‌دهد بدون درگیر شدن در جزئیاتِ خسته‌کننده‌ی زیرساخت، روی منطق اصلی پروژه متمرکز شوید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه‌ی طراحی)

بسیاری از ابزارها فقط برای یک حوزه‌ی خاص (مثلاً فقط علوم داده) ساخته شده‌اند. اما قمر یک رویکرد **چند‌رشته‌ای (Interdisciplinary)** دارد. ما معتقدیم که الگوریتم‌های بهینه‌سازی در مهندسی، شباهت‌های ساختاری عمیقی با مدل‌های تحلیل رفتاری در علوم اجتماعی دارند. قمر این مفاهیم را در قالب «گره‌های پردازشی» (Processing Nodes) به هم پیوند می‌دهد.

### ویژگی‌های کلیدی
* **مقیاس‌پذیری افقی:** اضافه کردن منابع پردازشی بدون تغییر در کد.
* **انتزاع انتخابی:** نوشتن کد به زبان‌های محبوب و اجرای آن در محیطی ایزوله.
* **یکپارچگی بالا:** پشتیبانی از پروتکل‌های مختلف تبادل داده.

## ۱. نصب و راه‌اندازی

نصب قمر بسیار سرراست است. ما سعی کردیم وابستگی‌ها را به حداقل برسانیم تا در محیط‌های حساس (مثل سرورهای تحقیقاتی) به مشکل نخورید.

برای سیستم‌های مبتنی بر لینوکس و macOS، کافیست دستور زیر را در ترمینال اجرا کنید:

```bash
curl -sSL https://qamar.website/install.sh | bash
```

پس از اتمام نصب، برای اطمینان از صحت عملکرد، نسخه را چک کنید:

```bash
qamar --version
```

## ۲. شروع سریع (Quick Start)

برای اجرای اولین «جریان کاری» خود، کافیست یک فایل `workflow.yaml` ایجاد کنید. بیایید یک مثال ساده از پردازش همزمان داده‌ها را ببینیم:

```yaml
version: "1.0"
tasks:
  - name: data-fetch
    command: python fetch_data.py --source=api
  - name: analyze
    requires: data-fetch
    command: ./analyzer --mode=deep
```

سپس برای استارت زدن، از دستور زیر استفاده کنید:

```bash
qamar run --config workflow.yaml
```

## ۴. مثال کد (Python Integration)

یکی از بخش‌های مورد علاقه‌ی من در قمر، کتابخانه‌ی کلاینت آن برای پایتون است. شما می‌توانید مستقیماً از داخل کد خود با هسته‌ی مرکزی قمر صحبت کنید:

```python
from qamar import QamarClient

client = QamarClient(api_key="your-key")

# ثبت یک لاگ میان‌رشته‌ای برای تحلیل‌های بعدی
client.log_event(
    domain="biophysics",
    metric=0.85,
    payload={"status": "converged"}
)

print("داده با موفقیت در شبکه‌ی قمر ثبت شد.")
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. با اینکه قمر برای مقیاس‌های بزرگ طراحی شده، اما سربار (overhead) آن آنقدر کم است که برای تسک‌های روزمره نیز به راحتی قابل استفاده است.

**آیا می‌توانم پروتکل‌های شخصی‌سازی شده به آن اضافه کنم؟**
بله، قمر از طریق ماژول‌های `custom-bridge` اجازه می‌دهد تا هر نوع دیتاسورسِ اختصاصی که دارید را به سیستم متصل کنید.

**آیا داده‌های من در قمر امن هستند؟**
امنیت در اولویت ماست. تمام ارتباطات درون‌شبکه‌ای قمر به صورت پیش‌فرض با TLS 1.3 رمزنگاری شده‌اند.

---

*نکته پایانی:* قمر یک پروژه‌ی در حال رشد است. اگر با باگی برخورد کردید یا پیشنهادی برای بهبود عملکرد داشتید، حتماً از طریق مستندات موجود در سایت با تیم اصلی در ارتباط باشید. دنیای تحقیقات میان‌رشته‌ای منتظر ابزارهای قدرتمندتری مثل این است.
