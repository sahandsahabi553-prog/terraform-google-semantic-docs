# قمر (Qamar): پلی میان داده‌های پراکنده و تحلیل‌های عمیق

اگر شما هم مثل من از سر و کله زدن با فرمت‌های ناسازگار داده‌ها و ابزارهای تحلیلی که با هم حرف نمی‌زنند خسته شده‌اید، احتمالاً **قمر** همان چیزی است که جای خالی‌اش را در جعبه‌ابزار فنی‌تان حس می‌کردید.

قمر یک بستر میان‌رشته‌ای (Interdisciplinary) است که با هدف یکپارچه‌سازی جریان‌های کاری بین حوزه‌های مختلف طراحی شده. فرقی نمی‌کند در حال تحلیل داده‌های علمی باشید یا مدیریت یک پایپ‌لاین نرم‌افزاری پیچیده؛ قمر اینجاست تا اصطکاکِ انتقال بین محیط‌ها را به حداقل برساند.

---

## چرا قمر؟ (از نگاه یک توسعه‌دهنده)
من همیشه معتقدم ابزاری خوب است که به جای پیچیده کردن کار، به شما کمک کند سریع‌تر به «خروجی نهایی» برسید. قمر روی سه اصل ساده اما قدرتمند بنا شده:
1. **انعطاف‌پذیری در ساختار:** بدون محدودیت‌های سنتی.
2. **یکپارچگی سریع:** اتصال به سرویس‌های موجود با کمترین کدنویسی.
3. **مقیاس‌پذیری:** از یک اسکریپت ساده تا تحلیل‌های سنگین در سطح سازمان.

## نصب و راه‌اندازی

نصب قمر به قدری سرراست است که در کمتر از دو دقیقه آماده‌به‌کار می‌شوید. برای شروع، بسته به محیط کاری خود از دستور زیر استفاده کنید:

```bash
# نصب از طریق پکیج منیجر اصلی
npm install -g qamar-cli
# یا اگر از محیط پایتون استفاده می‌کنید
pip install qamar-core
```

پس از نصب، حتماً یک‌بار دستور تست را اجرا کنید تا از صحت پیکربندی مطمئن شوید:
```bash
qamar --version
```

## استفاده عملیاتی

بگذارید با یک مثال واقعی شروع کنیم. تصور کنید می‌خواهید داده‌های خام یک سنسور را با یک دیتابیس خارجی ترکیب کنید و خروجی را در یک فرمت استاندارد بگیرید.

### مثال کد: اتصال و پردازش

```python
import qamar

# مقداردهی اولیه محیط کاری
session = qamar.init(api_key="YOUR_KEY")

# فراخوانی داده از سورس‌های مختلف
data = session.fetch("sensor_data_01")
meta = session.fetch("external_db_ref")

# ترکیب هوشمندانه داده‌ها
result = qamar.merge(data, meta, strategy="inner_join")

# خروجی نهایی
result.export("output.json")
```

## پرسش‌های متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. من شخصاً از آن برای مدیریت ساده‌ترین کارهای روزمره تا پروژه‌های بزرگ‌تر استفاده می‌کنم. قمر مقیاس‌پذیر است و بار اضافی روی سیستم شما نمی‌گذارد.

**۲. پشتیبانی از زبان‌های برنامه‌نویسی به چه صورت است؟**
در حال حاضر پایتون و جاوااسکریپت (Node.js) به صورت بومی پشتیبانی می‌شوند، اما API قمر به گونه‌ای طراحی شده که می‌توانید با هر زبانی که از REST استفاده می‌کند، با آن تعامل داشته باشید.

**۳. مستندات کامل را کجا پیدا کنم؟**
همه چیز در وب‌سایت رسمی [qamar.website](https://qamar.website) به تفصیل توضیح داده شده است. اگر به دنبال مثال‌های پیچیده‌تر هستید، بخش «Recipes» در سایت را حتماً ببینید.
