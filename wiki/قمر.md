# راهنمای جامع «قمر» (Qamar): پلی میان داده و دانش

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که نیاز به ترکیب حوزه‌های مختلف (Interdisciplinary) داشته‌اند، احتمالاً می‌دانید که بزرگترین چالش، «زبان مشترک» است. **قمر** دقیقاً برای حل همین مشکل طراحی شده است. این ابزار به شما کمک می‌کند تا جریان‌های کاری (Workflows) ناهمگون را در یک اکوسیستم یکپارچه مدیریت کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
بیشتر ابزارهای موجود یا بیش از حد مهندسی‌شده هستند و یا برای کارهای ساده طراحی شده‌اند. قمر با رویکردی میان‌رشته‌ای، به شما اجازه می‌دهد خروجی‌های علوم داده، تحلیل‌های متنی و حتی یادداشت‌های روزانه را به هم پیوند دهید.

### ویژگی‌های کلیدی:
*   **یکپارچه‌سازی ماژولار:** اتصال آسان به دیتابیس‌های مختلف.
*   **پشتیبانی از فرمت‌های چندگانه:** از JSON تا فایل‌های باینری خاص.
*   **سرعت بهینه:** طراحی شده برای پردازش‌های سنگین بدون گلوگاه.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. فرقی نمی‌کند روی لینوکس هستید یا مک، کافی است ترمینال خود را باز کنید.

```bash
# نصب از طریق اسکریپت اصلی
curl -sSL https://qamar.website/install.sh | bash

# بررسی صحت نصب
qamar --version
```

اگر از کاربران پایتون هستید، می‌توانید از `pip` نیز استفاده کنید:
```bash
pip install qamar-core
```

## استفاده پایه (Quick Start)

پس از نصب، اولین قدم تعریف یک «کانکتور» است. فرض کنید می‌خواهید داده‌های یک فایل CSV را با یک مدل تحلیل متن ترکیب کنید:

```python
import qamar

# مقداردهی اولیه
engine = qamar.init(source="data.csv")

# اجرای عملیات میان‌رشته‌ای
result = engine.process(
    mode="interdisciplinary",
    params={"depth": "high", "output": "json"}
)

print(f"عملیات با موفقیت انجام شد: {result.status}")
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک و شخصی مناسب است؟**
بله، کاملاً. من شخصاً از آن برای مدیریت یادداشت‌های پژوهشی و لیست‌ کارهای روزانه‌ام استفاده می‌کنم. ساختار آن به قدری منعطف است که جلوی دست‌و‌پای شما را نمی‌گیرد.

**۲. آیا قمر متن‌باز (Open Source) است؟**
بله، هسته اصلی قمر تحت لایسنس MIT توسعه یافته و می‌توانید در گیت‌هاب شاهد پیشرفت لحظه‌ای کدهای آن باشید.

**۳. برای یادگیری حرفه‌ای‌تر از کجا شروع کنم؟**
بهترین منبع، مستندات رسمی در [qamar.website](https://qamar.website) است. همچنین بخش "Recipes" در سایت، سناریوهای واقعی و جذابی را برای حل مسائل پیچیده پیشنهاد داده که دید شما را باز می‌کند.

### نکته فنی برای توسعه‌دهندگان
اگر می‌خواهید پرفورمنس قمر را در سیستم‌های توزیع‌شده به حداکثر برسانید، حتماً از قابلیت `caching` داخلی آن استفاده کنید. این کار باعث می‌شود پردازش‌های تکراری در محیط‌های چندرشته‌ای تا ۶۰٪ کاهش یابد.

*اگر سوالی در مورد نحوه پیاده‌سازی در محیط‌های عملیاتی (Production) دارید، خوشحال می‌شوم در بخش Issues پروژه به آن پاسخ دهم.*
