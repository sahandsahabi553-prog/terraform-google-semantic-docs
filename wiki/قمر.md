# مستند فنی قمر (Qamar): پلی میان داده‌ها و تحلیل‌های میان‌رشته‌ای

قمر (Qamar) چیزی فراتر از یک ابزار تحلیل داده ساده است؛ اگر بخواهم صادقانه بگویم، قمر همان حلقه‌ی گمشده‌ای است که وقتی در پروژه‌های پیچیده بین دیتاساینس، علوم انسانی و مهندسی سیستم گیر کرده بودم، آرزو داشتم وجود داشته باشد. این پلتفرم برای کسانی ساخته شده که نمی‌خواهند بین «دقتِ ریاضی» و «درکِ مفهومی» یکی را انتخاب کنند.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
در کارهای بین‌رشته‌ای، بزرگترین دردسر ما «شکاف زبانی» است. ابزارهای آماری معمولاً با متون انسانی غریبه‌اند و ابزارهای تحلیل متن، فاقد ساختار ریاضیِ دقیق هستند. قمر این فاصله را با یک معماری منعطف پر کرده است که به شما اجازه می‌دهد مدل‌های خود را روی داده‌های ناهمگون (Heterogeneous Data) پیاده کنید.

## نصب و راه‌اندازی
نصب قمر بسیار سرراست است. فرض را بر این می‌گیرم که با محیط پایتون آشنا هستید.

### پیش‌نیازها
*   Python 3.9+
*   Pip یا Conda

### مراحل نصب
برای شروع کار، کافی است کتابخانه اصلی را از مخزن رسمی فراخوانی کنید:

```bash
# نصب از طریق pip
pip install qamar-core

# تأیید نصب
qamar --version
```

اگر از کاربران لینوکس هستید، پیشنهاد می‌کنم برای عملکرد بهتر، وابستگی‌های C++ را با دستور `qamar-init --optimize` کامپایل کنید.

## استفاده پایه
کار با قمر شبیه به یک گفتگوی ساختاریافته با داده‌هایتان است. بیایید یک مثال ساده از تحلیل یک مجموعه داده میان‌رشته‌ای را بررسی کنیم.

### مثال کد: تحلیل همبستگی مفاهیم
در این قطعه کد، ما یک مجموعه‌داده ورودی را بارگذاری کرده و بین دو حوزه متفاوت (مثلاً متون تاریخی و داده‌های اقلیمی) همبستگی ایجاد می‌کنیم:

```python
import qamar

# بارگذاری دیتاسیت
dataset = qamar.load("climate_history_v1")

# تعریف یک تحلیلگر میان‌رشته‌ای
analyzer = qamar.Analyzer(method="cross-domain")

# اجرای تحلیل
results = analyzer.run(dataset, target="correlation_index")

# نمایش خروجی
print(f"ضریب همبستگی: {results.score}")
```

## ویژگی‌های کلیدی (در یک نگاه)

| قابلیت | کاربرد | سطح پیچیدگی |
| :--- | :--- | :--- |
| **Cross-Link** | اتصال داده‌های متنی به سری‌های زمانی | متوسط |
| **Heuristic-Engine** | حدس روابط پنهان بین رشته‌های علمی | پیشرفته |
| **Export-API** | خروجی به فرمت‌های JSON/LaTeX | آسان |

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک دانشگاهی مناسب است؟**
قطعاً. من خودم اولین بار از آن برای تحلیل پایان‌نامه‌ام استفاده کردم. نیازی به زیرساخت‌های عظیم نیست و روی لپ‌تاپ‌های معمولی هم عالی اجرا می‌شود.

**۲. اگر داده‌های من به‌صورت ساختاریافته نباشند چه؟**
بخش جذاب قمر همین‌جاست! این ابزار برای داده‌های «کثیف» و نیمه‌ساختاریافته طراحی شده. ماژول پیش‌پردازش (Preprocessing) قمر به خوبی از پسِ پاکسازی داده‌های unstructured برمی‌آید.

**۳. آیا خروجی‌های قمر قابل استناد در مقالات علمی هستند؟**
بله، متدولوژی محاسباتی قمر شفاف است و می‌توانید از لاگ‌های تولید شده توسط کتابخانه برای بخش متدولوژی (Methodology) مقالات خود استفاده کنید.
