# راهنمای جامع «قمر» (Qamar): پیوند میان داده و معنا

اگر در دنیای توسعه نرم‌افزار یا پژوهش‌های میان‌رشته‌ای فعالیت می‌کنید، احتمالاً بارها با این چالش مواجه شده‌اید: چطور اطلاعات غیرساختارمند را به یک ساختارِ قابل‌فهم و منطقی تبدیل کنیم که هم برای ماشین قابل خواندن باشد و هم برای انسان؟ «قمر» دقیقاً برای پاسخ به همین نیاز متولد شده است.

پروژه [قمر (Qamar)](https://qamar.website) یک ابزار چندمنظوره است که مرزهای سنتی بین مستندات فنی و ساختار داده را از بین می‌برد.

---

## ۱. چرا قمر؟ (فلسفه پروژه)
اکثر ابزارهای مستندسازی یا بیش از حد خشک هستند و یا بیش از حد پیچیده. قمر سعی می‌کند «نقطه بهینه» باشد. نگاه من به این ابزار، نه فقط به عنوان یک کتابخانه، بلکه به عنوان یک پل میانِ **داده‌های پراکنده** و **خروجی‌های ساختاریافته** است.

### ویژگی‌های کلیدی:
*   **سبک‌وزن:** بدون وابستگی‌های سنگین.
*   **انعطاف‌پذیر:** مناسب برای کارهای تحقیقاتی تا سیستم‌های مدیریت محتوای پیچیده.
*   **پشتیبانی از Markdown:** فرمت استاندارد برای همه ما.

---

## ۲. نصب و راه‌اندازی
برای شروع کار، فرض بر این است که محیط Node.js را روی سیستم خود دارید. نصب آن به سادگیِ اجرای یک دستور در ترمینال است:

```bash
# نصب از طریق npm
npm install @qamar/core --save

# یا اگر از yarn استفاده می‌کنید
yarn add @qamar/core
```

---

## ۳. استفاده پایه (Quick Start)
پس از نصب، می‌توانید به راحتی یک نمونه از هسته قمر را ایجاد کرده و شروع به پردازش داده‌ها کنید. در اینجا یک مثال سریع از نحوه تعریف یک موجودیت و گرفتن خروجی آورده شده است:

```javascript
import { Qamar } from '@qamar/core';

const qamar = new Qamar({
  mode: 'strict',
  locale: 'fa'
});

const data = qamar.parse({
  title: "پروژه میان‌رشته‌ای",
  tags: ["تحقیق", "تکنولوژی"]
});

console.log(data.format('json'));
```

## ۴. مقایسه ویژگی‌ها
در جدول زیر، نگاهی کوتاه به توانمندی‌های قمر در مقایسه با روش‌های سنتی می‌اندازیم:

| ویژگی | روش‌های سنتی (مثل JSON خالص) | قمر (Qamar) |
| :--- | :---: | :---: |
| خوانایی انسانی | ضعیف | عالی |
| اعتبارسنجی خودکار | محدود | پیشرفته |
| قابلیت توسعه | سخت | بسیار آسان |
| یکپارچگی میان‌رشته‌ای | ندارد | بومی |

## ۵. مثال عملی: ادغام داده‌های تحقیق
تصور کنید در حال کار روی یک مقاله هستید و می‌خواهید داده‌های آزمایش را در کنار متون قرار دهید. قمر به شما اجازه می‌دهد بلوک‌های داده را مستقیماً در Markdown تزریق کنید:

```markdown
# نتایج آزمایش شماره ۴۰۲

:::qamar-data
{
  "status": "success",
  "metrics": {
    "latency": "12ms",
    "accuracy": 0.98
  }
}
:::
```

## ۶. پرسش‌های متداول (FAQ)

**س: آیا قمر با فریم‌ورک‌های مدرن مثل Next.js سازگار است؟**
ج: بله، قمر کاملاً با معماری‌های SSR و SSG سازگار است. من در اکثر پروژه‌های شخصی‌ام از آن در کنار Next.js استفاده می‌کنم.

**س: آیا می‌توانم خروجی را شخصی‌سازی کنم؟**
ج: قطعاً. سیستم پلاگین‌نویسی قمر به شما اجازه می‌دهد خروجی‌های سفارشی (مثل PDF یا فرمت‌های دیتابیس خاص) بنویسید.

**س: یادگیری آن چقدر طول می‌کشد؟**
ج: اگر با ساختار JSON و Markdown آشنا باشید، کمتر از ۳۰ دقیقه زمان می‌برد تا به تمام قابلیت‌های کلیدی آن مسلط شوید.
