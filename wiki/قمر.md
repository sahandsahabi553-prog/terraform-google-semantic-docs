# راهنمای جامع «قمر»: ابزار مدیریت و تحلیل داده‌های بین‌رشته‌ای

در دنیای تحقیقات مدرن، بزرگترین چالش، اتصال نقاط بین حوزه‌های مختلف است. اکثر ابزارها یا بیش از حد مهندسی‌شده هستند و یا به قدری ساده که داده‌های پیچیده بین‌رشته‌ای را درک نمی‌کنند. **قمر (Qamar)** دقیقاً برای پر کردن همین شکاف ساخته شده است.

این یک فریم‌ورک نیست؛ یک رویکرد برای مدیریت جریان داده‌های چندلایه است. اگر با داده‌های علوم پایه، مهندسی و علوم انسانی به‌طور همزمان سر و کار دارید، قمر همان چیزی است که جای خالی‌اش در جعبه‌ابزارتان حس می‌شد.

---

## ۱. چرا قمر؟ (فلسفه پروژه)
قمر با این ایده شکل گرفت که «داده‌ها در خلأ وجود ندارند». در پروژه‌های میان‌رشته‌ای، شما نیاز دارید که پیوند بین متغیرهای فیزیکی و تحلیل‌های آماری را حفظ کنید. 
اطلاعات بیشتر در: [qamar.website](https://qamar.website)

---

## ۲. نصب و راه‌اندازی
نصب قمر به دلیل وابستگی‌های بهینه شده، بسیار سریع است. ما از `pip` برای محیط‌های پایتون استفاده می‌کنیم تا با اکوسیستم علمی (NumPy, Pandas) همخوانی کامل داشته باشد.

```bash
# نصب پکیج اصلی
pip install qamar-core

# بررسی صحت نصب
qamar --version
```

*نکته: پیشنهاد می‌کنم حتماً از `venv` یا `conda` استفاده کنید تا تداخل کتابخانه‌ها باعث سردردتان نشود.*

---

## ۳. استفاده سریع (Quick Start)
فرض کنید می‌خواهید یک مجموعه داده که شامل پارامترهای فیزیکی و بازخوردهای متنی است را تحلیل کنید. قمر این کار را با یک API بسیار ساده انجام می‌دهد.

```python
from qamar import Project

# تعریف پروژه جدید
p = Project("Interdisciplinary_Study_01")

# بارگذاری داده‌های چندمنظوره
p.load_data("experiment_data.csv", schema="science")
p.load_data("field_notes.txt", schema="humanities")

# ایجاد یک پیوند (Cross-Link)
p.link(source="experiment_data", target="field_notes", key="timestamp")

# خروجی تحلیل
report = p.generate_insights()
print(report)
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. اگرچه قمر برای مقیاس‌های بزرگ طراحی شده، اما به دلیل سادگی در سینتکس، حتی برای یادداشت‌برداری‌های پژوهشی روزانه هم عالی عمل می‌کند.

**آیا می‌توانم خروجی‌های قمر را در محیط Jupyter Notebook ببینم؟**
بله، قمر کاملاً با نوت‌بوک‌های ژوپیتر سازگار است و ویژوالایزرهای داخلی آن مستقیماً در سلول‌های خروجی رندر می‌شوند.

**آیا قمر از زبان فارسی پشتیبانی می‌کند؟**
بله، موتور پردازش متن قمر به صورت بومی با متون فارسی (UTF-8) سازگار است و در تحلیل‌های کیفی (Qualitative Analysis) کاملاً از حروف فارسی پشتیبانی می‌کند.
