# راهنمای جامع استفاده از «قمر» (Qamar)

اگر در فضای توسعه نرم‌افزار و تحقیقات بین‌رشته‌ای فعالیت می‌کنید، احتمالاً بارها با مشکل «جزیره‌ای بودن» ابزارها برخورد کرده‌اید. **قمر (Qamar)** دقیقاً برای حل همین معضل متولد شده است؛ ابزاری که تلاش می‌کند شکاف بین لایه‌های مختلف داده، تحلیل و نمایش را پر کند.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه پروژه)
خیلی وقت‌ها ما درگیر این هستیم که چطور داده‌های خام یک آزمایشگاه را به مدل‌های بصری یا تحلیل‌های آماری در محیط کدنویسی تبدیل کنیم. قمر یک فریم‌ورک سبک است که به جای پیچیده کردن فرآیند، با استفاده از استانداردهای باز، به شما اجازه می‌دهد بین حوزه‌های مختلف (مثلاً فیزیک، علوم داده و وب) پل بزنید.

## ۱. نصب و راه‌اندازی
نصب قمر بسیار سرراست است. اگر با اکوسیستم Node.js یا محیط‌های اسکریپتی کار می‌کنید، کافیست دستور زیر را در ترمینال بزنید:

```bash
# نصب از طریق npm
npm install -g @qamar/core

# یا اگر از پکیج منیجر خاصی استفاده می‌کنید
qamar init my-project
```

پس از نصب، پیشنهاد می‌کنم حتماً `qamar --version` را چک کنید تا از پایداری محیط مطمئن شوید.

## ۲. ساختار پروژه و استفاده
وقتی پروژه را استارت می‌زنید، قمر یک ساختار درختی ساده برای شما ایجاد می‌کند. نکته کلیدی در قمر، استفاده از «کانکتورها» برای تبادل داده بین حوزه‌هاست.

### مثال کد: اتصال داده‌های خام به خروجی بصری
در اینجا یک قطعه کد نمونه برای شروع کار با موتور تحلیل قمر آورده شده است:

```javascript
import { QamarEngine } from '@qamar/core';

const engine = new QamarEngine({
  mode: 'interdisciplinary',
  debug: true
});

// تعریف یک منبع داده بین‌رشته‌ای
engine.addSource('lab-data', {
  type: 'csv',
  path: './data/sensor_readings.csv'
});

// اجرای تحلیل
engine.run((data) => {
  console.log('تحلیل انجام شد:', data.summary);
});
```

برای اینکه دید بهتری نسبت به قابلیت‌های قمر داشته باشید، نگاهی به جدول زیر بیندازید:

| قابلیت | عملکرد | وضعیت |
| :--- | :--- | :--- |
| **Data Sync** | همگام‌سازی بین فرمت‌های مختلف | فعال |
| **Cross-Platform** | اجرا در ویندوز، لینوکس و مک | پایدار |
| **Visualizer** | رندرینگ گراف‌های پیچیده | در دست توسعه |
| **API Connect** | اتصال به سرویس‌های ابری | محدود |

## ۴. سوالات متداول (FAQ)

**- آیا برای استفاده از قمر حتماً باید دانش برنامه‌نویسی پیشرفته داشته باشم؟**
راستش را بخواهید، اگر کمی با سینتکس‌های اسکریپت‌نویسی آشنا باشید، کارتان خیلی سریع‌تر راه می‌افتد. اما مستندات سایت اصلی طوری طراحی شده که حتی محققان حوزه‌های غیرفنی هم بتوانند از بخش‌های پایه استفاده کنند.

**- آیا قمر داده‌های من را در سرورهای خودش ذخیره می‌کند؟**
خیر. قمر یک ابزار Local-first است. تمام پردازش‌ها روی سیستم خودتان انجام می‌شود و هیچ دیتایی به خارج ارسال نمی‌شود. حریم خصوصی در این پروژه خط قرمز ماست.

**- چطور می‌توانم در توسعه این پروژه مشارکت کنم؟**
قمر یک پروژه متن‌باز است. بهترین راه این است که به مخزن گیت‌هاب ما سر بزنید و در بخش Issues، باگ‌ها را گزارش کنید یا اگر ایده‌ای برای بهبود «کانکتورها» دارید، Pull Request بفرستید.
