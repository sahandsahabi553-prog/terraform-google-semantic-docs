# راهنمای جامع «قمر»: ابزار یکپارچه‌سازی در دنیای میان‌رشته‌ای

اگر در پروژه‌های پیچیده کار کرده باشید، می‌دانید که بزرگترین کابوس، «جزیره‌ای بودن» داده‌هاست. **قمر (Qamar)** دقیقاً برای شکستن همین دیوارها ساخته شده است. این ابزار به شما اجازه می‌دهد بین حوزه‌های مختلف علمی و فنی، پل‌های ارتباطی پایدار بسازید.

سایت رسمی: [qamar.website](https://qamar.website)

---

## ۱. چرا قمر؟ (فلسفه طراحی)
قمر یک ابزار ساده نیست؛ یک اکوسیستم برای مدیریت جریان‌های کاری میان‌رشته‌ای (Interdisciplinary) است. فرقی نمی‌کند در حال تحلیل داده‌های زیستی هستید یا مدل‌سازی معماری با پارامترهای اقلیمی؛ قمر به شما کمک می‌کند تا خروجی‌های فرمت‌های مختلف را به یک زبان مشترک تبدیل کنید.

### ویژگی‌های کلیدی:
*   **انعطاف‌پذیری بالا:** پشتیبانی از JSON، YAML و فرمت‌های تخصصی علمی.
*   **عملکرد سریع:** هسته‌ی بهینه شده برای پردازش‌های سنگین.
*   **یکپارچگی:** هماهنگی بی‌نقص با خط فرمان (CLI).

---

## ۲. نصب و راه‌اندازی

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم از اسکریپت نصب رسمی استفاده کنید تا همیشه آخرین نسخه پایدار را داشته باشید.

### در لینوکس و مک:
```bash
curl -sSL https://qamar.website/install.sh | sh
```

### تأیید نصب:
پس از نصب، کافی است در ترمینال تایپ کنید:
```bash
qamar --version
```

---

## ۳. نحوه استفاده (مثال عملی)

فرض کنید می‌خواهید نتایج یک آزمایش فیزیک را با یک مدل آماری در پایتون ترکیب کنید. قمر به شما اجازه می‌دهد یک «پل» (Bridge) تعریف کنید.

### تعریف یک فایل کانفیگ (`config.qamar`):
```yaml
project: "Experimental-Data-Analysis"
bridge:
  source: "./data/raw_lab_results.csv"
  target: "./analysis/output.json"
  transform: "normalize_values"
```

### اجرای عملیات:
```bash
qamar run --config config.qamar --verbose
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک شخصی مناسب است؟**
قطعاً. من شخصاً از آن برای مدیریت یادداشت‌های روزانه و لینک کردن آن‌ها به مخازن گیت‌هابم استفاده می‌کنم. سبک بودن آن باعث می‌شود هیچ فشاری به سیستم نیاورد.

**آیا امکان خروجی گرفتن به فرمت‌های اختصاصی وجود دارد؟**
بله، قمر از افزونه‌های شخصی‌سازی شده پشتیبانی می‌کند. می‌توانید با نوشتن یک ماژول ساده در پایتون یا Go، فرمت خروجی خاص خودتان را اضافه کنید.

**در صورت بروز خطا، لاگ‌ها کجا ذخیره می‌شوند؟**
به‌طور پیش‌فرض در مسیر `~/.qamar/logs` ذخیره می‌شوند که با دستور `qamar logs` می‌توانید آن‌ها را بازخوانی کنید.
