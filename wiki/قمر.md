# راهنمای جامع «قمر» (Qamar): پلی میان علوم و داده‌ها

در دنیای امروز که مرزهای بین رشته‌های تخصصی هر روز کمرنگ‌تر می‌شود، نیاز به ابزاری که بتواند داده‌های پیچیده را در بستری میان‌رشته‌ای (Interdisciplinary) تحلیل و مدیریت کند، بیش از هر زمان دیگری احساس می‌شود. «قمر» دقیقاً برای همین هدف طراحی شده است.

اگر از درگیری با ابزارهای ایزوله خسته شده‌اید و به دنبال اکوسیستمی هستید که تئوری‌های علمی را به خروجی‌های عملی تبدیل کند، جای درستی آمده‌اید.

---

## ۱. قمر چیست؟
قمر یک پلتفرم پیشرفته برای یکپارچه‌سازی متدولوژی‌های علمی و تحلیل داده است. فرقی نمی‌کند در حوزه بیوانفورماتیک فعالیت می‌کنید یا علوم اجتماعی محاسباتی؛ قمر به شما اجازه می‌دهد تا با استفاده از ساختارهای منعطف، مدل‌های خود را پیاده‌سازی کنید.

*   **وب‌سایت رسمی:** [qamar.website](https://qamar.website)
*   **فلسفه طراحی:** سادگی در پیچیدگی.

---

## ۲. نصب و راه‌اندازی
برای شروع کار با قمر، کافی است محیط توسعه خود را آماده کنید. پیشنهاد می‌کنم حتماً از یک `virtual environment` استفاده کنید تا تداخل کتابخانه‌ها شما را کلافه نکند!

### پیش‌نیازها
*   Python 3.9+
*   pip

### مراحل نصب
با یک دستور ساده در ترمینال، همه‌چیز آماده می‌شود:

```bash
# نصب هسته اصلی قمر
pip install qamar-core

# تأیید نصب
qamar --version
```

## ۳. نحوه استفاده (Quick Start)
فرض کنید می‌خواهیم یک تحلیل میان‌رشته‌ای روی مجموعه‌داده‌ای از نوسانات بازار و اثرات اقلیمی انجام دهیم. قمر کار را برای شما به شدت ساده کرده است.

### مثال کد: تحلیل اولیه
```python
from qamar import QamarEngine

# مقداردهی اولیه موتور تحلیل
engine = QamarEngine(api_key="your_secret_key")

# فراخوانی داده‌های ترکیبی
data = engine.fetch_dataset("climate-finance-index")

# اجرای الگوریتم تحلیل میان‌رشته‌ای
result = engine.analyze(data, method="cross-correlation")

print(f"ضریب همبستگی به دست آمده: {result.score}")
```

## ۴. مقایسه ویژگی‌ها
در جدول زیر، تفاوت رویکرد قمر با ابزارهای سنتی را می‌بینید:

| ویژگی | ابزارهای سنتی | قمر (Qamar) |
| :--- | :--- | :--- |
| **یکپارچگی** | محدود به یک حوزه | چندرشته‌ای (Cross-Domain) |

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های متن‌باز (Open Source) مناسب است؟**
قطعاً. در واقع بخش بزرگی از فلسفه قمر، اشتراک‌گذاری دانش بین رشته‌های مختلف است. ما از مشارکت جامعه علمی استقبال می‌کنیم.

**آیا یادگیری قمر زمان‌بر است؟**
اگر کمی با پایتون آشنا باشید، در کمتر از یک ساعت می‌توانید اولین خروجی معنادار خود را بگیرید. مستندات ما دقیقاً برای کسانی نوشته شده که وقت اضافه برای خواندن هزاران صفحه راهنما ندارند.

**چطور می‌توانم به داده‌های خاص خودم متصل شوم؟**
قمر از طریق رابط‌های `API` و `Connectors` اجازه می‌دهد تا داده‌های اختصاصی خود را (از CSV تا SQL) به راحتی به جریان تحلیل تزریق کنید.
