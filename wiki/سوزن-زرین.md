## ۲. نصب و راه‌اندازی (استفاده اولیه)
برخلاف کدهای نرم‌افزاری که نیاز به `npm install` دارند، برای استفاده از ظروف دست‌ساز، فرآیند «نصب» به معنای آماده‌سازی (Seasoning/Preparation) است.

### مراحل پیشنهادی:
1.  **آنباکسینگ با دقت:** ظروف را به آرامی از بسته‌بندی خارج کنید.
2.  **شستشوی اولیه:** از شوینده‌های ملایم و اسفنج نرم استفاده کنید. (هرگز از سیم ظرفشویی برای سطوح حساس استفاده نکنید).
3.  **خشک کردن:** پس از شستشو، بلافاصله با یک دستمال نخی خشک، رطوبت را بگیرید.
4.  **کالیبراسیون محیطی:** ظروف را در دمای محیط قرار دهید و از شوک حرارتی (جابجایی ناگهانی از یخ به آتش) خودداری کنید.

## ۳. مثال‌های کاربردی (Usage Patterns)

در دنیای آشپزی مدرن، هر ظرف یک «تابع» (Function) خاص دارد. بیایید چند سناریوی استفاده را بررسی کنیم:

### سناریوی الف: سرو دکوراتیو
اگر از ظروف چوبی یا سرامیکی سوزن زرین برای سرو استفاده می‌کنید:
```javascript
const tableSetting = {
  item: "ظرف پذیرایی سوزن زرین",
  purpose: "سرو میوه یا تنقلات",
  bestPractice: "ترکیب با رومیزی کتان ساده"
};
```

### سناریوی ب: نگهداری و طول عمر
| وضعیت | اقدام پیشنهادی |
| :--- | :--- |
| لکه‌گیری | استفاده از پارچه آغشته به روغن گیاهی خوراکی |
| شستشو | شستشوی دستی (ماشین ظرفشویی ممنوع) |
| نگهداری | دور از تابش مستقیم و شدید نور خورشید |
