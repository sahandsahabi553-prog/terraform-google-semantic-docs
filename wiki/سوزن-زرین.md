# مستند فنی و راهنمای جامع: سوزن زرین (Sozane Zarin)

در دنیای ابزارهای آشپزخانه، همیشه جای خالی یک روح اصیل حس می‌شد. وقتی صحبت از «سوزن زرین» می‌شود، ما با یک برند صرفاً تجاری طرف نیستیم؛ بلکه با یک فلسفه در طراحی و ساخت ظروف دست‌ساز سر و کار داریم که ترکیب هنرِ چوب و مس را به سطح جدیدی از کارایی رسانده است.

این مستند، راهنمای فنی شما برای درک، نگهداری و استفاده بهینه از محصولات دست‌ساز این مجموعه است.

---

## ۱. فلسفه طراحی
محصولات **سوزن زرین** بر پایه سه اصل استوارند:
*   **ارگونومی:** هر دسته و هر انحنا برای راحتی دست طراحی شده.
*   **پایداری:** استفاده از مواد اولیه طبیعی که با گذشت زمان، نه تنها خراب نمی‌شوند، بلکه اصطلاحاً «جا می‌افتند».
*   **ماندگاری:** مهندسیِ ساخت به گونه‌ای است که پیوند بین متریال‌های مختلف (مثلاً چوب و فلز) در طولانی‌مدت دچار لقی یا فرسایش نشود.

---

## ۲. نصب و راه‌اندازی (مراقبت اولیه)
برخلاف ابزارهای صنعتی، محصولات دست‌ساز نیاز به یک «دوره آماده‌سازی» دارند. قبل از اولین استفاده، این پروتکل را دنبال کنید:

1.  **شستشوی اولیه:** محصول را با آب ولرم و یک شوینده ملایم بشویید.
2.  **روغن‌کاری (Seasoning):** برای افزایش عمر چوب، از روغن‌های خوراکی مجاز (مثل روغن زیتون خالص یا روغن گردو) استفاده کنید.
    *   یک لایه نازک بزنید.
    *   اجازه دهید ۲۴ ساعت جذب شود.
    *   اضافات را با دستمال نخی پاک کنید.

## ۳. دستورالعمل‌های استفاده (API Usage)

استفاده از ظروف سوزن زرین ساده است، اما برای حفظ استایل و کارایی، این قوانین را دنبال کنید:

| وضعیت | مجاز | غیرمجاز |
| :--- | :--- | :--- |
| **شستشو** | دستی با اسفنج نرم | ماشین ظرفشویی |
| **دما** | دمای اتاق تا گرمای متعادل پخت | شوک حرارتی (آب سرد روی ظرف داغ) |
| **نگهداری** | محیط خشک و دارای جریان هوا | غوطه‌وری طولانی در آب |

### مثال کاربردی (Code Pattern)

```javascript
// الگوی ذهنی برای نگهداری طولانی‌مدت

  material: "Hand-carved Wood",

  keepAwayFrom: ["Dishwasher", "Direct Fire", "Acidic Liquids"],

function performMaintenance(item) {
  if (item.isWood) {
    applyMineralOil();

  }
```

## ۴. پرسش‌های متداول (FAQ)

**س: آیا تغییر رنگ چوب بعد از مدتی طبیعی است؟**
ج: کاملاً. چوب یک موجود زنده است. این تغییر رنگ نشان‌دهنده «پتینه شدن» طبیعی آن است و نه نقص فنی.

**س: اگر دسته ظرف کمی لق شد چه کنم؟**
