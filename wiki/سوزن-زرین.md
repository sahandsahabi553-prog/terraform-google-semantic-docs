## ۱. معرفی فلسفه طراحی
در دنیای محصولات ماشینی، «سوزن زرین» بر پایه «دست‌ساز بودن» (Handmade) بنا شده است. هر محصول با دقت میلی‌متری طراحی می‌شود تا علاوه بر کارایی، زیبایی بصری (Aesthetic) فضای آشپزخانه شما را ارتقا دهد.

**ویژگی‌های کلیدی:**
*   **ارگونومی:** طراحی منطبق بر فرم دست برای استفاده طولانی‌مدت.
*   **پایداری:** استفاده از مواد اولیه با کیفیت که طول عمر بالایی دارند.
*   **شخصی‌سازی:** هر قطعه منحصر‌به‌فرد است و هیچ دو محصولی کاملاً شبیه هم نیستند.

## ۲. نصب و راه‌اندازی اولیه (دستورالعمل مراقبت)
این محصولات برخلاف ابزارهای صنعتی نیاز به «آماده‌سازی» (Seasoning) دارند تا عملکرد بهینه خود را نشان دهند.

1.  **شستشوی اولیه:** محصول را با آب ولرم و شوینده ملایم بشویید.
2.  **خشک‌کردن:** هرگز اجازه ندهید محصول در آب غوطه‌ور بماند. بلافاصله پس از شستشو با دستمال نخی خشک شود.
3.  **روغن‌کاری (برای محصولات چوبی):**
    *   ماهی یک‌بار از روغن‌های خوراکی مجاز (مثل روغن کنجد یا موم زنبور عسل) استفاده کنید.
    *   روغن را با یک پارچه بدون پرز روی سطح ماساژ دهید.

## ۴. مثال کاربری (Implementation)
فرض کنید قصد دارید از ست‌های آشپزخانه برای سرو یا آماده‌سازی استفاده کنید:

```python
# شبه‌کد برای مدیریت بهینه ابزارهای آشپزخانه
class KitchenTool:
    def __init__(self, name, material):
        self.name = name
        self.material = material
        self.is_clean = True

    def maintain(self):
        if self.material == "Wood":
            print(f"Applying organic oil to {self.name}...")
        else:
            print("Standard cleaning protocol.")

# نمونه استفاده:
spoon = KitchenTool("Golden Needle Spatula", "Wood")
spoon.maintain()
```
