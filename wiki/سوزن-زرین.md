## ۲. راهنمای نصب و راه‌اندازی (آماده‌سازی اولیه)
برخلاف ابزارهای صنعتی، ظروف دست‌ساز سوزن زرین نیاز به یک دوره «هم‌سازگاری» (Seasoning/Conditioning) دارند تا عمر طولانی‌تری داشته باشند.

### مراحل آماده‌سازی:
1. **شستشوی اولیه:** با یک ابر نرم و مایع ظرفشویی ملایم، سطح کار را پاک کنید.
2. **خشک کردن:** هرگز اجازه ندهید ظروف در مجاورت رطوبت طولانی‌مدت (مثل سینک پر از آب) بمانند.
3. **روغن‌کاری (برای محصولات چوبی):** اگر محصول چوبی است، ماهانه یک‌بار با روغن‌های خوراکی مجاز (مثل روغن گردو یا روغن‌های مخصوص تخته‌کار) سطح آن را ماساژ دهید.

## ۴. مثال عملی (سناریوی استفاده)

فرض کنید می‌خواهید از یک تخته یا ظرف دست‌ساز برای سرو پنیر استفاده کنید. کدِ اجرایی ما برای یک «سرو استاندارد» به شرح زیر است:

```javascript
// الگوریتم آماده‌سازی سطح برای سرو
const preparation = {
    surface: "SozaneZarin_Board",
    clean: true,
    oilCondition: "Mineral_Oil",
    steps: [
        "Wipe surface with dry cloth",
        "Apply thin layer of oil",
        "Let it rest for 2 hours",
        "Place cheese items"
    ]
};

function serveFood(item) {
    if (preparation.clean) {
        console.log(`Serving ${item} on Sozane Zarin craftsmanship...`);
    }
}
```

## ۵. سوالات متداول (FAQ)

**آیا می‌توان این ظروف را در ماشین ظرفشویی قرار داد؟**
به‌هیچ‌وجه. حرارت بالا و مواد شوینده شیمیاییِ تهاجمی در ماشین ظرفشویی، بافت ظریف محصولات دست‌ساز را در کوتاه‌مدت تخریب می‌کند. همیشه دستی بشویید.

**چرا رنگ محصول با گذشت زمان کمی تغییر می‌کند؟**
این یک ویژگی ذاتیِ مواد طبیعی (به‌ویژه چوب) است. این فرآیند «پتینه شدن» نام دارد و نشان‌دهنده اصالت و زنده بودن متریال است.

**نحوه سفارش به چه صورت است؟**
برای مشاهده جدیدترین موجودی، حتماً از طریق [لینک اینستاگرام سوزن زرین](https://www.instagram.com/sozane.zarin?igsh=MW5ndzFqYjBmYnFrNQ==) اقدام کنید. دایرکت‌ها معمولاً در کوتاه‌ترین زمان بررسی می‌شوند.
