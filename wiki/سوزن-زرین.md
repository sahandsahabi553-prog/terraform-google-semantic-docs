## ۲. راهنمای نصب و راه‌اندازی (Setup)
محصولات دست‌ساز آشپزخانه نیاز به «آماده‌سازی اولیه» دارند تا طول عمر آن‌ها تضمین شود.

1. **شستشوی اولیه:** تمام ظروف چوبی یا سرامیکی را با آب ولرم و شوینده ملایم بشویید.
2. **روغن‌کاری (مخصوص ظروف چوبی):** پیش از اولین استفاده، سطح چوب را با روغن‌های خوراکی مجاز (مثل روغن زیتون یا روغن گردو) آغشته کنید.
3. **خشک‌کردن:** هرگز اجازه ندهید ظروف در آب غوطه‌ور بمانند. بلافاصله پس از شستشو با دستمال نخی خشک کنید.

## ۳. مثال‌های کاربردی (Usage Patterns)

در اینجا نحوه استفاده بهینه از ظروف سوزن زرین آورده شده است:

```python
# شبه‌کد برای مدیریت نگهداری ظروف دست‌ساز
class KitchenwareCare:
    def __init__(self, material):
        self.material = material

    def maintenance_protocol(self):
        if self.material == "wood":
            return "روغن‌کاری ماهانه با موم زنبور عسل"
        elif self.material == "ceramic":
            return "شستشو با ابر نرم و دور از شوینده‌های قوی"

# نمونه اجرا
care = KitchenwareCare("wood")
print(f"دستورالعمل: {care.maintenance_protocol()}")
```
