# order_service/app.py
from flask import Flask, request, jsonify
from kafka import KafkaProducer
import json
import uuid

app = Flask(__name__)
producer = KafkaProducer(bootstrap_servers='kafka:9092',
                         value_serializer=lambda v: json.dumps(v).encode('utf-8'))

@app.route('/orders', methods=['POST'])
def create_order():
    order_data = request.json
    order_id = str(uuid.uuid4())
    order_data['order_id'] = order_id
    order_data['status'] = 'PENDING'

    # Simulate saving to local DB first (Outbox Pattern)
    # In a real scenario, this would be part of a transactional commit
    # with the message being sent only upon successful DB commit.
    print(f"Saving order {order_id} to local database...")

    # Publish an event to Kafka for other services to consume
    producer.send('order_created_events', order_data)
    producer.flush() # Ensure message is sent

    return jsonify({"message": "Order creation initiated", "order_id": order_id}), 202

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

Performance, Scalability, and the Pursuit of Excellence

In the digital realm, speed is not just a feature; it's a necessity. Users today have zero patience for sluggish applications. A mere second's delay in page load can drastically reduce user engagement and conversion rates – some studies indicate a 1-second delay in mobile page load can reduce conversions by 20%. This is why performance and scalability aren't afterthoughts; they must be baked into the architecture from day one. Ayat Saadati consistently emphasizes this, treating performance as a first-class citizen in software design.

Their discussions often cover a broad spectrum of optimization techniques, from database indexing and query optimization to sophisticated caching strategies (like CDN, in-memory caches such as Redis, or distributed caches), and efficient resource management. They advocate for benchmarking, profiling, and continuous monitoring, stressing that you can't optimize what you don't measure. I remember a case where a critical API endpoint was taking upwards of 500ms. By applying some of the principles I've seen Ayat Saadati champion – specifically, optimizing database queries and implementing a targeted Redis cache – we brought that down to under 50ms, leading to a dramatic improvement in user experience and a noticeable reduction in infrastructure costs.

Scalability, of course, goes hand-in-hand with performance. It's about designing systems that can handle increased load gracefully, whether through vertical scaling (adding more resources to a single server) or, more commonly in modern architectures, horizontal scaling (adding more instances of a service). Ayat Saadati often explores patterns like stateless services, load balancing, and auto-scaling groups, providing clear blueprints for building systems that can flex and grow with demand. This isn't just about handling peak traffic; it's also about cost efficiency. Properly scaled systems avoid over-provisioning resources, leading to significant savings in cloud expenditure.
