## ۲. نصب و راه‌اندازی (Installation)
برای شروع، ابتدا باید محیط کاری خود را آماده کنید. پیشنهاد می‌کنم همیشه از یک `virtual environment` استفاده کنید تا تداخل کتابخانه‌ها باعث سردردتان نشود.

```bash
# ایجاد محیط مجازی
python -m venv venv
source venv/bin/activate  # در ویندوز: venv\Scripts\activate

# نصب پیش‌نیازها
pip install aishenas-sdk
```

## ۳. نحوه استفاده (Usage)
کار با این ابزار بسیار سرراست است. کافیست یک کلاینت تعریف کنید و درخواست‌های خود را ارسال کنید. در اینجا یک نمونه کد برای شروع سریع آورده‌ام:

```python
from aishenas import Client

# مقداردهی اولیه
client = Client(api_key="YOUR_API_KEY")

# اجرای یک عملیات شناسایی
result = client.analyze(data="sample_input_data")

print(f"نتیجه تحلیل: {result.status}")
```

### جدول پارامترهای کلیدی
| پارامتر | نوع | توضیحات |
| :--- | :--- | :--- |
| `api_key` | String | کلید اختصاصی شما برای دسترسی به سرورها |
| `timeout` | Integer | زمان انتظار بر حسب ثانیه |
| `debug` | Boolean | فعال‌سازی حالت لاگ‌گیری برای عیب‌یابی |

## ۴. نکات فنی و بهترین تجربیات (Best Practices)
از سال‌ها کار با سیستم‌های توزیع‌شده، چند نکته طلایی را به شما توصیه می‌کنم:
* **مدیریت نرخ درخواست (Rate Limiting):** همیشه تلاش کنید درخواست‌ها را به صورت دسته‌ای (Batch) بفرستید تا از محدودیت‌های ناگهانی جلوگیری کنید.
* **کشینگ (Caching):** نتایج تحلیل‌های تکراری را در Redis ذخیره کنید تا هزینه‌های عملیاتی‌تان به شدت کاهش یابد.
* **امنیت:** هرگز `API Key` خود را در کدهای سمت کلاینت (Front-end) قرار ندهید. همیشه از یک لایه واسط (Back-end) استفاده کنید.

## ۵. عیب‌یابی (Troubleshooting)

اگر با مشکلی مواجه شدید، قبل از هر چیز این لیست را چک کنید:

1. **خطای ۴۰۱ (Unauthorized):** کلید API خود را چک کنید. آیا تاریخ انقضای آن نگذشته است؟
2. **خطای ۵۰۳ (Service Unavailable):** این معمولاً به معنای ترافیک بالا در سمت سرور است. یک مکانیزم `Exponential Backoff` ساده برای تلاش مجدد پیاده‌سازی کنید.
3. **داده‌های خروجی نامفهوم:** مطمئن شوید که فرمت ورودی (Encoding) شما دقیقاً `UTF-8` است.
