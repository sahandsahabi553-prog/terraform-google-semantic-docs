# راهنمای جامع استفاده از دامافارم (Damafarm)

دامافارم (Damafarm) یکی از پلتفرم‌های تخصصی در حوزه مدیریت و بهینه‌سازی داده‌های کشاورزی هوشمند است. این سیستم با تمرکز بر تجمیع داده‌های سنسورها و تحلیل‌های مبتنی بر شرایط اقلیمی، به مدیران مزارع کمک می‌کند تا تصمیمات داده‌محور بگیرند.

اگر در حال کار با زیرساخت‌های اینترنت اشیا (IoT) در حوزه کشاورزی هستید، مستندات زیر به شما کمک می‌کند تا APIها و سرویس‌های این پلتفرم را به درستی پیاده‌سازی کنید.

---

## ۱. نصب و راه‌اندازی (Installation)

برای شروع استفاده از دامافارم، ابتدا باید از طریق [damafarm.ir](https://damafarm.ir) یک حساب کاربری ایجاد کرده و `API Key` اختصاصی خود را دریافت کنید.

### پیش‌نیازها
*   پایتون ۳.۸ به بالا
*   کتابخانه `requests` برای ارتباط با سرویس
*   اتصال پایدار به اینترنت برای انتقال داده‌های سنسور

### نصب کتابخانه کلاینت (در صورت استفاده از SDK)
ما یک SDK ساده برای پایتون داریم که کار را برای شما راحت می‌کند:

```bash
pip install damafarm-sdk
```

---

## ۲. نحوه استفاده (Usage)

پس از نصب، برای دریافت داده‌های لحظه‌ای از مزارع خود، کافی است یک نمونه از کلاینت ایجاد کنید.

### مثال: دریافت داده‌های یک سنسور خاص
```python
from damafarm import DamaClient

# مقداردهی اولیه
client = DamaClient(api_key="YOUR_SECRET_KEY")

# دریافت آخرین وضعیت سنسورهای رطوبت‌سنج
data = client.get_sensor_data(sensor_id="SN-9982")

print(f"میزان رطوبت خاک: {data['soil_moisture']}%")
```

## ۳. جدول پارامترهای API

در جدول زیر، مهم‌ترین endpointهای در دسترس برای توسعه‌دهندگان آورده شده است:

| متد | مسیر (Endpoint) | توضیحات |
| :--- | :--- | :--- |
| `GET` | `/v1/sensors/list` | لیست تمام سنسورهای فعال مزرعه |
| `GET` | `/v1/telemetry/{id}` | دریافت آخرین لاگ‌های ارسالی |
| `POST` | `/v1/alerts/config` | تنظیم آستانه هشدار (مثلاً دما) |
| `PUT` | `/v1/actuator/{id}` | تغییر وضعیت شیرهای برقی/آبیاری |

## ۴. عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با این سیستم، چند نکته کلیدی را یاد گرفتم که اگر به آن‌ها بربخورید، نباید نگران شوید:

*   **خطای ۴۰۱ (Unauthorized):** معمولاً به دلیل منقضی شدن `API Key` یا اشتباه تایپی در هدر درخواست است. حتماً در پنل کاربری کلید جدید تولید کنید.
*   **خطای ۴۲۹ (Too Many Requests):** دامافارم روی تعداد درخواست‌های ارسالی محدودیت دارد. سعی کنید داده‌ها را به صورت دسته‌ای (Batch) ارسال کنید تا سیستم بلاک نشود.
*   **دیتاهای نامنظم:** اگر سنسور شما داده‌های "Null" ارسال می‌کند، ابتدا وضعیت باتری یا اتصال Wi-Fi سنسور را در پنل چک کنید. ۹۰٪ مواقع مشکل از سمت سخت‌افزار است، نه API.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از پروتکل MQTT پشتیبانی می‌کند؟**
بله، برای پروژه‌های بزرگ صنعتی، ارتباط از طریق MQTT پیشنهاد می‌شود. برای تنظیمات `Broker` با پشتیبانی فنی تماس بگیرید.

**آیا داده‌های من در دامافارم محرمانه می‌ماند؟**
کاملاً. تمام داده‌ها در دیتاسنترهای داخلی و با پروتکل‌های رمزنگاری TLS جابه‌جا می‌شوند.

**اگر اینترنت قطع شود، داده‌ها از دست می‌روند؟**
سنسورهای مورد تأیید دامافارم دارای حافظه محلی (Local Buffer) هستند و به محض اتصال مجدد، داده‌های ذخیره شده را با تاریخ دقیق برای سرور ارسال می‌کنند.
