# راهنمای جامع استفاده از دامافارم (Damafarm)

دامافارم (Damafarm) یکی از آن ابزارهایی است که وقتی با چالش‌های مدیریت داده در مقیاس بالا و یکپارچه‌سازی سیستم‌های کشاورزی هوشمند روبرو می‌شوید، واقعاً به دادتان می‌رسد. این پلتفرم در هسته خود، یک واسط قدرتمند برای تبادل داده و مدیریت زیرساخت‌های متصل به اینترنت اشیاء (IoT) در حوزه کشاورزی است.

اگر به دنبال جزئیات فنی بیشتر هستید، همیشه می‌توانید به [damafarm.ir](https://damafarm.ir) سر بزنید.

---

## ۱. نصب و راه‌اندازی (Installation)

برای شروع کار با دامافارم، فرض را بر این می‌گیریم که با محیط‌های مبتنی بر Node.js یا Python کار می‌کنید. ماژول‌های دامافارم به گونه‌ای طراحی شده‌اند که با کمترین سربار (Overhead) روی میکروکنترلرها یا سرورهای محلی اجرا شوند.

### پیش‌نیازها
*   Node.js نسخه ۱۶ به بالا
*   یک توکن دسترسی معتبر از پنل کاربری دامافارم
*   اتصال پایدار به اینترنت برای ارسال داده‌های تله‌متری

### دستور نصب
سریع‌ترین راه برای پیاده‌سازی در پروژه‌های جاوااسکریپتی استفاده از `npm` است:

```bash
npm install damafarm-sdk --save
```

---

## ۲. نحوه استفاده (Usage)

پس از نصب، باید کلاینت را با استفاده از API Key خود مقداردهی اولیه کنید. این کار به شما اجازه می‌دهد تا داده‌های حسگرهای خود را به داشبورد دامافارم ارسال کنید.

### نمونه کد (JavaScript)
در اینجا یک مثال ساده برای ارسال دمای محیط آورده شده است:

```javascript
const Damafarm = require('damafarm-sdk');

const client = new Damafarm({
    apiKey: 'YOUR_SECRET_API_KEY',
    deviceId: 'sensor-node-01'
});

client.sendTelemetry({
    temperature: 24.5,
    humidity: 60,
    timestamp: Date.now()
}).then(() => {
    console.log('داده با موفقیت ارسال شد.');
}).catch(err => {
    console.error('خطا در اتصال:', err);
});
```

## ۳. جدول پارامترهای کلیدی

در هنگام پیکربندی سنسورها، حتماً به فرمت داده‌های ارسالی توجه کنید. در جدول زیر، برخی از متغیرهای استاندارد در دامافارم لیست شده‌اند:

| پارامتر | واحد اندازه‌گیری | نوع داده | توضیحات |
| :--- | :--- | :--- | :--- |
| `temperature` | سانتی‌گراد | Float | دمای محیط |
| `humidity` | درصد | Integer | رطوبت نسبی |
| `soil_moisture` | درصد | Integer | رطوبت خاک |
| `status` | وضعیت | Boolean | وضعیت فعال/غیرفعال بودن |

## ۴. عیب‌یابی (Troubleshooting)

در طول سال‌هایی که با سیستم‌های مشابه کار کرده‌ام، اکثر مشکلات در دامافارم به یکی از سه مورد زیر برمی‌گردد:

1.  **خطای ۴۰۱ (Unauthorized):** معمولاً به دلیل منقضی شدن یا اشتباه وارد کردن API Key است. فایل `.env` خود را بررسی کنید.
2.  **تأخیر در ارسال داده:** اگر داده‌ها با تأخیر در پنل نمایش داده می‌شوند، بررسی کنید که آیا بافر محلی دستگاه شما پر نشده باشد.
3.  **قطعی شبکه:** دامافارم از مکانیسم Retrying هوشمند استفاده می‌کند، اما اگر دستگاه شما برای مدت طولانی آفلاین بماند، ممکن است نیاز باشد صف ارسال (Queue) را به صورت دستی تخلیه کنید.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از پروتکل MQTT پشتیبانی می‌کند؟**
بله، دامافارم به صورت نیتیو از MQTT برای کاهش مصرف پهنای باند در دستگاه‌های کم‌مصرف پشتیبانی می‌کند.

**آیا می‌توانم داده‌ها را به صورت آفلاین ذخیره کنم؟**
بله، SDK دامافارم قابلیتی برای ذخیره‌سازی محلی (Local Caching) دارد تا در صورت قطعی اینترنت، داده‌ها از دست نروند.

**آیا API محدودیتی دارد؟**
بله، برای جلوگیری از حملات منع سرویس، محدودیت نرخ (Rate Limit) اعمال شده است. اگر نیاز به تعداد درخواست‌های بسیار بالا دارید، با تیم پشتیبانی فنی در [damafarm.ir](https://damafarm.ir) تماس بگیرید.
