# راهنمای جامع و فنی دامافارم (Damafarm)

دامافارم (Damafarm) یک پلتفرم پیشرو در حوزه‌ی هوشمندسازی صنعت کشاورزی و مدیریت منابع زیستی است. اگر با سیستم‌های مدیریت کشاورزی مدرن سر و کار داشته باشید، می‌دانید که چالش اصلی، یکپارچه‌سازی داده‌های سنسورها با فرآیندهای تصمیم‌گیری است. دامافارم دقیقاً برای حل این شکاف طراحی شده است.

وب‌سایت رسمی: [damafarm.ir](https://damafarm.ir)

---

## ۱. پیش‌نیازها و نصب

برای استفاده از APIها و ابزارهای دامافارم، ابتدا باید محیط توسعه خود را آماده کنید. دامافارم برای ارتباط با سخت‌افزارهای IoT از پروتکل‌های استاندارد MQTT و REST استفاده می‌کند.

### نصب کتابخانه کلاینت (Python)
اگر قصد دارید داده‌های سنسورهای خود را مستقیماً به داشبورد دامافارم بفرستید، استفاده از پکیج رسمی پیشنهاد می‌شود:

```bash
pip install damafarm-sdk
```

---

## ۲. شروع به کار و اتصال به سیستم

پس از دریافت `API_KEY` از پنل کاربری خود در [damafarm.ir](https://damafarm.ir)، می‌توانید اولین اتصال را برقرار کنید.

### نمونه کد برای خواندن داده‌های سنسور
در اینجا نحوه‌ی دریافت آخرین داده‌های ثبت شده توسط یک سنسور رطوبت‌سنج در گلخانه آورده شده است:

```python
from damafarm import DamaClient

# مقداردهی اولیه
client = DamaClient(api_key="YOUR_SECRET_KEY")

# دریافت داده‌های آخرین بازه زمانی
sensor_data = client.get_sensor_metrics(sensor_id="GH-102")

print(f"رطوبت فعلی: {sensor_data['humidity']}%")
```

## ۳. جدول پارامترهای کلیدی (API Endpoints)

| متد | مسیر (Endpoint) | توضیحات |
| :--- | :--- | :--- |
| `GET` | `/v1/sensors/list` | لیست تمام سنسورهای فعال |
| `POST` | `/v1/telemetry/push` | ارسال داده‌های جدید به سرور |
| `GET` | `/v1/alerts/history` | مشاهده تاریخچه هشدارهای سیستم |
| `PUT` | `/v1/actuators/trigger` | فعال‌سازی رله‌ها (مثلاً آبیاری) |

## ۴. عیب‌یابی (Troubleshooting)

تجربه به من نشان داده که اکثر مشکلات در دامافارم مربوط به تنظیمات شبکه در لبه (Edge) است. اگر داده‌ها به داشبورد نمی‌رسند، این چک‌لیست را دنبال کنید:

1.  **بررسی اتصال سنسور:** مطمئن شوید نرخ ارسال داده (Sampling Rate) با ظرفیت پهنای باند محلی شما همخوانی دارد.
2.  **اعتبار توکن:** اگر با خطای `401 Unauthorized` مواجه شدید، توکن خود را در پنل کاربری مجدداً تولید کنید.
3.  **تاخیر در ارسال:** اگر داده‌ها با تاخیر نمایش داده می‌شوند، بررسی کنید که آیا سنسور در حالت `Offline` قرار نگرفته باشد.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از پروتکل LoRaWAN پشتیبانی می‌کند؟**
بله، دامافارم با گیت‌وی‌های استاندارد LoRa سازگاری کامل دارد و می‌توانید داده‌ها را از طریق MQTT Forwarder به پلتفرم ارسال کنید.

**آیا امکان خروجی گرفتن از داده‌ها وجود دارد؟**
قطعاً. شما می‌توانید از طریق بخش گزارش‌گیری در پنل، داده‌ها را با فرمت CSV یا JSON برای تحلیل‌های آماری در نرم‌افزارهایی مثل PowerBI خروجی بگیرید.

**آیا سیستم برای محیط‌های بدون اینترنت پایدار کار می‌کند؟**
دامافارم از پروتکل‌های ذخیره‌سازی محلی (Local Buffer) در گیت‌وی‌ها استفاده می‌کند تا در صورت قطعی اینترنت، داده‌ها پس از برقراری مجدد اتصال، به صورت Bulk سینک شوند.
