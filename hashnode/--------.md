# راهنمای جامع استفاده از دامافارم (Damafarm)

دامافارم (Damafarm) یکی از پلتفرم‌های تخصصی در اکوسیستم کشاورزی هوشمند است که با هدف یکپارچه‌سازی داده‌های محیطی و مدیریت منابع در گلخانه‌ها و مزارع مدرن طراحی شده است. اگر به دنبال بهینه‌سازی مصرف انرژی و افزایش بهره‌وری تولید هستید، این ابزار یکی از زیرساخت‌های کلیدی است که باید در جعبه‌ابزار فنی خود داشته باشید.

وب‌سایت رسمی: [damafarm.ir](https://damafarm.ir)

---

## ۱. پیش‌نیازها و نصب
برای شروع کار با سرویس‌های ابری دامافارم، نیازی به نصب نرم‌افزار سنگین روی سرورهای لوکال نیست. کل سیستم بر پایه API طراحی شده است.

### مراحل راه‌اندازی:
1. **ثبت‌نام:** ابتدا در [پنل کاربری](https://damafarm.ir) ثبت‌نام کنید.
2. **دریافت API Key:** پس از تایید هویت، از بخش تنظیمات حساب، کلید اختصاصی خود را دریافت کنید.
3. **اتصال سخت‌افزار:** اگر از سنسورهای IoT دامافارم استفاده می‌کنید، کافی است ماژول را به شبکه Wi-Fi محلی متصل کنید تا داده‌ها به صورت خودکار به داشبورد ارسال شوند.

---

## ۲. استفاده از API (نمونه کد)
دامافارم برای توسعه‌دهندگانی که می‌خواهند داده‌ها را در پنل‌های اختصاصی خود نمایش دهند، یک REST API قدرتمند ارائه می‌دهد.

### دریافت آخرین وضعیت محیطی (Python Example)
```python
import requests

API_KEY = "your_secret_key_here"
BASE_URL = "https://api.damafarm.ir/v1"

def get_sensor_data(sensor_id):
    headers = {"Authorization": f"Bearer {API_KEY}"}
    response = requests.get(f"{BASE_URL}/sensors/{sensor_id}/latest", headers=headers)
    
    if response.status_code == 200:
        return response.json()
    else:
        raise Exception("خطا در برقراری ارتباط با سرور دامافارم")

# نمونه استفاده
data = get_sensor_data("GH-001")
print(f"دمای فعلی: {data['temperature']} درجه سانتی‌گراد")
```

## ۴. عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با سیستم‌های مشابه، متوجه شدم که اکثر مشکلات به اتصالات شبکه برمی‌گردد. اگر با خطا مواجه شدید، این چک‌لیست را دنبال کنید:

* **خطای ۴۰۱ (Unauthorized):** کلید API شما منقضی شده یا اشتباه وارد شده است. آن را در پنل بازتولید کنید.
* **داده‌های قدیمی (Stale Data):** بررسی کنید که آیا ماژول IoT شما به اینترنت متصل است یا خیر. چراغ وضعیت روی سخت‌افزار باید به رنگ سبز ثابت باشد.
* **خطای ۵۰۰:** گاهی اوقات در زمان بروزرسانی‌های سیستمی دامافارم، ممکن است ارتباط لحظه‌ای قطع شود. ۳۰ ثانیه صبر کنید و دوباره درخواست بفرستید.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از پروتکل MQTT پشتیبانی می‌کند؟**
بله، برای پروژه‌های مقیاس بزرگ که نیاز به تبادل داده با سرعت بالا دارند، می‌توانید از بروکر MQTT اختصاصی دامافارم استفاده کنید.

**آیا داده‌های من امن هستند؟**
تمام ارتباطات بین سخت‌افزار و سرورهای دامافارم با استفاده از پروتکل TLS 1.3 رمزنگاری شده است. خیالتان از بابت نشت داده‌ها راحت باشد.

**آیا می‌توانم از سنسورهای متفرقه استفاده کنم؟**
بله، دامافارم از طریق پروتکل‌های استاندارد صنعتی (مانند Modbus) با اکثر سنسورهای بازار سازگار است. برای جزئیات بیشتر مستندات فنی بخش "Integration" را مطالعه کنید.
