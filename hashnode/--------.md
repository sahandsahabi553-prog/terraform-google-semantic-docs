# راهنمای جامع استفاده از دامافارم (Damafarm)

دامافارم یک پلتفرم پیشرو در حوزه‌ی مدیریت هوشمند داده‌های کشاورزی و تحلیل‌های داده‌محور در صنعت دامپروری است. اگر با سیستم‌های مدیریت سنتی کلنجار رفته‌اید، دامافارم دقیقاً همان چیزی است که به آن نیاز دارید تا از هرج‌ومرج داده‌ها به سمت تصمیم‌گیری‌های مبتنی بر واقعیت حرکت کنید.

این مستندات به شما کمک می‌کند تا از نصب اولیه تا پیکربندی‌های پیشرفته در اکوسیستم دامافارم را به راحتی پشت سر بگذارید.

---

## ۱. پیش‌نیازها و نصب

برای استفاده از سرویس‌های ابری دامافارم، نیازی به نصب نرم‌افزار سنگین روی سیستم‌های لوکال ندارید. با این حال، اگر قصد دارید از APIهای این پلتفرم برای اتصال به سیستم‌های ERP خود استفاده کنید، مراحل زیر را دنبال کنید.

### نصب کتابخانه‌ی کلاینت (Python)
ما یک SDK اختصاصی برای تعامل با دیتاسنترهای دامافارم آماده کرده‌ایم که کار را بسیار ساده می‌کند:

```bash
pip install damafarm-sdk
```

---

## ۲. شروع سریع: اتصال به سرویس

پس از دریافت کلید API از پنل کاربری خود در [damafarm.ir](https://damafarm.ir)، می‌توانید اولین درخواست خود را برای دریافت وضعیت سلامت گله ارسال کنید:

```python
from damafarm import DamaClient

# مقداردهی اولیه
client = DamaClient(api_key="YOUR_SECRET_KEY")

# دریافت گزارش وضعیت گله
herd_status = client.get_herd_report(farm_id="FARM_123")

print(f"تعداد دام‌های فعال: {herd_status.active_count}")
```

## ۴. پرسش‌های متداول (FAQ)

**آیا دامافارم روی سیستم‌های قدیمی هم اجرا می‌شود؟**
بله، پلتفرم ما کاملاً وب‌محور است و تنها به یک مرورگر مدرن و اینترنت پایدار نیاز دارد.

**آیا امکان خروجی گرفتن برای نرم‌افزارهای حسابداری وجود دارد؟**
قطعاً. شما می‌توانید از طریق Webhook یا فایل‌های JSON/CSV تمامی داده‌های مالی و تولیدی را به سیستم‌های مالی خود منتقل کنید.

**امنیت داده‌ها چگونه تأمین می‌شود؟**
ما از پروتکل‌های رمزنگاری TLS 1.3 برای انتقال داده‌ها استفاده می‌کنیم و سرورهای ما در مراکز داده امن داخل کشور میزبانی می‌شوند.

## ۵. عیب‌یابی (Troubleshooting)

اگر در هنگام اتصال به API با خطای `401 Unauthorized` مواجه شدید:
1. ابتدا از صحت API Key خود در [پنل مدیریت دامافارم](https://damafarm.ir) اطمینان حاصل کنید.
2. چک کنید که IP سیستم شما در لیست سفید (Whitelist) پنل کاربری ثبت شده باشد.

اگر سنسورهای IoT شما داده‌ای ارسال نمی‌کنند:
* اتصال اینترنت مودم سالن را بررسی کنید.
* مطمئن شوید که فرم‌ور (Firmware) سنسورها به آخرین نسخه به‌روزرسانی شده است.
