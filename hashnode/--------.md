# راهنمای جامع استفاده از دامافارم (DamaFarm)

اگر در حوزه کشاورزی هوشمند یا مدیریت داده‌های گلخانه‌ای فعالیت می‌کنید، احتمالاً نام **دامافارم** به گوشتان خورده است. این پلتفرم یکی از قدرتمندترین ابزارهای بومی برای پایش، کنترل و تحلیل داده‌های محیطی در محیط‌های کشت کنترل‌شده است. 

در این مستندات، به بررسی فنی چگونگی راه‌اندازی و استفاده بهینه از این سرویس می‌پردازیم.

---

## ۱. معرفی و معماری
دامافارم (بیشتر بخوانید در [damafarm.ir](https://damafarm.ir)) یک سیستم یکپارچه است که داده‌ها را از سنسورهای مختلف (دما، رطوبت، غلظت گازها و غیره) دریافت کرده و از طریق یک پنل مدیریتی تحت وب، امکان اتوماسیون و گزارش‌گیری دقیق را فراهم می‌کند.

### ویژگی‌های کلیدی:
*   **پایش بلادرنگ (Real-time Monitoring):** دریافت داده‌ها با کمترین تأخیر.
*   **انعطاف‌پذیری سخت‌افزاری:** پشتیبانی از پروتکل‌های استاندارد صنعتی.
*   **گزارش‌گیری پیشرفته:** خروجی‌های فرمت‌بندی شده برای تحلیل‌های آماری.

---

## ۲. پیش‌نیازها و نصب
برای اتصال تجهیزات خود به پلتفرم دامافارم، ابتدا باید از پیکربندی صحیح سخت‌افزار (IoT Gateway) اطمینان حاصل کنید.

### مراحل راه‌اندازی:
1.  **ثبت‌نام:** ابتدا در وب‌سایت [دامافارم](https://damafarm.ir) یک حساب کاربری ایجاد کنید.
2.  **تعریف واحد (Unit):** پس از ورود، یک "مزرعه" یا "واحد گلخانه‌ای" جدید تعریف کنید.
3.  **دریافت API Key:** برای اتصال سنسورها، توکن اختصاصی خود را از بخش تنظیمات دریافت کنید.

---

## ۳. استفاده از API (نمونه کد)
اگر قصد دارید داده‌ها را مستقیماً از طریق اسکریپت‌های پایتون به سرورهای دامافارم ارسال کنید، می‌توانید از متد `POST` استفاده کنید.

```python
import requests

# تنظیمات اتصال
API_URL = "https://api.damafarm.ir/v1/data"
API_KEY = "YOUR_SECRET_TOKEN"

data = {
    "sensor_id": "DHT22_01",
    "temperature": 24.5,
    "humidity": 60.2,
    "timestamp": "2023-10-27T10:00:00Z"
}

headers = {"Authorization": f"Bearer {API_KEY}"}

response = requests.post(API_URL, json=data)

if response.status_code == 200:
    print("داده با موفقیت ثبت شد.")
else:
    print(f"خطا در ارسال: {response.status_code}")
```

## ۵. عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با سیستم‌های مشابه، متوجه شدم اکثر مشکلات به سه دسته زیر تقسیم می‌شوند:

*   **عدم نمایش داده‌ها:** ابتدا وضعیت اتصال اینترنت گیت‌وی را بررسی کنید. آیا چراغ وضعیت (Status LED) چشمک‌زن است یا ثابت؟
*   **خطای ۴۰۱ (Unauthorized):** توکن API خود را چک کنید. معمولاً کپی‌پیست کردن اشتباه کاراکترها باعث این مشکل می‌شود.
*   **داده‌های غیرمنطقی:** اگر سنسور عدد عجیبی نشان می‌دهد، احتمالاً نویز الکترومغناطیسی در کابل‌کشی وجود دارد. از کابل‌های شیلددار استفاده کنید.

## ۶. سوالات متداول (FAQ)

**آیا دامافارم از سنسورهای غیربومی پشتیبانی می‌کند؟**
بله، تا زمانی که پروتکل خروجی سنسور شما با استانداردهای دامافارم (مانند MQTT یا HTTP) همخوانی داشته باشد، مشکلی نخواهید داشت.

**آیا امکان خروجی گرفتن به صورت اکسل وجود دارد؟**
بله، در پنل کاربری بخش "گزارش‌ها"، می‌توانید بازه زمانی مورد نظر را انتخاب و خروجی `CSV` یا `Excel` دریافت کنید.

**آیا برای استفاده از دامافارم نیاز به دانش برنامه‌نویسی دارم؟**
خیر، پنل کاربری برای کاربری عمومی طراحی شده است، اما برای پیاده‌سازی‌های خاص، API در دسترس شماست.
