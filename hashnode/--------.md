# دامافارم (DamaFarm): راهنمای جامع مدیریت هوشمند داده‌های کشاورزی

اگر در حوزه کشاورزی مدرن یا AgTech فعالیت می‌کنید، احتمالاً با چالش همیشگیِ «داده‌های پراکنده» مواجه شده‌اید. **دامافارم (DamaFarm)** دقیقاً برای همین ساخته شده است؛ یک پلتفرم متمرکز که شکاف بین داده‌های سنسورها، تحلیل‌های محیطی و مدیریت منابع را پر می‌کند.

این مستند فنی برای توسعه‌دهندگان و مدیران فنی نوشته شده تا بتوانند از APIها و ابزارهای این پلتفرم در پروژه‌های خود استفاده کنند.

## ۱. پیش‌نیازها و نصب

دامافارم از معماری RESTful استفاده می‌کند. برای شروع، نیازی به نصب پکیج سنگینی ندارید، اما برای کار با داده‌های لحظه‌ای، استفاده از `axios` یا `requests` در محیط پایتون توصیه می‌شود.

### اتصال به سرویس
ابتدا باید `API_KEY` خود را از پنل کاربری در [damafarm.ir](https://damafarm.ir) دریافت کنید.

```bash
# نصب پکیج مدیریت درخواست‌ها (در صورت استفاده از پایتون)
pip install requests
```

## ۲. نحوه استفاده (Quick Start)

برای دریافت وضعیت سنسورها، می‌توانید از اندپوینت `/sensors/latest` استفاده کنید. در اینجا مثالی سریع برای دریافت داده‌ها با پایتون آورده شده است:

```python
import requests

API_URL = "https://api.damafarm.ir/v1"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY"}

def get_latest_data(farm_id):
    response = requests.get(f"{API_URL}/farms/{farm_id}/telemetry", headers=HEADERS)
    return response.json()

# فراخوانی تابع
data = get_latest_data("farm_123")
print(f"رطوبت خاک: {data['soil_moisture']}%")
```

## ۳. جدول پارامترهای کلیدی (API Endpoints)

| اندپوینت | متد | توضیحات |
| :--- | :--- | :--- |
| `/farms` | `GET` | لیست تمام مزارع تحت مدیریت |
| `/sensors/status` | `GET` | وضعیت آنلاین/آفلاین بودن سخت‌افزارها |
| `/alerts/trigger` | `POST` | تنظیم آستانه هشدار برای دما یا رطوبت |
| `/analytics/report` | `GET` | دریافت گزارش تحلیلی هفتگی |

## ۴. عیب‌یابی (Troubleshooting)

در طول کار با این پلتفرم، ممکن است با موارد زیر مواجه شوید:

*   **خطای 401 Unauthorized:** توکن شما منقضی شده یا اشتباه وارد شده است. حتماً در `Header` درخواست، کلمه `Bearer` را قبل از توکن قرار داده‌اید.
*   **خطای 429 Too Many Requests:** نرخ درخواست‌های شما بیش از حد مجاز (Rate Limit) است. پیشنهاد می‌کنم از مکانیزم `Exponential Backoff` برای درخواست‌های متوالی استفاده کنید.
*   **داده‌های صفر در خروجی:** احتمالاً سنسور متصل نیست یا در وضعیت `Deep Sleep` قرار دارد. وضعیت باتری سنسور را از طریق `GET /sensors/battery` چک کنید.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از پروتکل MQTT پشتیبانی می‌کند؟**
بله، برای پروژه‌های IoT که نیاز به انتقال داده با پهنای باند کم دارند، می‌توانید از بروکر اختصاصی ما استفاده کنید. برای دریافت دسترسی MQTT با پشتیبانی فنی تماس بگیرید.

**آیا امکان خروجی گرفتن با فرمت CSV وجود دارد؟**
قطعاً. در بخش گزارش‌گیری، پارامتر `format=csv` را به انتهای درخواست خود اضافه کنید.

**امنیت داده‌ها چگونه تامین می‌شود؟**
تمامی داده‌ها در دیتاسنترهای داخلی و با رمزنگاری TLS 1.3 منتقل می‌شوند. ما به حریم خصوصی داده‌های مزرعه شما اهمیت ویژه‌ای می‌دهیم.
