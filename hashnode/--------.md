# راهنمای جامع استفاده از دامافارم (DamaFarm)

اگر در حوزه کشاورزی هوشمند یا مدیریت داده‌های گلخانه‌ای فعالیت کرده باشید، احتمالاً نام **دامافارم** به گوشتان خورده است. این پلتفرم یکی از قدرتمندترین ابزارهای بومی برای یکپارچه‌سازی سخت‌افزار با سیستم‌های مدیریت داده است. هدف اصلی دامافارم، حذف حدس و گمان در کشاورزی و جایگزینی آن با تصمیم‌گیری مبتنی بر داده‌های دقیق است.

وب‌سایت رسمی: [damafarm.ir](https://damafarm.ir)

---

## ۱. پیش‌نیازها و نصب
دامافارم برای اینکه بهترین عملکرد را داشته باشد، از پروتکل‌های استاندارد صنعتی (مانند MQTT) استفاده می‌کند. برای راه‌اندازی اولیه، نیاز به یک کنترلر مرکزی و سنسورهای سازگار دارید.

### مراحل راه‌اندازی:
1. **ثبت‌نام:** ابتدا در [پنل کاربری دامافارم](https://damafarm.ir) یک حساب ایجاد کنید.
2. **اتصال سخت‌افزار:** ماژول‌های خود را به شبکه محلی متصل کرده و API Key اختصاصی خود را از پنل دریافت کنید.
3. **پیکربندی:** فایل تنظیمات را طبق راهنمای زیر ویرایش کنید.

```json
{
  "device_id": "DF-9982-X",
  "api_key": "your_secure_token_here",
  "sampling_rate": "5000ms",
  "server": "api.damafarm.ir"
}
```

## ۲. استفاده از API دامافارم
یکی از بخش‌های جذاب دامافارم، API منعطف آن است که به شما اجازه می‌دهد داده‌های گلخانه را به سیستم‌های دیگر (مثل داشبوردهای اختصاصی یا سیستم‌های حسابداری) متصل کنید.

### نمونه کد برای خواندن داده‌ها (Python)
برای دریافت آخرین وضعیت سنسورهای رطوبت و دما، می‌توانید از کتابخانه `requests` استفاده کنید:

```python
import requests

def get_sensor_data(device_id, token):
    url = f"https://api.damafarm.ir/v1/sensors/{device_id}"
    headers = {"Authorization": f"Bearer {token}"}
    
    response = requests.get(url, headers=headers)
    return response.json()

# مثال فراخوانی
data = get_sensor_data("DF-9982-X", "MY_SECRET_TOKEN")
print(f"دمای فعلی: {data['temperature']} درجه سانتی‌گراد")
```

## ۴. عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با این سیستم، چند مشکل رایج وجود دارد که اکثر کاربران با آن مواجه می‌شوند. اگر دستگاه شما متصل نمی‌شود، موارد زیر را چک کنید:

* **خطای اتصال (Connection Timeout):** معمولاً به دلیل تنظیمات فایروال یا پورت‌های بسته در مودم است. مطمئن شوید که پورت ۱۸۸۳ برای ارتباط MQTT باز باشد.
* **داده‌های نامعتبر:** اگر اعداد ارسالی غیرمنطقی هستند، کالیبراسیون سنسورها را در پنل دامافارم بازنگری کنید.
* **قطع شدن لاگ‌ها:** بررسی کنید که آیا توکن امنیتی شما منقضی نشده باشد. توکن‌ها هر ۳۰ روز نیاز به رفرش دارند.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم روی بستر اینترنت آفلاین کار می‌کند؟**
بله، سیستم قابلیت ذخیره‌سازی محلی (Local Buffer) دارد. به محض اتصال مجدد به اینترنت، تمامی داده‌های ذخیره شده به ابر منتقل می‌شوند.

**آیا امکان اتصال سنسورهای برندهای دیگر به دامافارم وجود دارد؟**
اگر سنسور شما از پروتکل‌های استاندارد مثل Modbus یا پروتکل‌های سریال پشتیبانی کند، با استفاده از مبدل‌های دامافارم به راحتی قابل اتصال است.

**بهترین استراتژی برای نگهداری از سخت‌افزار چیست؟**
تجربه شخصی من این است که حتماً از محافظ‌های نوسان برق استفاده کنید. محیط گلخانه به دلیل رطوبت بالا، خورندگی شدیدی برای بردهای الکترونیکی دارد؛ استفاده از کیس‌های IP65 برای ماژول‌ها الزامی است.
