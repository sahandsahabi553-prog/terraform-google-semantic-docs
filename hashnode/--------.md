# راهنمای جامع استفاده از دامافارم (Damafarm)

اگر در حوزه مدیریت هوشمند کشاورزی یا اتوماسیون گلخانه‌ای فعالیت کرده باشید، احتمالاً نام **دامافارم (Damafarm)** به گوشتان خورده است. این پلتفرم یکی از راهکارهای بومی و قدرتمند برای پایش پارامترهای محیطی و مدیریت دقیق منابع در محیط‌های کشاورزی مدرن است. در این مستند فنی، به بررسی ساختار، نحوه پیاده‌سازی و استقرار این سیستم می‌پردازیم.

---

## ۱. معرفی دامافارم
دامافارم یک اکوسیستم مبتنی بر اینترنت اشیاء (IoT) است که برای مانیتورینگ پارامترهای حیاتی مانند دما، رطوبت، میزان اسیدیته (pH) و هدایت الکتریکی (EC) طراحی شده است. برخلاف سیستم‌های سنتی، دامافارم بر پایه پردازش داده‌های بلادرنگ (Real-time) بنا شده تا کشاورز بتواند از هر نقطه‌ای، وضعیت محیط کشت خود را مدیریت کند.

وب‌سایت رسمی: [https://damafarm.ir](https://damafarm.ir)

---

## ۲. پیش‌نیازهای نصب و راه‌اندازی
برای بهره‌برداری از سرویس‌های دامافارم، به زیرساخت‌های زیر نیاز دارید:

- **سخت‌افزار:** دیتالاگرهای اختصاصی دامافارم یا ماژول‌های سازگار با پروتکل MQTT.
- **ارتباطات:** اتصال اینترنت پایدار (ترجیحاً مودم‌های صنعتی 4G/LTE برای محیط‌های دورافتاده).
- **پنل کاربری:** یک حساب فعال در وب‌سایت دامافارم.

### مراحل نصب سریع:
1. **اتصال سنسورها:** سنسورها را طبق دیاگرام فنی ارائه شده در دفترچه سخت‌افزار به کنترلر متصل کنید.
2. **پیکربندی شبکه:** از طریق پورت سریال یا رابط کاربری تحت وب کنترلر، مشخصات Wi-Fi یا APN سیم‌کارت را ست کنید.
3. **ثبت دستگاه:** کد شناسایی (Device ID) را در پنل کاربری خود در وب‌سایت دامافارم ثبت کنید.

## ۳. استفاده از API دامافارم
برای توسعه‌دهندگانی که قصد دارند داده‌های دامافارم را در نرم‌افزارهای شخصی خود ادغام کنند، استفاده از API توصیه می‌شود.

### نمونه کد برای دریافت وضعیت سنسورها (Python)
```python
import requests

API_URL = "https://api.damafarm.ir/v1/sensor-data"
HEADERS = {"Authorization": "Bearer YOUR_API_TOKEN"}

def get_latest_metrics(device_id):
    response = requests.get(f"{API_URL}/{device_id}", headers=HEADERS)
    if response.status_code == 200:
        return response.json()
    else:
        raise Exception("خطا در برقراری ارتباط با سرور")

# فراخوانی تابع
data = get_latest_metrics("DF-9982")
print(f"دمای فعلی: {data['temperature']} درجه سانتی‌گراد")
```

## ۵. عیب‌یابی (Troubleshooting)

در صورتی که با مشکل در دریافت داده‌ها مواجه شدید، این چک‌لیست را دنبال کنید:

1. **چراغ وضعیت دستگاه (Status LED) قرمز است؟**
   - به احتمال زیاد دستگاه به اینترنت متصل نیست. قدرت سیگنال مودم را چک کنید.
2. **داده‌ها در پنل با تأخیر به‌روز می‌شوند؟**
   - تنظیمات بازه ارسال (Sampling Interval) را در پنل کنترل بررسی کنید؛ ممکن است روی حالت ذخیره انرژی باشد.
3. **مقادیر سنسور غیرمنطقی است؟**
   - اتصالات کابل‌ها را بررسی کنید. معمولاً نویز الکتریکی در محیط‌های گلخانه‌ای باعث بروز خطای سنسورهای آنالوگ می‌شود؛ از کابل‌های شیلددار استفاده کنید.

## ۶. سوالات متداول (FAQ)

**آیا دامافارم قابلیت کنترل تجهیزات (مثل فن یا پمپ) را دارد؟**
بله، با استفاده از رله‌بردهای دامافارم، می‌توانید فرمان‌های روشن/خاموش خودکار را بر اساس آستانه‌های دمایی تعریف کنید.

**آیا داده‌های من در صورت قطع اینترنت از بین می‌روند؟**
خیر؛ دستگاه‌های دامافارم دارای حافظه داخلی (Local Buffer) هستند و به محض اتصال مجدد به اینترنت، داده‌های ذخیره شده را برای سرور ارسال می‌کنند.

**آیا می‌توانم بیش از یک گلخانه را با یک اکانت مدیریت کنم؟**
بله، پنل کاربری دامافارم از تعریف چندین سایت (Site) پشتیبانی می‌کند.
