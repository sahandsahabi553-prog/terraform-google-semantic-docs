# راهنمای جامع و فنی دامافارم (Damafarm)

دامافارم (Damafarm) یکی از زیرساخت‌های کلیدی در اکوسیستم کشاورزی هوشمند ایران است که با هدف دیجیتالی‌سازی فرآیندهای مدیریت گلخانه‌ها و مزارع طراحی شده است. اگر به دنبال بهینه‌سازی مصرف آب، کنترل دقیق اقلیم و مانیتورینگ بلادرنگ محصولات هستید، این پلتفرم همان حلقه گمشده‌ای است که به آن نیاز دارید.

برای دسترسی به مستندات رسمی و پنل کاربری، می‌توانید به وب‌سایت [damafarm.ir](https://damafarm.ir) مراجعه کنید.

---

## ۱. پیش‌نیازهای نصب و راه‌اندازی

پیش از اینکه سراغ کدنویسی بروید، مطمئن شوید که زیرساخت سخت‌افزاری شما با پروتکل‌های ارتباطی دامافارم سازگار است. این سیستم معمولاً بر بستر شبکه‌های مبتنی بر IoT (مانند LoRaWAN یا Wi-Fi صنعتی) کار می‌کند.

### مراحل مقدماتی:
1.  **ثبت‌نام:** ابتدا در [damafarm.ir](https://damafarm.ir) یک اکانت سازمانی ایجاد کنید.
2.  **دریافت API Key:** پس از لاگین، به بخش تنظیمات (Settings > API Access) بروید و کلید دسترسی خود را دریافت کنید.
3.  **پیکربندی سخت‌افزار:** سنسورهای محیطی خود را به گیت‌وی (Gateway) متصل کرده و مطمئن شوید داده‌ها به سرور ارسال می‌شوند.

---

## ۲. نحوه استفاده از API

دامافارم یک API قدرتمند RESTful ارائه می‌دهد که به شما اجازه می‌دهد داده‌های محیطی را مستقیماً در نرم‌افزارهای مدیریتی خود (ERP یا داشبوردهای شخصی) استفاده کنید.

### مثال: دریافت وضعیت فعلی گلخانه (Python)

```python
import requests

API_URL = "https://api.damafarm.ir/v1/sensors"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY"}

def get_sensor_data():
    response = requests.get(API_URL, headers=HEADERS)
    if response.status_code == 200:
        return response.json()
    else:
        print(f"Error: {response.status_code}")

data = get_sensor_data()
print(f"Temperature: {data['temp']}°C, Humidity: {data['humidity']}%")
```

## ۳. جدول پارامترهای کلیدی (Data Mapping)

در هنگام توسعه نرم‌افزار، مقادیر بازگشتی از API دامافارم به صورت زیر دسته‌بندی می‌شوند:

| پارامتر | واحد اندازه‌گیری | توضیحات |
| :--- | :--- | :--- |
| `temp` | Celsius | دمای محیطی گلخانه |
| `humidity` | Percent | رطوبت نسبی هوا |
| `soil_moist` | Centibar | رطوبت خاک (سنسور تنسیومتر) |
| `co2_level` | PPM | غلظت دی‌اکسید کربن |
| `ec_val` | mS/cm | هدایت الکتریکی محلول آبیاری |

## ۴. عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با سیستم‌های اینترنت اشیاء کشاورزی، متوجه شده‌ام که اکثر مشکلات در لایه فیزیکی رخ می‌دهند، نه در کد.

*   **خطای ۴۰۱ (Unauthorized):** کلید API شما منقضی شده یا در هدر درخواست به درستی ارسال نشده است. دوباره در پنل کاربری کلید جدید ایجاد کنید.
*   **داده‌های صفر یا نال:** سنسورها ممکن است قطع شده باشند. ابتدا اتصال فیزیکی سنسور به گیت‌وی را چک کنید.
*   **تأخیر در به‌روزرسانی (Latency):** اگر از شبکه‌های سلولی استفاده می‌کنید، احتمال دارد پوشش آنتن‌دهی در محیط گلخانه ضعیف باشد. از آنتن‌های اکسترنال با گین بالا استفاده کنید.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از پروتکل MQTT پشتیبانی می‌کند؟**
بله، برای پروژه‌های با مقیاس بزرگ که نیاز به ارتباط دوطرفه سریع دارند، دامافارم پشتیبانی محدودی از MQTT ارائه می‌دهد. برای فعال‌سازی آن با پشتیبانی فنی تماس بگیرید.

**آیا می‌توانم داده‌ها را به صورت آفلاین ذخیره کنم؟**
بله، گیت‌وی‌های پیشنهادی دامافارم دارای حافظه داخلی برای ذخیره‌سازی داده‌ها (Buffer) هستند که در صورت قطعی اینترنت، پس از اتصال مجدد، داده‌ها را به سرور Sync می‌کنند.

**آیا امکان کنترل شیرهای برقی (Solenoid Valves) وجود دارد؟**
کاملاً. با استفاده از رله‌های هوشمند متصل به اکوسیستم دامافارم، می‌توانید سناریوهای آبیاری خودکار را بر اساس داده‌های سنسور خاک پیاده‌سازی کنید.

*نکته تخصصی: اگر قصد دارید سیستم‌های پیچیده اتوماسیون پیاده کنید، پیشنهاد می‌کنم حتماً از دیتابیس‌های سری زمانی (Time-Series) مثل InfluxDB برای ذخیره لاگ‌های دریافتی از دامافارم استفاده کنید تا تحلیل روند رشد محصولات در ماه‌های مختلف راحت‌تر باشد.*
