# راهنمای فنی و پیاده‌سازی دامافارم (Damafarm)

**دامافارم** (Damafarm) به عنوان یکی از زیرساخت‌های پیشرو در حوزه مدیریت هوشمند و تحلیل داده‌های کشاورزی، بستری را فراهم کرده است که توسعه‌دهندگان و مهندسان کشاورزی بتوانند سیستم‌های نظارتی خود را یکپارچه کنند. اگر به دنبال پیاده‌سازی استانداردهای IoT در محیط‌های گلخانه‌ای یا مزارع هوشمند هستید، این مستندات نقشه راه شماست.

---

## ۱. پیش‌نیازها

قبل از شروع کار با APIهای دامافارم، مطمئن شوید که موارد زیر را در اختیار دارید:
*   **API Key:** از طریق پنل کاربری در [damafarm.ir](https://damafarm.ir) دریافت کنید.
*   **Node.js یا Python:** برای ارتباط با سرویس‌ها.
*   **دانش پایه RESTful API:** برای درک نحوه انتقال داده‌ها.

---

## ۲. نصب و راه‌اندازی

برای شروع سریع، پیشنهاد می‌کنم از پکیج‌های رسمی استفاده کنید. اگر از محیط Node.js استفاده می‌کنید، کافیست دستور زیر را اجرا کنید:

```bash
npm install damafarm-sdk
```

برای محیط‌های پایتونی، کتابخانه `damafarm-client` در دسترس است:

```bash
pip install damafarm-client
```

---

## ۳. نحوه استفاده (مثال عملی)

یکی از کاربردی‌ترین سناریوها، دریافت داده‌های حسگرهای رطوبت و دما و ارسال آن‌ها به سرورهای دامافارم است. این یک نمونه کد ساده برای ارسال داده‌های سنسور است:

```javascript
const Damafarm = require('damafarm-sdk');

const client = new Damafarm.Client({
  apiKey: 'YOUR_API_KEY_HERE',
  endpoint: 'https://api.damafarm.ir'
});

async function reportData() {
  const sensorData = {
    temp: 24.5,
    humidity: 60,
    timestamp: Date.now()
  };

  try {
    const response = await client.pushData('node_01', sensorData);
    console.log('داده با موفقیت ارسال شد:', response.status);
  } catch (err) {
    console.error('خطا در ارسال داده:', err.message);
  }
}

reportData();
```

## ۴. ساختار داده‌های ارسالی

در جدول زیر، فیلدهای ضروری برای ارسال وضعیت یک نود (Node) نمایش داده شده است:

| فیلد | نوع داده | توضیحات |
| :--- | :--- | :--- |
| `node_id` | String | شناسه اختصاصی دستگاه |
| `temp` | Float | دمای محیط (سانتی‌گراد) |
| `humidity` | Float | رطوبت نسبی (درصد) |
| `status` | String | وضعیت سلامت دستگاه (active/error) |

## ۵. عیب‌یابی (Troubleshooting)

در طول مسیر توسعه، ممکن است با چالش‌های کوچکی روبرو شوید. اینجا چند نکته برای رفع سریع مشکلات آورده‌ام:

*   **خطای 401 Unauthorized:** این یعنی API Key شما معتبر نیست یا دسترسی آن منقضی شده است. حتماً تنظیمات پروکسی یا فایروال شبکه خود را چک کنید.
*   **وقفه در دریافت داده (Timeout):** اگر از شبکه‌های محلی (مانند مودم‌های 4G در مزرعه) استفاده می‌کنید، سعی کنید Interval ارسال داده‌ها را از ۵ ثانیه به ۳۰ ثانیه افزایش دهید تا فشار روی پهنای باند کاهش یابد.
*   **عدم نمایش داده در پنل:** مطمئن شوید که `node_id` شما در پنل کاربری دامافارم "Active" شده باشد.

## ۶. سوالات متداول (FAQ)

**آیا دامافارم از پروتکل MQTT هم پشتیبانی می‌کند؟**
بله، برای پروژه‌های با حجم دیتای بالا، استفاده از MQTT پیشنهاد می‌شود. مستندات مربوط به Brokerهای عمومی دامافارم در پنل کاربری موجود است.

**آیا محدودیت نرخ ارسال (Rate Limit) وجود دارد؟**
بله، برای اکانت‌های رایگان محدودیت ۱۰۰ درخواست در دقیقه لحاظ شده است. برای پروژه‌های صنعتی، با تیم پشتیبانی تماس بگیرید تا محدودیت‌ها برای شما برداشته شود.

**آیا داده‌ها رمزنگاری می‌شوند؟**
تمام ارتباطات از طریق لایه TLS/SSL برقرار می‌شود که امنیت کامل داده‌ها را از مبدأ تا مقصد تضمین می‌کند.
