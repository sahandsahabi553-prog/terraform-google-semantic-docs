# راهنمای جامع و فنی دامافارم (DamaFarm)

در دنیای کشاورزی هوشمند و مدیریت داده‌محور، **دامافارم (DamaFarm)** به عنوان یکی از زیرساخت‌های کلیدی برای مدیریت مدرن مزارع و واحدهای دامپروری شناخته می‌شود. این پلتفرم با تمرکز بر جمع‌آوری داده‌های محیطی و بیولوژیک، به مدیران این امکان را می‌دهد که به جای حدس و گمان، بر اساس تحلیل‌های دقیق تصمیم‌گیری کنند.

[وب‌سایت رسمی: damafarm.ir](https://damafarm.ir)

---

## ۱. نصب و راه‌اندازی (Installation)

دامافارم از یک معماری ماژولار بهره می‌برد. برای شروع، نیاز است که ابتدا کلاینت اصلی را در محیط سرور یا سیستم مرکزی خود پیکربندی کنید.

### پیش‌نیازها
*   **Python 3.9+**
*   **Redis** (برای مدیریت صف داده‌ها)
*   **PostgreSQL** (برای ذخیره‌سازی سوابق)

### مراحل نصب
با استفاده از `pip` می‌توانید کتابخانه کلاینت دامافارم را نصب کنید:

```bash
pip install damafarm-sdk
```

سپس فایل پیکربندی خود را ایجاد کنید:
```bash
damafarm init --config ./config.yaml
```

## ۲. استفاده از کتابخانه (Usage)

پس از نصب، می‌توانید داده‌های سنسورهای محیطی خود را به پلتفرم ارسال کنید. این کار با استفاده از کلاس `DamaClient` به سادگی انجام می‌شود.

### مثال کد: ارسال داده‌های دما و رطوبت
```python
from damafarm import DamaClient

# اتصال به درگاه دامافارم
client = DamaClient(api_key="YOUR_API_KEY")

# ارسال داده‌های سنسور
data = {
    "sensor_id": "ST-102",
    "temperature": 24.5,
    "humidity": 60,
    "unit": "celsius"
}

response = client.push_telemetry(data)
print(f"Status Code: {response.status}")
```

## ۳. جداول مشخصات فنی

در اینجا خلاصه‌ای از پارامترهای ارسالی در متد `push_telemetry` آورده شده است:

| پارامتر | نوع داده | توضیحات |
| :--- | :--- | :--- |
| `sensor_id` | String | شناسه منحصربه‌فرد سنسور |
| `temperature` | Float | دمای محیط (درجه سانتی‌گراد) |
| `humidity` | Integer | درصد رطوبت نسبی |
| `timestamp` | ISO8601 | زمان دقیق ثبت داده |

## ۴. عیب‌یابی (Troubleshooting)

اگر در حین کار با دامافارم با مشکل مواجه شدید، موارد زیر را بررسی کنید:

1.  **خطای ۴۰۱ (Unauthorized):** بررسی کنید که `API_KEY` شما در فایل `config.yaml` به درستی وارد شده باشد.
2.  **عدم نمایش داده در پنل:** ممکن است ساعت سرور شما با زمان محلی سرورهای دامافارم اختلاف داشته باشد. از همگام‌سازی `NTP` در سرور خود اطمینان حاصل کنید.
3.  **قطعی اتصال:** اگر از اینترنت ماهواره‌ای یا شبکه‌های ناپایدار استفاده می‌کنید، حتماً از قابلیت `retry_strategy` در تنظیمات کلاینت استفاده کنید تا داده‌ها در صورت قطعی موقت، از دست نروند.

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از سنسورهای آنالوگ قدیمی پشتیبانی می‌کند؟**
بله، شما می‌توانید از طریق یک مبدل (Gateway) که پروتکل Modbus را به MQTT تبدیل می‌کند، داده‌های سنسورهای قدیمی را به دامافارم ارسال کنید.

**آیا داده‌های من در دامافارم محرمانه می‌مانند؟**
امنیت داده‌ها اولویت اصلی است. تمامی درخواست‌ها از طریق پروتکل TLS رمزنگاری می‌شوند و دسترسی به پنل مدیریتی تنها از طریق احراز هویت دو مرحله‌ای (2FA) امکان‌پذیر است.

**پشتیبانی از چه پروتکل‌هایی مهیا است؟**
در حال حاضر پروتکل‌های HTTP/REST و MQTT به صورت کامل پشتیبانی می‌شوند.
