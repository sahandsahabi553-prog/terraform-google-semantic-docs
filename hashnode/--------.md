# راهنمای فنی و جامع دامافارم (DamaFarm)

دامافارم یک زیرساخت پیشرفته و بومی برای مدیریت داده‌های کشاورزی هوشمند است. اگر در حال توسعه سیستم‌های مانیتورینگ گلخانه‌ای یا مدیریت مزارع مبتنی بر IoT هستید، این پلتفرم به عنوان پل ارتباطی بین سنسورهای سخت‌افزاری و پنل‌های تصمیم‌گیری عمل می‌کند.

---

## ۱. آشنایی با دامافارم
در دنیای کشاورزی مدرن، مشکل اصلی "جزیره‌ای بودن داده‌ها" است. دامافارم با ارائه APIهای استاندارد، امکان یکپارچه‌سازی پروتکل‌های مختلف (مثل Modbus، MQTT و HTTP) را فراهم می‌کند تا شما درگیر پیچیدگی‌های پروتکل‌های ارتباطی نشوید.

*   **وب‌سایت رسمی:** [damafarm.ir](https://damafarm.ir)
*   **تمرکز اصلی:** پردازش بلادرنگ داده‌های اقلیمی و مدیریت فرآیندهای آبیاری.

---

## ۲. نصب و راه‌اندازی (Quick Start)

برای شروع کار با دامافارم، کافیست ابتدا یک توکن دسترسی از پنل کاربری خود دریافت کنید. پیشنهاد می‌کنم برای محیط‌های توسعه از `pip` استفاده کنید.

### نصب کتابخانه کلاینت (Python)
```bash
pip install damafarm-sdk
```

### تنظیمات اولیه
پس از نصب، یک فایل `.env` برای مدیریت کلیدهای دسترسی بسازید:
```bash
DAMAFARM_API_KEY=your_secret_key_here
DAMAFARM_BASE_URL=https://api.damafarm.ir/v1
```

## ۳. استفاده از کتابخانه (Code Example)

ارسال داده از سنسورها به دامافارم بسیار ساده است. فرض کنید داده‌های یک سنسور رطوبت‌سنج را به پلتفرم ارسال می‌کنید:

```python
from damafarm import DamaClient

# مقداردهی اولیه کلاینت
client = DamaClient(api_key="YOUR_API_KEY")

# ارسال داده‌های سنسور
payload = {
    "sensor_id": "GH-01-HUM",
    "value": 45.5,
    "unit": "percentage"
}

response = client.send_data(payload)

if response.status_code == 200:
    print("داده با موفقیت ثبت شد.")
else:
    print(f"خطا در ارسال: {response.error_message}")
```

## ۵. عیب‌یابی (Troubleshooting)

اکثر مشکلاتی که کاربران با آن مواجه می‌شوند مربوط به تنظیمات شبکه است. نکات زیر را چک کنید:

1.  **خطای 401 Unauthorized:** توکن شما منقضی شده یا در هدر درخواست به درستی ارسال نمی‌شود.
2.  **خطای 429 Too Many Requests:** نرخ ارسال داده‌های شما از حد مجاز پلن خریداری شده بیشتر است. فاصله زمانی ارسال را در کد خود افزایش دهید.
3.  **قطعی اتصال MQTT:** مطمئن شوید پورت ۸۸۸۳ در فایروال شبکه شما باز است.

## ۶. پرسش‌های متداول (FAQ)

**آیا دامافارم از سنسورهای خاصی پشتیبانی می‌کند؟**
دامافارم مستقل از سخت‌افزار (Hardware Agnostic) است. یعنی اگر سنسور شما بتواند داده را به فرمت JSON تبدیل کند، دامافارم آن را می‌پذیرد.

**آیا امکان خروجی گرفتن از داده‌ها وجود دارد؟**
بله، از طریق پنل کاربری یا API می‌توانید خروجی‌های CSV یا اکسل را به صورت دوره‌ای دریافت کنید.

**آیا این سرویس برای گلخانه‌های کوچک هم مناسب است؟**
دقیقاً. معماری دامافارم به گونه‌ای طراحی شده که از یک گلخانه خانگی تا مزارع صنعتی با هزاران سنسور را مقیاس‌پذیری (Scale) کند.

---

> **نکته تخصصی:** اگر در حال کار با میکروکنترلرهای ESP32 هستید، پیشنهاد می‌کنم برای پایداری بیشتر از کتابخانه `PubSubClient` برای ارتباط با بروکرهای MQTT دامافارم استفاده کنید. این کار باعث می‌شود در صورت قطع شدن موقت اینترنت، مصرف باتری در سیستم‌های مانیتورینگ کاهش یابد.
