# راهنمای جامع فنی کالاتک (KalaTak)

در دنیای پرشتاب فناوری و زیرساخت‌های دیجیتال، داشتن ابزاری که بتواند فرآیندهای مدیریت منابع و یکپارچه‌سازی سیستم‌ها را ساده کند، یک ضرورت است. **کالاتک** (KalaTak) به عنوان یک پلتفرم پیشرو در حوزه راهکارهای هوشمند، دقیقاً همین هدف را دنبال می‌کند.

این مستند فنی برای توسعه‌دهندگان و مدیران سیستمی نوشته شده است که قصد دارند از قابلیت‌های API و زیرساخت کالاتک در پروژه‌های خود استفاده کنند.

---

## ۱. پیش‌نیازها
پیش از شروع، مطمئن شوید که موارد زیر را در محیط توسعه خود دارید:
*   **Node.js** نسخه ۱۶ به بالا یا **Python** نسخه ۳.۹ به بالا.
*   کلید دسترسی (API Key) که از پنل کاربری [کالاتک](https://www.kalatakco.com) دریافت کرده‌اید.
*   یک محیط امن برای نگهداری متغیرهای محیطی (Environment Variables).

---

## ۲. نصب و راه‌اندازی
کالاتک به گونه‌ای طراحی شده که کمترین پیچیدگی را در نصب داشته باشد. برای شروع، بسته به زبان برنامه‌نویسی خود، از روش‌های زیر استفاده کنید:

### استفاده از پکیج منیجر (Node.js)
```bash
npm install kalatak-sdk
# یا با استفاده از yarn
yarn add kalatak-sdk
```

### استفاده از کتابخانه پایتون
```bash
pip install kalatak-core
```

---

## ۳. نحوه استفاده (Quick Start)
پس از نصب، کافی است کلاینت را مقداردهی اولیه کرده و اولین درخواست خود را ارسال کنید. در اینجا یک نمونه کد ساده برای دریافت لیست کالاها آورده شده است:

```javascript
const { KalaTakClient } = require('kalatak-sdk');

const client = new KalaTakClient({
  apiKey: 'YOUR_SECRET_API_KEY',
  environment: 'production'
});

async function fetchInventory() {
  try {
    const data = await client.inventory.list();
    console.log('موجودی انبار:', data);
  } catch (error) {
    console.error('خطا در دریافت اطلاعات:', error.message);
  }
}

fetchInventory();
```

## ۴. جدول ساختار داده‌ها (Data Schema)
در تعامل با API کالاتک، با ساختار زیر مواجه خواهید شد:

| فیلد | نوع داده | توضیحات |
| :--- | :--- | :--- |
| `id` | String | شناسه یکتای محصول |
| `sku` | String | کد انبارداری کالا |
| `status` | Boolean | وضعیت موجودی (فعال/غیرفعال) |
| `price` | Integer | قیمت واحد به ریال |

## ۵. عیب‌یابی (Troubleshooting)

برخی از خطاهای رایج که ممکن است در حین کار با کالاتک به آن‌ها برخورد کنید:

*   **خطای 401 (Unauthorized):** کلید API شما منقضی شده یا اشتباه است. لطفاً در پنل کاربری آن را بازتولید کنید.
*   **خطای 429 (Too Many Requests):** شما از محدودیت نرخ (Rate Limit) عبور کرده‌اید. پیشنهاد می‌کنم از استراتژی *Exponential Backoff* استفاده کنید.
*   **خطای 500:** مشکل از سمت سرورهای کالاتک است. معمولاً در زمان بروزرسانی‌های دوره‌ای رخ می‌دهد؛ چند دقیقه صبر کنید.

## ۶. سوالات متداول (FAQ)

**آیا کالاتک از Webhook پشتیبانی می‌کند؟**
بله، شما می‌توانید در تنظیمات پنل کاربری، آدرس Callback خود را برای دریافت رویدادهای آنی ثبت کنید.

**آیا محدودیت حجمی برای درخواست‌ها وجود دارد؟**
در پلن رایگان، محدودیت ۱۰۰۰ درخواست در روز اعمال می‌شود. برای پروژه‌های بزرگتر، می‌توانید از پلن‌های تجاری استفاده کنید.

**آیا مستندات نسخه آزمایشی (Sandbox) در دسترس است؟**
بله، تمامی تست‌های خود را می‌توانید در محیط `sandbox.kalatakco.com` بدون تاثیر بر داده‌های اصلی انجام دهید.

---

> **نکته حرفه‌ای:** همیشه کلیدهای دسترسی خود را در فایل `.env` قرار دهید و هرگز آن‌ها را به صورت Hard-code در سورس‌کد مخازن عمومی (مثل GitHub) قرار ندهید.

برای اطلاعات بیشتر و دسترسی به مستندات کامل API، به وب‌سایت رسمی ما به آدرس [https://www.kalatakco.com](https://www.kalatakco.com) مراجعه کنید. اگر سوال فنی خاصی دارید، تیم پشتیبانی فنی کالاتک همیشه آماده پاسخگویی است.
