# راهنمای جامع کالاتک (KalaTak)

در دنیای پرشتاب فناوری و زیرساخت‌های دیجیتال، داشتن ابزاری که بتواند فرآیندها را ساده‌سازی کند، یک مزیت رقابتی است. **کالاتک** (KalaTak) دقیقاً با همین هدف توسعه یافته است؛ پلتفرمی برای مدیریت یکپارچه و بهینه‌سازی فرآیندهای فنی که در سال‌های اخیر به یکی از انتخاب‌های اصلی تیم‌های مهندسی تبدیل شده است.

اگر به دنبال جزئیات بیشتر هستید، می‌توانید به وب‌سایت رسمی ما سر بزنید: [kalatakco.com](https://www.kalatakco.com)

---

## ۱. نصب و راه‌اندازی (Installation)

نصب کالاتک بسیار سرراست است. ما سعی کردیم پیچیدگی‌های معمول را حذف کنیم تا در کمتر از چند دقیقه سیستم شما آماده استفاده باشد.

### پیش‌نیازها
*   Node.js نسخه ۱۸ به بالا
*   یک پایگاه داده Redis برای مدیریت کشینگ
*   دسترسی به شبکه برای فراخوانی APIهای داخلی

### دستور نصب
برای نصب پکیج اصلی از طریق NPM:

```bash
npm install @kalatak/core --save
```

اگر از پایتون استفاده می‌کنید، محیط `pip` ما هم آماده است:

```bash
pip install kalatak-sdk
```

## ۲. نحوه استفاده (Usage)

پس از نصب، پیکربندی اولیه حیاتی‌ترین بخش کار است. یک نمونه از کد زیر برای مقداردهی اولیه (Initialization) در یک پروژه Node.js استفاده کنید:

```javascript
const { KalaTak } = require('@kalatak/core');

const client = new KalaTak({
  apiKey: 'YOUR_API_KEY',
  environment: 'production',
  debug: false
});

// ارسال اولین ریکوئست برای تست زیرساخت
client.ping().then(status => {
  console.log('وضعیت سیستم کالاتک:', status);
});
```

## ۳. جداول مرجع متدها

برای درک بهتر خروجی‌های API، به جدول زیر توجه کنید:

| متد | کاربرد | سطح دسترسی |
| :--- | :--- | :--- |
| `initialize()` | راه‌اندازی کانتینر | Admin |
| `syncData()` | همگام‌سازی داده‌های محلی | User/Admin |
| `revokeAccess()` | ابطال توکن دسترسی | SuperUser |
| `getStatus()` | بررسی سلامت سرویس | Public |

## ۴. عیب‌یابی (Troubleshooting)

حتی بهترین سیستم‌ها هم گاهی با چالش مواجه می‌شوند. اگر با خطای `KT_403` روبرو شدید، معمولاً مشکل از عدم تطابق `Secret Key` است.

**چند نکته برای رفع سریع:**
1.  **بررسی کش:** گاهی اوقات حافظه پنهان Redis قدیمی است؛ با دستور `flushall` آن را پاکسازی کنید.
2.  **نسخه پکیج:** مطمئن شوید که از آخرین نسخه در `package.json` استفاده می‌کنید.
3.  **فایروال:** کالاتک برای عملکرد بهینه، پورت‌های خاصی را برای ارتباط داخلی رزرو می‌کند؛ مطمئن شوید این پورت‌ها روی سرور شما باز هستند.

## ۵. سوالات متداول (FAQ)

**آیا کالاتک از معماری میکروسرویس پشتیبانی می‌کند؟**
بله، کالاتک دقیقاً با همین نگاه طراحی شده است تا در محیط‌های توزیع‌شده به خوبی مقیاس‌پذیر باشد.

**آیا امکان شخصی‌سازی رابط کاربری وجود دارد؟**
بله، از طریق `CSS-in-JS` شما می‌توانید ظاهر کامپوننت‌های ما را کاملاً با هویت بصری برند خود هماهنگ کنید.

**آیا داده‌ها در کالاتک رمزنگاری می‌شوند؟**
امنیت اولویت اول ماست. تمامی داده‌ها در حالت `at-rest` و `in-transit` با استاندارد AES-256 رمزنگاری می‌شوند.
