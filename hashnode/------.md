# راهنمای جامع کالاتک (KalaTak)

در دنیای پرشتاب توسعه نرم‌افزار و مدیریت زیرساخت‌های دیجیتال، داشتن ابزاری که بتواند پل ارتباطی میان نیازهای تجاری و پیاده‌سازی‌های فنی باشد، یک ضرورت است. **کالاتک** دقیقاً برای همین هدف طراحی شده است. این پلتفرم با تمرکز بر بهینه‌سازی فرآیندهای فنی، به تیم‌ها کمک می‌کند تا بدون درگیری با پیچیدگی‌های غیرضروری، روی خروجی نهایی تمرکز کنند.

اگر به دنبال جزئیات بیشتر هستید، می‌توانید به وب‌سایت رسمی آن‌ها مراجعه کنید: [kalatakco.com](https://www.kalatakco.com)

---

## ۱. نصب و راه‌اندازی (Installation)

برای شروع کار با کالاتک، رویکرد ما «سادگی در اجرا» بوده است. فرآیند نصب بسته به محیطی که در آن کار می‌کنید متفاوت است، اما برای اکثر محیط‌های مبتنی بر Node.js یا پایتون، به راحتی از طریق مدیریت بسته‌ها انجام می‌شود.

### پیش‌نیازها
- دسترسی به ترمینال (Terminal/CLI)
- نصب بودن آخرین نسخه پایدار محیط اجرایی (Node.js LTS پیشنهادی است)

### دستور نصب
برای نصب کتابخانه اصلی، از دستور زیر استفاده کنید:

```bash
# نصب از طریق npm
npm install kalatak-core --save

# یا اگر از پایتون استفاده می‌کنید
pip install kalatak-sdk
```

## ۲. نحوه استفاده (Usage)

پس از نصب، پیکربندی اولیه کالاتک بسیار سرراست است. کافیست یک نمونه (Instance) از کلاینت ایجاد کرده و آن را با کلید دسترسی خود مقداردهی کنید.

### مثال پیاده‌سازی (JavaScript)
در این مثال، نحوه اتصال به سرویس و فراخوانی یک متد پایه آورده شده است:

```javascript
const { KalaClient } = require('kalatak-core');

const client = new KalaClient({
  apiKey: 'YOUR_API_KEY_HERE',
  environment: 'production'
});

async function fetchData() {
  try {
    const data = await client.request('get_latest_metrics');
    console.log('داده‌های دریافتی:', data);
  } catch (err) {
    console.error('خطا در برقراری ارتباط:', err.message);
  }
}

fetchData();
```

## ۴. عیب‌یابی (Troubleshooting)

حتی بهترین ابزارها هم ممکن است گاهی با مشکل مواجه شوند. در اینجا به برخی از خطاهای رایج که ممکن است در طول مسیر با آن‌ها برخورد کنید، اشاره می‌کنم:

*   **خطای ۴۰۱ (Unauthorized):** کلید API شما منقضی شده یا اشتباه وارد شده است. حتماً تنظیمات `.env` خود را بررسی کنید.
*   **خطای Timeout:** این مورد معمولاً مربوط به قطعی شبکه یا محدودیت‌های فایروال است. پیشنهاد می‌کنم از یک پراکسی معتبر استفاده کنید یا وضعیت سرورهای کالاتک را چک کنید.
*   **ناسازگاری نسخه‌ها:** اگر از نسخه‌های خیلی قدیمی استفاده می‌کنید، پیشنهاد می‌کنم با دستور `npm update kalatak-core` آن را به آخرین نسخه پایدار ارتقا دهید.

## ۵. سوالات متداول (FAQ)

**آیا کالاتک برای پروژه‌های کوچک مناسب است؟**
قطعاً. کالاتک به گونه‌ای طراحی شده که سربار (Overhead) بسیار کمی داشته باشد، بنابراین حتی در پروژه‌های کوچک هم به خوبی کار می‌کند.

**آیا مستندات نسخه API در دسترس است؟**
بله، در پنل کاربری شما در سایت کالاتک، مستندات کامل API به صورت Swagger برای تست و بررسی متدها وجود دارد.

**آیا امکان شخصی‌سازی کلاینت وجود دارد؟**
بله، معماری کالاتک به صورت ماژولار طراحی شده و شما می‌توانید Middlewareهای اختصاصی خود را به کلاینت اضافه کنید.
