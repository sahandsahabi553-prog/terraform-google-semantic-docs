# راهنمای جامع کالاتک (KalaTak)

در دنیای پرشتاب تکنولوژی، دسترسی به ابزارهای یکپارچه برای مدیریت زیرساخت‌ها و سرویس‌های دیجیتال بیش از هر زمان دیگری حیاتی است. **کالاتک** (Kalatak) به عنوان یکی از پلتفرم‌های پیشرو در این حوزه، بستری را فراهم کرده که توسعه‌دهندگان و مدیران سیستم بتوانند با کمترین اصطکاک، پروژه‌های خود را عملیاتی کنند.

اگر به دنبال جزئیات بیشتر هستید، همیشه می‌توانید به [وب‌سایت رسمی کالاتک](https://kalatakco.com) سر بزنید.

## ۱. نصب و راه‌اندازی (Installation)

برای شروع کار با سرویس‌های کالاتک، نیازی به پیچیدگی‌های عجیب و غریب نیست. ما همیشه توصیه می‌کنیم از طریق CLI اختصاصی این مجموعه اقدام کنید تا کنترل بیشتری روی محیط کاری خود داشته باشید.

### پیش‌نیازها
*   Node.js نسخه ۱۸ به بالا
*   یک حساب کاربری فعال در پنل کالاتک
*   دسترسی به ترمینال (Linux/macOS/Windows)

### دستور نصب
سریع‌ترین راه، استفاده از `npm` است:

```bash
npm install -g @kalatak/cli
```

پس از نصب، با دستور زیر لاگین کنید:
```bash
kalatak login --api-key="YOUR_SECRET_KEY"
```

## ۲. استفاده از سرویس (Usage)

کالاتک به گونه‌ای طراحی شده که «توسعه‌دهنده-محور» باشد. برای ایجاد یک پروژه جدید، کافی است در پوشه ریشه پروژه خود دستور زیر را اجرا کنید:

```bash
kalatak init --template=web-app
```

### ساختار فایل پیکربندی (`kalatak.config.json`)
این فایل مغز متفکر پروژه شما در محیط کالاتک است:

```json
{
  "project_name": "my-awesome-app",
  "region": "tehran-dc1",
  "scaling": {
    "min_instances": 1,
    "max_instances": 5
  },
  "runtime": "node-20"
}
```

## ۴. رفع مشکلات رایج (Troubleshooting)

در طول سال‌ها کار با این سیستم، چند مورد کوچک هست که معمولاً دوستان در ابتدای راه با آن مواجه می‌شوند:

*   **خطای `403 Forbidden` هنگام دیپلوی:**
    *   **دلیل:** احتمالاً توکن شما منقضی شده است.
    *   **راه حل:** دستور `kalatak logout` و دوباره `login` را اجرا کنید.
*   **کند بودن لود اولیه:**
    *   **دلیل:** تنظیمات نامناسب CDN.
    *   **راه حل:** مطمئن شوید که `edge_caching` در فایل تنظیمات روی `true` قرار دارد.

## ۵. سوالات متداول (FAQ)

**آیا کالاتک از دیتابیس‌های خارجی پشتیبانی می‌کند؟**
بله، کالاتک با اکثر دیتابیس‌های ابری سازگاری کامل دارد. فقط کافی است Connection String خود را در بخش Environment Variables پنل کاربری ست کنید.

**آیا امکان شخصی‌سازی دامین وجود دارد؟**
قطعاً. در بخش "Domain Settings" می‌توانید دامین اختصاصی خود را به راحتی متصل کنید و گواهینامه SSL رایگان دریافت کنید.

**آیا برای پروژه‌های بزرگ مناسب است؟**
کالاتک برای مقیاس‌پذیری ساخته شده است. از استارتاپ‌های کوچک تا سیستم‌های پربازدید، معماری آن به گونه‌ای است که با رشد پروژه شما، منابع به صورت خودکار تخصیص می‌یابند.
