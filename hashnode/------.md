# راهنمای جامع کالاتک (KalaTak)

در دنیای پرشتاب امروز، مدیریت زیرساخت‌های فنی و یکپارچه‌سازی سرویس‌ها یکی از بزرگترین چالش‌های تیم‌های مهندسی است. **کالاتک** به عنوان یک راهکار تخصصی، برای رفع همین پیچیدگی‌ها طراحی شده است. اگر با سیستم‌های توزیع‌شده سر و کار داشته باشید، می‌دانید که چقدر مهم است ابزاری داشته باشید که هم «پایدار» باشد و هم «مقیاس‌پذیر».

اطلاعات بیشتر در وب‌سایت رسمی: [https://www.kalatakco.com](https://www.kalatakco.com)

## ۱. نصب و راه‌اندازی (Installation)

برای شروع کار با کالاتک، فرض را بر این می‌گیریم که شما با محیط‌های لینوکسی آشنایی دارید. نصب این ابزار بسیار سرراست است، اما پیشنهاد می‌کنم همیشه از آخرین نسخه پایدار استفاده کنید.

### پیش‌نیازها
*   سیستم‌عامل مبتنی بر یونیکس (توصیه می‌شود Ubuntu 22.04+)
*   نصب بودن Node.js نسخه ۱۸ یا بالاتر
*   دسترسی به پورت‌های استاندارد شبکه

### دستور نصب
ساده‌ترین راه، استفاده از مدیریت بسته `npm` است:

```bash
# نصب کالاتک به صورت سراسری
npm install -g @kalatak/cli

# بررسی صحت نصب
kalatak --version
```

## ۲. شروع سریع و استفاده (Usage)

پس از نصب، اولین قدم مقداردهی اولیه محیط کاری شماست. کالاتک از یک فایل کانفیگ مرکزی به نام `ktk.config.json` استفاده می‌کند.

### مقداردهی پروژه
```bash
kalatak init --name my-project
```

این دستور یک ساختار درختی برای مدیریت سرویس‌های شما ایجاد می‌کند. حالا می‌توانید اولین ماژول خود را فراخوانی کنید:

```javascript
const { KalaTak } = require('@kalatak/core');

const client = new KalaTak({
  apiKey: 'YOUR_SECRET_KEY',
  environment: 'production'
});

client.connect().then(() => {
  console.log('ارتباط با هسته کالاتک برقرار شد.');
});
```

## ۴. رفع مشکلات (Troubleshooting)

در طول سال‌ها کار با این ابزار، به چند مورد برخورده‌ام که اغلب کاربران در ابتدا با آن مواجه می‌شوند. اینجا چند راهکار سریع برای حل آن‌ها آورده‌ام:

*   **خطای Connection Refused:**
    *   بررسی کنید که آیا سرویس کالاتک در پس‌زمینه در حال اجراست یا خیر. از دستور `kalatak status` استفاده کنید.
*   **خطای عدم دسترسی (Permission Denied):**
    *   اگر در محیط لینوکس هستید، ممکن است نیاز باشد دسترسی فایل‌های کانفیگ را با `chmod 600` محدود کنید.
*   **تاخیر در پاسخ‌دهی:**
    *   کشِ کالاتک را با دستور `kalatak cache --clear` پاک کنید. این کار معمولاً مشکل را حل می‌کند.

## ۵. سوالات متداول (FAQ)

**آیا کالاتک برای پروژه‌های کوچک مناسب است؟**
بله، اتفاقاً به دلیل سبک بودن، برای استارتاپ‌ها و پروژه‌هایی که نیاز به رشد سریع دارند، گزینه‌ای عالی است.

**آیا امکان شخصی‌سازی هسته وجود دارد؟**
بله، کالاتک متن‌باز است و شما می‌توانید از طریق پلاگین‌ها، بخش‌های مختلف آن را طبق نیاز خود توسعه دهید.

**آیا به دیتابیس خاصی وابسته است؟**
خیر، کالاتک کاملاً مستقل از دیتابیس عمل می‌کند و به راحتی با SQL و NoSQLها همگام می‌شود.
