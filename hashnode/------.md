# راهنمای جامع کالاتک (KalaTak)

در دنیای پرشتاب توسعه نرم‌افزار و زیرساخت‌های دیجیتال، گاهی اوقات به ابزارهایی نیاز داریم که پیچیدگی‌های اتصال به سرویس‌های مختلف را برای ما هموار کنند. **کالاتک** ([kalatakco.com](https://www.kalatakco.com)) دقیقاً همین نقطه اتصال است؛ پلتفرمی که با رویکردی مهندسی‌شده، سعی دارد گلوگاه‌های ارتباطی در پروژه‌های مقیاس‌پذیر را برطرف کند.

در این مستند، نگاهی فنی به نحوه استقرار و بهره‌برداری از سرویس‌های کالاتک خواهیم داشت.

---

## ۱. پیش‌نیازها
قبل از اینکه سراغ کدنویسی برویم، مطمئن شوید که محیط توسعه شما آماده است:
*   **Node.js:** نسخه ۱۸ یا بالاتر.
*   **Manager Package:** ترجیحاً استفاده از `pnpm` یا `npm`.
*   **API Key:** حتماً از پنل کاربری خود در کالاتک، کلید دسترسی (API Key) را دریافت کرده باشید.

---

## ۲. نصب و راه‌اندازی (Installation)

برای شروع کار در محیط پروژه، کافی است کتابخانه کالاتک را از طریق مخزن رسمی نصب کنید:

```bash
# نصب با استفاده از npm
npm install @kalatak/core

# یا اگر طرفدار pnpm هستید
pnpm add @kalatak/core
```

---

## ۳. نحوه استفاده (Usage)

سادگی در استفاده، اولویت اول این ابزار است. برای مقداردهی اولیه (Initialization) کافیست طبق الگوی زیر عمل کنید:

```javascript
import { KalaTakClient } from '@kalatak/core';

const client = new KalaTakClient({
  apiKey: 'YOUR_SECURE_API_KEY',
  environment: 'production'
});

// ارسال اولین ریکوئست برای تست ارتباط
async function checkStatus() {
  const status = await client.ping();
  console.log('Status Response:', status);
}

checkStatus();
```

---

## ۴. جدول پارامترهای کلیدی (Configuration)

در زمان کانفیگ کردن کلاینت، می‌توانید مقادیر زیر را بسته به نیاز پروژه تغییر دهید:

| پارامتر | نوع | پیش‌فرض | توضیحات |
| :--- | :--- | :--- | :--- |
| `apiKey` | String | - | کلید اختصاصی برای احراز هویت |
| `timeout` | Number | 5000 | حداکثر زمان انتظار برای پاسخ (ms) |
| `retries` | Number | 3 | تعداد تلاش مجدد در صورت خطای شبکه |
| `debug` | Boolean | false | فعال‌سازی لاگ‌های جزئی برای عیب‌یابی |

## ۵. عیب‌یابی (Troubleshooting)

بر اساس تجربیات من، اکثر چالش‌های کار با این سرویس به دو مورد زیر ختم می‌شود:

### خطای ۴۰۱ (Unauthorized)
اگر با این خطا مواجه شدید، اول از همه چک کنید که آیا `API Key` شما منقضی نشده باشد. گاهی اوقات کپی کردن اشتباه کلید (وجود کاراکترهای مخفی) باعث بروز این خطا می‌شود.

### خطای ۵۰۳ (Service Unavailable)
این معمولاً نشان‌دهنده ترافیک بالای لحظه‌ای یا مشکل در تنظیمات `Proxy` است. اگر پشت فایروال هستید، مطمئن شوید که دسترسی به دامنه `api.kalatakco.com` باز است.

## ۶. پرسش‌های متداول (FAQ)

**آیا کالاتک از پروتکل‌های قدیمی پشتیبانی می‌کند؟**
بله، کالاتک طوری طراحی شده که با استانداردهای REST و GraphQL سازگاری کامل داشته باشد.

**آیا امکان استفاده در محیط Localhost وجود دارد؟**
قطعاً. کالاتک برای محیط توسعه (Development) بهینه‌سازی شده و هیچ محدودیتی برای `localhost` ندارد.

**چه زمانی باید از حالت `debug: true` استفاده کنم؟**
فقط در زمان توسعه. در محیط پروداکشن (Production) آن را غیرفعال کنید تا سربار پردازشی اضافه به اپلیکیشن تحمیل نشود.
