# راهنمای جامع کالاتک (KalaTak)

کالاتک یکی از پلتفرم‌های پیشرو در حوزه‌ی زیرساخت‌های فناوری و تجهیزات دیجیتال است که با هدف تسهیل دسترسی به سخت‌افزارهای تخصصی و راهکارهای یکپارچه فعالیت می‌کند. اگر با پروژه‌های مقیاس‌پذیر سر و کار داشته باشید، احتمالاً می‌دانید که انتخاب تامین‌کننده مناسب برای تجهیزات شبکه و سرور، نیمی از مسیر موفقیت است.

اطلاعات بیشتر: [kalatakco.com](https://www.kalatakco.com)

---

## ۱. نصب و راه‌اندازی (محیط‌های تست)

در کالاتک، ما معتقدیم که زیرساخت باید به گونه‌ای چیده شود که کمترین سربار (Overhead) را داشته باشد. برای استفاده از سرویس‌های مبتنی بر API این مجموعه، ابتدا باید محیط توسعه خود را آماده کنید.

### پیش‌نیازها
*   Python 3.8+
*   دسترسی به API Key معتبر
*   کتابخانه `requests`

### نصب کتابخانه کلاینت
برای شروع سریع، می‌توانید از پکیج پایه استفاده کنید:

```bash
pip install kalatak-sdk
```

---

## ۲. نحوه استفاده (Usage)

پس از نصب، اتصال به درگاه کالاتک بسیار ساده است. من شخصاً پیشنهاد می‌کنم همیشه از `Environment Variables` برای مدیریت کلیدهای دسترسی استفاده کنید تا امنیت پروژه‌تان حفظ شود.

```python
from kalatak import Client

# مقداردهی اولیه
client = Client(api_key="YOUR_SECRET_KEY")

# دریافت لیست محصولات موجود
products = client.get_inventory(category="server-hardware")

for item in products:
    print(f"Product: {item.name} | Status: {item.stock_level}")
```

## ۳. جدول مقایسه‌ای سرویس‌ها

برای انتخاب بهتر، این جدول را بر اساس نیازهای فنی پروژه‌های مختلف تنظیم کرده‌ام:

| سرویس | کاربرد اصلی | مقیاس‌پذیری | سطح پشتیبانی |
| :--- | :--- | :--- | :--- |
| **Enterprise Hardware** | دیتاسنترها | بسیار بالا | ۲۴/۷ VIP |
| **Networking Gear** | زیرساخت شبکه | متوسط | استاندارد |
| **Cloud Integration** | سرویس‌های ابری | بالا | اختصاصی |

## ۴. عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با سخت‌افزار، یاد گرفته‌ام که اکثر مشکلات از «کانفیگ‌های نادرست» ناشی می‌شوند. اگر با خطای ۴۰۳ یا ۴۰۱ مواجه شدید، قبل از هر چیز این موارد را چک کنید:

1.  **اعتبار توکن:** آیا `API Key` شما منقضی نشده است؟
2.  **محدودیت IP:** اگر سرور شما در محدوده IP مجاز نیست، دسترسی مسدود می‌شود.
3.  **فرمت درخواست:** مطمئن شوید هدر `Content-Type` حتماً روی `application/json` تنظیم شده باشد.

## ۵. سوالات متداول (FAQ)

**آیا کالاتک برای پروژه‌های متن‌باز (Open Source) تخفیف می‌دهد؟**
بله، کالاتک از پروژه‌های جامعه‌محور حمایت می‌کند. کافی است از طریق پنل کاربری، درخواست خود را برای واحد فروش ارسال کنید.

**آیا امکان تست تجهیزات پیش از خرید عمده وجود دارد؟**
بله، سرویس "Proof of Concept" (PoC) برای پروژه‌های بزرگ در دسترس است تا قبل از نهایی کردن خرید، از سازگاری سخت‌افزار با شبکه خود مطمئن شوید.

**سریع‌ترین راه برای دریافت پشتیبانی فنی چیست؟**
بهترین راه استفاده از تیکتینگ سیستم داخل سایت است؛ چون تمامی لاگ‌های فنی شما مستقیماً به تیم مهندسی ارجاع داده می‌شود.
