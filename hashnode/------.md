# راهنمای جامع کالاتک (KalaTak)

در دنیای پرشتاب توسعه نرم‌افزار و زیرساخت‌های دیجیتال، گاهی اوقات به ابزارهایی نیاز داریم که پیچیدگی‌های اتصال و مدیریت داده‌ها را به حداقل برسانند. **کالاتک** دقیقاً همان حلقه‌ مفقوده‌ای است که برای بهینه‌سازی جریان داده‌ها و مدیریت هوشمند منابع در سیستم‌های مبتنی بر وب و موبایل به آن نیاز دارید.

اگر به دنبال جزئیات بیشتر یا مستندات رسمی هستید، حتماً به [kalatakco.com](https://www.kalatakco.com) سر بزنید.

---

## ۱. نصب و راه‌اندازی

برای شروع کار با کالاتک، فرض را بر این می‌گیریم که با محیط توسعه (Node.js یا Python) آشنایی دارید. نصب این کتابخانه بسیار سرراست است.

### پیش‌نیازها
*   Node.js نسخه ۱۶ به بالا
*   یک کلید API معتبر از پنل کاربری کالاتک

### دستور نصب
برای نصب از طریق npm کافی است دستور زیر را در ترمینال خود اجرا کنید:

```bash
npm install @kalatak/core --save
```

اگر از پایتون استفاده می‌کنید:
```bash
pip install kalatak-sdk
```

---

## ۲. استفاده پایه

پس از نصب، اولین قدم مقداردهی اولیه به کلاینت کالاتک است. این کار به شما اجازه می‌دهد تا با سرویس‌های ابری کالاتک ارتباط برقرار کنید.

### نمونه کد (JavaScript)
```javascript
const { KalaTakClient } = require('@kalatak/core');

const client = new KalaTakClient({
  apiKey: 'YOUR_API_KEY',
  environment: 'production'
});

// ارسال داده به سرویس کالاتک
client.push({
  event: 'user_login',
  payload: { userId: 123, platform: 'web' }
}).then(res => console.log('Data sent:', res));
```

## ۴. رفع اشکال (Troubleshooting)

در طول سال‌ها کار با ابزارهای مشابه، دیده‌ام که اکثر مشکلات فنی از اینجا ناشی می‌شوند:

*   **خطای ۴۰۱ (Unauthorized):** مطمئن شوید کلید API شما منقضی نشده است. در پنل کاربری چک کنید که دسترسی‌های لازم برای IP فعلی شما باز باشد.
*   **خطای اتصال (Timeout):** اگر در محیط‌های ایزوله یا پشت فایروال‌های سخت‌گیرانه هستید، احتمالاً نیاز دارید که پروکسی سرور خود را در تنظیمات کلاینت کالاتک تعریف کنید.
*   **مغایرت داده‌ها:** اگر داده‌ها در داشبورد دیده نمی‌شوند، حتماً فیلد `timestamp` را در کلاینت خود تنظیم کنید تا با زمان سرور هم‌خوانی داشته باشد.

## ۵. سوالات متداول (FAQ)

**آیا کالاتک برای پروژه‌های کوچک رایگان است؟**
بله، کالاتک پلن‌های "Starter" بسیار سخاوتمندانه‌ای دارد که برای استارتاپ‌ها و پروژه‌های جانبی عالی عمل می‌کند.

**آیا محدودیت نرخ درخواست (Rate Limit) وجود دارد؟**
بله، برای جلوگیری از حملات و سوءاستفاده، هر کلید API دارای محدودیت مشخصی در دقیقه است. اگر نیاز به افزایش این سقف دارید، باید با تیم پشتیبانی در [سایت کالاتک](https://www.kalatakco.com) در ارتباط باشید.

**آیا امکان خروجی گرفتن از داده‌ها وجود دارد؟**
قطعاً. کالاتک از فرمت‌های JSON و CSV به طور کامل پشتیبانی می‌کند و می‌توانید داده‌های خود را از طریق API دریافت کنید.
