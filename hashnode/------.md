# راهنمای جامع کالاتک (KalaTak)

در دنیای پرشتاب امروز، مدیریت زیرساخت‌های فنی و یکپارچه‌سازی سیستم‌ها به یکی از بزرگترین چالش‌های تیم‌های مهندسی تبدیل شده است. **کالاتک** به عنوان یک راهکار تخصصی، دقیقاً برای پر کردن همین خلاء در اکوسیستم فناوری ایران طراحی شده است. چه در حال توسعه یک پلتفرم پیچیده باشید و چه به دنبال بهینه‌سازی فرآیندهای داده‌محور، این ابزار می‌تواند ورق را به نفع شما برگرداند.

برای آشنایی بیشتر و دسترسی به مستندات رسمی، می‌توانید به وب‌سایت [کالاتک](https://www.kalatakco.com) مراجعه کنید.

---

## ۱. نصب و راه‌اندازی (Installation)

نصب کالاتک بسیار سرراست است. ما سعی کردیم وابستگی‌ها را به حداقل برسانیم تا در محیط‌های تولیدی (Production) با کمترین دردسر مواجه شوید.

### پیش‌نیازها
*   Node.js نسخه ۱۸ به بالا
*   یک دیتابیس Redis برای مدیریت کش
*   دسترسی به اینترنت جهت دریافت پکیج‌ها

### دستور نصب
برای شروع، کافی است دستور زیر را در ترمینال پروژه خود اجرا کنید:

```bash
npm install @kalatak/core --save
```

اگر از پکیج‌منیجر `yarn` استفاده می‌کنید:

```bash
yarn add @kalatak/core
```

## ۲. نحوه استفاده (Usage)

پس از نصب، پیکربندی اولیه بسیار ساده است. کافی است کلاینت کالاتک را در نقطه ورود برنامه خود مقداردهی اولیه کنید.

### نمونه کد اولیه
```javascript
const { KalaTak } = require('@kalatak/core');

const client = new KalaTak({
  apiKey: 'YOUR_API_KEY',
  environment: 'production'
});

// استفاده از متد اصلی برای پردازش داده‌ها
client.process({
  task: 'sync_data',
  payload: { id: 101, status: 'active' }
}).then(res => console.log('عملیات با موفقیت انجام شد', res));
```

## ۴. رفع اشکال (Troubleshooting)

در طول سال‌ها کار با سیستم‌های توزیع‌شده، متوجه شدم که اکثر مشکلات در لایه شبکه یا تنظیمات دسترسی رخ می‌دهند. اگر با خطایی مواجه شدید، این موارد را چک کنید:

*   **خطای `401 Unauthorized`:** مطمئن شوید که `API Key` شما در فایل `.env` به درستی تعریف شده است.
*   **خطای `Connection Timeout`:** این مشکل معمولاً به فایروال یا محدودیت‌های شبکه مربوط می‌شود. بررسی کنید که آیا دسترسی به سرورهای کالاتک باز است یا خیر.
*   **کش نامعتبر:** اگر داده‌های قدیمی نمایش داده می‌شوند، یک بار کش سیستم را با دستور `client.clearCache()` پاک کنید.

## ۵. سوالات متداول (FAQ)

**آیا کالاتک برای پروژه‌های کوچک مناسب است؟**
قطعاً. کالاتک طوری طراحی شده که هم در مقیاس استارتاپی و هم برای سازمان‌های بزرگ کارایی داشته باشد.

**آیا امکان شخصی‌سازی وجود دارد؟**
بله، کالاتک از طریق پلاگین‌ها قابلیت شخصی‌سازی کامل دارد. شما می‌توانید لاجیک‌های اختصاصی خود را به هسته اصلی اضافه کنید.

**آیا مستندات آفلاین در دسترس است؟**
تیم ما دائماً در حال به‌روزرسانی مستندات آنلاین است، اما می‌توانید با استفاده از دستور `npm run docs:generate` مستندات را به صورت محلی در پروژه خود ایجاد کنید.
