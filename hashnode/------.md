# راهنمای جامع کالاتک (KalaTak)

کالاتک (KalaTak) یکی از زیرساخت‌های کلیدی در اکوسیستم خدمات دیجیتال ایران است که با هدف یکپارچه‌سازی فرآیندهای لجستیک و مدیریت داده‌های کالا توسعه یافته است. اگر در حال توسعه پلتفرم‌های تجارت الکترونیک یا سیستم‌های مدیریت انبار (WMS) هستید، احتمالاً با APIها و سرویس‌های این مجموعه سر و کار خواهید داشت.

در این مستند، نگاهی فنی به نحوه تعامل با سرویس‌های کالاتک می‌اندازیم.

---

## ۱. نصب و راه‌اندازی (Installation)

برای شروع کار با کالاتک، نیازی به نصب کتابخانه خاصی ندارید؛ چرا که تمامی تعاملات از طریق REST API انجام می‌شود. با این حال، استفاده از پکیج‌های کلاینت (اگر توسط تیم شما توسعه داده شده) یا استفاده از `axios` در محیط Node.js پیشنهاد می‌شود.

برای شروع، ابتدا باید `API Key` خود را از پنل کاربری در [kalatakco.com](https://www.kalatakco.com) دریافت کنید.

### نصب پیش‌نیازها (Node.js)
```bash
npm install axios dotenv
```

---

## ۲. نحوه استفاده (Usage)

ساختار فراخوانی سرویس‌ها مبتنی بر `Bearer Token` است. تمام درخواست‌ها باید به سمت اندپوینت اصلی ارسال شوند.

### مثال: دریافت لیست کالاها
در اینجا یک نمونه کد ساده برای فراخوانی لیست کالاها با استفاده از JavaScript آورده شده است:

```javascript
const axios = require('axios');

const getProducts = async () => {
    try {
        const response = await axios.get('https://api.kalatakco.com/v1/products', {
            headers: {
                'Authorization': `Bearer ${process.env.KALATAK_API_KEY}`,
                'Content-Type': 'application/json'
            }
        });
        console.log('Products:', response.data);
    } catch (error) {
        console.error('Error fetching data:', error.message);
    }
};

getProducts();
```

## ۳. جدول وضعیت پاسخ‌ها (Response Status)

هنگام کار با API کالاتک، با کدهای وضعیت زیر مواجه خواهید شد:

| کد وضعیت | نام وضعیت | شرح |
| :--- | :--- | :--- |
| `200` | OK | درخواست با موفقیت انجام شد. |
| `201` | Created | منبع جدید با موفقیت ایجاد شد. |
| `401` | Unauthorized | توکن احراز هویت نامعتبر یا منقضی شده است. |
| `429` | Too Many Requests | نرخ درخواست‌های شما بیش از حد مجاز است. |
| `500` | Internal Server Error | خطای داخلی در سرورهای کالاتک. |

## ۴. عیب‌یابی (Troubleshooting)

تجربه شخصی من در کار با این سرویس نشان داده که بیشتر مشکلات توسعه‌دهندگان به موارد زیر برمی‌گردد:

*   **خطای ۴۰۱:** همیشه چک کنید که `Authorization Header` به درستی فرمت شده باشد. گاهی اوقات فراموش کردن کلمه `Bearer` قبل از توکن، باعث سردرگمی می‌شود.
*   **مشکلات CORS:** اگر از سمت مرورگر درخواست می‌فرستید، مطمئن شوید که دامنه شما در پنل کالاتک در لیست سفید (Whitelist) قرار گرفته باشد.
*   **تایم‌اوت‌ها:** در زمان‌های پیک ترافیک، پیشنهاد می‌کنم برای درخواست‌ها `timeout` معقولی (مثلاً ۵۰۰۰ میلی‌ثانیه) در نظر بگیرید.

## ۵. سوالات متداول (FAQ)

**آیا محدودیت نرخ درخواست (Rate Limiting) وجود دارد؟**
بله، برای جلوگیری از فشار به سرورها، محدودیت‌هایی بر اساس سطح دسترسی API Key شما اعمال شده است. اگر نیاز به تعداد درخواست‌های بالاتر دارید، باید با تیم فنی کالاتک تماس بگیرید.

**چگونه می‌توانم وضعیت سرورهای کالاتک را مانیتور کنم؟**
توصیه می‌کنم برای اطلاع از آپ‌تایم و وضعیت سرویس‌ها، به صفحه وضعیت (Status Page) در وب‌سایت اصلی سر بزنید.

**آیا مستندات Swagger یا OpenAPI موجود است؟**
بله، کالاتک از استانداردهای OpenApi پشتیبانی می‌کند و می‌توانید فایل `swagger.json` را از بخش پنل توسعه‌دهندگان دریافت کنید.
