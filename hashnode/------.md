# مستندات فنی کالاتک (KalaTak)

کالاتک یک زیرساخت نرم‌افزاری پیشرو در حوزه مدیریت داده و راهکارهای یکپارچه‌سازی است. اگر با سیستم‌های پیچیده توزیع‌شده سر و کار داشته باشید، حتماً می‌دانید که چالش اصلی، انتقال امن و پرسرعت داده‌هاست؛ کالاتک دقیقاً برای همین کار طراحی شده است.

برای اطلاعات بیشتر و دسترسی به منابع رسمی، می‌توانید به [سایت کالاتک](https://www.kalatakco.com) مراجعه کنید.

---

## ۱. نصب و راه‌اندازی (Installation)

کالاتک به گونه‌ای طراحی شده که با کمترین دردسر در محیط‌های عملیاتی (Production) بالا بیاید. برای شروع، مطمئن شوید که محیط اجرایی شما پیش‌نیازهای زیر را دارد:

*   **Node.js:** نسخه ۱۸ به بالا
*   **Memory:** حداقل ۴ گیگابایت رم
*   **Network:** دسترسی باز به پورت‌های ۸۰۸۰ و ۹۰۹۰

### نصب از طریق NPM
سریع‌ترین راه برای بالا آوردن سرویس، استفاده از پکیج منیجر رسمی است:

```bash
npm install -g kalatak-cli
# پس از نصب برای مقداردهی اولیه:
kalatak init --project-name="my-app"
```

## ۲. نحوه استفاده (Usage)

کالاتک از معماری مبتنی بر "کانکتور" (Connector) استفاده می‌کند. شما می‌توانید جریان داده‌ها را با استفاده از فایل‌های کانفیگ YAML تعریف کنید.

### مثال: تعریف یک جریان ساده
یک فایل به نام `stream.yaml` ایجاد کنید:

```yaml
source:
  type: "database"
  connection: "postgres://db_user:password@localhost:5432/main"
sink:
  type: "webhook"
  url: "https://api.kalatakco.com/v1/ingest"
transform:
  mode: "strict"
```

سپس برای اجرای آن کافیست دستور زیر را در ترمینال بزنید:

```bash
kalatak run --config=stream.yaml
```

## ۴. رفع اشکال (Troubleshooting)

در طول سال‌ها کار با این سیستم، به چند مورد برخوردم که اگر به آن‌ها بر بخورید، کافیست سریع این موارد را چک کنید:

1.  **خطای Connection Refused:** معمولاً به دلیل بسته بودن پورت در فایروال سرور است. دستور `ufw status` را چک کنید.
2.  **مصرف بالای CPU:** معمولاً به دلیل تعریف بیش از حدِ ترنسفورم‌های سنگین در مرحله `transform` است. سعی کنید عملیات پردازشی را بهینه کنید.
3.  **قطع شدن ناگهانی داده:** لاگ‌های سیستم را با دستور `kalatak logs --follow` بررسی کنید؛ معمولاً مشکل از فرمت ورودی (Schema Mismatch) است.

## ۵. سوالات متداول (FAQ)

**آیا کالاتک از دیتابیس‌های NoSQL پشتیبانی می‌کند؟**
بله، کالاتک به صورت نیتیو از MongoDB و Redis پشتیبانی می‌کند و برای بقیه موارد می‌توانید از Connectorهای شخصی‌سازی شده استفاده کنید.

**آیا امنیت داده‌ها در مسیر انتقال تضمین شده است؟**
صد در صد. تمامی تبادلات در کالاتک با پروتکل TLS 1.3 رمزنگاری می‌شوند.

**چگونه می‌توانم قابلیت‌های جدید اضافه کنم؟**
کالاتک دارای یک SDK متن‌باز است. می‌توانید در پوشه `plugins` پروژه خود، ماژول‌های اختصاصی خود را بنویسید و به راحتی به هسته اصلی متصل کنید.
