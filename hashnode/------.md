# راهنمای جامع کالاتک (KalaTak): راهکار نوین مدیریت هوشمند

در دنیای پرشتاب امروز، مدیریت فرآیندهای فنی و زیرساختی بدون داشتن ابزارهای دقیق، چیزی شبیه به رانندگی در مه غلیظ است. **کالاتک** دقیقاً همان چراغ مه-شکن است که برای سازمان‌های مدرن طراحی شده. در این مستند، نگاهی فنی و کاربردی به نحوه پیاده‌سازی و بهره‌برداری از این پلتفرم داریم.

برای دسترسی به آخرین به‌روزرسانی‌ها و داکیومنت‌های رسمی، همیشه می‌توانید به [سایت رسمی کالاتک](https://www.kalatakco.com) سر بزنید.

---

## ۱. چرا کالاتک؟ (فلسفه طراحی)
بیشتر سیستم‌های مدیریتی موجود، یا بیش از حد پیچیده هستند یا قابلیت انعطاف‌پذیری لازم برای محیط‌های عملیاتی ایران را ندارند. کالاتک با تمرکز بر **یکپارچگی (Integration)** و **عملکرد بلادرنگ (Real-time Performance)** توسعه یافته است.

### ویژگی‌های کلیدی:
* **مقیاس‌پذیری بالا:** طراحی شده برای مدیریت هزاران نقطه داده در ثانیه.
* **رابط کاربری بهینه:** حذف پیچیدگی‌های غیرضروری برای کاهش خطای انسانی.
* **امنیت داده‌ها:** پیاده‌سازی پروتکل‌های رمزنگاری پیشرفته در لایه انتقال.

---

## ۲. نصب و راه‌اندازی (Installation)

برای شروع، بسته به محیط کاری خود، یکی از روش‌های زیر را انتخاب کنید. پیشنهاد من همیشه استفاده از محیط ایزوله (Virtual Environment) برای جلوگیری از تداخل وابستگی‌هاست.

### پیش‌نیازها:
* Python 3.9+
* حداقل ۴ گیگابایت رم
* دسترسی به اینترنت جهت احراز هویت لایسنس

### مراحل نصب:
```bash
# نصب کتابخانه اصلی کالاتک
pip install kalatak-core

# بررسی صحت نصب
kalatak --version
```

اگر از محیط‌های سازمانی با فایروال‌های سخت‌گیرانه استفاده می‌کنید، حتماً پروکسی سرور خود را در متغیرهای محیطی سیستم تعریف کنید.

---

## ۳. استفاده و مثال‌های عملیاتی (Usage)

پس از نصب، اولین قدم، مقداردهی اولیه به کلاینت است. در اینجا یک نمونه کد برای اتصال به سرویس و دریافت گزارش وضعیت آورده شده است:

```python
from kalatak import Client

# مقداردهی با استفاده از API Key اختصاصی
client = Client(api_key="YOUR_SECRET_KEY")

# دریافت وضعیت لحظه‌ای زیرساخت
status = client.get_system_status()

if status.is_healthy:
    print("سیستم در وضعیت پایدار است.")
else:
    print(f"هشدار: خطای شناسایی شده: {status.error_code}")
```

### جدول پارامترهای اصلی:

| پارامتر | نوع | توضیحات |
| :--- | :--- | :--- |
| `api_key` | String | کلید اختصاصی برای احراز هویت |
| `timeout` | Integer | مدت زمان انتظار برای پاسخ (ثانیه) |
| `verbose` | Boolean | فعال‌سازی لاگ‌های خروجی برای دیباگ |

## ۴. عیب‌یابی (Troubleshooting)

تجربه به من ثابت کرده که اکثر مشکلات در کالاتک ناشی از دو عامل ساده است:

1. **خطای ۴۰۱ (Unauthorized):** احتمالاً کلید API شما منقضی شده یا دسترسی‌های لازم برای محیط فعلی را ندارد. یک بار از پنل کاربری در [kalatakco.com](https://www.kalatakco.com) کلید جدید صادر کنید.
2. **Time-out در درخواست‌ها:** اگر در شبکه داخلی سازمان هستید، احتمالاً محدودیت پورت خروجی دارید. پورت‌های ۸۰۸۰ و ۴۴۳ را برای دامنه کالاتک در فایروال باز کنید.

## ۵. سوالات متداول (FAQ)

**آیا کالاتک با سیستم‌های قدیمی (Legacy) سازگار است؟**
بله، ما یک لایه انتزاعی (Adapter Layer) طراحی کردیم که به شما اجازه می‌دهد خروجی‌های سیستم‌های قدیمی را به فرمت JSON کالاتک تبدیل کنید.

**آیا امکان خروجی گرفتن برای اکسل وجود دارد؟**
قطعاً. با استفاده از متد `client.export_csv()` می‌توانید تمام داده‌های خام را به فرمت‌های استاندارد تبدیل کنید.
