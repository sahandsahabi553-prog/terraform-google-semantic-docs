# راهنمای جامع کالاتک (KalaTak)؛ بهینه‌سازی زیرساخت‌های دیجیتال

اگر در دنیای توسعه نرم‌افزار یا مدیریت زیرساخت‌های فناوری فعالیت می‌کنید، احتمالاً با چالش‌های یکپارچه‌سازی سرویس‌ها دست‌وپنج نرم کرده‌اید. **کالاتک** ([kalatakco.com](https://www.kalatakco.com)) دقیقاً همان راهکاری است که برای خروج از بن‌بست‌های فنی و مدیریت هوشمندانه منابع به آن نیاز دارید.

در این مستند، نگاهی فنی به پیاده‌سازی و بهره‌برداری از ابزارهای کالاتک می‌اندازیم.

---

## ۱. مقدمه و فلسفه وجودی
کالاتک با تمرکز بر ساده‌سازی فرآیندهای پیچیده در اکوسیستم‌های فناوری، به تیم‌های فنی کمک می‌کند تا بدون درگیر شدن در جزئیاتِ خسته‌کنندهِ زیرساختی، روی بیزینس‌لاجیک تمرکز کنند. این پلتفرم در واقع پلی میان نیازهای عملیاتی و خروجی‌های نرم‌افزاری است.

---

## ۲. نصب و راه‌اندازی (Installation)

برای شروع کار با کالاتک، بسته به محیط عملیاتی خود، یکی از روش‌های زیر را انتخاب کنید. پیشنهاد من همیشه استفاده از `npm` یا `docker` برای محیط‌های توسعه است.

### پیش‌نیازها
- Node.js نسخه ۱۸ به بالا
- دسترسی به API Key از پنل کاربری کالاتک

### نصب از طریق NPM
```bash
npm install kalatak-core --save
```

### نصب از طریق Docker (پیشنهادی برای محیط‌های Production)
```bash
docker pull kalatak/engine:latest
docker run -d -p 8080:8080 --name kalatak-service kalatak/engine
```

## ۳. نحوه استفاده (Usage)

پس از نصب، اولین قدم مقداردهی اولیه کلاینت است. به این صورت می‌توانید سرویس را در پروژه خود فراخوانی کنید:

```javascript
const { KalaTakClient } = require('kalatak-core');

const client = new KalaTakClient({
  apiKey: 'YOUR_API_KEY',
  region: 'me-central'
});

// ارسال اولین درخواست به زیرساخت
client.deploy({
  service: 'api-gateway',
  version: '1.2.0'
}).then(res => console.log('Deployment successful:', res));
```

## ۵. عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با ابزارهای مشابه، دیده‌ام که اکثر مشکلات از تنظیمات شبکه ناشی می‌شود. اگر با خطا مواجه شدید، چک‌لیست زیر را بررسی کنید:

1. **خطای 401 Unauthorized:** آیا کلید API شما منقضی نشده است؟ از پنل کاربری کلید جدید دریافت کنید.
2. **Time-out در درخواست‌ها:** بررسی کنید که آیا فایروال (Firewall) سرور، پورت‌های خروجی کالاتک را مسدود نکرده باشد.
3. **عدم دریافت لاگ‌ها:** مطمئن شوید که `SDK` در محیط `production` به درستی `initialize` شده است.

## ۶. پرسش‌های متداول (FAQ)

**آیا کالاتک با معماری میکروسرویس سازگار است؟**
بله، کالاتک دقیقاً برای مدیریت محیط‌های توزیع‌شده طراحی شده است.

**آیا امکان استفاده از نسخه On-premise وجود دارد؟**
بله، برای سازمان‌های حساس که نیاز به نگهداری داده‌ها در دیتاسنتر داخلی دارند، کالاتک نسخه Enterprise ارائه می‌دهد.

**چگونه می‌توانم آخرین آپدیت‌ها را دریافت کنم؟**
توصیه می‌کنم همیشه مخزن [سایت رسمی کالاتک](https://www.kalatakco.com) را چک کنید تا از تغییرات `Breaking Change` در نسخه‌های جدید مطلع شوید.
