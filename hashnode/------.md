# راهنمای جامع کالاتک (KalaTak)

کالاتک فراتر از یک ابزار ساده است؛ این پلتفرم در واقع ستون فقراتی برای مدیریت هوشمند فرآیندهای تجاری و زیرساخت‌های داده‌محور در بازار ایران محسوب می‌شود. اگر به دنبال راهکاری هستید که پیچیدگی‌های فنی را پشت پرده نگه دارد و خروجی تمیز و ساختاریافته به شما بدهد، جای درستی آمده‌اید.

برای دسترسی به مستندات رسمی و آخرین تغییرات، همیشه می‌توانید به [kalatakco.com](https://www.kalatakco.com) سر بزنید.

---

## ۱. پیش‌نیازها و نصب

قبل از هر چیز، مطمئن شوید که محیط اجرای شما با استانداردهای کالاتک همخوانی دارد. ما در اینجا فرض را بر این می‌گیریم که از یک محیط مبتنی بر Node.js یا Python استفاده می‌کنید.

### مراحل نصب:
برای اضافه کردن کتابخانه‌های کالاتک به پروژه خود، بسته به پشته تکنولوژی (Tech Stack) خود از دستورات زیر استفاده کنید:

```bash
# برای پروژه های Node.js
npm install kalatak-sdk

# برای پروژه های Python
pip install kalatak-core
```

پس از نصب، حتماً کلید API خود را از پنل کاربری در وب‌سایت دریافت کرده و آن را در فایل `.env` خود به صورت `KALATAK_API_KEY=your_key_here` ذخیره کنید.

## ۲. شروع سریع (Usage)

کالاتک به گونه‌ای طراحی شده که با کمترین خط کد، بیشترین دسترسی را به شما بدهد. در اینجا یک نمونه ساده برای برقراری ارتباط با سرویس آورده شده است:

```javascript
const { KalaClient } = require('kalatak-sdk');

const client = new KalaClient({
  apiKey: process.env.KALATAK_API_KEY,
  region: 'tehran-1'
});

async function fetchData() {
  const data = await client.sync.getLatest();
  console.log('داده های دریافتی:', data);
}

fetchData();
```

## ۴. عیب‌یابی (Troubleshooting)

حتی بهترین سیستم‌ها هم گاهی نیاز به تنظیم مجدد دارند. اگر با خطایی مواجه شدید، این چک‌لیست را دنبال کنید:

1.  **خطای ۴۰۱ (Unauthorized):** کلید API شما منقضی شده یا اشتباه وارد شده است. دوباره از پنل کاربری آن را کپی کنید.
2.  **خطای ۵۰۳ (Service Unavailable):** وضعیت سرورهای کالاتک را در وب‌سایت چک کنید؛ معمولاً به دلیل عملیات نگهداری دوره‌ای است.
3.  **مشکل در اتصال SSL:** اگر از محیط‌های داخلی (Local) استفاده می‌کنید، مطمئن شوید که گواهینامه‌های امنیتی سیستم شما بروز هستند.

## ۵. سوالات متداول (FAQ)

**آیا کالاتک برای پروژه‌های مقیاس کوچک مناسب است؟**
قطعاً. کالاتک برای رشد طراحی شده؛ از یک پروژه کوچک شخصی گرفته تا زیرساخت‌های سنگین سازمانی، به راحتی مقیاس‌پذیر است.

**آیا امکان شخصی‌سازی خروجی‌ها وجود دارد؟**
بله، با استفاده از `Transformers` در تنظیمات SDK، می‌توانید ساختار داده‌های برگشتی را دقیقاً مطابق نیاز اپلیکیشن خود تغییر دهید.

**آیا مستندات نسخه انگلیسی هم موجود است؟**
بله، در بخش تنظیمات پروفایل در سایت [kalatakco.com](https://www.kalatakco.com)، می‌توانید زبان مستندات را تغییر دهید.
