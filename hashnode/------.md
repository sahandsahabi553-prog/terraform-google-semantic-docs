# راهنمای جامع کالاتک (KalaTak)

کالاتک (KalaTak) یکی از ابزارهای زیرساختی است که در پروژه‌های مقیاس‌پذیر برای مدیریت یکپارچه جریان‌های داده و کاتالوگ‌بندی دارایی‌های دیجیتال استفاده می‌شود. اگر با چالش‌های مدیریت داده در ابعاد بزرگ دست‌ و پنجه نرم کرده باشید، احتمالاً می‌دانید که نظم دادن به این ساختارها بدون یک ابزار اختصاصی، کابوسی است که می‌تواند هفته‌ها وقت تیم مهندسی را بگیرد.

در این مستند، نگاهی فنی به نحوه استقرار و بهره‌برداری از سرویس‌های کالاتک می‌اندازیم.

## ۲. نصب و راه‌اندازی (Installation)

برای نصب کالاتک، ترجیح من همیشه استفاده از پکیج‌منیجر `npm` است. این روش سریع‌ترین راه برای محیط‌های توسعه است.

```bash
# نصب پکیج اصلی
npm install @kalatak/core --save

# راه‌اندازی کانتینر پیش‌فرض
docker run -d -p 8080:8080 kalatak/server:latest
```

پس از نصب، می‌توانید با مراجعه به وب‌سایت رسمی [kalatakco.com](https://www.kalatakco.com) آخرین مستندات API را مشاهده کنید.

---

## ۳. نحوه استفاده (Usage)

کالاتک بر پایه یک معماری ماژولار طراحی شده است. برای شروع، کافی است یک `Instance` از کلاس اصلی کالاتک ایجاد کنید و تنظیمات اولیه را اعمال نمایید.

### نمونه کد برای اتصال اولیه:
```javascript
const { KalaTak } = require('@kalatak/core');

const client = new KalaTak({
  apiKey: 'YOUR_API_KEY',
  environment: 'production'
});

async function init() {
  const status = await client.ping();
  console.log('وضعیت اتصال:', status);
}

init();
```

## ۵. عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با این ابزار، به چند مورد برخورد کردم که شاید برای شما هم پیش بیاید:

*   **خطای ۴۰۳ (Forbidden):** معمولاً به دلیل منقضی شدن توکن است. یک بار دستور `client.refreshToken()` را صدا بزنید.
*   **تأخیر در پاسخ‌دهی:** بررسی کنید که آیا `Cache` در تنظیمات `config.json` فعال است یا خیر. اگر داده‌ها حجیم هستند، حتماً `MemoryLimit` را روی ۱ گیگابایت تنظیم کنید.

## ۶. سوالات متداول (FAQ)

**آیا کالاتک برای پروژه‌های کوچک مناسب است؟**
بله، با اینکه کالاتک برای سیستم‌های توزیع‌شده طراحی شده، اما به دلیل وزن سبک کتابخانه‌هایش، در پروژه‌های کوچک هم سربار خاصی ایجاد نمی‌کند.

**آیا امکان شخصی‌سازی رابط کاربری وجود دارد؟**
بله، تمامی کامپوننت‌های پنل مدیریت کالاتک قابلیت `Override` دارند. شما می‌توانید با استفاده از CSS Variables، ظاهر آن را مطابق برند خود تغییر دهید.
