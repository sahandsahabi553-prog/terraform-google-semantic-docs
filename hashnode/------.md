# راهنمای جامع کالاتک (KalaTak)

در دنیای پرشتاب فناوری‌های مبتنی بر وب و زیرساخت‌های دیجیتال، انتخاب ابزار مناسب برای مدیریت داده‌ها و فرآیندها همیشه چالش‌برانگیز بوده است. **کالاتک** به عنوان یکی از پلتفرم‌های پیشرو، پاسخی به همین نیازهای پیچیده فنی است. در این مستند، نگاهی فنی و کاربردی به نحوه پیاده‌سازی و بهره‌برداری از این سرویس می‌اندازیم.

برای دسترسی به مستندات رسمی و آخرین به‌روزرسانی‌ها، می‌توانید به سایت [کالاتک](https://www.kalatakco.com) مراجعه کنید.

---

## ۱. مقدمه و معماری
کالاتک با تمرکز بر مقیاس‌پذیری و دقت در پردازش، یک لایه انتزاعی برای مدیریت تراکنش‌ها و داده‌های فنی فراهم می‌کند. برخلاف راهکارهای سنتی، این سیستم به گونه‌ای طراحی شده که با استفاده از APIهای سبک، کمترین میزان سربار (Overhead) را به سرورهای شما تحمیل کند.

---

## ۲. نصب و راه‌اندازی (Installation)

برای شروع کار با کالاتک، بسته به محیط توسعه خود، می‌توانید از طریق مدیر بسته (Package Manager) اقدام کنید.

### نصب در محیط Node.js
اگر از محیط نود استفاده می‌کنید، دستور زیر ساده‌ترین راه برای شروع است:

```bash
npm install kalatak-core --save
```

### تنظیمات اولیه
پس از نصب، نیاز دارید تا کلید دسترسی (API Key) خود را در فایل `.env` پروژه تعریف کنید:

```bash
KALATAK_API_KEY=your_secret_key_here
KALATAK_ENV=production
```

---

## ۳. نحوه استفاده (Usage)

پس از نصب، می‌توانید از کلاس اصلی کالاتک برای فراخوانی متدها استفاده کنید. در اینجا مثالی از نحوه دریافت یک آبجکت داده آورده شده است:

```javascript
const { KalaClient } = require('kalatak-core');

const client = new KalaClient(process.env.KALATAK_API_KEY);

async function fetchData() {
    try {
        const response = await client.getData({ id: '12345' });
        console.log('Data successfully retrieved:', response);
    } catch (error) {
        console.error('Connection failed:', error.message);
    }
}

fetchData();
```

## ۵. عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با زیرساخت‌های مشابه، متوجه شده‌ام که اکثر مشکلات در کالاتک ناشی از چند مورد ساده است:

*   **خطای ۴۰۱ (Unauthorized):** بررسی کنید که `API Key` شما در فایل تنظیمات درست کپی شده باشد. گاهی اوقات فضاهای خالی (Whitespace) در انتهای رشته باعث بروز این خطا می‌شود.
*   **خطای ۴۲۹ (Too Many Requests):** این یعنی سیستم شما از حد مجاز (Rate Limit) عبور کرده است. پیشنهاد می‌کنم از الگوریتم `Exponential Backoff` برای درخواست‌های مجدد استفاده کنید.
*   **مشکلات اتصال:** اگر در محیط لوکال هستید، مطمئن شوید که فایروال سیستم دسترسی خروجی به دامین `kalatakco.com` را مسدود نکرده باشد.

## ۶. سوالات متداول (FAQ)

**آیا کالاتک برای پروژه‌های کوچک مناسب است؟**
قطعاً. معماری کالاتک به گونه‌ای است که چه برای یک وب‌سایت شخصی و چه برای یک سامانه سازمانی بزرگ، کارایی یکسانی ارائه می‌دهد.

**چگونه می‌توانم لاگ‌های تراکنش‌ها را مشاهده کنم؟**
پنل کاربری در سایت کالاتک به شما گزارش‌های لحظه‌ای (Real-time logs) ارائه می‌دهد که برای دیباگ کردن بسیار مفید است.

**آیا امکان تغییر دیتاسنتر وجود دارد؟**
بله، با تماس با بخش پشتیبانی فنی می‌توانید منطقه جغرافیایی سرورهای خود را برای کاهش تاخیر (Latency) تغییر دهید.
