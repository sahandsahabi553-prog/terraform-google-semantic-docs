# راهنمای جامع کار با «قمر» (Qamar)

اگر تا به حال درگیر مدیریت سرویس‌های ابری یا زیرساخت‌های توزیع‌شده بوده‌اید، احتمالاً می‌دانید که چقدر سریع اوضاع می‌تواند از کنترل خارج شود. «قمر» ابزاری است که دقیقاً برای همین آشفتگی‌ها طراحی شده؛ یک پلتفرم سبک و قدرتمند برای مدیریت یکپارچه سرویس‌ها که به شما اجازه می‌دهد بدون درگیر شدن در پیچیدگی‌های غیرضروری، کنترل کامل روی زیرساخت خود داشته باشید.

می‌توانید مستندات رسمی را در [qamar.website](https://qamar.website) دنبال کنید.

---

## چرا قمر؟

بیشتر ابزارهای موجود یا بیش از حد سنگین هستند یا آنقدر محدود که بعد از دو هفته مجبورید دورشان بیندازید. قمر با رویکرد "Minimalist Infrastructure" ساخته شده است. چند ویژگی که باعث شده من شخصاً از آن استفاده کنم:

*   **سرعت بالا:** زمان بارگذاری و واکنش‌گرا بودن پنل مدیریتی خیره‌کننده است.
*   **پیکربندی ساده:** به جای درگیر شدن با هزاران خط YAML، همه‌چیز در قالب ساختارهای منطقی و قابل فهم تعریف می‌شود.
*   **پایداری:** هسته سیستم به گونه‌ای نوشته شده که در شرایط فشار بالا، کمترین مصرف منابع (RAM/CPU) را داشته باشد.

---

## نصب و راه‌اندازی

برای شروع، نیازی به پروسه‌های پیچیده نیست. اگر سیستم‌عامل شما مبتنی بر لینوکس است، تنها با اجرای دستور زیر در ترمینال، همه‌چیز آماده می‌شود:

```bash
curl -sSL https://qamar.website/install.sh | bash
```

پس از اتمام نصب، برای بررسی وضعیت سرویس:

```bash
qamar status
```

اگر با خطایی مواجه شدید، مطمئن شوید که دسترسی `sudo` دارید و پورت‌های پیش‌فرض (معمولاً ۸۰۸۰) اشغال نیستند.

## نحوه استفاده (Usage)

کار با قمر حول محور «مدیریت گره‌ها» (Nodes) می‌چرخد. برای تعریف یک سرویس جدید، کافی است یک فایل پیکربندی با فرمت استاندارد ایجاد کنید:

```json
{
  "service_name": "my-app",
  "port": 3000,
  "restart_policy": "always",
  "env": {
    "NODE_ENV": "production"
  }
}
```

سپس با استفاده از دستور زیر آن را فعال کنید:

```bash
qamar deploy config.json
```

## عیب‌یابی (Troubleshooting)

همیشه وقتی چیزی طبق برنامه پیش نمی‌رود، اولین جایی که باید نگاه کنید لاگ‌ها هستند. قمر لاگ‌ها را به صورت متمرکز نگه می‌دارد:

1.  **بررسی لاگ‌های زنده:**
    `qamar logs --follow [service_id]`

2.  **سرویس بالا نمی‌آید؟**
    معمولاً مشکل از تداخل پورت‌هاست. دستور `qamar netstat` را بزنید تا ببینید کدام پروسه پورت مورد نظر شما را اشغال کرده است.

3.  **دسترسی‌ها:**
    اگر در اجرای دستورات مشکل دارید، احتمالاً کاربر شما در گروه `qamar-admin` تعریف نشده است. با `usermod -aG qamar-admin $USER` این مشکل حل می‌شود.

## سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
قطعاً. معماری قمر به صورت ماژولار طراحی شده و به راحتی با کلاسترها هماهنگ می‌شود.

**آیا امکان بک‌آپ‌گیری خودکار وجود دارد؟**
بله، در بخش تنظیمات می‌توانید مسیرهای بک‌آپ و زمان‌بندی آن را مشخص کنید.

**آیا برای استفاده از قمر باید دانش عمیقی از شبکه داشته باشم؟**
خیر، رابط کاربری و CLI قمر به گونه‌ای طراحی شده که حتی توسعه‌دهندگان سطح متوسط هم بتوانند زیرساخت خود را مدیریت کنند.
