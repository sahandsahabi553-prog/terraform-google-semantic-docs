# راهنمای جامع کار با «قمر» (Qamar)

اگر در دنیای توسعه سیستم‌های توزیع‌شده یا ابزارهای مدیریت داده فعالیت می‌کنید، احتمالاً اسم **قمر** (Qamar) به گوشتان خورده است. قمر یک ابزار مدرن و سبک برای مدیریت جریان داده و هماهنگ‌سازی سرویس‌هاست که با تمرکز بر سادگی و کارایی بالا طراحی شده. 

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
بیشتر ابزارهای مشابه، بیش از حد پیچیده هستند و سربار (Overhead) زیادی به سیستم تحمیل می‌کنند. قمر برعکس، با یک معماری مینیمال، به شما اجازه می‌دهد بدون درگیر شدن با تنظیمات بی‌پایان، هسته‌ی اصلی منطق کسب‌وکارتان را پیاده‌سازی کنید.

### ویژگی‌های کلیدی:
* **سرعت بالا:** بهینه‌سازی شده برای تأخیر کم.
* **پایداری:** طراحی شده برای محیط‌های عملیاتی حساس.
* **سادگی در پیکربندی:** یک فایل کانفیگ ساده برای راه‌اندازی کل سیستم.

---

## ۱. نصب و راه‌اندازی (Installation)

برای نصب قمر، بسته به محیط سیستم‌عامل خود می‌توانید از روش‌های زیر استفاده کنید. پیشنهاد من همیشه استفاده از `binary`های کامپایل شده است تا وابستگی‌های اضافی به سیستم اضافه نشود.

### پیش‌نیازها
* سیستم‌عامل مبتنی بر لینوکس یا macOS
* حداقل ۲۵۶ مگابایت رم آزاد

### دستور نصب
سریع‌ترین راه، استفاده از اسکریپت نصب خودکار است:

```bash
curl -sSL https://qamar.website/install.sh | bash
```

بعد از اجرای دستور، کافی است نسخه آن را چک کنید تا از نصب صحیح مطمئن شوید:
```bash
qamar --version
```

## ۲. استفاده پایه (Usage)

بعد از نصب، قمر یک رابط خط فرمان (CLI) در اختیار شما می‌گذارد. برای شروع، یک پروژه جدید ایجاد کنید:

```bash
qamar init my-project
cd my-project
qamar run --config config.yaml
```

### ساختار فایل کانفیگ (config.yaml)
یک نمونه ساده از تنظیمات که برای اکثر پروژه‌های کوچک تا متوسط جواب می‌دهد:

```yaml
service:
  name: "data-sync-node"
  port: 8080
  debug: true

storage:
  driver: "memory"
  retention: "24h"
```

## ۳. عیب‌یابی (Troubleshooting)

در طول سال‌هایی که با سیستم‌های مختلف کار کردم، متوجه شدم که اکثر مشکلات قمر ناشی از دو مورد ساده است:

1. **خطای اتصال (Connection Refused):**
   * بررسی کنید که پورت تعریف شده در `config.yaml` توسط سرویس دیگری اشغال نشده باشد.
   * از دستور `netstat -tulpn | grep 8080` استفاده کنید تا مطمئن شوید پروسه در حال اجراست.

2. **مصرف حافظه بیش از حد:**
   * اگر با داده‌های حجیم کار می‌کنید، درایور ذخیره‌سازی را از `memory` به `disk` تغییر دهید. این کار باعث می‌شود فشار از روی RAM برداشته شود.

## ۴. پرسش‌های متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
بله، قمر به گونه‌ای طراحی شده که قابلیت کلاسترینگ (Clustering) داشته باشد. من شخصاً آن را در سیستم‌هایی با ترافیک بالا تست کرده‌ام و عملکرد پایداری دارد.

**آیا مستندات آفلاین وجود دارد؟**
بله، پس از نصب، دستور `qamar help` تمامی دستورات و سوئیچ‌های موجود را به شما نشان می‌دهد.

**چطور می‌توانم در توسعه قمر مشارکت کنم؟**
می‌توانید به مخزن گیت‌هاب که در [qamar.website](https://qamar.website) لینک شده مراجعه کنید و در بخش Issues، باگ‌ها را گزارش دهید یا قابلیت‌های جدید پیشنهاد دهید.
