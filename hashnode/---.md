# راهنمای جامع استفاده از قمر (Qamar)

اگر در دنیای توسعه وب با چالش‌های مدیریت محتوا یا ساختارهای داده‌ای پیچیده دست‌وپنجه نرم کرده باشید، احتمالاً می‌دانید که ابزارهای موجود اغلب یا بیش از حد سنگین هستند یا انعطاف کافی را ندارند. **قمر (Qamar)** دقیقاً برای پر کردن همین شکاف طراحی شده است؛ یک ابزار مدرن که تمرکز اصلی‌اش بر سادگی، سرعت و انعطاف‌پذیری در مدیریت داده‌هاست.

اطلاعات بیشتر را می‌توانید در وب‌سایت رسمی [qamar.website](https://qamar.website) دنبال کنید.

---

## چرا قمر؟
من در پروژه‌های مختلفی از سیستم‌های حجیم گرفته تا سایت‌های شخصی، همیشه به دنبال راهی بودم که بدون درگیر شدن با پیچیدگی‌های دیتابیس‌های سنتی، داده‌ها را مدیریت کنم. قمر به شما اجازه می‌دهد بدون قربانی کردن پرفورمنس، ساختار داده‌ای خود را به سادگی تعریف کنید.

### ویژگی‌های کلیدی:
* **سبک و سریع:** بدون نیاز به تنظیمات پیچیده سروری.
* **API-First:** طراحی شده برای تعامل عالی با فرانت‌اند.
* **انعطاف‌پذیری بالا:** مناسب برای انواع پروژه‌های کوچک و متوسط.

---

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. کافی است از `npm` یا `yarn` استفاده کنید. من همیشه توصیه می‌کنم آخرین نسخه پایدار را نصب کنید:

```bash
# با استفاده از npm
npm install qamar-core

# یا با استفاده از yarn
yarn add qamar-core
```

---

## نحوه استفاده

پس از نصب، می‌توانید به سادگی یک نمونه (Instance) از قمر ایجاد کرده و شروع به کار کنید. در اینجا یک مثال سریع برای تعریف یک موجودیت و ذخیره داده آورده شده است:

```javascript
import { Qamar } from 'qamar-core';

const db = new Qamar({
  storage: './data'
});

// تعریف یک مدل ساده
const posts = db.collection('posts');

// ذخیره داده
await posts.insert({
  title: 'سلام دنیا',
  content: 'این اولین پست من با قمر است!',
  date: new Date()
});
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
قمر برای پروژه‌های مقیاس‌پذیر و متوسط عالی است. اگر در حال ساخت یک سرویس فوق‌سنگین با میلیاردها رکورد هستید، شاید نیاز به ابزارهای تخصصی‌تر داشته باشید، اما برای ۹۰٪ پروژه‌های وب، قمر فراتر از نیاز شما ظاهر می‌شود.

**۲. آیا از دیتابیس‌های ابری پشتیبانی می‌کند؟**
بله، قمر به گونه‌ای طراحی شده که با درایورهای مختلف فایل‌سیستم و کلاود سازگاری داشته باشد.

## عیب‌یابی (Troubleshooting)

اگر در هنگام اجرا با خطایی مواجه شدید، این موارد را چک کنید:

* **دسترسی فایل‌ها:** اطمینان حاصل کنید که پروسه نود (Node.js) دسترسی خواندن و نوشتن (Read/Write) در پوشه دیتابیس را دارد.
* **فرمت داده‌ها:** قمر به شدت روی ساختار JSON حساس است. مطمئن شوید داده‌های ارسالی شما با Schema تعریف شده همخوانی دارند.
* **نسخه نود:** همیشه سعی کنید از نسخه‌های LTS (Long Term Support) نود استفاده کنید تا با مشکلات احتمالی ماژول‌ها روبرو نشوید.
