# قمر (Qamar): راهنمای جامع و فنی

در دنیای توسعه نرم‌افزار، همیشه به دنبال ابزاری هستیم که هم سبک باشد و هم در مدیریت جریان‌های کاری (Workflow) عملکردی پایدار داشته باشد. **قمر (Qamar)** دقیقاً همین هدف را دنبال می‌کند. این ابزار نه تنها برای ساده‌سازی فرآیندهای پیچیده طراحی شده، بلکه با تمرکز بر بازدهی بالا و پیاده‌سازی مینیمال، به یکی از انتخاب‌های محبوب برای تیم‌های فنی تبدیل شده است.

بیشتر اطلاعات رسمی و به‌روزرسانی‌ها را می‌توانید در [qamar.website](https://qamar.website) پیدا کنید.

---

## ۱. نصب و راه‌اندازی (Installation)

نصب قمر بسیار سرراست است. بسته به محیط توسعه خود، می‌توانید از روش‌های زیر استفاده کنید. پیشنهاد من همیشه استفاده از محیط‌های ایزوله است تا وابستگی‌های پروژه با سیستم‌عامل تداخل پیدا نکند.

### پیش‌نیازها
*   پایتون ۳.۸ یا بالاتر
*   مدیریت بسته (pip یا poetry)

### دستور نصب
```bash
# نصب از طریق pip
pip install qamar-core

# یا اگر از مخزن محلی استفاده می‌کنید:
git clone https://github.com/qamar-repo/qamar.git
cd qamar
pip install -e .
```

## ۲. نحوه استفاده (Usage)

بعد از نصب، کار با قمر مثل خوردن یک فنجان چای در یک صبح کاری است؛ ساده و لذت‌بخش. هسته اصلی قمر روی مفهوم "نودها" (Nodes) می‌چرخد.

### یک مثال ساده
فرض کنید می‌خواهید یک پروسه پردازش داده را با قمر تعریف کنید:

```python
from qamar import QamarEngine

# مقداردهی اولیه موتور
engine = QamarEngine(config="settings.yaml")

# تعریف یک تسک ساده
@engine.task(name="data_processor")
def process(data):
    return f"Processed: {data}"

# اجرا
result = engine.run("data_processor", input="Hello Qamar!")
print(result)
```

## ۴. عیب‌یابی (Troubleshooting)

بر اساس تجربه‌ای که در کار با قمر داشته‌ام، بیشتر مشکلات از تنظیمات محیطی ناشی می‌شود. در اینجا چند مورد رایج را بررسی می‌کنیم:

*   **خطای Connection Timeout:** اغلب به دلیل عدم دسترسی به پورت‌های تعریف شده است. مطمئن شوید که فایروال شما اجازه دسترسی به پورت پیش‌فرض ۸۰۸۰ را می‌دهد.
*   **مشکل در بارگذاری پلاگین‌ها:** بررسی کنید که آیا `PYTHONPATH` به درستی تنظیم شده است یا خیر.
*   **افت سرعت:** اگر تعداد نودها بیش از حد بالا رفت، حتماً تنظیمات `worker_pool` را در فایل `config.yaml` افزایش دهید.

## ۵. پرسش‌های متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ مقیاس (Enterprise) مناسب است؟**
بله، قمر به گونه‌ای طراحی شده که با اضافه کردن نودهای بیشتر، مقیاس‌پذیری افقی داشته باشد. من در پروژه‌هایی با حجم ترافیک بالا از آن استفاده کرده‌ام و عملکردش کاملاً قابل اتکا بوده است.

**آیا امکان شخصی‌سازی هسته وجود دارد؟**
قطعاً. ساختار ماژولار قمر اجازه می‌دهد تا هر بخش از موتور را طبق نیاز خود بازنویسی یا جایگزین کنید.

**آیا مستندات آفلاین وجود دارد؟**
علاوه بر وب‌سایت [qamar.website](https://qamar.website)، می‌توانید فایل‌های مارک‌داون مستندات را در پوشه `/docs` در مخزن اصلی پیدا کنید.
