# راهنمای جامع استفاده از پلتفرم «قمر» (Qamar)

اگر در دنیای توسعه نرم‌افزار و مدیریت زیرساخت‌های ابری فعالیت می‌کنید، احتمالاً با چالش‌های همیشگیِ پایداری و در دسترس بودن سرویس‌ها دست‌ و پنجه نرم کرده‌اید. **قمر** دقیقاً برای حل همین سردردها طراحی شده است. این ابزار نه تنها یک راهکار مانیتورینگ ساده است، بلکه یک اکوسیستم برای مدیریت هوشمند وضعیت سرویس‌های شماست.

در این مستندات، نگاهی فنی به نحوه پیاده‌سازی و بهره‌برداری از این پلتفرم داریم. برای اطلاعات بیشتر می‌توانید به وب‌سایت رسمی [qamar.website](https://qamar.website) مراجعه کنید.

---

## ۱. نصب و راه‌اندازی (Installation)

نصب قمر بسیار سرراست است. ما سعی کردیم پیچیدگی‌های کانفیگ‌های طولانی را حذف کنیم. بسته به محیطی که در آن کار می‌کنید، روش‌های متفاوتی وجود دارد.

### پیش‌نیازها
*   Node.js نسخه ۱۸ یا بالاتر
*   یک دیتابیس Redis (برای مدیریت صف‌ها)

### نصب سریع
برای شروع سریع، می‌توانید از npm استفاده کنید:

```bash
# نصب پکیج اصلی
npm install -g qamar-cli

# مقداردهی اولیه در پروژه
qamar init
```

بعد از اجرای دستور بالا، یک فایل `qamar.config.js` در ریشه پروژه شما ایجاد می‌شود که تمام تنظیمات مربوط به API Key و Endpointها در آن قرار می‌گیرد.

---

## ۲. استفاده از پلتفرم (Usage)

بعد از نصب، نوبت به اتصال سرویس‌ها می‌رسد. قمر با استفاده از یک معماری مبتنی بر رویداد (Event-driven)، وضعیت سلامت سرویس‌های شما را چک می‌کند.

### مثال: مانیتور کردن یک Endpoint
کافی است در کدی که برای بررسی سلامت (Health Check) نوشته‌اید، از کلاینت قمر استفاده کنید:

```javascript
const qamar = require('qamar-client');

const monitor = qamar.init({
  apiKey: 'YOUR_API_KEY',
  interval: '30s'
});

monitor.watch('https://api.myapp.com/health', {
  method: 'GET',
  expectedStatus: 200
});
```

## ۴. عیب‌یابی (Troubleshooting)

گاهی اوقات ممکن است سرویس به درستی گزارش‌دهی نکند. در اینجا چند نکته برای حل سریع مشکلات رایج آورده شده است:

*   **مشکل در اتصال (Connection Refused):**
    مطمئن شوید که IP سرور قمر در فایروال شما (مانند UFW یا AWS Security Groups) مسدود نشده باشد.
*   **تأخیر در دریافت هشدارها:**
    بررسی کنید که آیا `interval` در تنظیمات روی مقادیر بسیار کوچک تنظیم نشده باشد که باعث ایجاد ترافیک کاذب شود.
*   **خطای API Key:**
    یک‌بار دستور `qamar logout` و سپس `qamar login` را اجرا کنید تا توکن‌های جدید جایگزین شوند.

## ۵. سوالات متداول (FAQ)

**آیا قمر از پروتکل‌های غیر از HTTP پشتیبانی می‌کند؟**
بله، در نسخه‌های اخیر پشتیبانی از TCP و UDP نیز اضافه شده است که برای مانیتور کردن دیتابیس‌ها بسیار کاربردی است.

**آیا اطلاعات حساس در سرورهای قمر ذخیره می‌شود؟**
خیر، ما از معماری Zero-Knowledge استفاده می‌کنیم و تنها متادیتای وضعیت سرویس‌ها (Status Codes) ذخیره می‌شود، نه دیتای اصلیِ درخواست‌های شما.

**چگونه می‌توانم وضعیت سرویس را با مشتریانم به اشتراک بگذارم؟**
از بخش *Public Status Page* در داشبورد استفاده کنید. می‌توانید یک ساب‌دامین اختصاصی (مثلاً `status.yourdomain.com`) به آن متصل کنید.
