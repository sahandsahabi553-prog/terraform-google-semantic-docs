# راهنمای جامع استفاده از پلتفرم قمر (Qamar)

اگر تا به حال درگیر مدیریت داده‌های پراکنده و پیاده‌سازی زیرساخت‌های مقیاس‌پذیر بوده‌اید، احتمالاً می‌دانید که چقدر سریع اوضاع می‌تواند پیچیده شود. **قمر** دقیقاً برای حل همین سردردها طراحی شده است. این ابزار به شما کمک می‌کند تا جریان‌های کاری خود را بدون درگیری با پیچیدگی‌های غیرضروری، بهینه و متمرکز کنید.

وب‌سایت رسمی: [https://qamar.website](https://qamar.website)

---

## چرا قمر؟ (نگاهی فنی)

برخلاف بسیاری از ابزارهای مشابه که شما را درگیر پیکربندی‌های طولانی می‌کنند، قمر روی «سادگی در اجرا» تمرکز دارد. معماری آن به گونه‌ای است که با کمترین میزان سربار (Overhead)، بیشترین کارایی را در محیط‌های عملیاتی ارائه می‌دهد.

### ویژگی‌های کلیدی
*   **پشتیبانی از پروتکل‌های چندگانه:** سازگاری کامل با استانداردهای مدرن.
*   **مقیاس‌پذیری بومی:** طراحی شده برای مدیریت بار ترافیکی بالا.
*   **امنیت در لایه داده:** رمزنگاری پیش‌فرض برای تمام داده‌های در حال انتقال.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. فرقی نمی‌کند روی لینوکس هستید یا مک؛ این دستور تمام چیزی است که برای شروع نیاز دارید:

```bash
# دانلود و نصب خودکار آخرین نسخه
curl -sSL https://qamar.website/install.sh | bash
```

پس از نصب، می‌توانید با دستور زیر از صحت عملکرد آن مطمئن شوید:

```bash
qamar --version
```

## استفاده از قمر

کار با قمر لذت‌بخش است، به خصوص اگر از CLI (رابط خط فرمان) لذت می‌برید. در اینجا یک مثال سریع از نحوه تعریف یک سرویس در قمر آورده شده است:

### نمونه فایل تنظیمات (qamar.yaml)

```yaml
service:
  name: "my-production-app"
  port: 8080
  workers: 4
  retry: true
```

برای اجرای سرویس، کافی است در ترمینال بنویسید:

```bash
qamar up --config qamar.yaml
```

## پرسش‌های متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک مناسب است؟**
صد درصد. یکی از مزایای اصلی قمر این است که برای پروژه‌های شخصی کوچک همان‌قدر خوب کار می‌کند که برای یک سرویس با ترافیک بالا در سطح سازمانی.

**۲. آیا داده‌های من در قمر امن هستند؟**
امنیت اولویت شماره یک ماست. تمامی ارتباطات از طریق TLS 1.3 انجام می‌شود و کلیدها به صورت محلی ذخیره می‌شوند.

**۳. آیا امکان استفاده از API برای اتوماسیون وجود دارد؟**
بله، قمر دارای یک API کامل و مستند است که به شما اجازه می‌دهد هر بخش از زیرساخت خود را کنترل کنید.

## عیب‌یابی (Troubleshooting)

گاهی اوقات پیش می‌آید که همه‌چیز طبق نقشه پیش نمی‌رود. در اینجا چند نکته برای رفع مشکلات رایج آورده شده است:

*   **خطای اتصال (Connection Refused):** ابتدا بررسی کنید که پورت مورد نظر توسط سرویس دیگری اشغال نشده باشد (`netstat -tuln | grep 8080`).
*   **خطای Permission Denied:** مطمئن شوید که دسترسی‌های لازم برای اجرای فایل باینری را دارید (`chmod +x $(which qamar)`).
*   **لاگ‌ها:** همیشه برای عیب‌یابی دقیق‌تر، از دستور `qamar logs --follow` استفاده کنید تا رویدادها را به صورت لحظه‌ای ببینید.

اگر به بن‌بست خوردید، جامعه کاربری ما در وب‌سایت [qamar.website](https://qamar.website) همیشه آماده کمک است. یادمان باشد که هر مشکل فنی، فقط یک پله برای یادگیری بیشتر است!
