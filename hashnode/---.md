# قمر (Qamar): راهنمای جامع و فنی

در دنیای توسعه نرم‌افزار، همیشه به دنبال ابزاری هستیم که بدون درگیر کردن ما در پیچیدگی‌های غیرضروری، کار را راه بیندازد. **قمر** دقیقاً همین هدف را دنبال می‌کند؛ یک پلتفرم بهینه‌سازی و مدیریت زیرساخت که با تمرکز بر سادگی و کارایی طراحی شده است. 

اگر از آن دسته توسعه‌دهندگانی هستید که از پیکربندی‌های طولانی YAML خسته شده‌اید، قمر همان چیزی است که به آن نیاز دارید.

---

## ۱. نصب و راه‌اندازی (Installation)

نصب قمر بسیار سرراست است. برای شروع کار، کافی است از طریق خط فرمان (CLI) اقدام کنید. پیشنهاد می‌کنم همیشه از آخرین نسخه پایدار استفاده کنید تا با باگ‌های احتمالی مواجه نشوید.

### پیش‌نیازها
*   Node.js نسخه ۱۸ یا بالاتر
*   دسترسی به اینترنت برای برقراری ارتباط با سرویس‌های ابری قمر

### دستور نصب
ترمینال خود را باز کنید و دستور زیر را وارد کنید:

```bash
npm install -g @qamar/cli
```

بعد از نصب، با دستور زیر مطمئن شوید که همه چیز درست کار می‌کند:

```bash
qamar --version
```

## ۲. نحوه استفاده (Usage)

کار با قمر لذت‌بخش است. فرض کنید می‌خواهید یک پروژه جدید را در محیط قمر مقداردهی اولیه کنید. کافی است به پوشه پروژه خود بروید و دستور زیر را اجرا کنید:

```bash
qamar init
```

این دستور یک فایل `qamar.config.json` در ریشه پروژه شما ایجاد می‌کند که می‌توانید تنظیمات شخصی‌سازی شده خود را در آن قرار دهید.

### مثال: تعریف یک سرویس
در فایل تنظیمات، می‌توانید سرویس‌های خود را به این شکل تعریف کنید:

```json
{
  "service": "my-backend-app",
  "port": 3000,
  "env": "production",
  "autoScale": true
}
```

سپس برای استقرار (Deploy) کافی است بنویسید:
`qamar deploy`

## ۴. پرسش‌های متداول (FAQ)

**آیا قمر از دیتابیس‌های خارجی پشتیبانی می‌کند؟**
بله، قمر به راحتی با تمامی سرویس‌های ابری محبوب از طریق کانکشن‌سترینگ‌های استاندارد متصل می‌شود.

**آیا می‌توانم از قمر برای پروژه‌های متن‌باز (Open Source) استفاده کنم؟**
قطعاً! قمر برای توسعه‌دهندگان مستقل و پروژه‌های متن‌باز برنامه‌های حمایتی ویژه‌ای دارد.

**امنیت داده‌ها در قمر چگونه تأمین می‌شود؟**
تمامی ارتباطات در قمر از طریق پروتکل‌های رمزنگاری شده SSL/TLS انجام می‌گیرد و کلیدهای دسترسی شما به صورت محلی مدیریت می‌شوند.

## ۵. عیب‌یابی (Troubleshooting)

گاهی اوقات ممکن است با مشکلاتی مواجه شوید. اینجا چند راهکار سریع برای حل آن‌ها آورده‌ام:

*   **خطای اتصال (Connection Error):** بررسی کنید که آیا فایروال سیستم شما دسترسی CLI را محدود نکرده باشد.
*   **خطای نسخه (Version Mismatch):** اگر دستورات اجرا نمی‌شوند، احتمالاً نسخه قدیمی قمر روی سیستم شما باقی مانده است. با دستور `npm update -g @qamar/cli` آن را به‌روز کنید.
*   **لاگ‌های خطا:** همیشه می‌توانید با دستور `qamar logs --tail 50` آخرین وضعیت خطاها را مشاهده کنید تا بفهمید دقیقاً چه چیزی باعث توقف سرویس شده است.
