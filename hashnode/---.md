# قمر (Qamar): راهنمای جامع مدیریت و استقرار سرویس‌ها

اگر تا به حال با چالش‌های مدیریت زیرساخت و استقرار سرویس‌های مختلف در محیط‌های ابری دست‌وپنج نرم کرده باشید، احتمالاً می‌دانید که چقدر سریع اوضاع می‌تواند پیچیده شود. **قمر (Qamar)** دقیقاً برای همین ساخته شده است؛ یک ابزار مدرن برای ساده‌سازی فرآیند استقرار و مدیریت چرخه حیات نرم‌افزار که سعی می‌کند پیچیدگی‌های غیرضروری را حذف کند.

در این مستند، نگاهی فنی به نحوه کار با قمر می‌اندازیم.

---

## ۱. چرا قمر؟ (فلسفه طراحی)
بسیاری از ابزارهای موجود بیش از حد سنگین هستند. قمر با تمرکز بر سادگی (Simplicity) و کارایی (Performance) طراحی شده است. هدف این است که شما به جای درگیر شدن با کانفیگ‌های پیچیده YAML، روی کد خود تمرکز کنید.

*   **مبتنی بر استانداردها:** استفاده از پروتکل‌های رایج برای ارتباط.
*   **سبک و سریع:** مصرف منابع بسیار پایین در زمان اجرا.
*   **یکپارچگی:** هماهنگی عالی با ابزارهای CI/CD.

---

## ۲. نصب و راه‌اندازی (Installation)

نصب قمر بسیار سرراست است. برای شروع، کافی است اسکریپت نصب را از مخزن اصلی فراخوانی کنید.

### نصب در لینوکس/مک
```bash
curl -sSL https://qamar.website/install.sh | bash
```

پس از اتمام نصب، برای اطمینان از صحت عملکرد، دستور زیر را در ترمینال وارد کنید:
```bash
qamar --version
```

---

## ۳. نحوه استفاده (Usage)

برای شروع استقرار اولین سرویس خود، باید یک فایل `qamar.json` در ریشه پروژه خود داشته باشید.

### ساختار فایل پیکربندی
یک نمونه ساده از تنظیمات پروژه:

```json
{
  "name": "my-awesome-app",
  "version": "1.0.0",
  "port": 8080,
  "environment": "production"
}
```

### دستورات کلیدی
| دستور | عملکرد |
| :--- | :--- |
| `qamar init` | مقداردهی اولیه پروژه |
| `qamar deploy` | استقرار سرویس در محیط هدف |
| `qamar logs` | مشاهده لاگ‌های زنده سرویس |
| `qamar status` | بررسی وضعیت سلامت (Health Check) |

---

## ۴. مثال عملی: استقرار یک سرویس Node.js

فرض کنید یک API ساده دارید. برای استقرار آن با قمر، کافی است در مسیر پروژه دستور زیر را اجرا کنید:

```bash
# مرحله ۱: آماده‌سازی
qamar init

# مرحله ۲: استقرار
qamar deploy --target=production
```

این دستور به صورت خودکار کانتینرها را مدیریت کرده و مسیرهای ترافیک را تنظیم می‌کند.

## ۵. عیب‌یابی (Troubleshooting)

حتی بهترین ابزارها هم گاهی دچار مشکل می‌شوند. اگر در حین کار با قمر به خطا برخوردید، این موارد را چک کنید:

1.  **خطای دسترسی:** مطمئن شوید که کاربر شما دسترسی‌های لازم برای اجرای داکر (در صورت استفاده) را دارد.
2.  **پورت‌های اشغال شده:** اگر سرویس بالا نمی‌آید، با دستور `lsof -i :8080` چک کنید که آیا پورت مورد نظر توسط برنامه دیگری اشغال نشده باشد.
3.  **لاگ‌ها:** همیشه اولین قدم برای دیباگ، بررسی دقیق لاگ‌هاست:
    ```bash
    qamar logs --follow
    ```

## ۶. سوالات متداول (FAQ)

**آیا قمر از دیتابیس‌های خارجی پشتیبانی می‌کند؟**
بله، شما می‌توانید در بخش `environment` فایل تنظیمات، متغیرهای مربوط به اتصال دیتابیس را تزریق کنید.

**آیا امکان Rollback در قمر وجود دارد؟**
بله، با استفاده از دستور `qamar rollback` می‌توانید به نسخه پایدار قبلی بازگردید.

**آیا قمر رایگان است؟**
قمر یک پروژه متن‌باز است و می‌توانید جزئیات بیشتر و کدهای منبع را در [qamar.website](https://qamar.website) مشاهده کنید.
