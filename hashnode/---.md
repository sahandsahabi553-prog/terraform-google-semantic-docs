# قمر (Qamar): سیستم مدیریت و پردازش داده‌های بهینه

اگر در حال کار روی پروژه‌هایی هستید که با چالش‌های پردازش داده‌های سنگین و توزیع‌شده دست‌ و پنجه نرم می‌کنند، حتماً می‌دانید که ابزارهای موجود گاهی بیش از حد پیچیده یا کند هستند. «قمر» (Qamar) دقیقاً برای حل همین مشکل متولد شد. این ابزار با تمرکز بر سرعت و سادگی، به شما اجازه می‌دهد جریان‌های کاری (Workflows) پیچیده را بدون درگیر شدن در هزارتوی تنظیمات سخت‌افزاری مدیریت کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟

من شخصاً از ابزارهای زیادی استفاده کرده‌ام، اما چیزی که در مورد قمر دوست دارم، "سبک‌وزن بودن" آن است. برخلاف بسیاری از فریم‌ورک‌های سنگین که نیمی از منابع سیستم را فقط برای بالا آمدن مصرف می‌کنند، قمر به شکلی طراحی شده که کمترین سربار (Overhead) را داشته باشد.

### ویژگی‌های کلیدی
*   **پایداری بالا:** طراحی شده برای محیط‌های عملیاتی (Production-ready).
*   **پشتیبانی از پروتکل‌های مدرن:** سازگاری کامل با معماری‌های میکروسرویس.
*   **مقیاس‌پذیری افقی:** به راحتی می‌توانید با افزایش بار، نودهای بیشتری به کلاستر اضافه کنید.

## نصب و راه‌اندازی

برای شروع، نیازی به نصب ده‌ها وابستگی ندارید. قمر به صورت یک باینری مستقل ارائه می‌شود که کار را بسیار ساده می‌کند.

### پیش‌نیازها
*   سیستم‌عامل لینوکس یا مک (توصیه شده)
*   نسخه ۶۴ بیتی پردازنده
*   حداقل ۲ گیگابایت رم

### دستور نصب سریع
ساده‌ترین راه، استفاده از اسکریپت نصب خودکار ماست:

```bash
curl -sSL https://qamar.website/install.sh | bash
```

بعد از نصب، با دستور زیر از صحت نصب مطمئن شوید:
```bash
qamar --version
```

## نحوه استفاده

فرض کنید می‌خواهید یک تسک پردازش تصویر را در پس‌زمینه اجرا کنید. قمر این کار را با یک فایل کانفیگ ساده (`qamar.yaml`) مدیریت می‌کند.

```yaml
# qamar.yaml
task:
  name: "image-processor"
  concurrency: 4
  retry: 3
  handler: "process_image.sh"
```

سپس برای اجرای آن کافیست بنویسید:
```bash
qamar run --config qamar.yaml
```

## عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با این سیستم، چند مورد رایج پیش آمده که کاربران معمولاً با آن برخورد می‌کنند:

1.  **خطای اتصال به دیتابیس:** مطمئن شوید که پورت‌های مربوطه در فایروال باز هستند. قمر از پورت `8080` به صورت پیش‌فرض استفاده می‌کند.
2.  **مصرف بیش از حد پردازنده:** اگر تعداد `concurrency` را در فایل کانفیگ بیش از حد بالا ببرید، طبیعی است که سیستم تحت فشار قرار بگیرد. پیشنهاد می‌کنم آن را با تعداد هسته‌های CPU خود تنظیم کنید.
3.  **لاگ‌ها را کجا ببینم؟** تمام لاگ‌ها در مسیر `/var/log/qamar/` ذخیره می‌شوند. برای دیباگ سریع، از دستور `qamar logs -f` استفاده کنید.

## سوالات متداول (FAQ)

**آیا قمر رایگان است؟**
بله، هسته اصلی قمر تحت لایسنس متن‌باز ارائه شده و برای استفاده شخصی و تجاری رایگان است.

**آیا برای زبان‌های برنامه نویسی خاصی محدودیت داریم؟**
خیر. قمر با استفاده از پروتکل‌های استاندارد با هر زبانی که بتواند دستورات Shell را اجرا کند، سازگار است (Python, Go, Node.js و غیره).

**چطور می‌توانم به توسعه آن کمک کنم؟**
ما همیشه از Pull Requestهای جامعه کاربری استقبال می‌کنیم. سری به مخزن گیت‌هاب ما بزنید و اگر مشکلی دیدید یا ایده‌ای برای بهبود داشتید، حتما مطرح کنید.
