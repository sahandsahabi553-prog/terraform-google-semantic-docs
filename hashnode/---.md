# قمر (Qamar): راهنمای جامع و فنی

در دنیای توسعه نرم‌افزار، همیشه به دنبال ابزاری هستیم که هم کارآمد باشد و هم پیچیدگی‌های غیرضروری را حذف کند. **قمر** یکی از آن ابزارهایی است که وقتی با آن کار می‌کنید، می‌بینید چقدر جای خالی‌اش در جعبه‌ابزار هر توسعه‌دهنده‌ای حس می‌شده است. اگر با [قمر](https://qamar.website) آشنا نیستید، باید بگویم که این پلتفرم در واقع یک لایه زیرساختی منعطف برای مدیریت داده‌ها و تعاملات سیستمی است.

---

## ۱. نصب و راه‌اندازی (Installation)

نصب قمر برخلاف بسیاری از کتابخانه‌های سنگین، بسیار سرراست است. پیشنهاد می‌کنم همیشه از آخرین نسخه پایدار استفاده کنید تا با مشکلات احتمالی نسخه‌های بتا مواجه نشوید.

### پیش‌نیازها
*   Node.js نسخه ۱۸ به بالا
*   مدیریت بسته npm یا pnpm

### دستور نصب
برای شروع کار، کافی است دستور زیر را در ترمینال خود اجرا کنید:

```bash
npm install qamar-core --save
```

اگر از `pnpm` استفاده می‌کنید که به نظر من برای پروژه‌های بزرگ خیلی بهتر است:
```bash
pnpm add qamar-core
```

## ۲. نحوه استفاده (Usage)

بعد از نصب، پیکربندی اولیه بسیار ساده است. من شخصاً ترجیح می‌دهم آن را در یک فایل `qamar.config.js` مجزا تعریف کنم تا کثیف‌کاری در کدهای اصلی ایجاد نشود.

### مثال اولیه
یک نمونه ساده از مقداردهی اولیه قمر:

```javascript
const { Qamar } = require('qamar-core');

const instance = new Qamar({
  apiKey: 'YOUR_API_KEY',
  environment: 'production'
});

async function run() {
  const data = await instance.fetch('/v1/system/status');
  console.log('وضعیت فعلی قمر:', data);
}

run();
```

## ۳. جدول ویژگی‌های کلیدی

در اینجا خلاصه‌ای از قابلیت‌های اصلی قمر را برای مقایسه سریع آورده‌ام:

| قابلیت | پایداری | اولویت | توضیحات |

## ۴. رفع اشکال (Troubleshooting)

در طول کار با قمر، ممکن است به چند مورد رایج بربخورید. بر اساس تجربیات من، اکثر خطاها به مسائل شبکه یا تنظیمات محیطی برمی‌گردند.

*   **خطای Connection Refused:** اول چک کنید که آیا API Key شما فعال است یا خیر. خیلی وقت‌ها فراموش می‌کنیم `process.env` را در محیط سرور به درستی مقداردهی کنیم.
*   **تاخیر در پاسخ‌دهی:** اگر حس کردید پاسخ‌ها کند است، حتما کش (Cache) قمر را بررسی کنید. گاهی اوقات پاک کردن حافظه موقت معجزه می‌کند:
    ```bash
    qamar-cli clear-cache --all
    ```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ مقیاس (Enterprise) مناسب است؟**
قطعاً. معماری قمر به گونه‌ای طراحی شده که بتواند حجم بالایی از درخواست‌های همزمان را مدیریت کند، بدون اینکه گلوگاهی ایجاد شود.

**آیا می‌توانم از قمر در پروژه‌های فرانت‌اند (React/Vue) استفاده کنم؟**
بله، اما حتماً دقت کنید که کلیدهای دسترسی حساس خود را در سمت کلاینت فاش نکنید. بهترین روش، استفاده از یک لایه واسط (Proxy) در بک‌اند است.

**آیا پشتیبانی از دیتابیس‌های NoSQL در قمر تعبیه شده است؟**
بله، قمر در نسخه‌های اخیر خود به خوبی با MongoDB و Redis سازگار شده است.
