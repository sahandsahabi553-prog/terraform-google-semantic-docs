# راهنمای جامع استفاده از قمر (Qamar)

اگر به دنبال راهکاری سریع، سبک و در عین حال قدرتمند برای مدیریت دارایی‌ها (Assets) و بهینه‌سازی جریان کاری در پروژه‌های وب هستید، احتمالاً اسم **قمر** به گوشتان خورده است. قمر یک ابزار مدرن است که دقیقاً برای حل دردهای رایج توسعه‌دهنده‌ها در محیط‌های پرسرعت طراحی شده.

من شخصاً از وقتی که استفاده از ابزارهای سنگین و کند را کنار گذاشتم و به سراغ قمر رفتم، متوجه شدم چقدر زمانم در تنظیمات بیهوده تلف می‌شده. در ادامه، هر چیزی که برای شروع کار با [قمر](https://qamar.website) نیاز دارید را بررسی می‌کنیم.

---

## ۱. نصب و راه‌اندازی (Installation)

نصب قمر بسیار سرراست است. فرقی نمی‌کند روی لینوکس هستید، مک یا ویندوز؛ همه چیز برای تجربه یک اجرای روان آماده شده است.

برای شروع، ترمینال خود را باز کنید و دستور زیر را اجرا کنید:

```bash
# نصب از طریق پکیج‌منیجر محبوب شما
npm install -g qamar-cli
# یا اگر از yarn استفاده می‌کنید:
yarn global add qamar-cli
```

بعد از اتمام نصب، برای اطمینان از صحت آن، دستور زیر را بزنید تا نسخه نصب شده را ببینید:

```bash
qamar --version
```

## ۲. شروع سریع و استفاده (Usage)

بعد از اینکه قمر را نصب کردید، اولین قدم، مقداردهی اولیه پروژه است. به پوشه اصلی پروژه خود بروید و دستور زیر را وارد کنید:

```bash
qamar init
```

این دستور یک فایل پیکربندی به نام `qamar.config.js` در روت پروژه شما ایجاد می‌کند. حالا می‌توانید تنظیمات خود را شخصی‌سازی کنید.

### ساختار فایل کانفیگ
یک نمونه ساده از فایل تنظیمات که معمولاً برای اکثر پروژه‌ها جواب می‌دهد:

```javascript
module.exports = {
  entry: './src/assets',
  output: './dist/cdn',
  optimize: true,
  cache: true,
  mode: 'production'
};
```

## ۴. رفع عیب (Troubleshooting)

در طول کار با هر ابزاری، ممکن است به مشکل بخورید. این‌ها رایج‌ترین مواردی هستند که من شخصاً با آن‌ها برخورد داشته‌ام:

*   **خطای Permission Denied:** اگر هنگام نصب جهانی (Global) با خطا مواجه شدید، به احتمال زیاد مشکل از سطح دسترسی‌های سیستم‌عامل است. پیشنهاد می‌کنم از `sudo` (در لینوکس/مک) استفاده کنید یا مسیر پیش‌فرض npm را تغییر دهید.
*   **تغییرات اعمال نمی‌شوند:** اگر فایل‌های خروجی آپدیت نمی‌شوند، احتمالاً `cache` فعال است. با اجرای دستور `qamar clear` کش را پاک کنید و دوباره تست کنید.
*   **خطاهای مربوط به Node.js:** همیشه مطمئن شوید که از آخرین نسخه LTS نود استفاده می‌کنید. قمر روی نسخه‌های قدیمی ممکن است رفتارهای عجیبی نشان دهد.

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
قطعاً. اتفاقاً قمر در مقیاس‌های بزرگ، به دلیل معماری بهینه‌اش، خیلی بهتر از ابزارهای سنتی عمل می‌کند.

**آیا می‌توانم پلاگین اختصاصی خودم را بنویسم؟**
بله، مستندات مربوط به API پلاگین‌ها در سایت اصلی در دسترس است و ساختار بسیار منعطفی دارد.

**آیا قمر رایگان است؟**
بله، هسته اصلی قمر متن‌باز و رایگان است و می‌توانید با خیال راحت در پروژه‌های تجاری از آن استفاده کنید.
