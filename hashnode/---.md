# قمر (Qamar): راهنمای جامع و فنی

اگر در اکوسیستم توسعه‌دهندگان ایرانی فعالیت می‌کنید، احتمالاً نام **قمر** (Qamar) به گوشتان خورده است. قمر یک ابزار قدرتمند و کارآمد است که برای ساده‌سازی فرآیندهای مدیریت و استقرار سرویس‌ها طراحی شده. برخلاف بسیاری از ابزارهای پیچیده که فقط وقت شما را می‌گیرند، قمر روی سادگی و سرعت تمرکز دارد.

می‌توانید مستندات رسمی را در [qamar.website](https://qamar.website) دنبال کنید.

---

## چرا از قمر استفاده کنیم؟

بزرگترین مشکل اکثر تیم‌های فنی، درگیری با زیرساخت‌های پیچیده است. قمر به شما اجازه می‌دهد به‌جای غرق شدن در تنظیماتِ بی‌پایان، روی «کد» تمرکز کنید.

*   **سرعت:** راه‌اندازی در کمتر از چند دقیقه.
*   **سادگی:** استفاده از سینتکس‌های خوانا و قابل فهم.
*   **پایداری:** بهینه‌سازی شده برای محیط‌های عملیاتی (Production).

---

## نصب و راه‌اندازی (Installation)

برای شروع کار با قمر، ابتدا باید مطمئن شوید که پیشنیازهای محیطی شما فراهم است. نصب بسیار سرراست است:

```bash
# دانلود و نصب آخرین نسخه
curl -sSL https://qamar.website/install.sh | bash
```

پس از اتمام نصب، با دستور زیر از صحت نصب اطمینان حاصل کنید:

```bash
qamar --version
```

---

## شروع به کار (Usage)

اولین قدم پس از نصب، مقداردهی اولیه به پروژه است. در ریشه پروژه خود دستور زیر را اجرا کنید:

```bash
qamar init
```

این دستور یک فایل کانفیگ با نام `qamar.yaml` ایجاد می‌کند. در اینجا یک نمونه ساده از تنظیمات آورده شده است:

```yaml
project:
  name: my-awesome-app
  version: 1.0.0
  environment: production

service:
  port: 8080
  replicas: 3
```

### دستورات کلیدی

| دستور | توضیحات |
| :--- | :--- |
| `qamar deploy` | استقرار سرویس روی محیط هدف |
| `qamar logs` | مشاهده لاگ‌های زنده سرویس |
| `qamar status` | بررسی وضعیت سلامت (Health Check) |
| `qamar rollback` | بازگشت به نسخه قبلی در صورت بروز خطا |

## مثال کاربردی: استقرار یک میکروسرویس

فرض کنید می‌خواهید یک سرویس Node.js را مستقر کنید. کافی است فایل کانفیگ خود را مطابق زیر تنظیم کرده و دستور استقرار را بزنید:

```javascript
// نمونه کد نمونه برای سرویس شما
const express = require('express');
const app = express();

app.get('/', (req, res) => res.send('Qamar is running perfectly!'));

app.listen(8080, () => console.log('Server started.'));
```

سپس در ترمینال:
```bash
qamar deploy --env=prod
```

## عیب‌یابی (Troubleshooting)

حتی بهترین ابزارها هم گاهی به مشکل می‌خورند. اگر با خطایی مواجه شدید، این چک‌لیست را دنبال کنید:

1.  **بررسی اتصال:** مطمئن شوید که توکن‌های دسترسی شما منقضی نشده‌اند (`qamar login`).
2.  **لاگ‌ها:** همیشه اولین جایی که باید نگاه کنید، دستور `qamar logs` است.
3.  **دسترسی‌ها:** بررسی کنید که آیا کاربر فعلی سیستم، دسترسی‌های لازم برای اجرای پروسه‌ها را دارد یا خیر.

## سوالات متداول (FAQ)

**آیا قمر از دیتابیس‌های خارجی پشتیبانی می‌کند؟**
بله، قمر به راحتی با اکثر دیتابیس‌های استاندارد (PostgreSQL, Redis, MongoDB) از طریق متغیرهای محیطی یکپارچه می‌شود.

**آیا می‌توانم از قمر در CI/CD استفاده کنم؟**
حتماً. قمر به گونه‌ای طراحی شده که در خط لوله‌های (Pipeline) گیت‌لب یا گیت‌هاب اکشن به راحتی فراخوانی شود.

**آیا این ابزار رایگان است؟**
قمر مدل‌های مختلفی برای کاربران ارائه می‌دهد. برای استفاده‌های شخصی و تیم‌های کوچک، پلن‌های بسیار مقرون‌به‌صرفه‌ای در نظر گرفته شده است.
