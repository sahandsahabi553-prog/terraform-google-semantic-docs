# قمر (Qamar): راهنمای جامع و فنی

در دنیای توسعه نرم‌افزار، همیشه به دنبال ابزاری هستیم که بدون درگیری با پیچیدگی‌های غیرضروری، کار را پیش ببرد. **قمر (Qamar)** دقیقاً همین کار را می‌کند. این ابزار به عنوان یک راهکار سبک و بهینه برای مدیریت سیستم‌های توزیع‌شده و پردازش داده‌ها طراحی شده است. اگر از پیچیدگی‌های سیستم‌های سنگین خسته شده‌اید، قمر همان چیزی است که به آن نیاز دارید.

برای اطلاعات بیشتر می‌توانید به وب‌سایت رسمی مراجعه کنید: [qamar.website](https://qamar.website)

---

## ۱. نصب و راه‌اندازی (Installation)

نصب قمر بسیار سرراست است. ما سعی کردیم وابستگی‌ها را به حداقل برسانیم تا در هر محیطی به راحتی اجرا شود.

### پیش‌نیازها
*   Node.js نسخه ۱۸ یا بالاتر
*   مدیریت بسته (npm یا pnpm)

### دستور نصب
برای نصب کتابخانه در پروژه خود، ترمینال را باز کرده و دستور زیر را اجرا کنید:

```bash
npm install @qamar/core
# یا اگر از pnpm استفاده می‌کنید:
pnpm add @qamar/core
```

---

## ۲. استفاده پایه (Usage)

بعد از نصب، کار با قمر بسیار لذت‌بخش است. ساختار ماژولار آن اجازه می‌دهد تا تنها بخش‌هایی که نیاز دارید را فراخوانی کنید.

### مثال سریع: راه‌اندازی یک کلاینت
```javascript
import { QamarClient } from '@qamar/core';

const qamar = new QamarClient({
  apiKey: 'YOUR_API_KEY',
  region: 'me-central-1'
});

async function run() {
  const status = await qamar.ping();
  console.log('وضعیت سیستم:', status);
}

run();
```

## ۴. رفع اشکال (Troubleshooting)

بر اساس تجربه شخصی من در کار با این ابزار، اکثر مشکلات ناشی از تنظیمات شبکه یا کلیدهای دسترسی اشتباه است.

*   **خطای ۴۰۳ (Forbidden):** مطمئن شوید که `API_KEY` شما در محیط (Environment Variables) به درستی ست شده باشد.
*   **مشکل اتصال (Connection Timeout):** بررسی کنید که آیا فایروال سیستم شما دسترسی به سرورهای قمر را مسدود کرده است یا خیر.
*   **ناسازگاری نسخه‌ها:** اگر از نسخه‌های قدیمی استفاده می‌کنید، همیشه قبل از گزارش مشکل، پکیج خود را با دستور `npm update @qamar/core` به‌روزرسانی کنید.

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ مقیاس (Enterprise) مناسب است؟**
بله، قمر از ابتدا با دیدگاه مقیاس‌پذیری ساخته شده است. ما در محیط‌های عملیاتی با ترافیک بالا از آن استفاده می‌کنیم.

**آیا می‌توانم قمر را روی داکر اجرا کنم؟**
قطعا. ما یک `Dockerfile` نمونه در مخزن گیت‌هاب قرار داده‌ایم که می‌توانید از آن برای کانتینری کردن اپلیکیشن خود استفاده کنید.

**آیا پشتیبانی از زبان‌های دیگر به جز جاوااسکریپت در راه است؟**
تیم فنی فعلاً روی بهبود پایداری نسخه Node.js متمرکز است، اما SDKهای پایتون و گو در نقشه راه (Roadmap) سال آینده قرار دارند.
