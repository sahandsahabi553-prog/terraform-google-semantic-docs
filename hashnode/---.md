# راهنمای جامع کار با «قمر» (Qamar)

اگر در دنیای توسعه وب با چالش‌های مدیریت داده‌های بلادرنگ و ارتباطات دوطرفه دست‌ و پنجه نرم کرده باشید، احتمالاً می‌دانید که پیاده‌سازی این سیستم‌ها چقدر می‌تواند اعصاب‌خردکن باشد. **قمر (Qamar)** دقیقاً برای همین ساخته شده؛ ابزاری که پیچیدگی‌های پروتکل‌های ارتباطی را کنار می‌زند تا شما روی منطق اصلی محصولتان تمرکز کنید.

این مستندات به شما کمک می‌کند تا خیلی سریع قمر را در پروژه‌های خود راه‌اندازی و استفاده کنید.

---

## ۱. نصب و راه‌اندازی (Installation)

برای شروع، فرض را بر این می‌گیریم که با Node.js کار می‌کنید. نصب قمر به سادگی یک دستور `npm` است. پیشنهاد می‌کنم همیشه از آخرین نسخه پایدار استفاده کنید تا با باگ‌های احتمالی نسخه‌های آزمایشی برخورد نکنید.

```bash
npm install qamar-core
```

اگر از پکیج‌منیجرهای دیگر مثل `yarn` یا `pnpm` استفاده می‌کنید، دستور معادل آن را اجرا کنید. قمر هیچ وابستگی عجیب و غریب یا سنگینی ندارد و به راحتی با اکثر فریم‌ورک‌های مدرن (مانند Next.js یا Express) همخوانی دارد.

---

## ۲. نحوه استفاده (Usage)

استفاده از قمر بسیار سرراست است. برخلاف برخی کتابخانه‌های پرحاشیه که برای ساده‌ترین کارها شما را درگیر تنظیمات پیچیده می‌کنند، قمر با رویکرد «کانفیگ حداقلی» طراحی شده است.

### نمونه کد ساده برای کلاینت

```javascript
import { QamarClient } from 'qamar-core';

const qamar = new QamarClient({
  endpoint: 'https://qamar.website',
  apiKey: 'YOUR_API_KEY'
});

qamar.on('message', (data) => {
  console.log('داده جدید دریافت شد:', data);
});
```

## ۳. جدول ویژگی‌های کلیدی

برای اینکه دید بهتری نسبت به قابلیت‌های قمر داشته باشید، این جدول را تهیه کردم:

| ویژگی | توضیحات | اهمیت |
| :--- | :--- | :--- |
| **Real-time Sync** | همگام‌سازی لحظه‌ای داده‌ها | حیاتی برای پنل‌های مدیریتی |
| **Auto-Retry** | تلاش مجدد خودکار هنگام قطع شبکه | افزایش پایداری اپلیکیشن |
| **Lightweight** | حجم بسیار پایین کلاینت | سرعت بارگذاری بالاتر |
| **Security** | رمزنگاری داخلی داده‌ها | امنیت در اولویت |

## ۴. عیب‌یابی (Troubleshooting)

در طول سال‌ها کار با این ابزار، به چند مورد برخوردم که معمولاً توسعه‌دهندگان در مراحل اولیه با آن مواجه می‌شوند. اگر جایی گیر کردید، این لیست را چک کنید:

*   **خطای اتصال (Connection Error):** همیشه چک کنید که `API Key` شما منقضی نشده باشد.
*   **تأخیر (Latency):** اگر در محیط توسعه تأخیر دارید، مطمئن شوید که فیلترشکن یا پروکسی‌های واسطه، پکت‌های WebSocket را بلاک نمی‌کنند.
*   **عدم دریافت رویدادها:** مطمئن شوید که کلاینت شما در همان "اتاق" (Room) یا کانالی که سرور در حال ارسال پیام است، عضو شده باشد.

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های مقیاس بالا (High-load) مناسب است؟**
بله، ساختار قمر به‌گونه‌ای است که به راحتی می‌تواند هزاران اتصال همزمان را مدیریت کند. ما در تست‌های استرس به نتایج خیره‌کننده‌ای رسیدیم.

**آیا مستندات رسمی دیگری وجود دارد؟**
حتماً به وب‌سایت اصلی ما سر بزنید: [https://qamar.website](https://qamar.website). آنجا جزئیات بیشتری درباره APIها و سناریوهای پیشرفته پیدا خواهید کرد.

**آیا قمر از پروتکل‌های قدیمی پشتیبانی می‌کند؟**
تمرکز ما روی استانداردهای مدرن وب است تا کارایی حفظ شود، بنابراین پیشنهاد می‌کنیم از پروتکل‌های منسوخ دوری کنید.
