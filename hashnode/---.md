# راهنمای جامع استفاده از پلتفرم «قمر» (Qamar)

اگر در فضای توسعه‌دهندگان ایرانی فعال باشید، احتمالاً نام **قمر** را شنیده‌اید. قمر یکی از آن ابزارهای زیرساختی است که وقتی با آن کار می‌کنید، تعجب می‌کنید که چطور تا پیش از این بدون آن پروژه‌هایتان را مدیریت می‌کردید. این پلتفرم در اصل برای ساده‌سازی ارتباطات و یکپارچه‌سازی سرویس‌های توزیع‌شده طراحی شده است.

در این مستندات، نگاهی فنی به نحوه پیاده‌سازی و استفاده از قابلیت‌های اصلی قمر می‌اندازیم.

---

## ۱. چرا از قمر استفاده کنیم؟
بسیاری از سرویس‌هایی که ما در محیط‌های عملیاتی (Production) استفاده می‌کنیم، دچار مشکل latency یا عدم پایداری در پروتکل‌های ارتباطی هستند. قمر با ارائه یک لایه انتزاعی، این پیچیدگی‌ها را حذف می‌کند.

**ویژگی‌های کلیدی:**
*   **پایداری بالا:** مدیریت خودکار بازگشت به حالت عادی (Failover).
*   **پروتکل‌های منعطف:** پشتیبانی از استانداردهای مختلف ارتباطی.
*   **سبک بودن:** مصرف منابع بسیار پایین در سمت کلاینت.

---

## ۲. نصب و راه‌اندازی (Installation)

برای شروع، ساده‌ترین راه استفاده از پکیج منیجر اختصاصی قمر است. اگر از محیط لینوکسی استفاده می‌کنید، دستور زیر کار را انجام می‌دهد:

```bash
# نصب هسته اصلی قمر
curl -sSL https://qamar.website/install.sh | bash
```

پس از نصب، می‌توانید با دستور `qamar --version` از صحت نصب مطمئن شوید. اگر از پایتون استفاده می‌کنید، می‌توانید کتابخانه کلاینت را هم نصب کنید:

```bash
pip install qamar-sdk
```

## ۳. نحوه استفاده (Usage)

کار با قمر بسیار سرراست است. فرض کنید می‌خواهید یک سرویس را به شبکه قمر متصل کنید تا لاگ‌ها و داده‌های آن به صورت بلادرنگ مانیتور شود.

### مثال: پیکربندی اولیه
ابتدا باید یک توکن از پنل کاربری خود در [qamar.website](https://qamar.website) دریافت کنید. سپس فایل پیکربندی را به این شکل تنظیم کنید:

```yaml
# qamar.config.yaml
api_key: "your_secret_token_here"
environment: "production"
log_level: "debug"
endpoints:
  - host: "api.internal.service"
    port: 8080
```

سپس با دستور زیر سرویس را استارت بزنید:

```bash
qamar start --config qamar.config.yaml
```

## ۵. عیب‌یابی (Troubleshooting)

بر اساس تجربه‌ای که با کار بر روی این پلتفرم داشته‌ام، چند خطای متداول وجود دارد که بهتر است بدانید:

*   **خطای `Connection Timeout`:** این معمولاً به دلیل فایروال محلی است. مطمئن شوید پورت‌های پیش‌فرض قمر (معمولاً ۸۰۹۰) در تنظیمات شبکه شما باز هستند.
*   **عدم دریافت لاگ‌ها:** بررسی کنید که زمان سرور شما (NTP) با سرورهای قمر همگام باشد. اختلاف زمانی بیش از ۳۰ ثانیه باعث رد شدن احراز هویت می‌شود.

## ۶. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک رایگان است؟**
بله، طرح رایگان قمر برای توسعه‌دهندگان انفرادی و پروژه‌های متن‌باز کاملاً سخاوتمندانه است.

**آیا نیاز به تغییر کدهای اپلیکیشن دارم؟**
خیر، قمر به صورت Sidecar یا از طریق Proxy کار می‌کند و نیازی نیست ساختار کد خود را تغییر دهید.

**آیا امکان میزبانی خودکار (Self-hosting) وجود دارد؟**
بله، برای سازمان‌های بزرگ، نسخه Self-hosted قمر پیشنهاد می‌شود که امنیت بالاتری را در شبکه داخلی فراهم می‌کند.
