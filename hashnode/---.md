# راهنمای جامع استفاده از «قمر» (Qamar)

اگر در دنیای توسعه نرم‌افزار و مدیریت زیرساخت‌های ابری فعالیت می‌کنید، احتمالاً بارها با چالش پیچیدگی در پیاده‌سازی و یکپارچه‌سازی سرویس‌ها دست‌وپنج نرم کرده‌اید. **قمر (Qamar)** دقیقاً برای حل همین گره‌های کور طراحی شده است. این ابزار با رویکردی مدرن، لایه‌ای انتزاعی و در عین حال قدرتمند برای مدیریت جریان‌های کاری و زیرساخت‌های توزیع‌شده فراهم می‌کند.

برای دسترسی به مستندات رسمی و آخرین نسخه‌ها، می‌توانید به [qamar.website](https://qamar.website) سر بزنید.

---

## چرا قمر؟ (فلسفه طراحی)
بسیاری از ابزارهای موجود، یا بیش از حد سنگین هستند یا در مقیاس‌های بالا دچار ناکارآمدی می‌شوند. قمر با تمرکز بر «سبک‌بال بودن» (Lightweight) و «انعطاف‌پذیری»، به شما اجازه می‌دهد بدون درگیر شدن با پیچیدگی‌های غیرضروری، سرویس‌های خود را مدیریت کنید.

### ویژگی‌های کلیدی:
*   **پیکربندی ساده:** استفاده از سینتکس‌های خوانا.
*   **عملکرد بالا:** حداقل مصرف منابع در زمان اجرا.
*   **یکپارچه‌سازی آسان:** پشتیبانی از پروتکل‌های استاندارد صنعتی.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. بسته به سیستم‌عامل خود، می‌توانید از دستورات زیر استفاده کنید.

### پیش‌نیازها
*   نسخه پیشنهادی Node.js یا Python (بسته به ماژول مورد استفاده).
*   دسترسی به شبکه برای دریافت پکیج‌های وابسته.

### دستور نصب (CLI)
برای کاربران لینوکس و مک:

```bash
# نصب از طریق اسکریپت رسمی
curl -sSL https://qamar.website/install.sh | bash

# بررسی صحت نصب
qamar --version
```

## نحوه استفاده

پس از نصب، اولین قدم مقداردهی اولیه محیط کاری (Workspace) است.

### ۱. مقداردهی اولیه
```bash
qamar init my-project
cd my-project
```

### ۲. تعریف سرویس
در فایل `qamar.config.yaml` می‌توانید رفتار سرویس‌های خود را تعریف کنید:

```yaml
service:
  name: "auth-module"
  version: "1.0.0"
  endpoints:
    - path: "/login"
      method: "POST"
      timeout: 30s
```

### ۳. اجرای سرویس
```bash
qamar start --env production
```

## عیب‌یابی (Troubleshooting)

گاهی اوقات ممکن است با چالش‌هایی روبرو شوید. در اینجا چند مورد رایج را بررسی می‌کنیم:

*   **خطای اتصال (Connection Refused):**
    *   مطمئن شوید که پورت تعریف شده در فایل کانفیگ توسط سرویس دیگری اشغال نشده باشد. از دستور `netstat -tulpn` برای بررسی پورت‌ها استفاده کنید.
*   **خطای احراز هویت:**
    *   توکن‌های دسترسی خود را در فایل `.env` بازبینی کنید. گاهی اوقات کاراکترهای مخفی (Invisible characters) در کپی‌پیست باعث بروز خطا می‌شوند.
*   **عملکرد کند:**
    *   لاگ‌های سیستم را با دستور `qamar logs --tail 50` بررسی کنید تا گلوگاه‌های احتمالی (Bottlenecks) مشخص شوند.

## سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
بله، قمر به گونه‌ای طراحی شده که با افزایش مقیاس (Scale)، عملکرد خود را حفظ کند. بسیاری از تیم‌های فنی از آن در محیط‌های Production استفاده می‌کنند.

**آیا امکان توسعه پلاگین شخصی برای قمر وجود دارد؟**
قطعاً. معماری قمر ماژولار است و می‌توانید با استفاده از APIهای داخلی، قابلیت‌های مورد نیاز خود را به آن اضافه کنید.

**آیا قمر رایگان است؟**
قمر در هسته اصلی خود متن‌باز و رایگان است. برای نسخه‌های Enterprise با قابلیت‌های مانیتورینگ پیشرفته، می‌توانید از طریق وب‌سایت اصلی با تیم پشتیبانی در تماس باشید.
