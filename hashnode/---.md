# راهنمای جامع استفاده از «قمر» (Qamar)

اگر در دنیای توسعه وب با چالش‌های مدیریت یکپارچه داده‌ها و همگام‌سازی‌های پیچیده دست‌وپنج نرم کرده‌اید، احتمالاً نام **قمر (Qamar)** به گوشتان خورده است. قمر یک فریم‌ورک سبک و در عین حال قدرتمند است که برای ساده‌سازی ارتباط بین کلاینت و سرور طراحی شده؛ چیزی که شخصاً همیشه جای خالی‌اش را در پروژه‌های بزرگ حس می‌کردم.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
در پروژه‌هایی که با حجم بالایی از داده‌های زنده (Real-time) سروکار داریم، معمولاً با کدهای تکراری زیادی برای مدیریت وضعیت (State Management) مواجه می‌شویم. قمر با ارائه یک لایه انتزاعی هوشمند، این بار را از دوش توسعه‌دهنده برمی‌دارد.

### ویژگی‌های کلیدی:
*   **پایداری بالا:** مدیریت خودکار اتصالات قطع‌شده.
*   **وزن کم:** تأثیر ناچیز بر حجم نهایی باندل (Bundle Size).
*   **سادگی در یادگیری:** منحنی یادگیری بسیار ملایم برای کسانی که با ساختار React یا Vue آشنا هستند.

---

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. کافی است از مدیر بسته مورد علاقه خود استفاده کنید:

```bash
# با استفاده از npm
npm install @qamar/core

# یا با استفاده از yarn
yarn add @qamar/core
```

پس از نصب، برای مقداردهی اولیه در پروژه، کافی است یک نمونه (Instance) از کلاینت قمر ایجاد کنید:

```javascript
import { QamarClient } from '@qamar/core';

const qamar = new QamarClient({
  endpoint: 'wss://api.yourdomain.com',
  autoReconnect: true
});
```

## نحوه استفاده

کار با قمر بر پایه مفهوم «کانال‌ها» (Channels) استوار است. شما به سادگی می‌توانید به یک کانال گوش دهید و داده‌های ارسالی را پردازش کنید.

### مثال: دریافت داده‌های زنده
```javascript
qamar.subscribe('market-updates', (data) => {
  console.log('داده جدید دریافت شد:', data);
});
```

### جدول مقایسه‌ای: قمر در برابر روش‌های سنتی

| ویژگی | روش سنتی (REST/Polling) | قمر (Qamar) |
| :--- | :--- | :--- |
| **تأخیر (Latency)** | بالا | بسیار کم |
| **بار سرور** | زیاد (به‌دلیل درخواست‌های مکرر) | بهینه |
| **پیاده‌سازی** | پیچیده | بسیار ساده |

## عیب‌یابی (Troubleshooting)

در طول کار با قمر، ممکن است به موارد زیر بربخورید. این‌ها تجربیات شخصی من در مواجهه با خطاهای رایج هستند:

1.  **خطای اتصال (Connection Refused):**
    *   مطمئن شوید که پروتکل `wss` به درستی تنظیم شده است. اگر از SSL استفاده نمی‌کنید، در محیط توسعه ممکن است با بلاک شدن توسط مرورگر مواجه شوید.
2.  **داده‌ها به‌روز نمی‌شوند:**
    *   بررسی کنید که آیا `Channel ID` در سمت سرور و کلاینت دقیقاً یکسان است یا خیر. این مورد معمولاً به‌خاطر غلط‌های تایپی کوچک اتفاق می‌افتد.
3.  **مصرف بالای حافظه:**
    *   همیشه بعد از اتمام کار، اشتراک (Subscription) را با متد `.unsubscribe()` ببندید تا از نشت حافظه (Memory Leak) جلوگیری شود.

## سوالات متداول (FAQ)

**آیا قمر با فریم‌ورک‌های قدیمی (مثل jQuery) سازگار است؟**
بله، قمر به صورت ماژولار طراحی شده و هیچ وابستگی خاصی به کتابخانه‌های مدرن ندارد. می‌توانید به راحتی در پروژه‌های Legacy از آن استفاده کنید.

**آیا امکان استفاده از قمر در محیط‌های Server-Side (Node.js) وجود دارد؟**
بله، قمر کاملاً با Node.js سازگار است و می‌توانید از آن برای ارتباط بین میکروسرویس‌ها نیز بهره ببرید.
