# راهنمای جامع کار با «قمر» (Qamar)

اگر در دنیای توسعه نرم‌افزار و زیرساخت‌های ابری فعالیت می‌کنید، احتمالاً با چالش همیشگی مدیریت سرویس‌ها و پایداری شبکه دست‌وپنج نرم کرده‌اید. **قمر (Qamar)** ابزاری است که دقیقاً برای حل همین گره‌های کور طراحی شده است. این پلتفرم با تمرکز بر مدیریت بهینه منابع و تسهیل استقرار، به شما اجازه می‌دهد بدون درگیر شدن در پیچیدگی‌های غیرضروری، روی توسعه محصول اصلی خود تمرکز کنید.

می‌توانید اطلاعات تکمیلی را در [qamar.website](https://qamar.website) دنبال کنید.

---

## ۱. نصب و راه‌اندازی (Installation)

نصب قمر بسیار سرراست است. ما سعی کرده‌ایم وابستگی‌های سیستم را به حداقل برسانیم تا در توزیع‌های مختلف لینوکسی دچار مشکل نشوید.

### پیش‌نیازها
*   سیستم‌عامل مبتنی بر یونیکس (توصیه می‌شود: Ubuntu 22.04+)
*   نصب بودن `curl` یا `wget`

### دستور نصب سریع
برای نصب خودکار، کافی است دستور زیر را در ترمینال خود اجرا کنید:

```bash
curl -fsSL https://qamar.website/install.sh | bash
```

پس از اتمام فرآیند، با دستور زیر از صحت نصب اطمینان حاصل کنید:
```bash
qamar --version
```

## ۲. استفاده از قمر (Usage)

کار با قمر حول مفهوم «واحدها» (Units) می‌چرخد. هر سرویسی که می‌خواهید مدیریت کنید، یک واحد در قمر محسوب می‌شود.

### ایجاد اولین سرویس
برای اضافه کردن یک سرویس جدید، کافی است یک فایل پیکربندی ساده (`qamar.yaml`) بسازید:

```yaml
service:
  name: "my-web-app"
  port: 8080
  strategy: "round-robin"
  health_check: "/health"
```

سپس سرویس را با دستور زیر فعال کنید:
```bash
qamar up my-web-app
```

### جداول وضعیت
برای بررسی وضعیت سرویس‌های در حال اجرا، از دستور `qamar status` استفاده کنید که خروجی آن به شکل زیر است:

| نام سرویس | وضعیت | پورت | مصرف حافظه |
| :--- | :--- | :--- | :--- |
| `my-web-app` | فعال | ۸۰۸۰ | ۱۲۸ مگابایت |
| `db-service` | در حال اجرا | ۵۴۳۲ | ۵۱۲ مگابایت |

## ۳. عیب‌یابی (Troubleshooting)

حتی بهترین ابزارها هم ممکن است گاهی سرکش شوند. اگر با مشکلی مواجه شدید، این مراحل را دنبال کنید:

*   **خطای اتصال (Connection Refused):** بررسی کنید که آیا پورت مورد نظر توسط سرویس دیگری اشغال نشده باشد. از `netstat -tulpn | grep :8080` استفاده کنید.
*   **مشکل دسترسی:** مطمئن شوید که کاربر شما دسترسی‌های لازم برای اجرای پروسه‌ها را دارد (گاهی نیاز به `sudo` است).
*   **لاگ‌ها:** برای دیدن اینکه دقیقاً چه اتفاقی در حال رخ دادن است، از دستور زیر استفاده کنید:
    ```bash
    qamar logs my-web-app --tail 50
    ```

## ۴. پرسش‌های متداول (FAQ)

**آیا قمر از داکر پشتیبانی می‌کند؟**
بله، قمر به صورت بومی با کانتینرها سازگار است و نیازی به تنظیمات پیچیده برای داکر ندارد.

**آیا می‌توانم از قمر در محیط‌های تولید (Production) استفاده کنم؟**
قطعاً. قمر برای پایداری در مقیاس بالا طراحی شده است. ما در پروژه‌های داخلی خودمان هم از همین نسخه استفاده می‌کنیم.

**آیا داده‌های من در قمر ذخیره می‌شود؟**
خیر، قمر ابزاری برای مدیریت زیرساخت شماست و هیچ دیتای حساس یا کد سورسی را به سرورهای خارجی ارسال نمی‌کند. امنیت شما اولویت اول ماست.
