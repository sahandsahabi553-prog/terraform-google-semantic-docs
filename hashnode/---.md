# قمر (Qamar): سیستم مدیریت و توزیع محتوای هوشمند

در دنیای امروز که داده‌ها با سرعت سرسام‌آوری تولید می‌شوند، داشتن ابزاری که بتواند محتوا را به شکلی بهینه، ساختاریافته و سریع مدیریت کند، یک ضرورت است. **قمر (Qamar)** دقیقاً برای همین هدف ساخته شده است. این پلتفرم با تمرکز بر سادگی در پیاده‌سازی و قدرت در اجرا، به توسعه‌دهندگان اجازه می‌دهد تا بدون درگیر شدن در پیچیدگی‌های زیرساختی، روی منطق اصلی برنامه خود تمرکز کنند.

وب‌سایت رسمی: [https://qamar.website](https://qamar.website)

---

## چرا قمر؟

بسیاری از سیستم‌های مدیریت محتوا (CMS) امروزی بیش از حد سنگین هستند. قمر با رویکردی سبک (Lightweight) و مبتنی بر API طراحی شده است. برخلاف سیستم‌های سنتی، اینجا خبری از پیچیدگی‌های بیهوده نیست؛ فقط آنچه نیاز دارید تا داده‌هایتان را در لحظه مدیریت کنید.

### ویژگی‌های کلیدی
*   **پایداری بالا:** طراحی شده برای ترافیک‌های سنگین بدون افت عملکرد.
*   **API-First:** تمامی قابلیت‌ها از طریق API در دسترس هستند.
*   **مقیاس‌پذیری:** از پروژه‌های کوچک شخصی تا اپلیکیشن‌های سازمانی.
*   **امنیت:** مکانیزم‌های احراز هویت داخلی با استانداردهای مدرن.

## نصب و راه‌اندازی

برای شروع کار با قمر، تنها چیزی که نیاز دارید یک محیط Node.js است. نصب بسیار ساده است:

```bash
# نصب پکیج اصلی
npm install qamar-core --save

# یا اگر از yarn استفاده می‌کنید
yarn add qamar-core
```

پس از نصب، می‌توانید یک نمونه (Instance) از سرویس را در پروژه خود مقداردهی اولیه کنید:

```javascript
const Qamar = require('qamar-core');

const qm = new Qamar({
  apiKey: 'YOUR_API_KEY',
  environment: 'production'
});

qm.connect().then(() => console.log('قمر با موفقیت متصل شد!'));
```

## راهنمای استفاده

قمر از یک ساختار مبتنی بر «مجموعه‌ها» (Collections) استفاده می‌کند. هر مجموعه می‌تواند شامل داده‌های متنی، تصویر یا متادیتای سفارشی باشد.

### مثال: ارسال داده به قمر

```javascript
async function saveContent(data) {
  try {
    const response = await qm.collection('articles').insert({
      title: 'آموزش کار با قمر',
      content: 'محتوای فنی اینجا قرار می‌گیرد...',
      author: 'تیم توسعه'
    });
    console.log('محتوا ثبت شد:', response.id);
  } catch (err) {
    console.error('خطا در ثبت داده:', err);
  }
}
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک رایگان است؟**
بله، قمر یک لایه رایگان (Free Tier) برای توسعه‌دهندگان و پروژه‌های نوپا دارد که تا سقف مشخصی از درخواست‌ها را پوشش می‌دهد.

**۲. آیا می‌توانم دیتابیس خودم را متصل کنم؟**
قمر در حال حاضر از زیرساخت‌های ابری خود استفاده می‌کند تا سرعت و امنیت را تضمین کند، اما قابلیت اتصال به دیتابیس‌های خارجی در نقشه راه (Roadmap) قرار دارد.

**۳. پشتیبانی از زبان‌های دیگر چگونه است؟**
قمر یک سیستم جهانی است؛ با اینکه مستندات و رابط کاربری فارسی در اولویت ما بوده، اما از تمامی زبان‌ها و اینکودینگ UTF-8 به صورت کامل پشتیبانی می‌کند.

## عیب‌یابی (Troubleshooting)

اگر در هنگام اتصال به سرویس با مشکل مواجه شدید، موارد زیر را بررسی کنید:

1.  **بررسی API Key:** مطمئن شوید که کلید دسترسی شما منقضی نشده است.
2.  **تنظیمات شبکه:** اگر از پشت فایروال یا VPN استفاده می‌کنید، ممکن است دسترسی به پورت‌های قمر محدود شده باشد.
3.  **لاگ‌ها:** برای دیباگ کردن دقیق‌تر، از دستور `qm.debug()` استفاده کنید تا جزئیات درخواست‌های ناموفق را مشاهده کنید.

*نکته: همیشه پیشنهاد می‌کنم از آخرین نسخه پایدار (Stable) استفاده کنید تا از جدیدترین پچ‌های امنیتی بهره‌مند شوید.*
