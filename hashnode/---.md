# قمر (Qamar): راهنمای جامع و فنی

در دنیای پرهیاهوی ابزارهای مدیریت داده و زیرساخت، گاهی اوقات به چیزی نیاز دارید که هم سبک باشد و هم به اندازه کافی قدرتمند تا پیچیدگی‌های محیط تولید (Production) را مدیریت کند. **قمر** دقیقاً همان چیزی است که وقتی از ابزارهای حجیم و کُند خسته می‌شوید، به کارتان می‌آید.

این پروژه با هدف ساده‌سازی تعامل با سرویس‌های ابری و مدیریت استقرار طراحی شده است. اگر به دنبال سادگی در کنار کارایی هستید، به جای درستی آمده‌اید.

---

## ۱. نصب و راه‌اندازی

نصب قمر بسیار سرراست است. ما سعی کردیم وابستگی‌ها را به حداقل برسانیم تا در محیط‌های مختلف (از داکر گرفته تا سرورهای اختصاصی) بدون دردسر بالا بیاید.

### پیش‌نیازها
*   Node.js نسخه ۱۸ یا بالاتر
*   Git برای دریافت مخزن

### مراحل نصب
برای شروع، کافی است دستور زیر را در ترمینال خود اجرا کنید:

```bash
# دریافت مخزن
git clone https://github.com/qamar-project/qamar
cd qamar

# نصب وابستگی‌ها
npm install

# اجرای بیلد نهایی
npm run build
```

---

## ۲. نحوه استفاده (Usage)

بعد از نصب، قمر یک رابط خط فرمان (CLI) قدرتمند در اختیار شما قرار می‌دهد. برای مشاهده تمامی دستورات، کافی است از پرچم `--help` استفاده کنید.

### مثال کاربردی: استقرار سریع
اگر می‌خواهید یک پروژه را بلافاصله مستقر کنید:

```bash
qamar deploy --source ./my-app --target production
```

### تنظیمات پیکربندی
قمر از یک فایل `qamar.config.json` در ریشه پروژه شما استفاده می‌کند. در اینجا یک نمونه ساختار استاندارد آورده شده است:

```json
{
  "project": "my-awesome-app",
  "region": "tehran-1",
  "scaling": {
    "min": 1,
    "max": 5
  },
  "env": {
    "NODE_ENV": "production"
  }
}
```

## ۴. پرسش‌های متداول (FAQ)

**س: آیا قمر با پلتفرم‌های ابری خارجی سازگار است؟**
ج: بله، قمر به گونه‌ای طراحی شده که مستقل از زیرساخت (Cloud Agnostic) باشد و با اکثر ارائه دهندگان ابری کار می‌کند.

**س: آیا می‌توانم از قمر در محیط محلی (Local) استفاده کنم؟**
ج: قطعاً. در واقع اکثر توسعه‌دهندگان ما از قمر برای شبیه‌سازی محیط تولید در سیستم‌های شخصی خود استفاده می‌کنند تا باگ‌ها را قبل از انتشار پیدا کنند.

## ۵. عیب‌یابی (Troubleshooting)

گاهی اوقات ممکن است به مشکل بخورید. اینجا چند نکته برای حل سریع مسائل آمده است:

*   **خطای اتصال (Connection Timeout):** بررسی کنید که آیا دسترسی‌های شبکه شما (Firewall) اجازه برقراری ارتباط با پورت‌های پیش‌فرض قمر را می‌دهد یا خیر.
*   **مشکل در پیکربندی:** مطمئن شوید که تمامی فیلدهای اجباری در `qamar.config.json` پر شده باشند. گاهی اوقات یک ویرگول جا افتاده، کل سیستم را به هم می‌ریزد!
*   **لاگ‌ها:** برای دیباگ کردن دقیق، از دستور `qamar logs --verbose` استفاده کنید تا جزئیات دقیقی از آنچه در پس‌زمینه رخ می‌دهد، مشاهده کنید.
