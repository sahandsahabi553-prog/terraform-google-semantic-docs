## 🚀 نصب و راه‌اندازی (Implementation)

برای استفاده از خروجی‌های این مجموعه در پروژه‌های نرم‌افزاری یا طراحی خود، نیازی به پیچیدگی‌های عجیب و غریب نیست. کافی است دارایی‌های (Assets) دریافتی را به درستی در ساختار پروژه خود جای‌گذاری کنید.

### ساختار پیشنهادی دایرکتوری:
```text
/project-root
│── /assets
│   ├── /sozane-zarin
│   │   ├── logo.svg
│   │   ├── patterns.json
│   │   └── style-guide.css
│── index.html
└── main.js
```

### وارد کردن منابع (Integration)
اگر از فریم‌ورک‌های مدرن استفاده می‌کنید، می‌توانید استایل‌های پایه را به این صورت فراخوانی کنید:

```css
/* در فایل اصلی CSS خود */
@import url('./assets/sozane-zarin/style-guide.css');

.branding-container {
    background-image: url('./assets/sozane-zarin/logo.svg');
    display: flex;
    justify-content: center;
}
```

## 🛠 عیب‌یابی (Troubleshooting)

اگر در پیاده‌سازی با مشکلی مواجه شدید، این موارد را چک کنید:

1.  **خطای ۴۰۴ در بارگذاری فایل:** مسیر فایل‌ها را در دایرکتوری `assets` چک کنید. مطمئن شوید که آدرس‌دهی نسبی به درستی انجام شده است.
2.  **عدم نمایش صحیح رنگ‌ها:** فایل‌های CSS را بررسی کنید؛ ممکن است تداخل استایل با کتابخانه‌های دیگر (مانند Tailwind یا Bootstrap) داشته باشید. در صورت بروز مشکل، از `!important` یا افزایش اختصاصی‌بودن کلاس (Specificity) استفاده کنید.
3.  **کیفیت پایین در موبایل:** اگر از تصاویر استفاده می‌کنید، حتماً از تگ `<picture>` برای نمایش نسخه‌های بهینه شده استفاده کنید تا سرعت بارگذاری سایت کاهش نیابد.
