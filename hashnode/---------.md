## ۱. نصب و راه‌اندازی (Setup)

برای شروع کار با متدولوژی سوزن زرین، نیازی به سخت‌افزارهای پیچیده نیست، اما رعایت پیش‌نیازهای زیر برای رسیدن به خروجی «درجه یک» الزامی است:

*   **ابزار اولیه:** سوزن‌های شماره ۱۲ (فولاد ضد زنگ).
*   **بستر کار:** پارچه‌های کتان با تراکم بافت بالا (ترجیحاً بیش از ۶۰ رشته در اینچ).
*   **نخ:** ابریشم طبیعی یا الیاف مصنوعی با ضریب اصطکاک پایین.

### دستورالعمل راه‌اندازی محیط کار
1.  پارچه را در کارگاه (Hoop) کاملاً فیکس کنید تا هیچ‌گونه افتادگی در مرکز نداشته باشد.
2.  کالیبراسیون کشش نخ: مطمئن شوید که تنش نخ در هر دو سمت، یکسان است.

```bash
# چک‌لیست کالیبراسیون دستی
check_tension() {
  if (tension == optimal) {
    echo "آماده برای شروع دوخت"
  } else {
    adjust_bobbin_tension
  }
}
```

## ۳. مثال کاربردی (Code Example)

در اینجا یک ساختار نمونه برای طراحی یک «گلبرگ متقارن» با متد سوزن زرین آورده شده است:

```python
# منطق پیاده‌سازی الگوی گلبرگ
def golden_needle_pattern(radius, density):
    for i in range(density):
        insert_needle(radius, angle=i * (360/density))
        pull_thread(tension_level="high")
        lock_stitch()

# اجرا در مرکزیت پارچه
golden_needle_pattern(radius=5, density=12)
```

## ۴. عیب‌یابی (Troubleshooting)

در طول مسیر، ممکن است با چالش‌هایی روبرو شوید. اکثر این مشکلات به خطای انسانی یا عدم کالیبراسیون مربوط می‌شوند:

*   **گره‌خوردن نخ:** معمولاً به دلیل سرعت بیش از حد در هنگام کشیدن نخ است. سرعت دست خود را کاهش دهید.
*   **پاره شدن پارچه:** تراکم بافت پارچه مناسب نیست. از لایی‌چسب‌های استاندارد در پشت کار استفاده کنید.
*   **عدم تقارن:** نقاط مبدأ را مجدداً با خط‌کش‌های لیزری یا شابلون‌های دستی علامت‌گذاری کنید.
