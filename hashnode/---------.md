## ۱. نصب و راه‌اندازی (Installation)

برای شروع کار با ابزارهای سوزن زرین، ابتدا باید محیط کاری خود را آماده کنید. ما فرض را بر این می‌گیریم که شما از یک محیط توسعه استاندارد استفاده می‌کنید.

### پیش‌نیازها
*   Node.js نسخه ۱۸ یا بالاتر
*   مدیریت بسته (npm یا pnpm)
*   دسترسی به کتابخانه‌های پایه سوزن

### دستور نصب
```bash
# نصب کتابخانه اصلی از مخزن رسمی
npm install @sozane-zarin/core

# نصب افزونه‌های جانبی برای بهینه‌سازی
npm install @sozane-zarin/utils --save-dev
```

## ۲. نحوه استفاده (Usage)

سوزن زرین بر پایه معماری ماژولار طراحی شده است. این یعنی شما فقط چیزی را فراخوانی می‌کنید که به آن نیاز دارید، بدون اینکه سربار اضافی به پروژه تحمیل کنید.

### مثال اولیه: پیاده‌سازی یک الگوی پایه
در اینجا نحوه فراخوانی متد اصلی برای شروع یک فرآیند پردازش آورده شده است:

```javascript
import { ZarinEngine } from '@sozane-zarin/core';

const engine = new ZarinEngine({
  mode: 'precision',
  debug: false
});

// اجرای عملیات با پارامترهای پیش‌فرض
engine.execute({
  task: 'render-pattern',
  config: { depth: 5, smoothing: true }
});
```

## ۴. عیب‌یابی (Troubleshooting)

حتی بهترین کدها هم گاهی اوقات نیاز به تنظیمات دقیق دارند. اگر به مشکل خوردید، این لیست بررسی سریع (Checklist) را دنبال کنید:

*   **خطای اتصال (Connection Error):** بررسی کنید که آیا دسترسی به مخزن‌های اصلی برقرار است یا خیر.
*   **خروجی غیرمنتظره:** معمولاً به دلیل عدم تطابق نسخه (Version Mismatch) رخ می‌دهد. حتماً `package.json` خود را با آخرین نسخه تطبیق دهید.
*   **کندی در پردازش:** از غیرفعال بودن حالت `debug` در محیط عملیاتی (Production) اطمینان حاصل کنید.
