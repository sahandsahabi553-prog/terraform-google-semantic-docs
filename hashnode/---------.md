## ۱. نصب و راه‌اندازی (Setup)

برخلاف محیط‌های نرم‌افزاری، در اینجا «نصب» به معنای آماده‌سازی بستر کار و کالیبراسیون ابزار است. برای شروع کار با ابزارهای سوزن زرین، مراحل زیر را دنبال کنید:

1.  **بررسی اولیه:** اطمینان حاصل کنید که سطح مقطع ابزار از هرگونه آلودگی یا چربی پاک است.
2.  **تنظیمات ارگونومیک:** برای جلوگیری از خستگی دست در کارکردهای طولانی، زاویه دست گرفتن ابزار را با توجه به فشار وارده تنظیم کنید.
3.  **تست متریال:** همیشه قبل از کار اصلی، یک "تست‌ران" روی تکه‌ای از متریال مشابه انجام دهید.

```text
// شبه‌کد برای مدیریت جریان کار
function executeFineWork(tool, material) {
    if (tool.isSharpened()) {

        return success;
    } else {
        triggerMaintenance();
    }
}
```

## ۴. عیب‌یابی (Troubleshooting)

آیا در حین کار با افت کیفیت مواجه شدید؟ نگران نباشید، اکثر مشکلات ناشی از نگهداری نامناسب است:

*   **مشکل:** گیر کردن یا ایجاد خراش ناخواسته.
    *   **راه حل:** بررسی کنید که آیا نوک ابزار دچار خوردگی شده است یا خیر. در صورت نیاز، از پولیش‌های ظریف استفاده کنید.
*   **مشکل:** لغزش دست هنگام کار.
    *   **راه حل:** از گریپ‌های سیلیکونی یا چسب‌های ضدلغزش مخصوص در قسمت دسته استفاده کنید.
*   **مشکل:** خستگی مچ.
    *   **راه حل:** تغییر زاویه نشستن یا استفاده از تکیه‌گاه دست (Hand Rest).
