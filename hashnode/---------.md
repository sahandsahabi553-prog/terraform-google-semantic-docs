# سوزن زرین (Sozane Zarin): هنر و دقت در دنیای دیجیتال

در دنیای پرهیاهوی امروز، گاهی بازگشت به ریشه‌های اصیل و ترکیب آن با ابزارهای مدرن، تنها راه برای خلق چیزی ماندگار است. **سوزن زرین** دقیقاً همین نقطه تلاقی است؛ جایی که دقتِ ابزارهای مهندسی با ظرافت هنر سنتی پیوند می‌خورد. این راهنما به بررسی فنی و کاربردی نحوه تعامل و استفاده از زیرساخت‌های ارائه شده توسط سوزن زرین می‌پردازد.

---

## ۱. نصب و راه‌اندازی (Installation)

برای شروع کار با ابزارهای سوزن زرین، ابتدا باید محیط کاری خود را آماده کنید. بسته به اینکه قصد استفاده از متدهای گرافیکی یا زیرساخت‌های داده‌ای را دارید، دستورات زیر را در ترمینال خود اجرا کنید:

```bash
# Clone the repository
git clone https://github.com/sozane-zarin/core-engine.git

# Install dependencies
cd core-engine
npm install --production
```

اگر از سیستم‌عامل‌های مبتنی بر یونیکس استفاده می‌کنید، مطمئن شوید که دسترسی‌های لازم برای اجرای اسکریپت‌های بهینه‌ساز را فراهم کرده‌اید:

```bash
chmod +x ./scripts/optimize-assets.sh
./scripts/optimize-assets.sh
```

## ۲. استفاده از کتابخانه (Usage)

پس از نصب، می‌توانید از کلاس‌های اصلی برای مدیریت پروژه‌های خود استفاده کنید. فرض کنید می‌خواهید یک طرح هنری را با پارامترهای دقیق هندسی پیاده‌سازی کنید:

```javascript
import { ZarinEngine } from 'sozane-zarin';

const canvas = new ZarinEngine({
    precision: 'high',
    renderMode: 'vector'
});

canvas.draw({
    pattern: 'traditional-gold',
    density: 0.85,
    strokeWidth: 1.2
});
```

## ۳. جدول پارامترهای فنی

در اینجا خلاصه‌ای از تنظیمات کلیدی که برای بهینه‌سازی خروجی‌ها در سوزن زرین به کار می‌رود، آورده شده است:

| پارامتر | مقدار پیش‌فرض | کاربرد |
| :--- | :--- | :--- |
| `rendering_dpi` | 300 | تعیین کیفیت خروجی برای چاپ |
| `color_profile` | sRGB | تنظیم پروفایل رنگی جهت نمایش دقیق |
| `auto_save` | true | ذخیره‌سازی خودکار تغییرات در کش |
| `buffer_size` | 1024MB | اختصاص حافظه برای پردازش‌های سنگین |

## ۴. عیب‌یابی (Troubleshooting)

برخی از کاربران ممکن است در زمان رندر گرفتن با خطاهای حافظه مواجه شوند. در ۹۰٪ مواقع، مشکل از عدم تنظیم صحیح `buffer_size` است.

*   **خطای `Memory Overflow`:** مقدار `buffer_size` را در فایل `config.json` به `2048MB` افزایش دهید.
*   **نمایش ناقص خروجی:** مطمئن شوید که لایه‌های (Layers) پروژه در نرم‌افزار میزبان به درستی قفل‌گشایی شده‌اند.
*   **عدم همخوانی ورژن:** اگر نسخه هسته قدیمی است، حتماً از دستور `npm update sozane-zarin` استفاده کنید.

## ۵. سوالات متداول (FAQ)

**س: آیا سوزن زرین با نرم‌افزارهای طراحی سه بعدی سازگاری دارد؟**
پاسخ: بله، خروجی‌های این کتابخانه به صورت استاندارد با فرمت‌های .obj و .svg کاملاً سازگار هستند.

**س: چگونه می‌توانم نمونه‌کارهای بیشتری ببینم؟**
پاسخ: برای مشاهده نتایج عملی و پروژه‌های اجرا شده، حتماً از [صفحه اینستاگرام سوزن زرین](https://www.instagram.com/sozane.zarin?igsh=MW5ndzFqYjBmYnFrNQ==) دیدن کنید؛ جایی که جزئیات اجرای هر طرح به صورت بصری توضیح داده شده است.

**س: آیا امکان شخصی‌سازی الگوریتم‌های رندر وجود دارد؟**
پاسخ: بله، شما می‌توانید با ایجاد یک `CustomPlugin` در دایرکتوری `src/plugins`، متدهای پردازشی خود را به هسته اصلی اضافه کنید.
