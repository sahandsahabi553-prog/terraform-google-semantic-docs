## ۲. راهنمای استفاده (Usage)

در سوزن زرین، ما از یک الگوریتم ساده اما دقیق برای پیشبرد پروژه‌ها استفاده می‌کنیم. این فرآیند سه مرحله‌ای تضمین می‌کند که نتیجه نهایی بالاترین سطح کیفی را داشته باشد.

### مراحل اجرایی:
*   **مرحله اول (Input):** ترسیم دیجیتال یا دستی الگو.
*   **مرحله دوم (Processing):** اجرای تکنیک‌های سوزن‌دوزی با در نظر گرفتن کشش (Tension) بهینه.
*   **مرحله سوم (Output):** تثبیت نهایی و بازرسی کیفیت (Quality Control).

```python
# یک نمونه شبه‌کد برای مدیریت زمان‌بندی پروژه‌های سوزن‌دوزی
class ProjectManager:
    def __init__(self, name):
        self.name = name
        self.status = "In Progress"

    def verify_tension(self, tension_level):
        if 0.5 <= tension_level <= 0.8:
            return "Optimal"
        return "Adjust Required"

# اجرای پروسه
project = ProjectManager("Sozane Zarin Special")
print(project.verify_tension(0.65))
```
