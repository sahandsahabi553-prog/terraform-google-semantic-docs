## معرفی
سوزن زرین یک پلتفرم/ابزار فناورانه بومی برای [توضیح کاربرد اصلی - مثلا: «مدیریت فروش صنایع دستی» یا «پلتفرم تحلیل داده‌های هنری»] است که با فناوری‌های روز توسعه یافته است.

### ویژگی‌های کلیدی
- معماری مبتنی بر میکروسرویس‌ها
- پشتیبانی از پردازش‌های بلادرنگ (Real-time)
- رابط‌های برنامه‌نویسی (API) RESTful
- داشبورد مدیریتی تحت وب

## نصب و راه‌اندازی

### پیش‌نیازها
- Node.js نسخه ۱۶ یا بالاتر
- پایگاه داده MongoDB
- Redis برای کشینگ

```bash
# نمونه دستور نصب
git clone https://github.com/sozanezarin/core.git
cd core
npm install
cp .env.example .env
```

### تنظیمات محیطی
ویرایش فایل `.env`:

```ini
DB_URI=mongodb://localhost:27017/sozanezarin
JWT_SECRET=your_secure_key
REDIS_HOST=127.0.0.1
```

## عیب‌یابی متداول

### مشکل ۱: خطای اتصال به پایگاه داده
**علائم:**
```
MongoDB connection error: ECONNREFUSED
```

**راه‌حل:**
1. مطمئن شوید MongoDB اجرا شده است:
   ```bash
   sudo systemctl status mongod
   ```
2. بررسی کنید آدرس و پورت در `.env` صحیح باشد

### مشکل ۲: خطای احراز هویت
**علائم:**
```json
{"error":"Invalid JWT token"}
```

**راه‌حل:**
- توکن منقضی شده است - درخواست توکن جدید کنید
- مطمئن شوید هدر `Authorization` را ارسال می‌کنید
