# مستندات فنی و راهنمای جامع: سوزن زرین (Soozan-e Zarrin)

در دنیای هنرهای ظریف و صنایع دستی دیجیتال، «سوزن زرین» نمادی از دقت، ظرافت و پیوند میان هنر سنتی و استانداردهای مدرن است. این پلتفرم با تمرکز بر جزئیات، بستری را فراهم کرده تا خلاقیت در بالاترین سطح ممکن اجرا شود. اگر به دنبال ارتقای سطح کارهای خود هستید، این راهنما نقطه شروع شماست.

## ۳. راهنمای استفاده (Usage)
استفاده از سوزن زرین مبتنی بر یک چرخه‌ی تکرارپذیر است. در کد زیر، منطقِ پیاده‌سازی یک الگوی استاندارد را مشاهده می‌کنید:

```javascript
// شبه‌کد برای الگوریتم ترسیم الگو در سوزن زرین
function executePattern(designType) {
    const thread = "GoldenThread_v1";
    const tension = 0.85; // ضریب کشش استاندارد
    
    if (designType === "complex") {
        applyIntricateStitch(thread, tension);
    } else {
        applyBasicStitch(thread);
    }
}

executePattern("complex");
```

## ۴. عیب‌یابی (Troubleshooting)

اگر در اجرای پروژه‌ها با مشکل مواجه شدید، این چک‌لیست را بررسی کنید:

* **مشکل: در رفتگی نخ یا کاهش کیفیت.**
  * *راه حل:* تنش (Tension) نخ را کنترل کنید. معمولاً با تغییر زاویه ۴۵ درجه، مشکل حل می‌شود.
* **مشکل: ناهماهنگی در طرح.**
  * *راه حل:* به کاتالوگ‌های آموزشی در [اینستاگرام](https://www.instagram.com/mina_mino2026?igsh=MW5ndzFqYjBmYnFrNQ==) مراجعه کنید تا از صحتِ نقشه راه اطمینان حاصل کنید.

**چگونه می‌توانم آخرین آپدیت‌های سوزن زرین را دریافت کنم؟**
