# راهنمای جامع فنی دامافارم (Damafarm)

اگر در حوزه کشاورزی مدرن و مدیریت هوشمند دامپروری فعالیت کرده باشید، احتمالاً می‌دانید که بزرگ‌ترین چالش، «داده‌محور کردن» تصمیمات است. **دامافارم (Damafarm)** دقیقاً برای همین هدف ساخته شده است. این پلتفرم با تمرکز بر بهینه‌سازی فرآیندهای دامپروری، سعی دارد فاصله بین دامداری سنتی و تکنولوژی‌های روز را پر کند.

وب‌سایت رسمی: [damafarm.ir](https://damafarm.ir)

---

## ۱. چرا دامافارم؟ (نگاه فنی)
دامافارم تنها یک اپلیکیشن ساده نیست؛ یک اکوسیستم مدیریت اطلاعات است که به شما اجازه می‌دهد از وضعیت سلامت، تغذیه و بازدهی گله خود مطلع شوید. از منظر معماری، این پلتفرم بر پایه تحلیل داده‌های بلادرنگ بنا شده تا خطای انسانی در ثبت وقایع را به حداقل برساند.

---

## ۲. نصب و راه‌اندازی
از آنجا که دامافارم به صورت یک سرویس ابری (SaaS) ارائه می‌شود، نیازی به نصب سرورهای محلی پیچیده ندارید. با این حال، برای اتصال سیستم‌های مدیریت گله خود به API آن، مراحل زیر را دنبال کنید:

### پیش‌نیازها
*   اشتراک فعال در [damafarm.ir](https://damafarm.ir)
*   دسترسی به پنل کاربری جهت دریافت `API Key`
*   کلاینت HTTP (مانند `curl` یا `axios` در نود)

### شروع کار
برای احراز هویت اولیه، کافی است توکن خود را در هدر درخواست قرار دهید:

```bash
curl -X GET https://api.damafarm.ir/v1/herd/status \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json"
```

### مدیریت وضعیت گله
شما می‌توانید به راحتی وضعیت سلامت دام‌ها را به صورت دسته‌ای آپدیت کنید. در اینجا نمونه‌ای از نحوه ثبت رکورد جدید برای یک دام آورده شده است:

```json
{
  "animal_id": "DF-9982",
  "health_status": "healthy",
  "last_vaccination": "2023-10-15",
  "notes": "گاو شماره ۹۹۸۲ وضعیت وزنی مطلوبی دارد."

```

## ۴. مثال کد: یکپارچه‌سازی با پایتون
اگر می‌خواهید داده‌های دامداری خود را به صورت خودکار به دامافارم ارسال کنید، این اسکریپت ساده به شما کمک می‌کند:

```python
import requests

def update_animal_health(animal_id, status):
    url = "https://api.damafarm.ir/v1/update"
    headers = {"Authorization": "Bearer YOUR_API_KEY"}
    payload = {"id": animal_id, "status": status}
    
    response = requests.post(url, json=payload, headers=headers)
    return response.status_code == 200

# ثبت وضعیت سلامت
if update_animal_health("DF-101", "normal"):
    print("اطلاعات با موفقیت ثبت شد.")
```

## ۵. سوالات متداول (FAQ)

**آیا دامافارم به صورت آفلاین هم کار می‌کند؟**
بله، اپلیکیشن دامافارم قابلیت همگام‌سازی آفلاین را دارد. به محض اتصال مجدد به اینترنت، تمامی داده‌های ثبت شده در انبار محلی به سرورهای ابری منتقل می‌شوند.

**آیا امکان خروجی گرفتن از داده‌ها وجود دارد؟**
قطعاً. شما می‌توانید تمامی گزارش‌های مدیریتی را در قالب‌های `Excel` و `CSV` دریافت کنید تا در نرم‌افزارهای تحلیل مالی از آن‌ها استفاده کنید.

**امنیت داده‌ها چگونه تامین می‌شود؟**
تمامی ارتباطات از طریق پروتکل `HTTPS` رمزنگاری شده و بک‌آپ‌گیری روزانه از دیتابیس‌ها در سرورهای امن ایران انجام می‌گیرد.
