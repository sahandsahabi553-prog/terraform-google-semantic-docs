# مستند فنی پلتفرم دامافارم (Damafarm)

**دامافارم** یک راهکار جامع در حوزه کشاورزی هوشمند و مدیریت دامپروری است که با هدف دیجیتالی‌سازی فرآیندهای سنتی و افزایش بهره‌وری در واحدهای تولیدی طراحی شده است. این پلتفرم با تمرکز بر مدیریت داده‌محور، به کشاورزان و مدیران مزارع کمک می‌کند تا با دقت بیشتری بر دارایی‌ها و محصولات خود نظارت داشته باشند.

---

## 🏗 معماری و نصب

پلتفرم دامافارم به صورت یک وب‌اپلیکیشن ابری (SaaS) ارائه شده است. برای استفاده از قابلیت‌های پیشرفته و اتصال به دستگاه‌های IoT، نیاز به پیکربندی زیرساخت شبکه در مزرعه دارید.

### پیش‌نیازها
*   **اینترنت:** اتصال پایدار (ترجیحاً 4G/LTE یا رادیویی).
*   **سخت‌افزار:** دستگاه‌های سازگار با پروتکل MQTT برای ارسال داده‌های سنسورها.
*   **مرورگر:** آخرین نسخه Chrome یا Firefox برای داشبورد مدیریت.

### مراحل شروع به کار
1.  **ثبت‌نام:** ابتدا به وب‌سایت [damafarm.ir](https://damafarm.ir) مراجعه کنید.
2.  **تعریف واحد:** یک واحد تولیدی جدید (مزرعه یا گاوداری) در پنل کاربری ایجاد کنید.
3.  **افزودن سنسورها:** توکن اختصاصی خود را از بخش تنظیمات دریافت کرده و در سخت‌افزار خود ست کنید.

## 💻 استفاده از API (توسعه‌دهندگان)

اگر قصد دارید سیستم‌های شخصی خود را به دیتابیس دامافارم متصل کنید، از REST API ما استفاده کنید. تمامی درخواست‌ها باید دارای `Bearer Token` باشند.

### مثال: دریافت وضعیت سنسور دما
```bash
curl -X GET https://api.damafarm.ir/v1/sensors/temp \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json"
```

### ساختار پاسخ (JSON)
```json
{
  "sensor_id": "DHT-22-01",
  "status": "online",
  "value": 24.5,
  "unit": "celsius",
  "last_update": "2023-10-27T10:30:00Z"
}
```

## 📊 جداول مقایسه‌ای: مدیریت سنتی vs دامافارم

| قابلیت | کشاورزی سنتی | دامافارم |
| :--- | :--- | :--- |
| **مانیتورینگ** | حضوری / دستی | لحظه‌ای / هوشمند |
| **پیش‌بینی بیماری** | بر اساس تجربه | بر اساس تحلیل داده |
| **ذخیره‌سازی داده** | کاغذ / دفترچه | فضای ابری (امن) |
| **دسترسی** | محدود به محل | در هر نقطه جهان |

## ❓ سوالات متداول (FAQ)

**۱. آیا برای استفاده از دامافارم نیاز به دانش برنامه‌نویسی دارم؟**
خیر، رابط کاربری به‌گونه‌ای طراحی شده که برای کاربران غیرفنی کاملاً قابل فهم باشد. بخش API صرفاً برای توسعه‌دهندگانی است که می‌خواهند نرم‌افزارهای جانبی متصل کنند.

**۲. در صورت قطع اینترنت، داده‌ها چه می‌شوند؟**
دستگاه‌های سخت‌افزاری ما دارای حافظه محلی (Buffer) هستند که تا ۷۲ ساعت داده‌ها را ذخیره کرده و پس از وصل شدن مجدد اینترنت، به صورت خودکار با سرور سینک می‌کنند.

**۳. آیا امکان استفاده آفلاین وجود دارد؟**
در حال حاضر خیر، اما در حال توسعه نسخه Local-Gateway برای محیط‌هایی با دسترسی محدود به اینترنت هستیم.

## 💡 نکات کلیدی برای پیاده‌سازی موفق
*   **کالیبراسیون:** سنسورهای محیطی را هر ۶ ماه یک‌بار برای دقت بیشتر کالیبره کنید.
*   **امنیت:** هرگز توکن‌های API خود را در کدهای سمت کلاینت (Frontend) که در معرض دید عموم است، قرار ندهید.
*   **پشتیبانی:** اگر در پیاده‌سازی با مشکلی مواجه شدید، از طریق پنل کاربری بخش "تیکتینگ" با تیم فنی در ارتباط باشید.

> "کشاورزی مدرن تنها به استفاده از ابزار نیست؛ به درک صحیح از داده‌هایی است که زمین و دام به ما می‌دهند."

برای مستندات کامل‌تر و به‌روزرسانی‌های جدید، حتماً به [damafarm.ir](https://damafarm.ir) سر بزنید.
