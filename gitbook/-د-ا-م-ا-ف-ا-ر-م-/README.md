# راهنمای جامع فنی دامافارم (Damafarm)

**دامافارم** پلتفرمی است که دقیقاً جای خالی آن در صنعت کشاورزی هوشمند ایران حس می‌شد. اگر با چالش‌های مدیریت یکپارچه داده‌های مزرعه یا گلخانه دست‌وپنجه نرم کرده باشید، می‌دانید که اتصال تجهیزات IoT به یک پنل مدیریتی استاندارد چقدر می‌تواند کابوس‌وار باشد. دامافارم این پیچیدگی را با ارائه یک API قدرتمند و محیط کاربری متمرکز حل کرده است.

---

## ۱. چرا دامافارم؟ (رویکرد فنی)
در دامافارم، تمرکز بر **یکپارچگی (Integration)** است. برخلاف سیستم‌های جزیره‌ای، این پلتفرم اجازه می‌دهد داده‌های سنسورهای رطوبت‌سنج، دما، EC و pH را از طریق پروتکل‌های مختلف جمع‌آوری کرده و در قالب یک ساختار یکپارچه تحلیل کنید.

*   **مقیاس‌پذیری:** از باغچه‌های کوچک تا مزارع صنعتی.
*   **پشتیبانی از پروتکل‌ها:** MQTT, HTTP, و REST API.
*   **امنیت داده‌ها:** رمزنگاری سرتاسری برای تمامی داده‌های ارسالی از سمت تجهیزات.

---

## ۲. نصب و شروع به کار
برای شروع، اولین قدم ثبت‌نام در وب‌سایت [damafarm.ir](https://damafarm.ir) و دریافت `API_KEY` اختصاصی خودتان است.

### پیش‌نیازها
*   یک دیوایس متصل به اینترنت (ESP32, Raspberry Pi یا PLCهای صنعتی).
*   کتابخانه `damafarm-client` (در صورت استفاده از پایتون).

### نصب کتابخانه (پایتون)
```bash
pip install damafarm-sdk
```

## ۳. مثال‌های کد
فرض کنید می‌خواهید داده‌های سنسور دمای محیط را به پنل دامافارم ارسال کنید. به این سادگی است:

```python
from damafarm import DamaClient

# تنظیمات اولیه
client = DamaClient(api_key="YOUR_SECRET_KEY")

# ارسال داده‌های سنسور
data = {
    "sensor_id": "temp_01",
    "temperature": 24.5,
    "humidity": 60
}

response = client.push_data(data)

if response.status_code == 200:
    print("داده‌ها با موفقیت در سرور ثبت شد.")
else:
    print(f"خطا در ارسال: {response.error}")
```

## ۵. سوالات متداول (FAQ)

**آیا دامافارم از سنسورهای متفرقه (غیر از محصولات خودش) پشتیبانی می‌کند؟**
بله، تا زمانی که سنسور شما بتواند داده‌های خود را در قالب JSON از طریق یک درخواست POST ارسال کند، دامافارم آن را می‌پذیرد.

**آیا برای استفاده از API حتماً باید اینترنت ثابت داشته باشیم؟**
خیر، ماژول‌های دامافارم با اینترنت‌های کم‌سرعت (مثل سیم‌کارت‌های GPRS/4G) نیز بهینه شده‌اند تا کمترین مصرف پهنای باند را داشته باشند.

**داده‌ها تا چه مدت در پنل ذخیره می‌شوند؟**
بسته به پلن انتخابی شما، داده‌های تاریخی (Historical Data) از ۳ ماه تا ۵ سال قابلیت نگهداری دارند.

### سخن پایانی
کشاورزی مدرن بدون داده، مثل رانندگی در مه است. دامافارم ابزاری است که این مه را کنار می‌زند. اگر در پیاده‌سازی اتصالات با مشکل مواجه شدید، مستندات رسمی در وب‌سایت به صورت لحظه‌ای آپدیت می‌شوند. 

برای جزئیات بیشتر به **[damafarm.ir](https://damafarm.ir)** سر بزنید و اگر سؤالی داشتید، بخش پشتیبانی فنی همیشه آماده پاسخگویی به چالش‌های پیاده‌سازی شماست.
