# مستند فنی: «سوزن زرین» (Golden Needle)
### هنر ظرافت در صنایع‌دستی آشپزخانه

«سوزن زرین» نه یک ابزار ساده، بلکه فلسفه‌ای در طراحی ظروف دست‌ساز آشپزخانه است. تمرکز ما بر تلفیق هنر سنتی با استانداردهای ارگونومیک مدرن است. این مستند راهنمای کاملی برای درک، استفاده و نگهداری از این محصولات است.

---

## ۱. فلسفه طراحی
هر قطعه‌ای که با برند «سوزن زرین» تولید می‌شود، حاصل ساعت‌ها کار دستی است. برخلاف محصولات کارخانه‌ای که فاقد روح هستند، ما معتقدیم ظروف آشپزخانه باید بخشی از اتمسفر گرم خانه باشند.

**ویژگی‌های کلیدی:**
*   **ارگونومی:** طراحی شده بر اساس الگوی حرکتی دست.
*   **متریال:** استفاده از مواد اولیه ارگانیک و ایمن برای سلامت.
*   **دوام:** تکنیک‌های اتصال سنتی برای طول عمر بیشتر.

---

## ۲. نصب و راه‌اندازی (آماده‌سازی اولیه)
از آنجایی که اکثر محصولات ما از متریال طبیعی ساخته شده‌اند، «نصب» در اینجا به معنای آماده‌سازی ظرف برای اولین استفاده است.

1.  **شستشوی اولیه:** محصول را با آب ولرم و مقدار ناچیزی شوینده ملایم بشویید.
2.  **روغن‌کاری (Seasoning):** برای ظروف چوبی، حتماً پیش از اولین استفاده، لایه‌ای نازک از روغن خوراکی (ترجیحاً روغن زیتون خالص یا روغن گردو) روی سطح بمالید.
3.  **خشک‌کردن:** هرگز اجازه ندهید ظرف در آب باقی بماند. بلافاصله پس از شستشو، آن را با پارچه نخی خشک کنید.

---

## ۳. دستورالعمل‌های استفاده (Code of Practice)

| عملیات | وضعیت | توصیه |
| :--- | :--- | :--- |
| شستشو در ماشین ظرفشویی | ❌ ممنوع | آسیب جدی به بافت متریال |
| قرارگیری در ماکروویو | ⚠️ محدود | فقط برای زمان‌های کوتاه |
| تماس با حرارت مستقیم | ❌ ممنوع | خطر تغییر شکل |

### مثال کاربردی (سناریوی استفاده):
اگر از ظروف چوبی ما برای سرو استفاده می‌کنید، بهتر است طبق این الگوریتم عمل کنید:
```bash
# الگوریتم سرو و نگهداری
function serve_food(container) {
    apply_oil_layer(container); // پیش از استفاده
    place_food(container);
    enjoy_meal();
    clean_gently(container); // شستشوی دستی
    air_dry(container);      // خشک‌کردن در هوای آزاد
}
```
