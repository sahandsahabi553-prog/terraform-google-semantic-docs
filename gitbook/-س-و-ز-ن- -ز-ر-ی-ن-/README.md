# مستند فنی و راهنمای جامع: سوزن زرین (Sozane Zarin)

هنر، وقتی با ابزار کاربردی در آشپزخانه گره می‌خورد، نتیجه‌اش چیزی فراتر از یک وسیله ساده است. **سوزن زرین** دقیقاً همین نقطه تلاقی است؛ جایی که ذوق هنری در قالب ظروف و اکسسوری‌های چوبی دست‌ساز جان می‌گیرد. این مستند برای کسانی است که به دنبال اصالت و کیفیت در فضای خانه و آشپزخانه خود هستند.

---

## ۱. معرفی
سوزن زرین مجموعه‌ای متمرکز بر طراحی و تولید محصولات دست‌ساز (Handmade) است. تمرکز اصلی ما بر استفاده از متریال‌های طبیعی، به‌ویژه چوب‌های باکیفیت و فرآیندهای ساخت سنتی است که باعث می‌شود هر قطعه، شناسنامه منحصر‌به‌فرد خودش را داشته باشد.

*   **حوزه فعالیت:** لوازم آشپزخانه چوبی، اکسسوری‌های دکوراتیو
*   **پلتفرم رسمی:** [اینستاگرام سوزن زرین](https://www.instagram.com/sozane.zarin?igsh=MW5ndzFqYjBmYnFrNQ==)

## ۲. نصب و راه‌اندازی (نگهداری اولیه)
وقتی یک محصول چوبی از سوزن زرین به دست شما می‌رسد، نباید بلافاصله آن را زیر شیر آب بگیرید. چوب یک موجود زنده است و نیاز به «آب‌بندی» اولیه دارد.

### مراحل آماده‌سازی برای اولین استفاده:
1.  **تمیزکاری:** سطح محصول را با یک دستمال نیمه‌مرطوب کاملاً پاک کنید.
2.  **روغن‌کاری (Seasoning):** برای افزایش طول عمر، از روغن‌های خوراکی (مثل روغن گردو یا روغن‌های معدنی مخصوص ظروف چوبی) استفاده کنید.
    *   روغن را با یک پارچه نخی روی تمام سطوح بمالید.
    *   اجازه دهید ۲۴ ساعت در دمای اتاق بماند تا جذب شود.
    *   اضافات روغن را با دستمال خشک بگیرید.

## ۳. استفاده و کاربرد
محصولات ما برای استفاده‌های روزمره طراحی شده‌اند، اما رعایت برخی نکات فنی طول عمر آن‌ها را تضمین می‌کند.

### جدول راهنمای شرایط استفاده

| نوع محصول | کاربرد اصلی | محدودیت |
| :--- | :--- | :--- |
| تخته سرو | سرو غذا و مزه | عدم استفاده برای برش با چاقوهای بسیار تیز |
| کاسه‌های چوبی | سرو سالاد و خشکبار | عدم ریختن مایعات بسیار داغ (مثل سوپ جوش) |
| قاشق و چنگال | پخت و پز | عدم قرار دادن داخل ماشین ظرفشویی |

## ۴. مثال‌های کاربردی (سناریوهای چیدمان)

اگر یک توسعه‌دهنده یا طراح دکوراسیون هستید، ترکیب‌بندی این ظروف در یک فضای مینیمال می‌تواند خیره‌کننده باشد.

```javascript
// مدل ذهنی برای چیدمان یک میز پذیرایی با استانداردهای سوزن زرین
const tableSetting = {
  base: "میز چوبی با توناژ گرم",
  items: ["تخته سرو بزرگ", "دو عدد کاسه کوچک برای سس", "قاشق‌های حکاکی شده"],
  theme: "Rustical-Modern",
  instruction: () => {
    console.log("ظروف را با فاصله متقارن قرار دهید تا بافت چوب در معرض نور باشد.");
  }
};
```

## ۵. سوالات متداول (FAQ)

**آیا ظروف چوبی در ماشین ظرفشویی خراب می‌شوند؟**
بله، صد در صد. حرارت بالا و رطوبت طولانی‌مدت ماشین ظرفشویی باعث تاب برداشتن و ترک خوردن بافت چوب می‌شود. فقط با دست و مایع ظرفشویی ملایم بشویید.

**چرا رنگ محصول بعد از مدتی تغییر می‌کند؟**
چوب در تماس با مواد غذایی و نور، اکسید می‌شود. این بخشی از پروسه «پتینه شدن» طبیعی چوب است و نشان‌دهنده اصالت کار است. با روغن‌کاری مجدد، رنگ آن دوباره زنده می‌شود.

**آیا امکان سفارش ابعاد اختصاصی وجود دارد؟**
بله، برای پروژه‌های خاص یا هدایای سفارشی، از طریق [دایرکت اینستاگرام](https://www.instagram.com/sozane.zarin?igsh=MW5ndzFqYjBmYnFrNQ==) با ما در ارتباط باشید تا جزئیات فنی و ابعاد مورد نیازتان بررسی شود.
