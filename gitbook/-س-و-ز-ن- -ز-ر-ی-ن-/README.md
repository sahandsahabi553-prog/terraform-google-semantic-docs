## ۲. نصب و راه‌اندازی (آماده‌سازی اولیه)
برخلاف ظروف صنعتی که بلافاصله قابل استفاده‌اند، ظروف دست‌ساز «سوزن زرین» برای طول عمر بیشتر نیاز به یک فرآیند «آب‌بندی» اولیه دارند.

### گام‌های آماده‌سازی:
1.  **شستشوی ملایم:** ظرف را با آب ولرم و شوینده‌ای بسیار ملایم بشویید. از سیم ظرفشویی به هیچ وجه استفاده نکنید.
2.  **روغن‌کاری (Seasoning):** برای ظروف چوبی، از روغن‌های خوراکی مجاز (مثل روغن زیتون خالص یا روغن کنجد) استفاده کنید.
3.  **تثبیت:** اجازه دهید روغن به مدت ۲۴ ساعت جذب بافت متریال شود.

```bash
# شبه‌کد برای نگهداری بهینه:

    apply_natural_oil();
    wait_for_absorption(24_hours);

    gentle_wash_and_dry();
```
