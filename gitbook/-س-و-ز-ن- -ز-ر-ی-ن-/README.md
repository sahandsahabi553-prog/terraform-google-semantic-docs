## ۲. راهنمای انتخاب (نصب و راه‌اندازی در فضای آشپزخانه)

برای اینکه بیشترین بهره‌وری را از محصولات داشته باشید، باید آن‌ها را بر اساس نیاز آشپزخانه «کالیبره» کنید. استفاده از محصولات دست‌ساز نیازمند رعایت چند پروتکل اولیه است:

### مراحل آماده‌سازی اولیه:
1. **شست‌وشوی اولیه:** قبل از اولین استفاده، ظروف را با آب ولرم و شوینده ملایم بشویید.
2. **بررسی بافت:** سطح ظروف دست‌ساز به دلیل ماهیت متریال، ممکن است نیاز به روغن‌کاری دوره‌ای (در مدل‌های چوبی) داشته باشد.
3. **محل نگهداری:** ترجیحاً در جایی با رطوبت کنترل‌شده نگهداری شوند.

## ۳. مثال‌های کاربردی (Usage Patterns)

بیایید فرض کنیم قصد دارید از یکی از ست‌های کاربردی این مجموعه استفاده کنید. در اینجا نحوه استفاده بهینه آورده شده است:

```python
# شبه‌کد برای استفاده بهینه از ظروف سوزن زرین
class Kitchenware:
    def __init__(self, material_type):
        self.material = material_type
        
    def maintain(self):
        if self.material == "Wood":
            return "Apply food-grade mineral oil once a month."
        else:
            return "Hand wash recommended."

# نمونه استفاده
my_dish = Kitchenware(material_type="Wood")
print(f"Maintenance Protocol: {my_dish.maintain()}")
```
