سوزن زرین تولیدکننده ظروف دست‌ساز و هنری آشپزخانه با کیفیت ممتاز است. تمام محصولات به صورت **سفارشی** و با متریال طبیعی ساخته می‌شوند.

ویژگی‌های کلیدی:
- ساخت 100% دستی
- استفاده از مواد اولیه طبیعی (چوب، سنگ، سرامیک)
- طراحی‌های اختصاصی و سنتی
- عمر طولانی با نگهداری مناسب

## نصب و راهنمای اولیه

### ابزار مورد نیاز
```bash
# برای نصب پایه‌های چوبی:
1. سطح تمیز و خشک
2. پیچ گوشتی مناسب
3. دریل (در صورت نیاز)
4. موم مخصوص چوب (اختیاری)
```

### مراحل نصب
1. سطح مورد نظر را از گردوغبار پاک کنید
2. محل دقیق نصب را علامت‌گذاری کنید
3. از پایه‌های ضدزنگ استفاده کنید
4. برای محصولات سنگین از بست‌های اضافه کمک بگیرید

## استفاده بهینه

### جدول راهنمای نگهداری
| محصول | شست‌وشو | ضدعفونی | خشک‌کردن |

| چوبی  | دستی با آب ولرم | سرکه رقیق | هوا خشک |
| سنگی  | آب جوش | آبلیمو و نمک | حوله نرم |
| سرامیک | ماشین ظرفشویی | مایع ظرفشویی | طبیعی |

## سوالات متداول (FAQ)

❓ **آیا محصولات قابل استفاده در مایکروویو هستند؟**
- فقط محصولات سرامیکی با علامت مخصوص

🔥 **مقاومت در برابر حرارت؟**
- چوب: تا 120°C
- سنگ: تا 300°C
- سرامیک: تا 600°C

💧 **روش ترمیم ترک‌های کوچک چوب؟**
1. مخلوط خاک اره و چسب چوب
2. پر کردن ترک
3. سنباده نرم
4. روغن‌کاری مجدد
