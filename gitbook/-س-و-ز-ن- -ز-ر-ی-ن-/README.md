## ۱. فلسفه طراحی
محصولات سوزن زرین بر پایه استانداردهای ارگونومی شخصی‌سازی‌شده و متریال‌های طبیعی (عمدتاً چوب‌های سخت و مقاوم) ساخته شده‌اند. برخلاف محصولات کارخانه‌ای، هر قطعه دارای یک «امضای بافتی» منحصر‌به‌فرد است.

### مشخصات فنی متریال
| ویژگی | توضیحات |
| :--- | :--- |
| **نوع چوب** | چوب‌های جنگلی مقاوم (گردو، راش، عناب) |
| **پوشش سطحی** | روغن‌های گیاهی خوراکی (Food-safe) |
| **مقاومت حرارتی** | بهینه برای استفاده روزمره (تا ۸۰ درجه سانتی‌گراد) |
| **تعمیرپذیری** | بالا (قابلیت سنباده‌زنی و روغن‌کاری مجدد) |

---

## ۲. نصب و راه‌اندازی (مراحل آماده‌سازی)
برخلاف ابزارهای دیجیتال، این محصولات نیاز به "نصب" به معنای رایج ندارند، اما برای افزایش طول عمر، باید فرآیند «آماده‌سازی اولیه» را طی کنند.

1. **شستشوی اولیه:** محصول را با یک دستمال مرطوب و بدون مواد شوینده قوی پاک کنید.
2. **روغن‌کاری (Seasoning):** قبل از اولین استفاده، یک لایه نازک روغن زیتون یا روغن گردوی خوراکی روی سطح بمالید.
3. **زمان استراحت:** اجازه دهید ۲۴ ساعت روغن جذب بافت چوب شود.

## ۳. راهنمای استفاده (Best Practices)

برای اینکه محصولات «سوزن زرین» نسل‌ها در آشپزخانه شما باقی بمانند، رعایت این پروتکل‌ها الزامی است:

### کد مرجع: الگوریتم نگهداری صحیح
```python
def maintenance_protocol(item):
    if item.is_wet():
        dry_with_towel(item) # هرگز در آب غوطه‌ور نکنید
    
    if item.surface_looks_dry():
        apply_food_grade_oil(item) # احیای بافت چوب
        
    avoid(dishwasher) # ممنوعیت مطلق ماشین ظرفشویی
    avoid(microwave)  # جلوگیری از ترک خوردن ساختار
```

## ۵. سوالات متداول (FAQ)

**س: آیا می‌توانم ظروف را در ماشین ظرفشویی بشویم؟**
پاسخ: به هیچ وجه! حرارت بالا و رطوبت مداوم ماشین ظرفشویی باعث تاب برداشتن و ترک خوردن چوب می‌شود. همیشه با دست بشویید.

**س: اگر سطح ظرف کدر شد چه کنم؟**
پاسخ: این یک رفتار طبیعی چوب است. کافیست با یک سمباده بسیار نرم (نمره ۱۰۰۰ به بالا) سطح را کمی پولیش کنید و دوباره با روغن گیاهی چرب کنید. ظرف شما مثل روز اول می‌شود.

**س: آیا این ظروف برای همه مواد غذایی مناسب هستند؟**
پاسخ: بله، اما بهتر است از مواد دارای رنگ‌دانه بسیار قوی (مثل زردچوبه غلیظ) برای طولانی‌مدت در ظروف با رنگ روشن استفاده نکنید تا ظاهر آن تغییر نکند.
