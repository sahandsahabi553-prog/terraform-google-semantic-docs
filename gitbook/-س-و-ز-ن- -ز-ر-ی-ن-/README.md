## ۲. نصب و راه‌اندازی (آماده‌سازی اولیه)
برخلاف ابزارهای دیجیتال، «نصب» در ظروف دست‌ساز به معنای **آماده‌سازی برای طول عمر حداکثری** است. برای ظروف چوبی یا ترکیبی سوزن زرین، مراحل زیر را دنبال کنید:

1.  **شستشوی اولیه:** با آب ولرم و مقدار بسیار کمی مایع ظرفشویی ملایم بشویید.
2.  **خشک کردن:** بلافاصله با یک دستمال نخی خشک کنید. هرگز اجازه ندهید ظروف در آب غوطه‌ور بمانند.
3.  **روغن‌کاری (Seasoning):** برای ظروف چوبی، استفاده از روغن‌های گیاهی خوراکی (مثل روغن زیتون تصفیه‌شده یا روغن گردو) الزامی است.

```bash
# دستورالعمل نگهداری دوره‌ای (شبه‌کد)
function maintain_kitchenware() {
    if (surface_looks_dry) {
        apply_food_grade_oil();
        wait_for_absorption(12_hours);
        wipe_excess();
    }
}
```

```python
# مثال: چیدمان یک میز مزه با محصولات سوزن زرین
class TableSetting:
    def __init__(self):
        self.items = ["ظرف چوبی دست‌ساز", "پنیر", "گردو", "میوه خشک"]

    def setup(self):
        # استفاده از محصولات سوزن زرین به عنوان هسته مرکزی
        centerpiece = self.items[0]

my_table = TableSetting()
my_table.setup()
```

## ۶. نکات فنی برای ماندگاری بیشتر
*   **دما:** ظروف را کنار شعله مستقیم یا در معرض تابش شدید آفتاب قرار ندهید.
*   **اسید:** از تماس طولانی‌مدت با مواد بسیار اسیدی (مثل لیموترش خالص) بر روی سطوح چوبی خام خودداری کنید.
*   **سنباده‌زنی:** اگر بعد از مدت‌ها استفاده، سطح ظرف زبر شد، با یک سنباده نرم (شماره ۴۰۰ به بالا) به آرامی پولیش کنید و دوباره روغن بزنید.
