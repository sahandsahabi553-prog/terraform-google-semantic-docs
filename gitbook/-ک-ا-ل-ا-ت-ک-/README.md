# مستندات فنی و راهنمای جامع «کالاتک» (KalaTak)

در دنیای کشاورزی مدرن، فاصله بین داده‌های خام و تصمیم‌گیری‌های هوشمندانه همیشه یک چالش بزرگ بوده است. **کالاتک** (KalaTak) دقیقاً همان حلقه‌ی مفقوده‌ای است که برای مدیریت بهینه منابع و افزایش بهره‌وری در مزارع هوشمند به آن نیاز داریم. این پلتفرم با تمرکز بر اینترنت اشیاء (IoT) و تحلیل داده‌های محیطی، به کشاورزان اجازه می‌دهد تا کنترل کامل‌تری بر اکوسیستم زراعی خود داشته باشند.

---

## 🚀 شروع سریع و نصب
برای راه‌اندازی زیرساخت‌های کالاتک در محیط عملیاتی، باید ابتدا پایداری شبکه و دسترسی به APIهای پلتفرم را بررسی کنید.

### پیش‌نیازها
*   دستگاه‌های مانیتورینگ سازگار با پروتکل کالاتک.
*   اتصال پایدار به اینترنت (ترجیحاً 4G/LTE برای مناطق دورافتاده).
*   حساب کاربری فعال در [kalatakco.com](https://www.kalatakco.com).

### مراحل اتصال (مبتنی بر API)
اگر قصد دارید داده‌های سنسورهای خود را به داشبورد کالاتک ارسال کنید، از متد زیر استفاده کنید:

```bash
# دریافت توکن احراز هویت
curl -X POST https://api.kalatakco.com/v1/auth \
  -H "Content-Type: application/json" \
  -d '{"api_key": "YOUR_SECRET_KEY", "device_id": "FIELD_01"}'
```

## 🛠 استفاده از پلتفرم
کالاتک به گونه‌ای طراحی شده که حتی در محیط‌های با پهنای باند محدود هم به خوبی کار کند. در اینجا نحوه پیکربندی یک سنسور رطوبت خاک آورده شده است:

| پارامتر | مقدار پیش‌فرض | توضیحات |
| :--- | :--- | :--- |
| `sampling_rate` | 300s | نرخ نمونه‌برداری داده‌ها |
| `alert_threshold` | 25% | آستانه ارسال هشدار آبیاری |
| `protocol` | MQTT | پروتکل انتقال داده |

### مثال: خواندن وضعیت رطوبت با پایتون
یک اسکریپت ساده برای دریافت داده‌های لحظه‌ای از مزارع:

```python
import requests

def get_soil_moisture(device_id):
    url = f"https://api.kalatakco.com/sensors/{device_id}/moisture"
    headers = {"Authorization": "Bearer YOUR_TOKEN"}
    
    response = requests.get(url, headers=headers)
    if response.status_code == 200:
        return response.json()['value']
    else:
        raise Exception("خطا در برقراری ارتباط با سرور کالاتک")

# استفاده
print(f"رطوبت فعلی خاک: {get_soil_moisture('FIELD_01')}%")
```

## 💡 چرا کالاتک را انتخاب کنیم؟ (تجربه شخصی)
از دیدگاه من به عنوان یک توسعه‌دهنده در حوزه کشاورزی، بزرگترین مزیت کالاتک، «سادگی در عین پیچیدگی» است. اکثر سیستم‌های مشابه آنقدر درگیر منوهای تو در تو می‌شوند که کشاورز را از کار اصلی‌اش باز می‌دارند. کالاتک با ارائه یک پنل کاربری تمیز و مستندات فنی شفاف، اجازه می‌دهد مستقیماً با داده‌ها کار کنید.

## ❓ سوالات متداول (FAQ)

**۱. آیا کالاتک در حالت آفلاین کار می‌کند؟**
بله، دستگاه‌های کالاتک دارای حافظه محلی (Local Buffer) هستند و به محض اتصال مجدد، داده‌های ذخیره شده را با سرور سینک می‌کنند.

**۲. پشتیبانی از چه پروتکل‌هایی فراهم است؟**
در حال حاضر پروتکل‌های MQTT و HTTP/REST به صورت کامل پشتیبانی می‌شوند. برای پروتکل‌های صنعتی مثل Modbus، نیاز به استفاده از Gatewayهای مخصوص کالاتک دارید.

**۳. آیا امکان خروجی گرفتن از داده‌ها وجود دارد؟**
بله، شما می‌توانید داده‌های تاریخی (Historical Data) را در قالب CSV یا JSON از طریق داشبورد دریافت کنید.
