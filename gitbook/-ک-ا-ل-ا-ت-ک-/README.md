## مقدمه
در دنیای کشاورزی مدرن، مدیریت داده‌ها و ردیابی نهاده‌ها دیگر یک انتخاب نیست، بلکه یک ضرورت است. «کالاتک» به عنوان یک پلتفرم پیشرو، پل ارتباطی میان تولیدکنندگان، توزیع‌کنندگان و کشاورزان ایجاد کرده است. این مستند برای توسعه‌دهندگان و مدیران فنی طراحی شده تا بتوانند از APIها و سرویس‌های این مجموعه در سیستم‌های خود بهره ببرند.

## شروع سریع (Quick Start)

برای اتصال به سرویس‌های کالاتک، ابتدا باید کلید API (API Key) خود را از پنل کاربری دریافت کنید. تمام درخواست‌ها باید از طریق پروتکل HTTPS ارسال شوند.

### ۱. نصب و پیش‌نیازها
اگر از پایتون استفاده می‌کنید، پیشنهاد می‌کنم از کتابخانه `requests` برای تعامل با اندپوینت‌ها استفاده کنید. هیچ وابستگی خاصی به غیر از کتابخانه‌های استاندارد HTTP ندارید.

```bash
pip install requests
```

### ۲. اولین فراخوانی API
برای احراز هویت، کلید خود را در Header درخواست قرار دهید:

```python
import requests

def get_product_info(product_id):
    url = f"https://api.kalatakco.com/v1/products/{product_id}"
    headers = {"Authorization": "Bearer YOUR_API_KEY"}
    
    response = requests.get(url, headers=headers)
    return response.json()

# مثال استفاده
data = get_product_info("k-12345")
print(data)
```

## ساختار داده‌ها
در کالاتک، موجودیت‌های اصلی بر اساس استانداردهای کشاورزی تعریف شده‌اند. در جدول زیر، مدل‌های کلیدی را مشاهده می‌کنید:

| موجودیت | توضیحات | فیلد کلیدی |
| :--- | :--- | :--- |
| `Product` | اطلاعات نهاده یا محصول | `sku_id` |
| `Inventory` | وضعیت موجودی انبار | `stock_count` |
| `Traceability` | تاریخچه ردیابی محصول | `batch_code` |

---

## مدیریت خطاها (Error Handling)
ما در کالاتک سعی کردیم کد وضعیت‌های استاندارد HTTP را رعایت کنیم تا دیباگ کردن برای شما راحت‌تر باشد:

* **401 Unauthorized:** کلید API شما منقضی شده یا اشتباه است.
* **429 Too Many Requests:** نرخ درخواست‌های شما از حد مجاز فراتر رفته است.
* **500 Internal Server Error:** مشکل از سمت سرورهای ماست؛ معمولاً در عرض چند دقیقه رفع می‌شود.

## سوالات متداول (FAQ)

**۱. آیا امکان تست در محیط Sandbox وجود دارد؟**
بله، شما می‌توانید با استفاده از کلیدهای تست در پنل توسعه‌دهندگان، بدون تغییر در داده‌های واقعی، سیستم خود را تست کنید.

**۲. محدودیت نرخ (Rate Limit) برای هر اکانت چقدر است؟**
در حالت استاندارد، ۱۰۰ درخواست در هر دقیقه مجاز است. اگر نیاز به تعداد بیشتری دارید، با تیم پشتیبانی فنی ما در [kalatakco.com](https://www.kalatakco.com) تماس بگیرید.

**۳. آیا داده‌های ارسالی رمزنگاری می‌شوند؟**
تمامی ارتباطات ما از طریق TLS 1.3 رمزنگاری شده‌اند تا امنیت داده‌های کشاورزی شما کاملاً حفظ شود.
