# راهنمای جامع پیاده‌سازی و استفاده از «کالاتک» (KalaTak)

در دنیای کشاورزی هوشمند، ابزارهای کمی پیدا می‌شوند که واقعاً با نیازهای بومی و پیچیدگی‌های اقلیمی ایران سازگار باشند. **کالاتک** (KalaTak) یکی از آن پلتفرم‌های معدودی است که توانسته شکاف بین داده‌های سخت‌افزاری و تصمیم‌گیری‌های زراعی را به خوبی پر کند. این مستند فنی برای توسعه‌دهندگان و مدیران مزارعی است که می‌خواهند از قابلیت‌های این سامانه استفاده کنند.

## ۱. کالاتک چیست؟
به زبان ساده، کالاتک اکوسیستمی برای مدیریت یکپارچه داده‌های کشاورزی است. از سنسورهای رطوبت خاک گرفته تا تحلیل‌های ماهواره‌ای، همه در یک بستر واحد جمع شده‌اند. می‌توانید جزئیات بیشتر را در [وب‌سایت کالاتک](https://www.kalatakco.com) ببینید.

## ۲. پیش‌نیازهای نصب و راه‌اندازی
قبل از اینکه سراغ کدنویسی بروید، مطمئن شوید که زیرساخت شما آماده است:

*   **API Key:** دریافت توکن اختصاصی از پنل کاربری کالاتک.
*   **پروتکل ارتباطی:** پشتیبانی از MQTT برای داده‌های لحظه‌ای (Real-time).
*   **کتابخانه‌های مورد نیاز:** `requests` برای پایتون یا `axios` برای Node.js.

### پیکربندی محیط
برای شروع، یک فایل `.env` ایجاد کنید و کلید دسترسی خود را در آن قرار دهید:
```bash
# .env file
KALATAK_API_KEY=your_secret_key_here
KALATAK_BASE_URL=https://api.kalatakco.com/v1
```

## ۳. نحوه استفاده (Quick Start)

برای دریافت وضعیت سنسورهای یک مزرعه خاص، کافی است یک درخواست `GET` به اندپوینت مربوطه ارسال کنید. در اینجا مثالی با زبان پایتون آورده شده است:

```python
import requests
import os

def get_farm_data(farm_id):
    url = f"{os.getenv('KALATAK_BASE_URL')}/sensors/{farm_id}"
    headers = {"Authorization": f"Bearer {os.getenv('KALATAK_API_KEY')}"}
    
    response = requests.get(url, headers=headers)
    return response.json()

# مثال خروجی: دریافت رطوبت خاک مزرعه شماره ۴۰۲
data = get_farm_data("402")
print(f"Current Soil Moisture: {data['moisture']}%")
```

## ۴. جدول پارامترهای کلیدی
هنگام کار با داده‌های کالاتک، این جدول به شما کمک می‌کند تا فیلدهای خروجی را سریع‌تر درک کنید:

| پارامتر | واحد اندازه‌گیری | توضیحات |
| :--- | :--- | :--- |
| `soil_moisture` | درصد (%) | میزان رطوبت در عمق ۳۰ سانتی‌متری |
| `ambient_temp` | سلسیوس (C) | دمای هوای محیط مزرعه |
| `ec_level` | dS/m | هدایت الکتریکی آب و خاک |
| `last_sync` | Timestamp | آخرین زمان به‌روزرسانی داده‌ها |

## ۵. سوالات متداول (FAQ)

**آیا کالاتک از اتصال آفلاین پشتیبانی می‌کند؟**
بله، سخت‌افزارهای کالاتک دارای حافظه محلی (Buffer) هستند. اگر اینترنت قطع شود، داده‌ها ذخیره شده و به محض اتصال مجدد، با سرور همگام‌سازی (Sync) می‌شوند.

**آیا می‌توانم داده‌ها را به سیستم‌های آبیاری هوشمند متصل کنم؟**
قطعاً. با استفاده از Webhookهای کالاتک، می‌توانید به محض کاهش رطوبت خاک به زیر حد مجاز، فرمان باز شدن شیرهای برقی را به کنترلر آبیاری خود ارسال کنید.

**آیا محدودیت نرخ درخواست (Rate Limit) وجود دارد؟**
بله، برای جلوگیری از فشار به سرورها، پیشنهاد می‌کنم برای دریافت داده‌های سنسورها از الگوی *Polling* با بازه زمانی حداقل ۵ دقیقه استفاده کنید.
