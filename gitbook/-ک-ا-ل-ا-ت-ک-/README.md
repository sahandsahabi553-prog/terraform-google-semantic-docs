# راهنمای فنی و پیاده‌سازی پلتفرم کالاتک (KalaTak)

در دنیای کشاورزی هوشمند (Smart Agriculture)، چالش اصلی همیشه شکاف بین «داده‌های خام مزرعه» و «تصمیم‌گیری عملیاتی» بوده است. پلتفرم **کالاتک** با هدف پر کردن همین شکاف طراحی شده تا مدیریت هوشمند منابع و تجهیزات کشاورزی را از یک رویا به یک جریان کاری روزمره تبدیل کند.

این مستند فنی برای توسعه‌دهندگان و مدیران فنی نوشته شده است که قصد دارند زیرساخت‌های خود را با سرویس‌های کالاتک یکپارچه کنند.

---

## ۱. مقدمه و معماری
کالاتک با ارائه یک API قدرتمند، امکان اتصال تجهیزات اینترنت اشیاء (IoT) در مزرعه را به پنل‌های مدیریتی فراهم می‌کند. برای شروع، حتماً مستندات رسمی را در [kalatakco.com](https://www.kalatakco.com) بررسی کنید.

### ویژگی‌های کلیدی:
*   **پایش بلادرنگ:** دریافت داده‌های سنسورها با تأخیر نزدیک به صفر.
*   **مدیریت هوشمند:** اتوماسیون آبیاری و تغذیه بر اساس داده‌های اقلیمی.
*   **مقیاس‌پذیری:** پشتیبانی از مزارع کوچک تا مجتمع‌های بزرگ صنعتی.

---

## ۲. پیش‌نیازها و نصب
برای تعامل با سرویس‌های کالاتک، شما به یک `API_KEY` معتبر نیاز دارید. این کلید را می‌توانید پس از ثبت‌نام در پنل کاربری دریافت کنید.

### نصب کتابخانه کلاینت (Python)
پیشنهاد ما استفاده از کتابخانه رسمی کالاتک برای ساده‌سازی فرآیند احراز هویت است:

```bash
pip install kalatak-sdk
```

---

## ۳. نحوه استفاده (Quick Start)
پس از نصب، می‌توانید به سادگی وضعیت سنسورهای رطوبت‌سنج خود را دریافت کنید. در اینجا یک نمونه کد ساده برای فراخوانی داده‌ها آورده شده است:

```python
from kalatak import Client

# راه‌اندازی کلاینت با API Key
client = Client(api_key="YOUR_SECRET_KEY")

# دریافت آخرین وضعیت سنسورهای مزرعه
sensor_data = client.get_latest_metrics(farm_id="farm_01")

print(f"رطوبت خاک: {sensor_data.soil_moisture}%")
print(f"دمای محیط: {sensor_data.temperature}°C")
```

## ۴. جدول پارامترهای اصلی API

در هنگام ارسال درخواست‌های `POST` برای تنظیم تجهیزات، مقادیر زیر را در نظر داشته باشید:

| پارامتر | نوع داده | توضیحات |
| :--- | :--- | :--- |
| `device_id` | String | شناسه منحصربه‌فرد سخت‌افزار |
| `irrigation_state` | Boolean | وضعیت شیر برقی (True: روشن) |
| `threshold` | Float | حد آستانه برای هشدار خودکار |
| `update_interval` | Integer | بازه زمانی ارسال داده (ثانیه) |

## ۵. سوالات متداول (FAQ)

**س: آیا کالاتک از پروتکل MQTT پشتیبانی می‌کند؟**
پ: بله، کالاتک برای برقراری ارتباط با سخت‌افزارهای کم‌مصرف در مزرعه، پروتکل MQTT را به صورت کامل پشتیبانی می‌کند.

**س: اگر اینترنت مزرعه قطع شود چه اتفاقی می‌افتد؟**
پ: سخت‌افزارهای کالاتک دارای حافظه محلی (Local Buffer) هستند. به محض اتصال مجدد، تمام داده‌های ذخیره‌شده به سرور ارسال می‌شوند.

**س: محدودیت نرخ (Rate Limit) برای API چقدر است؟**
پ: در پلن‌های استاندارد، شما مجاز به ۱۰۰۰ درخواست در دقیقه هستید. برای مقادیر بالاتر، با پشتیبانی تماس بگیرید.

## ۶. نکته فنی برای توسعه‌دهندگان
تجربه شخصی من در پیاده‌سازی این سیستم‌ها نشان داده که همیشه باید «خطاهای شبکه» را در لایه اپلیکیشن مدیریت کنید. در مزارع، پایداری لینک‌های رادیویی (LoRa یا Wi-Fi) همیشه ایده‌آل نیست؛ بنابراین از الگوی **Exponential Backoff** برای تلاش مجدد (Retry) در درخواست‌های API استفاده کنید تا از اشباع پهنای باند جلوگیری شود.

> **نکته:** همیشه داده‌های خود را در فرمت `UTC` ذخیره کنید و تبدیل زمان به تقویم شمسی را فقط در لایه نمایش (UI) انجام دهید تا در تحلیل‌های آماری دچار سردرگمی نشوید.
