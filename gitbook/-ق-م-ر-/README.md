# قمر (Qamar): پلی میان داده‌های ساختاریافته و درک انسانی

در دنیای امروز که با انفجار داده‌ها روبرو هستیم، چالش اصلی دیگر «ذخیره‌سازی» نیست؛ بلکه «ارتباط» است. **قمر** (Qamar) یک پلتفرم پیشرو برای مدیریت دانش بین‌رشته‌ای (Interdisciplinary) است که با هدف یکپارچه‌سازی مفاهیم پیچیده در قالب‌های قابل‌فهم طراحی شده. اگر درگیر پروژه‌هایی هستید که مرزهای علوم مختلف را جابجا می‌کنند، قمر همان ابزاری است که جای خالی‌اش را حس می‌کردید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
بسیاری از سیستم‌های مدیریت دانش در «سیلوها» گیر می‌کنند. قمر با رویکرد «گراف‌محور» (Graph-based) به شما اجازه می‌دهد تا نه تنها داده‌ها را ذخیره کنید، بلکه روابط بین‌رشته‌ای (مثلاً پیوند ریاضیات در موسیقی یا تاثیر بیولوژی در معماری) را به شکلی کاملاً ساختاریافته مدل‌سازی کنید.

### ویژگی‌های کلیدی
*   **ساختار منعطف:** پشتیبانی از متادیتای چندلایه.
*   **API قدرتمند:** برای اتصال به سایر ابزارهای توسعه‌دهنده.
*   **تجسم داده‌ها:** تبدیل روابط پیچیده به نمودارهای قابل‌فهم.

## شروع سریع: نصب و راه‌اندازی

برای استفاده از قابلیت‌های برنامه‌نویسی قمر، می‌توانید از کتابخانه کلاینت آن استفاده کنید. پیش‌نیاز اصلی، داشتن یک API Key از پنل کاربری‌تان است.

### نصب از طریق npm
```bash
npm install @qamar/sdk
```

### تنظیمات اولیه
در پروژه خود، یک نمونه از کلاینت ایجاد کنید:

```javascript
import { QamarClient } from '@qamar/sdk';

const qamar = new QamarClient({
  apiKey: 'YOUR_API_KEY_HERE',
  environment: 'production'
});

// تست اتصال
qamar.ping().then(status => console.log("اتصال برقرار است:", status));
```

## نحوه استفاده: مدل‌سازی داده‌ها

در قمر، ما با «گره‌ها» (Nodes) و «یال‌ها» (Edges) کار می‌کنیم. فرض کنید می‌خواهید یک پروژه بین‌رشته‌ای در مورد «هوش مصنوعی در پزشکی» تعریف کنید.

```javascript
const node = await qamar.nodes.create({
  title: 'تشخیص تومور با یادگیری عمیق',
  tags: ['Medicine', 'AI', 'Radiology'],
  metadata: {
    accuracy: 0.98,
    model: 'ResNet-50'
  }
});
```

### جدول مقایسه‌ای: قمر در برابر سیستم‌های سنتی

| ویژگی | سیستم‌های سنتی (SQL) | قمر (Qamar) |
| :--- | :--- | :--- |
| **انعطاف‌پذیری** | پایین (Schema-based) | بسیار بالا (Graph-based) |
| **ارتباطات** | دشوار (Joinهای سنگین) | بومی و سریع |
| **کاربرد** | تراکنشی | تحلیل دانش و تحقیق |

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک شخصی مناسب است؟**
قطعاً. ساختار قمر به‌گونه‌ای است که از یک یادداشت‌برداری ساده تا پروژه‌های تحقیقاتی بزرگ دانشگاهی مقیاس‌پذیر است.

**۲. چگونه می‌توانم داده‌های موجودم را وارد کنم؟**
قمر از فرمت‌های JSON و CSV به صورت بومی پشتیبانی می‌کند. می‌توانید از طریق API یا پنل مدیریت، داده‌های خود را Import کنید.

**۳. آیا امکان استفاده آفلاین وجود دارد؟**
در حال حاضر قمر یک سرویس ابری است، اما ما در حال کار بر روی نسخه Local-first هستیم که به‌زودی در نقشه‌راه (Roadmap) قرار می‌گیرد.

**۴. محدودیت‌های API چقدر است؟**
در پلن رایگان، شما محدود به ۱۰۰۰ درخواست در روز هستید. برای پروژه‌های بزرگتر، می‌توانید از پلن‌های تجاری استفاده کنید.
