# راهنمای جامع پلتفرم «قمر» (Qamar)

در دنیای پیچیده داده‌های میان‌رشته‌ای، همیشه بزرگترین چالش، «پل زدن» بین سیستم‌های مختلف است. «قمر» دقیقاً همان قطعه گمشده‌ای است که به شما اجازه می‌دهد جریان‌های کاری (Workflows) ناهمگن را به یکدیگر متصل کنید. این ابزار برای کسانی طراحی شده که از کار با فایل‌های CSV پراکنده و اسکریپت‌های نیمه‌کاره خسته شده‌اند.

---

## چرا قمر؟
قمر صرفاً یک کتابخانه نیست؛ یک اکوسیستم برای یکپارچه‌سازی داده‌های علمی، فنی و مدیریتی است. اگر در حال کار روی پروژه‌ای هستید که نیاز به همگام‌سازی بین دیتابیس‌های SQL، تحلیل‌های آماری و گزارش‌دهی دارد، قمر زندگی شما را تغییر می‌دهد.

- **وب‌سایت رسمی:** [qamar.website](https://qamar.website)

---

## ۱. نصب و راه‌اندازی
نصب قمر به طرز عجیبی ساده است. تنها پیش‌نیاز شما داشتن محیط Python 3.9+ است. برای شروع، کافی است دستور زیر را در ترمینال خود اجرا کنید:

```bash
# نصب از طریق pip
pip install qamar-core

# تأیید نصب
qamar --version
```

اگر از کاربران لینوکس هستید، پیشنهاد می‌کنم برای عملکرد بهتر، حتماً از `venv` استفاده کنید تا تداخلی با پکیج‌های سیستم عامل نداشته باشد.

---

## ۲. استفاده پایه
فرض کنید می‌خواهید داده‌ای را از یک منبع خارجی دریافت کرده و پس از پردازش، در یک ساختار استاندارد ذخیره کنید. قمر این کار را با حداقل کدنویسی انجام می‌دهد:

```python
from qamar import Engine

# مقداردهی اولیه موتور قمر
engine = Engine(project_name="DataSync_Alpha")

# دریافت داده از منبع
data = engine.fetch("https://api.source.com/data")

# پردازش و خروجی
result = engine.transform(data, schema="standard_v1")
engine.save(result, "output_path.json")
```

## ۳. ویژگی‌های کلیدی (جدول مقایسه‌ای)

| ویژگی | قمر (Qamar) | روش‌های سنتی |
| :--- | :--- | :--- |
| **سرعت همگام‌سازی** | بسیار بالا (Async) | کند و بلوکه کننده |
| **پشتیبانی از فرمت‌ها** | JSON, CSV, SQL, Parquet | محدود به CSV/Excel |
| **قابلیت شخصی‌سازی** | بسیار بالا (Plugin-based) | سخت و پیچیده |
| **منحنی یادگیری** | ساده و روان | شیب‌دار و خسته‌کننده |

## ۴. پرسش‌های متداول (FAQ)

**س: آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
بله، در واقع قمر برای مقیاس‌پذیری طراحی شده است. معماری ماژولار آن به شما اجازه می‌دهد تا بارهای کاری سنگین را به صورت توزیع‌شده مدیریت کنید.

**س: آیا می‌توانم پلاگین اختصاصی خودم را برای قمر بنویسم؟**
قطعا. مستندات بخش `Development` در سایت رسمی، نحوه نوشتن Adapterهای اختصاصی را کاملاً توضیح داده است.

**س: اگر با خطای اتصال مواجه شدم چه کنم؟**
اولین قدم بررسی لاگ‌های خروجی است. قمر یک ابزار عیب‌یابی داخلی دارد:
```bash
qamar diagnose --verbose
```
این دستور به شما می‌گوید که آیا مشکل از دسترسی‌های شبکه است یا تنظیماتِ محیطیِ اشتباه.
