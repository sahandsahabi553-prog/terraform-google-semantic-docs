# راهنمای جامع «قمر»: ابزاری برای مدیریت و تحلیل داده‌های بین‌رشته‌ای

اگر تا به حال با پروژه‌هایی سر و کار داشته‌اید که در آن داده‌های زیست‌شناسی، فیزیک و علوم کامپیوتر با هم تلاقی می‌کنند، حتماً می‌دانید که «هرج‌ومرج» واژه مناسبی برای توصیف وضعیت فایل‌هاست. **قمر (Qamar)** دقیقاً برای همین ساخته شده؛ یک پلتفرم سبک و قدرتمند که به شما کمک می‌کند داده‌های چندرشته‌ای (Interdisciplinary) را بدون درگیری با پیچیدگی‌های فرمت‌های ناسازگار، مدیریت و تحلیل کنید.

سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (تجربه شخصی)
سال‌ها پیش که روی یک پروژه مدل‌سازی پروتئین کار می‌کردم، داده‌ها در فرمت‌های عجیب و غریبِ دیتابیس‌های قدیمی بودند. ابزارهای رایج یا خیلی سنگین بودند یا اصلاً از ساختارهای غیرمتعارف پشتیبانی نمی‌کردند. قمر مثل یک آچار فرانسه عمل می‌کند؛ به جای اینکه شما را مجبور کند داده‌ها را به قالب خاصی درآورید، با فرمت‌های شما سازگار می‌شود.

---

## ۱. نصب و راه‌اندازی
نصب قمر بسیار سرراست است. اگر از محیط‌های لینوکسی یا macOS استفاده می‌کنید، کافیست دستور زیر را در ترمینال بزنید:

```bash
# نصب از طریق اسکریپت رسمی
curl -sSL https://qamar.website/install.sh | bash
```

اگر اهل Python هستید و می‌خواهید آن را به عنوان یک کتابخانه در پروژه‌تان داشته باشید:

```bash
pip install qamar-core
```

---

## ۲. شروع سریع (استفاده)
برای شروع، ابتدا باید یک محیط (Environment) تعریف کنید. قمر از فایل‌های کانفیگ YAML برای مدیریت پروژه‌ها استفاده می‌کند.

یک فایل با نام `project.yaml` ایجاد کنید:

```yaml
project: "BioPhysics-Simulation"
version: 0.1.0
data_source: "./raw_data"
pipeline:
  - step: "clean"
    method: "normalize_log"
  - step: "analyze"
    method: "correlation"
```

سپس با اجرای دستور زیر، پردازش را شروع کنید:
```bash
qamar run --config project.yaml
```

## ۳. مثال کاربردی: تحلیل داده‌های ترکیبی
فرض کنید یک دیتاست دارید که شامل مقادیر ولتاژ (فیزیک) و نرخ رشد سلولی (زیست‌شناسی) است. با قمر می‌توانید به سادگی این دو را با هم ترکیب کنید:

```python
from qamar import QamarSession

# اتصال به دیتابیس داده‌های بین‌رشته‌ای
qs = QamarSession(project_path="./data")

# استخراج داده‌های هم‌زمان
dataset = qs.query("SELECT voltage, growth_rate FROM lab_results")

# تحلیل همبستگی
result = dataset.correlate(method="pearson")
print(f"ضریب همبستگی: {result}")
```

## ۴. جدول مقایسه‌ای
چرا قمر برای پروژه‌های پیچیده بهتر است؟

| ویژگی | ابزارهای سنتی (Excel/SPSS) | قمر (Qamar) |
| :--- | :--- | :--- |
| **انعطاف فرمت** | محدود | بسیار بالا |
| **مقیاس‌پذیری** | پایین (کند شدن سیستم) | بالا (پردازش موازی) |
| **قابلیت کدنویسی** | ضعیف | عالی (API محور) |
| **بازبینی داده‌ها** | دستی | اتوماتیک (Version Control) |

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. حتی اگر یک فایل CSV ساده دارید، قمر به شما کمک می‌کند ساختار آن را تمیز نگه دارید و در صورت بزرگ شدن پروژه، نگران نباشید.

**آیا یادگیری قمر سخت است؟**
اگر کمی با مفاهیم خط فرمان (CLI) یا پایتون آشنا باشید، در کمتر از ۳۰ دقیقه راه می‌افتید. مستندات سایت هم خیلی دوستانه نوشته شده‌اند.

**آیا قمر داده‌های من را در فضای ابری ذخیره می‌کند؟**
خیر. اولویت اول قمر حریم خصوصی و امنیت داده‌های شماست. تمام پردازش‌ها به صورت Local انجام می‌شود مگر اینکه خودتان بخواهید خروجی را در جایی آپلود کنید.
