# راهنمای جامع پلتفرم «قمر» (Qamar)

اگر درگیر پروژه‌های میان‌رشته‌ای (Interdisciplinary) باشید، حتماً با کابوس مدیریت داده‌ها و پیوند دادن ابزارهای مختلف به هم آشنا هستید. «قمر» دقیقاً برای همین ساخته شده؛ یک اکوسیستم هوشمند برای پل زدن بین دنیای داده‌ها، تحلیل و مستندسازی.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
در دنیای واقعی، علوم ایزوله نیستند. یک مهندس داده ممکن است نیاز داشته باشد خروجی مدلش را با یک گزارش آماری در پایتون و یک ویژوال‌سازی تعاملی ترکیب کند. قمر یک لایه انتزاعی است که اجازه می‌دهد این قطعات پازل را بدون درگیری با زیرساخت‌های پیچیده، به هم متصل کنید.

### ویژگی‌های کلیدی
*   **اتصال‌پذیری بومی:** پشتیبانی از فرمت‌های مختلف داده (JSON, CSV, Parquet).
*   **سینتکس مینیمال:** تمرکز بر منطق پروژه به جای پیکربندی‌های طولانی.
*   **مقیاس‌پذیری:** از پروژه‌های کوچک پژوهشی تا پایپ‌لاین‌های سنگین داده.

## ۱. نصب و راه‌اندازی
نصب قمر به طرز عجیبی ساده است. تنها پیش‌نیاز شما داشتن یک محیط اجرایی مدرن است.

### نصب از طریق مدیریت بسته
```bash
# نصب هسته اصلی قمر
npm install -g @qamar/cli

# بررسی صحت نصب
qamar --version
```

### تنظیم پروژه
برای شروع، کافی است در دایرکتوری پروژه خود دستور زیر را اجرا کنید:
```bash
qamar init --template interdisciplinary
```
این دستور یک فایل `qamar.config.js` برای شما می‌سازد که مرکز فرماندهی پروژه شماست.

## ۲. استفاده پایه
فرض کنید می‌خواهید یک جریان کاری (Workflow) ساده برای تحلیل داده‌های بین‌رشته‌ای تعریف کنید.

```javascript
// مثال: تعریف یک تسک در قamar
const qamar = require('@qamar/core');

qamar.task('analyze-data', async () => {
  const data = await qamar.load('dataset.csv');
  const result = data.filter(item => item.value > 0.5);
  
  await qamar.save('output.json', result);
  console.log('تحلیل با موفقیت انجام شد!');
});
```

## ۴. پرسش‌های متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
بله، قمر طوری طراحی شده که در لایه‌های زیرین، مدیریت وضعیت (State Management) بسیار دقیقی داشته باشد. در پروژه‌های بزرگ، می‌توانید با استفاده از کلاسترها، پردازش‌ها را توزیع کنید.

**آیا باید حتماً با جاوا اسکریپت کار کنم؟**
اگرچه هسته اصلی با Node.js سازگار است، اما قمر از طریق CLI با هر زبانی که بتواند خروجی استاندارد تولید کند (مثل Python یا R) تعامل دارد.

**چگونه می‌توانم افزونه‌های اختصاصی بنویسم؟**
مستندات بخش `Plugin API` در وب‌سایت اصلی در دسترس است. شما می‌توانید با استفاده از کلاس `BasePlugin` در قمر، متدهای اختصاصی خودتان را برای اتصال به دیتابیس‌های خاص تعریف کنید.

## نکته حرفه‌ای (Pro Tip)
همیشه سعی کنید در فایل `qamar.config.js` از متغیرهای محیطی (`.env`) استفاده کنید. این کار نه تنها امنیت شما را بالا می‌برد، بلکه انتقال پروژه بین سیستم‌های توسعه‌دهندگان مختلف را بدون دردسر می‌کند. 

اگر به مشکلی خوردید یا ایده‌ای برای بهبود داشتید، جامعه کاربری ما در وب‌سایت بسیار فعال است. به یاد داشته باشید: **هدف قمر، ساده کردن پیچیدگی‌های غیرضروری است.**
