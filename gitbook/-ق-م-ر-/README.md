# راهنمای جامع «قمر» (Qamar): پلی میان دانش و تکنولوژی

در دنیای امروز که مرزهای بین رشته‌های علمی روزبه‌روز کمرنگ‌تر می‌شوند، داشتن ابزاری که بتواند داده‌های میان‌رشته‌ای (Interdisciplinary) را به شکلی ساختاریافته مدیریت کند، یک ضرورت است. **قمر** دقیقاً برای همین هدف طراحی شده است.

اگر به دنبال راهکاری هستید که پیچیدگی‌های تحلیل داده‌های ترکیبی را کاهش دهد، جای درستی آمده‌اید.

---

## ۱. قمر چیست؟
قمر (Qamar) یک پلتفرم متن‌باز برای مدل‌سازی و تحلیل داده‌های چندوجهی است. برخلاف ابزارهای سنتی که فقط روی یک حوزه خاص تمرکز دارند، قمر به شما اجازه می‌دهد پارامترهای حوزه‌های مختلف (مثلاً فیزیک و علوم داده) را در یک محیط واحد با هم ترکیب کنید.

*   **وب‌سایت رسمی:** [qamar.website](https://qamar.website)
*   **فلسفه طراحی:** سادگی در پیاده‌سازی، قدرت در محاسبات.

---

## ۲. نصب و راه‌اندازی
نصب قمر بسیار سرراست است. پیشنهاد می‌کنم از محیط مجازی (Virtual Environment) استفاده کنید تا وابستگی‌های سیستم‌عامل‌تان تداخل پیدا نکنند.

### پیش‌نیازها
*   Python 3.9+
*   pip

### دستور نصب
برای نصب آخرین نسخه پایدار، کافی است دستور زیر را در ترمینال خود اجرا کنید:

```bash
pip install qamar-lib
```

اگر می‌خواهید آخرین تغییرات توسعه‌دهندگان را تست کنید، می‌توانید مستقیماً از مخزن گیت‌هاب کلون کنید:

```bash
git clone https://github.com/qamar-project/core
cd core
pip install -e .
```

---

## ۳. استفاده سریع (Quick Start)
فرض کنید می‌خواهید یک مدل ساده میان‌رشته‌ای بسازید که داده‌های حسگرهای محیطی را با تحلیل‌های آماری ترکیب می‌کند.

```python
import qamar

# مقداردهی اولیه محیط قمر
env = qamar.Environment(name="my_research_project")

# افزودن ماژول داده‌های ترکیبی
data_layer = env.add_layer("sensors", type="time-series")
data_layer.load_csv("data.csv")

# اجرای تحلیل میان‌رشته‌ای
result = env.run_analysis(method="cross-correlation")

print(f"نتیجه تحلیل: {result.summary}")
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ صنعتی مناسب است؟**
بله، معماری قمر به گونه‌ای است که با افزایش حجم داده‌ها، به راحتی مقیاس‌پذیر (Scalable) می‌شود.

**آیا مستندات آفلاین هم موجود است؟**
بله، در دایرکتوری `docs/` در مخزن پروژه، فایل‌های PDF کاملی برای مطالعه آفلاین قرار داده شده است.

**چگونه می‌توانم در توسعه قمر مشارکت کنم؟**
ما همیشه از Pull Requestها استقبال می‌کنیم. کافی است نگاهی به لیست `Good First Issue` در گیت‌هاب بیندازید.
