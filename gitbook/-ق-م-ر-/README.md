# قمر (Qamar): پلی برای داده‌های بین‌رشته‌ای

در دنیای امروز، بزرگترین چالش ما کمبود داده نیست؛ بلکه «سیلوها» (Silos) هستند. داده‌های زیستی در یک محیط، داده‌های مالی در محیطی دیگر و تحلیل‌های متنی در جایی کاملاً مجزا گیر افتاده‌اند. **قمر** ابزاری است که دقیقاً برای شکستن همین دیوارهای نامرئی طراحی شده است.

اگر به دنبال راهکاری هستید که مفاهیم پیچیده بین‌رشته‌ای را به زبان ماشین و ساختارهای دیتایی تبدیل کند، قمر همان حلقه‌ی مفقوده است.

---

## ۱. چرا قمر؟ (فلسفه پروژه)
قمر یک چارچوب (Framework) سبک برای مدیریت دانش میان‌رشته‌ای است. برخلاف دیتابیس‌های سنتی که فقط روی "ذخیره" تمرکز دارند، قمر روی **«ارتباطات» (Interconnectivity)** متمرکز است. 

*   **انعطاف‌پذیری:** مدل داده‌ای مبتنی بر گراف.
*   **سرعت:** بهینه‌شده برای پرس‌وجوهای پیچیده.
*   **دسترسی:** [وب‌سایت رسمی قمر](https://qamar.website)

---

## ۲. نصب و راه‌اندازی
نصب قمر بسیار سرراست است. کافی است پایتون ۳.۹ به بالا داشته باشید.

```bash
# نصب از طریق pip
pip install qamar-core

# تأیید نصب
qamar --version
```

برای پروژه‌های بزرگتر، پیشنهاد می‌کنم از یک محیط مجازی (Virtual Environment) استفاده کنید تا وابستگی‌ها با کتابخانه‌های دیگر تداخل پیدا نکنند.

---

## ۳. استفاده سریع
فرض کنید می‌خواهید داده‌های یک تحقیق پزشکی را با داده‌های جغرافیایی ترکیب کنید. با قمر، این کار فقط چند خط کد نیاز دارد:

```python
from qamar import Engine, Node

# مقداردهی اولیه
engine = Engine(db_path="research.db")

# ایجاد گره‌های بین‌رشته‌ای
bio_node = Node(id="virus_a", type="biology", data={"mutation": 0.02})
geo_node = Node(id="region_x", type="geography", data={"temp": 25})

# ایجاد رابطه بین دو دامنه مختلف
engine.link(bio_node, geo_node, relation="observed_in")
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های تجاری بزرگ مناسب است؟**
بله، ساختار قمر به‌گونه‌ای است که در محیط‌های تولیدی (Production) با حجم دیتای بالا به خوبی پاسخگوست.

**آیا یادگیری آن زمان‌بر است؟**
اگر با مفاهیم دیتابیس‌های گراف آشنا باشید، کمتر از یک ساعت طول می‌کشد تا منطق آن را درک کنید. مستندات سایت بسیار گویا هستند.

**آیا می‌توانم از قمر در پروژه‌های فرانت‌اِند استفاده کنم؟**
قمر در اصل برای بک‌اِند و پردازش دیتا طراحی شده، اما از طریق APIهای واسط می‌توانید آن را به هر فرانت‌اِندی متصل کنید.

اگر به مشکلی خوردید، در فروم‌های مرتبط با پروژه فعال هستیم و خوشحال می‌شویم به شما کمک کنیم. خوش بگذره!
