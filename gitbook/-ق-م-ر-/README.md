# قمر (Qamar): پلی میان داده‌ها و تحلیل‌های میان‌رشته‌ای

اگر درگیر پروژه‌هایی هستید که در آن داده‌های پراکنده از حوزه‌های مختلف (مثلاً از علوم اجتماعی تا مهندسی داده) را به هم گره می‌زنید، احتمالاً می‌دانید که بزرگ‌ترین دردسر، «یکپارچگی» است. **قمر (Qamar)** دقیقاً برای حل همین مشکل طراحی شده؛ ابزاری که برخلاف ابزارهای سنتی ETL، رویکردی میان‌رشته‌ای (Interdisciplinary) به پردازش داده دارد.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
بیشتر ابزارها تک‌بعدی هستند. یا فقط دیتابیس را می‌فهمند یا فقط تحلیل آماری را. قمر به شما اجازه می‌دهد لایه‌های مختلف داده را بدون نیاز به زیرساخت‌های پیچیده به هم متصل کنید. من شخصاً وقتی برای اولین بار از آن برای ترکیب داده‌های متنی (NLP) با سری‌های زمانی (Time-series) استفاده کردم، از سادگیِ خط‌لوله‌اش شگفت‌زده شدم.

---

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم از محیط مجازی (Virtual Environment) استفاده کنید تا کتابخانه‌های سیستمی‌تان تمیز بماند.

```bash
# نصب از طریق pip
pip install qamar-core

# تأیید نصب
qamar --version
```

اگر از توزیع‌های مبتنی بر لینوکس استفاده می‌کنید و نیاز به شتاب‌دهنده سخت‌افزاری دارید:
```bash
# نصب پیش‌نیازهای محاسباتی
sudo apt-get install qamar-dev-libs
```

## نحوه استفاده: یک مثال عملی

فرض کنید می‌خواهید داده‌های یک پژوهش میدانی را با یک API خارجی ترکیب کنید. قمر این کار را با یک فایل کانفیگ ساده (`qamar.yaml`) انجام می‌دهد.

### کد نمونه: اتصال به منبع داده
```python
import qamar

# مقداردهی اولیه
engine = qamar.Pipeline(source="survey_data.csv")

# اعمال یک فیلتر میان‌رشته‌ای
engine.apply_filter(lambda x: x['confidence_score'] > 0.8)

# خروجی به فرمت JSON برای تحلیل‌های بعدی
engine.export("output.json")
```

| :--- | :--- | :--- |
| **نوع داده** | چندساختاری (Multi-modal) | ساختاریافته (Tabular) |
| **منحنی یادگیری** | بسیار سریع | طولانی و پیچیده |

| **یکپارچگی** | عالی | محدود |

## پرسش‌های متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
بله، معماری قمر به گونه‌ای است که در کلاسترهای بزرگ به راحتی مقیاس‌پذیر است. ما در تیم از آن برای پردازش بیش از ۵۰ میلیون رکورد در روز استفاده می‌کنیم.

**۲. آیا نیاز به دانش عمیق در برنامه‌نویسی دارم؟**
اگر کمی با پایتون آشنا باشید، ظرف کمتر از یک ساعت می‌توانید اولین خروجی خود را بگیرید. مستندات قمر روی «سادگی در عین قدرت» تمرکز دارند.

**۳. آیا می‌توانم فیلترهای شخصی‌سازی شده بنویسم؟**
دقیقاً! یکی از نقاط قوت قمر، قابلیت گسترش‌پذیری (Extensibility) آن است. شما می‌توانید کلاس‌های پردازشی خودتان را بنویسید و به راحتی به خط‌لوله (Pipeline) تزریق کنید.
