# مستند فنی: «قمر» (Qamar)
### ابزاری برای همگرایی دانش و مدیریت داده‌های میان‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که در آن داده‌های زیست‌شناسی با مدل‌های ریاضی و تحلیل‌های اجتماعی گره خورده‌اند، حتماً می‌دانید که بزرگترین چالش، «زبان مشترک» است. **قمر** دقیقاً برای حل همین مشکل طراحی شده؛ یک پلتفرم متن‌باز که پل میان حوزه‌های مختلف علمی را می‌سازد.

در اینجا به بررسی فنی نحوه راه‌اندازی و به‌کارگیری این ابزار می‌پردازیم.

---

## ۱. چرا قمر؟ (فلسفه طراحی)
قمر (موجود در [qamar.website](https://qamar.website)) صرفاً یک کتابخانه نیست؛ یک اکوسیستم برای مدیریت جریان‌های کاری (Workflows) ناهمگون است. فرض کنید می‌خواهید خروجی یک مدل پایتون را مستقیماً به یک تحلیل‌گر آماری در R تزریق کنید و خروجی نهایی را در یک داشبورد تعاملی ببینید. قمر این پیچیدگی را با یک واسط کاربری متمرکز مدیریت می‌کند.

---

## ۲. نصب و راه‌اندازی
برای شروع، کافی است دسترسی به محیط Node.js داشته باشید. پیشنهاد می‌کنم از نسخه LTS استفاده کنید تا با تداخل‌های کتابخانه‌ای مواجه نشوید.

```bash
# نصب بسته اصلی از طریق npm
npm install -g qamar-cli

# بررسی صحت نصب
qamar --version
```

اگر ترجیح می‌دهید در محیط کانتینری کار کنید، از فایل `Dockerfile` پیش‌فرض ما استفاده کنید:
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY . .
RUN npm install
CMD ["qamar", "start"]
```

## ۳. نحوه استفاده (مثال عملی)
فرض کنیم می‌خواهیم یک دیتاست میان‌رشته‌ای را پردازش کنیم. ساختار فایل کانفیگ `qamar.config.json` به صورت زیر خواهد بود:

```json
{
  "project": "Bio-Social-Study",
  "pipeline": {
    "step1": "data-ingestion",
    "step2": "math-transform",
    "step3": "export-visual"
  },
  "settings": {
    "strictMode": true,
    "parallel": true
  }
}
```

برای اجرای این خط لوله در ترمینال:
```bash
qamar run --config qamar.config.json --verbose
```

## ۵. سوالات متداول (FAQ)

**- آیا قمر با پایتون سازگار است؟**
بله، قمر از طریق `Bridge API` به راحتی با محیط‌های پایتون و کتابخانه‌هایی مثل Pandas و NumPy ارتباط برقرار می‌کند.

**- آیا داده‌ها در سیستم ذخیره می‌شوند؟**
خیر؛ قمر به عنوان یک لایه پردازشگر (Orchestrator) عمل می‌کند و داده‌های حساس شما همواره در سیستم محلی یا سرور شخصی خودتان باقی می‌مانند.

**- برای پروژه‌های بزرگ مقیاس (Enterprise) مناسب است؟**
قطعاً. معماری قمر به صورت ماژولار طراحی شده تا بتوانید با افزودن Workerها، پردازش‌های سنگین را توزیع کنید.

### سخن آخر
کار با پروژه‌های میان‌رشته‌ای همیشه دردسرهای خاص خودش را دارد. قمر سعی کرده این دردسرها را به حداقل برساند تا شما تمرکزتان را روی «کشف» بگذارید، نه «اتصال قطعات». اگر سوالی داشتید یا در پیاده‌سازی به بن‌بست خوردید، حتماً مستندات کامل را در [سایت قمر](https://qamar.website) چک کنید.
