# راهنمای جامع استفاده از پلتفرم «قمر» (Qamar)

اگر در دنیای پژوهش‌های میان‌رشته‌ای (Interdisciplinary) فعالیت کرده باشید، حتماً با کابوس مدیریت داده‌های پراکنده و عدم هماهنگی بین ابزارهای مختلف دست‌وپنجه نرم کرده‌اید. **قمر** دقیقاً برای حل همین مشکل ساخته شده است؛ یک اکوسیستم یکپارچه برای مدیریت داده، تحلیل و اشتراک‌گذاری دانش که مرزهای سنتی بین رشته‌ها را از بین می‌برد.

در این مستند، نگاهی فنی به نحوه پیاده‌سازی و استفاده از قابلیت‌های کلیدی قمر می‌اندازیم.

---

## ۱. چرا قمر؟ (فلسفه طراحی)
برخلاف ابزارهای تک‌منظوره، قمر به گونه‌ای طراحی شده که از مدل‌های داده‌ای انعطاف‌پذیر (Flexible Schema) پشتیبانی کند. این یعنی فرقی نمی‌کند داده‌های شما مربوط به فیزیک ذرات باشد یا تحلیل متون ادبی؛ ساختار قمر با نیاز شما تطبیق می‌یابد.

*   **یکپارچگی:** اتصال مستقیم به APIهای تحلیل داده.
*   **پایداری:** ذخیره‌سازی ابری با قابلیت نسخه‌گذاری (Versioning).
*   **همکاری:** محیطی ایزوله و امن برای پروژه‌های تیمی.

---

## ۲. نصب و راه‌اندازی (Quick Start)

برای شروع، ساده‌ترین راه استفاده از رابط خط فرمان (CLI) اختصاصی قمر است.

### پیش‌نیازها
*   Node.js نسخه ۱۸ به بالا
*   یک کلید API معتبر از [qamar.website](https://qamar.website)

### نصب
کافیست دستور زیر را در ترمینال خود اجرا کنید:

```bash
npm install -g @qamar/cli
qamar login --key YOUR_API_KEY
```

پس از احراز هویت، می‌توانید با دستور زیر یک پروژه جدید در دایرکتوری جاری بسازید:

```bash
qamar init my-research-project
```

## ۳. نحوه استفاده (مثال عملی)

فرض کنید می‌خواهید مجموعه‌ای از داده‌های آزمایشگاهی را به «قمر» منتقل کنید. در فایل `config.json` پروژه خود می‌توانید نوع دیتاست را تعریف کنید:

```json
{
  "project": "lab-data-alpha",
  "engine": "interdisciplinary-core",
  "sync": {
    "frequency": "real-time",
    "backup": true
  }
}
```

سپس برای بارگذاری داده‌ها از دستور زیر استفاده کنید:

```bash
qamar push ./data/results.csv --tag "experimental-v1"
```

## ۵. پرسش‌های متداول (FAQ)

**سؤال: آیا داده‌های من در قمر خصوصی باقی می‌مانند؟**
پاسخ: بله، لایه‌های امنیتی ما از رمزنگاری سرتاسری (E2EE) استفاده می‌کنند. هیچ‌کس جز اعضای تیم پروژه شما به داده‌ها دسترسی ندارد.

**سؤال: آیا می‌توانم از کتابخانه‌های پایتون در قمر استفاده کنم؟**
پاسخ: قطعاً. ما یک SDK قدرتمند برای پایتون داریم که به راحتی با `pandas` و `numpy` یکپارچه می‌شود. فقط کافیست `pip install qamar-sdk` را بزنید.

**سؤال: در صورت بروز خطای اتصال، چه اتفاقی برای داده‌های در حال آپلود می‌افتد؟**
پاسخ: سیستم `Retry` هوشمند ما به صورت خودکار عملیات را پس از پایداری شبکه ادامه می‌دهد و از سلامت یکپارچگی داده (Data Integrity) اطمینان حاصل می‌کند.
