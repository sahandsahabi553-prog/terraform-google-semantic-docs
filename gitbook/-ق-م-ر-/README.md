# قمر (Qamar): راهنمای جامع مدیریت و یکپارچه‌سازی سیستم‌های توزیع‌شده

اگر در دنیای توسعه سیستم‌های پیچیده فعالیت کرده باشید، حتماً با مشکل «جزیره‌ای بودن» ابزارها دست‌وپنج نرم کرده‌اید. **قمر (Qamar)** دقیقاً برای حل همین معضل طراحی شده است. این پلتفرم با رویکردی بین‌رشته‌ای (Interdisciplinary)، شکاف بین زیرساخت‌های داده و لایه‌های کاربردی را پر می‌کند.

سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
بیشتر ابزارهای موجود یا بیش از حد روی «شبکه» تمرکز دارند یا بیش از حد «داده‌محور» هستند. قمر به عنوان یک لایه انتزاعی هوشمند عمل می‌کند که اجازه می‌دهد سرویس‌های مختلف با پروتکل‌های متفاوت (مثل gRPC، REST و حتی صف‌های پیام) در یک اکوسیستم واحد با هم صحبت کنند.

### ویژگی‌های کلیدی:
*   **پشتیبانی از پروتکل‌های چندگانه:** بدون نیاز به بازنویسی کد.
*   **مقیاس‌پذیری بومی:** طراحی شده برای کلاسترهای کوچک و بزرگ.
*   **امنیت لایه‌بندی شده:** احراز هویت متمرکز برای تمام سرویس‌های زیرمجموعه.

## نصب و راه‌اندازی

برای شروع، پیشنهاد می‌کنم از اسکریپت نصب خودکار استفاده کنید که محیط را برای شما کانفیگ می‌کند.

```bash
# نصب قمر در محیط لینوکسی/مک
curl -sSL https://qamar.website/install.sh | bash
```

پس از نصب، برای اطمینان از صحت عملکرد، دستور زیر را اجرا کنید:
```bash
qamar version
```

## استفاده سریع (Quick Start)

قمر از فایل‌های کانفیگ `YAML` برای مدیریت سرویس‌ها استفاده می‌کند. یک نمونه ساده از `qamar.yml`:

```yaml
service:
  name: "auth-gateway"
  port: 8080
  protocol: "grpc"
  retry_policy:
    attempts: 3
    delay: "500ms"

endpoints:
  - path: "/login"
    method: "POST"
    timeout: "2s"
```

برای اجرای سرویس با این تنظیمات:
```bash
qamar run --config qamar.yml
```

## پرسش‌های متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
بله، اگرچه قدرت اصلی قمر در سیستم‌های توزیع‌شده بزرگ نمایان می‌شود، اما معماری سبک آن باعث شده که حتی در پروژه‌های کوچک هم به عنوان یک لایه مدیریت ترافیک عالی عمل کند.

**۲. تفاوت قمر با سرویس‌مش‌هایی مثل Istio چیست؟**
قمر برخلاف Istio، پیچیدگی‌های غیرضروری کوبرنتیز را حذف کرده است. اگر به دنبال سرعت در پیاده‌سازی هستید و نمی‌خواهید درگیر تنظیمات تو در توی YAML شوید، قمر انتخاب هوشمندانه‌تری است.

**۳. چطور می‌توانم پلاگین اختصاصی خودم را بنویسم؟**
قمر از یک معماری ماژولار مبتنی بر Go استفاده می‌کند. می‌توانید در پوشه `/plugins` کدهای خود را قرار دهید و با کامپایل مجدد هسته، از آن‌ها بهره‌مند شوید.

## نکات حرفه‌ای (Pro-Tips)
*   **مانیتورینگ:** همیشه از ابزار `qamar stats` برای بررسی لحظه‌ای گلوگاه‌های ترافیکی استفاده کنید.
*   **امنیت:** در محیط‌های عملیاتی، حتماً `TLS` را در بخش کانفیگ فعال کنید؛ قمر به طور پیش‌فرض از گواهینامه‌های `Let's Encrypt` پشتیبانی می‌کند.

اگر در حین کار با قمر به چالش خاصی برخوردید، مستندات کامل را در [qamar.website](https://qamar.website) مطالعه کنید. معتقدم استفاده از این ابزار می‌تواند حداقل ۳۰ درصد از زمان توسعه زیرساخت شما را کاهش دهد. اگر سوالی داشتید، در جامعه کاربری ما مطرح کنید!
