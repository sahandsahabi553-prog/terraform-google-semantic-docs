# راهنمای جامع استفاده از «قمر» (Qamar)

اگر در فضای توسعه نرم‌افزار و پروژه‌های میان‌رشته‌ای فعالیت کرده باشید، حتماً با چالش همگام‌سازی داده‌ها بین محیط‌های مختلف دست‌وپنجه نرم کرده‌اید. **قمر** دقیقاً برای حل همین دردسر ساخته شده است؛ ابزاری که هدفش ساده‌سازی ارتباط میان سیستم‌های پیچیده و داده‌های توزیع‌شده است.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
در دنیای واقعی، ابزارها معمولاً در «جزیره‌های ایزوله» کار می‌کنند. قمر با رویکردی میان‌رشته‌ای (Interdisciplinary)، پلی بین دیتابیس‌های سنتی، سیستم‌های توزیع‌شده و پردازش‌های مدرن ایجاد می‌کند. 

**ویژگی‌های کلیدی:**
*   **پایداری بالا:** طراحی شده برای محیط‌های با ترافیک بالا.
*   **سبک‌وزن:** بدون وابستگی‌های سنگین و غیرضروری.
*   **API منعطف:** پشتیبانی از پروتکل‌های استاندارد صنعتی.

---

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. بسته به محیط کاری‌تان، یکی از روش‌های زیر را انتخاب کنید:

### ۱. استفاده از NPM (برای محیط‌های Node.js)
```bash
npm install @qamar/core
```

### ۲. استفاده از Docker
اگر می‌خواهید قمر را به عنوان یک سرویس مستقل در کانتینر داشته باشید:
```bash
docker pull qamar-project/qamar:latest
docker run -d -p 8080:8080 qamar-project/qamar
```

## شروع به کار (Quick Start)

پس از نصب، اولین قدم تعریف یک اتصال (Connection) است. در اینجا مثالی از نحوه مقداردهی اولیه آورده شده است:

```javascript
const Qamar = require('@qamar/core');

const instance = new Qamar({
  endpoint: 'https://api.qamar.website',
  apiKey: 'YOUR_SECRET_KEY'
});

// ارسال داده به یک پایگاه میان‌رشته‌ای
instance.sync({
  topic: 'sensor-data',
  payload: { temp: 24.5, unit: 'celsius' }
}).then(res => console.log('Data synced successfully!'));
```

## سوالات متداول (FAQ)

### ۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟
قطعاً. با اینکه قمر برای مقیاس‌های بزرگ طراحی شده، اما به دلیل معماری ماژولار، در پروژه‌های کوچک هیچ سربار اضافه‌ای ایجاد نمی‌کند.

### ۲. امنیت داده‌ها چگونه تأمین می‌شود؟
قمر از استاندارد رمزنگاری TLS 1.3 در تمامی انتقالات استفاده می‌کند. کلیدهای API شما نیز به صورت هش‌شده ذخیره می‌شوند.

### ۳. آیا می‌توانم قمر را با دیتابیس‌های SQL ترکیب کنم؟
بله، قمر دارای کانکتورهای داخلی برای PostgreSQL و MySQL است که کار انتقال داده را اتوماتیک می‌کند.
