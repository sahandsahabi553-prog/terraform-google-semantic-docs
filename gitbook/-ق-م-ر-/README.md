# قمر (Qamar): راهنمای جامع مدیریت و هم‌افزایی میان‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که در آن نیاز به پیوند دادن دنیای داده‌های حجیم با رویکردهای علوم انسانی یا تحلیل‌های پیچیده ریاضی داشته‌اید، حتماً می‌دانید که «اتصال» این دنیاها چقدر می‌تواند دردناک باشد. **قمر (Qamar)** دقیقاً برای حل همین مشکل طراحی شده است؛ ابزاری که هدفش ساده‌سازی فرآیند تعامل بین رشته‌های مختلف علمی و فنی است.

در این مستند، نگاهی فنی به نحوه راه‌اندازی و استفاده از قمر می‌اندازیم.

---

## ۱. چرا قمر؟
قمر صرفاً یک کتابخانه یا فریم‌ورک نیست؛ یک اکوسیستم برای مدیریت جریان‌های کاری (Workflows) است که از مرزهای سنتی علوم عبور می‌کند. وقتی داده‌های شما از جنس «متن» هستند و پردازش شما از جنس «بهینه‌سازی ریاضی»، قمر همان پل ارتباطی است که به آن نیاز دارید.

*   **انعطاف‌پذیری بالا:** پشتیبانی از فرمت‌های داده‌ای متنوع.
*   **معماری ماژولار:** اضافه کردن قابلیت‌های جدید بدون دستکاری هسته.
*   **مقیاس‌پذیری:** طراحی شده برای پروژه‌های آکادمیک و صنعتی.

---

## ۲. نصب و راه‌اندازی
برای شروع، کافی است محیط پایتون خود را آماده داشته باشید. پیشنهاد می‌کنم همیشه از یک `venv` یا `conda` استفاده کنید تا تداخل کتابخانه‌ها کلافه‌تان نکند.

### پیش‌نیازها
- Python 3.9+
- دسترسی به اینترنت برای دریافت پکیج‌های وابسته

### دستور نصب
```bash
# نصب از طریق مخزن اصلی
pip install qamar-core

# تأیید نصب
qamar --version
```

## ۳. استفاده پایه
کار با قمر بسیار سرراست است. فرض کنید می‌خواهید یک مجموعه داده متنی را با یک الگوریتم تحلیل آماری ترکیب کنید.

```python
from qamar import Engine, Bridge

# مقداردهی اولیه موتور قمر
engine = Engine(config="settings.yaml")

# تعریف پل ارتباطی بین دو حوزه
bridge = Bridge(source="text_data", target="stat_model")

# اجرای عملیات
result = engine.execute(bridge, task="analysis_01")
print(f"نتیجه نهایی: {result.summary()}")
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. با اینکه قمر برای مقیاس‌های بزرگ ساخته شده، اما ساختار سبک آن باعث می‌شود در پروژه‌های کوچک هم سربار (Overhead) اضافه‌ای نداشته باشد.

**چگونه می‌توانم ماژول اختصاصی خودم را اضافه کنم؟**
شما می‌توانید با ارث‌بری از کلاس `BaseModule` در قمر، منطق شخصی‌سازی شده خود را بنویسید و آن را در پوشه `extensions` پروژه قرار دهید.

**آیا از داده‌های حجیم (Big Data) پشتیبانی می‌کند؟**
بله، قمر به صورت بومی از پردازش‌های توزیع‌شده پشتیبانی می‌کند تا در هنگام کار با داده‌های سنگین، سیستم شما قفل نکند.
