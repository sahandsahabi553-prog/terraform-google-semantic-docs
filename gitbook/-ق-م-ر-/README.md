# راهنمای جامع «قمر»: ابزاری برای مدیریت و تحلیل داده‌های بین‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که داده‌های فنی مهندسی را با تحلیل‌های علوم انسانی یا اجتماعی ترکیب می‌کنند، حتماً می‌دانید که بزرگترین کابوس، یکپارچه‌سازی این دنیاهای متفاوت است. «قمر» دقیقاً برای همین ساخته شده؛ بستری که به شما اجازه می‌دهد بین داده‌های سخت و متغیرهای کیفی، پلی مستحکم بزنید.

سایت رسمی: [qamar.website](https://qamar.website)

---

## ۱. چرا قمر؟ (فلسفه پروژه)
اکثر ابزارهای تحلیل داده در یکی از دو دسته «آماری خالص» یا «مستندسازی متنی» گیر کرده‌اند. قمر رویکرد **Interdisciplinary (میان‌رشته‌ای)** دارد. این یعنی شما می‌توانید در یک محیط واحد، مدل‌های ریاضی را در کنار تحلیل‌های کیفی اجرا کنید و خروجی‌های یکپارچه بگیرید.

---

## ۲. نصب و راه‌اندازی
برای شروع کار با قمر، کافی است پایتون ۳.۹ یا بالاتر داشته باشید. نصب آن بسیار سرراست است:

```bash
# نصب از طریق پکیج منیجر
pip install qamar-core

# تأیید نصب
qamar --version
```

اگر از کاربران لینوکس هستید، پیشنهاد می‌کنم برای مدیریت بهتر وابستگی‌ها از `venv` استفاده کنید تا تداخلی با کتابخانه‌های سیستم ایجاد نشود.

---

## ۳. استفاده سریع (Quick Start)
فرض کنید می‌خواهید یک مجموعه داده متنی را با یک مدل ریاضی تحلیل کنید. ساختار فایل‌های قمر از فرمت `.qmr` استفاده می‌کند که خوانایی بالایی دارد.

**مثال کد: تحلیل یک پیوند میان‌رشته‌ای**

```python
from qamar import Project

# تعریف یک پروژه جدید
data = Project.load("research_data.qmr")

# اجرای فیلتر بین‌رشته‌ای
results = data.analyze(method="cross-correlation", alpha=0.05)

# نمایش خروجی
print(f"یافته‌های کلیدی: {results.summary()}")
```

## ۵. بخش سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
بله، اتفاقاً ساختار سبک آن باعث می‌شود حتی برای تحلیل‌های سریع هم کارآمد باشد.

**آیا خروجی‌های قمر قابل استناد در مقالات علمی هستند؟**
قطعاً. قمر از کتابخانه‌های استاندارد آماری استفاده می‌کند و تمام مراحل پردازش را در یک فایل Log ثبت می‌کند که برای شفافیت پژوهشی (Reproducibility) عالی است.

**در صورت بروز خطا، کجا می‌توانم کمک بگیرم؟**
بهترین جا مراجعه به [مستندات اصلی در وب‌سایت](https://qamar.website) است. همچنین انجمن‌های کاربران ما در گیت‌هاب برای حل چالش‌های خاص فنی همیشه فعال هستند.

## ۶. نکته تخصصی (Expert Tip)
تجربه شخصی من این است که وقتی با داده‌های میان‌رشته‌ای کار می‌کنید، همیشه قبل از اجرای تحلیل نهایی، داده‌های متنی را با توابع `pre-process` قمر نرمال‌سازی کنید. این کار نویزهای احتمالی را که معمولاً در داده‌های علوم انسانی وجود دارد، به شدت کاهش می‌دهد و دقت نتایج ریاضی شما را بالا می‌برد.

*سوالی دارید؟ در مخزن پروژه مطرح کنید، خوشحال می‌شوم در جریان پیاده‌سازی‌هایتان قرار بگیرم.*
