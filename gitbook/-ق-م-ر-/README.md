# راهنمای جامع کار با «قمر» (Qamar)

در دنیای پیچیده مدیریت داده‌ها و ابزارهای میان‌رشته‌ای، گاهی اوقات به چیزی نیاز دارید که نه تنها کارآمد باشد، بلکه به‌خوبی با جریان کاری (Workflow) شما ترکیب شود. **قمر (Qamar)** دقیقاً همین خلاء را پر می‌کند. این ابزار برای کسانی طراحی شده که در تقاطع علوم مختلف، از تحلیل داده گرفته تا مدیریت محتوا، فعالیت می‌کنند.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
بیشتر ابزارهای موجود یا بیش از حد تخصصی هستند (و کار با آن‌ها کابوس است) یا بیش از حد ساده. قمر به شما اجازه می‌دهد لایه‌های مختلف اطلاعات را بدون درگیری با پیچیدگی‌های غیرضروری به هم متصل کنید. 

### ویژگی‌های کلیدی
*   **انعطاف‌پذیری بالا:** پشتیبانی از فرمت‌های متنوع داده.
*   **سرعت:** بهینه‌سازی شده برای پردازش‌های میان‌رشته‌ای.
*   **رابط کاربری مینیمال:** تمرکز بر آنچه واقعاً اهمیت دارد: محتوا.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. برای شروع، ترمینال خود را باز کنید و دستور زیر را وارد کنید:

```bash
# نصب از طریق پکیج‌منیجر محبوب شما
npm install -g qamar-cli
# یا اگر از محیط پایتون استفاده می‌کنید
pip install qamar-core
```

پس از نصب، می‌توانید با دستور `qamar --version` از صحت نصب مطمئن شوید.

## شروع به کار (Quick Start)

برای اینکه سریع دست‌به‌کار شوید، یک پروژه جدید ایجاد کنید:

```bash
qamar init my-project
cd my-project
qamar run --input data.json
```

در اینجا یک مثال ساده از ساختار فایل تنظیمات `config.yaml` آورده شده است:

```yaml
project: "Research_Alpha"
mode: "interdisciplinary"
settings:
  deep_scan: true
  export_format: "pdf"
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ مقیاس (Enterprise) مناسب است؟**
بله، معماری ماژولار قمر اجازه می‌دهد تا در پروژه‌های بزرگ به‌راحتی مقیاس‌پذیر باشد.

**۲. پشتیبانی از زبان فارسی چطور است؟**
قمر از همان ابتدا با در نظر گرفتن حروف فارسی و نیم‌فاصله‌ها بهینه‌سازی شده است. در پردازش متون فارسی، عملکرد آن بسیار دقیق‌تر از ابزارهای مشابه است.

**۳. آیا نیاز به دانش برنامه‌نویسی عمیق دارم؟**
خیر، رابط کاربری به‌گونه‌ای طراحی شده که حتی با دانش اندک در مورد خط فرمان (CLI) هم می‌توانید از آن خروجی‌های فوق‌العاده بگیرید.
