# مستند فنی: «قمر» (Qamar)
### پلتفرم پیشرو در تحلیل و بصری‌سازی داده‌های میان‌رشته‌ای

اگر درگیر پروژه‌هایی هستید که مرزهای علوم داده، هنر و تحلیل‌های رفتاری را جابه‌جا می‌کنند، احتمالاً نام «قمر» به گوشتان خورده است. قمر یک ابزار قدرتمند برای کسانی است که نمی‌خواهند بین «دقت ریاضی» و «روایت بصری» یکی را انتخاب کنند. این ابزار دقیقاً برای پر کردن شکاف بین فیلدهای مختلف طراحی شده است.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه پروژه)
خیلی از ما در پروژه‌های میان‌رشته‌ای با یک مشکل بزرگ مواجه می‌شویم: داده‌ها ایزوله هستند. قمر به شما اجازه می‌دهد تا جریان‌های مختلف داده را به هم گره بزنید و خروجی‌هایی بگیرید که هم برای یک دانشمند قابل فهم است و هم برای یک طراح، خیره‌کننده.

## ۱. نصب و راه‌اندازی
نصب قمر بسیار سرراست است. ما سعی کردیم وابستگی‌ها را به حداقل برسانیم تا در محیط‌های مختلف (از سرورهای لینوکسی تا سیستم‌عامل‌های شخصی) به راحتی اجرا شود.

### پیش‌نیازها:
*   Node.js نسخه ۱۸ به بالا
*   یک پردازنده با قابلیت پردازش موازی (پیشنهادی)

```bash
# نصب پکیج اصلی از طریق npm
npm install -g @qamar/core

# بررسی صحت نصب
qamar --version
```

---

## ۲. استفاده پایه
برای شروع، کافی است یک فایل پیکربندی ساده ایجاد کنید. قمر بر اساس ساختار JSON-Schema پیش می‌رود که کار را برای تیم‌های فنی بسیار ساده کرده است.

### ساختار یک پروژه ساده:
```javascript
const qamar = require('@qamar/core');

const project = qamar.init({
  mode: 'interdisciplinary',
  dataset: './data/raw_inputs.csv',
  output: './build/report'
});

project.run();
```

## ۴. مثال کاربردی: ترکیب علوم شناختی و گرافیک
فرض کنید می‌خواهید خروجی‌های رفتاری یک آزمایشگاه علوم اعصاب را به یک مدل سه‌بعدی تبدیل کنید. قمر این کار را در چند خط انجام می‌دهد:

```javascript
// تعریف یک نگاشت بصری از داده‌های عصبی
qamar.map('neural_signals', {
  to: 'geometry_nodes',
  intensity: 'scale',
  frequency: 'color_spectrum'
});
```
این قابلیت باعث می‌شود تا داده‌های خشک عددی، به یک فرم بصری معنادار تبدیل شوند که در جلسات دفاع یا ارائه پروژه‌های پیچیده، برگ برنده شما خواهد بود.

## ۵. سوالات متداول (FAQ)

**س: آیا قمر برای پروژه‌های کوچک شخصی هم مناسب است؟**
ج: قطعاً. قمر به همان اندازه که برای پروژه‌های سازمانی مقیاس‌پذیر است، برای کارهای خلاقانه شخصی نیز منعطف طراحی شده.

**س: آیا می‌توانم پلاگین اختصاصی خودم را بنویسم؟**
ج: بله! معماری قمر کاملاً ماژولار است. شما می‌توانید با استفاده از هسته TypeScript ما، هر نوع پردازنده داده‌ای که نیاز دارید را به سیستم تزریق کنید.

**س: سنگین‌ترین بخش قمر چیست؟**
ج: رندر کردن داده‌های حجیم (Big Data). پیشنهاد می‌کنم برای این کار از قابلیت *Stream Processing* استفاده کنید که در مستندات پیشرفته قمر توضیح داده شده است.
