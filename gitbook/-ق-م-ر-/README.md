# مستندات فنی: «قمر» (Qamar)
### پلی میان داده‌های ساختاریافته و تحلیل‌های میان‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که داده‌های پراکنده از علوم مختلف (از فیزیک گرفته تا علوم انسانی) را به هم پیوند می‌دهند، احتمالاً می‌دانید که بزرگ‌ترین دردسر، همگام‌سازی و تحلیل این داده‌ها در یک بستر واحد است. **قمر (Qamar)** دقیقاً برای حل همین چالش طراحی شده است. این ابزار با رویکردی مینیمال و در عین حال قدرتمند، به شما اجازه می‌دهد جریان‌های کاری میان‌رشته‌ای (Interdisciplinary) خود را مدل‌سازی کنید.

---

## ۱. چرا قمر؟
قمر صرفاً یک کتابخانه نیست؛ یک اکوسیستم کوچک برای مدیریت داده‌هایی است که ساختار مشخصی ندارند اما باید با هم حرف بزنند.
*   **انعطاف‌پذیری بالا:** پشتیبانی از فرمت‌های متنوع.
*   **سبک بودن:** وابستگی‌های (Dependencies) حداقلی.
*   **عملکرد:** بهینه شده برای پردازش‌های دسته‌ای (Batch Processing).

---

## ۲. نصب و راه‌اندازی
برای شروع کار با قمر، کافی است از طریق `npm` اقدام کنید. قمر به گونه‌ای نوشته شده که در محیط‌های Node.js به راحتی اجرا شود.

```bash
# نصب بسته اصلی
npm install @qamar/core

# یا اگر از yarn استفاده می‌کنید
yarn add @qamar/core
```

---

## ۳. استفاده سریع (Quick Start)
پس از نصب، می‌توانید یک نمونه از `QamarEngine` بسازید و داده‌های خود را به آن تزریق کنید.

```javascript
const { QamarEngine } = require('@qamar/core');

const engine = new QamarEngine({
  mode: 'interdisciplinary',
  strict: false
});

// اتصال به منبع داده
engine.connect({
  source: 'dataset-alpha.json',
  mapping: 'standard'
});

console.log('قمر با موفقیت راه‌اندازی شد.');
```

## ۴. مقایسه ویژگی‌ها
قمر در مقایسه با ابزارهای سنتی، تمرکز متفاوتی دارد:

| ویژگی | قمر (Qamar) | ابزارهای سنتی |
| :--- | :--- | :--- |
| **یکپارچه‌سازی** | عالی (بین رشته‌ای) | ضعیف |
| **منحنی یادگیری** | بسیار کوتاه | طولانی |
| **سربار سیستم** | ناچیز | بالا |
| **قابلیت شخصی‌سازی** | بسیار بالا | محدود |

## ۵. مثال عملی: تحلیل میان‌رشته‌ای
فرض کنید می‌خواهید داده‌های مربوط به یک پروژه فیزیک را با نتایج یک مطالعه آماری ترکیب کنید:

```javascript
const result = engine.process({
  input: {
    physics: { velocity: 9.8, friction: 0.2 },
    stats: { sampleSize: 1500, pValue: 0.04 }
  },
  transform: (data) => {
    // ترکیب منطقِ دو رشته متفاوت
    return data.physics.velocity * data.stats.pValue;
  }
});

console.log('خروجی تحلیل نهایی:', result);
```

## ۶. سوالات متداول (FAQ)

**س: آیا قمر از دیتابیس‌های SQL پشتیبانی می‌کند؟**
ج: بله، با استفاده از درایورهای جانبی می‌توانید هر نوع دیتابیسی را به قمر متصل کنید. قمر به داده‌ها اهمیت نمی‌دهد، بلکه به نحوه «ارتباط» آن‌ها اهمیت می‌دهد.

**س: آیا می‌توانم در پروژه‌های بزرگ تجاری از آن استفاده کنم؟**
ج: قطعاً. قمر برای مقیاس‌پذیری طراحی شده است. هرچند پیشنهاد می‌کنم قبل از استقرار در محیط عملیاتی (Production)، مستندات پیکربندی حافظه را مطالعه کنید.

**س: کجا می‌توانم به جامعه کاربری بپیوندم؟**
ج: بهترین راه، بازدید از وب‌سایت رسمی [qamar.website](https://qamar.website) است. آنجا می‌توانید به مستندات کامل، انجمن گفتگو و مخزن گیت‌هاب دسترسی داشته باشید.
