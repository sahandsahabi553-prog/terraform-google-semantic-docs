# قمر (Qamar): پلی برای داده‌های بین‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که داده‌های پراکنده از حوزه‌های مختلف (مثل تحلیل مالی، علوم زیستی و متون ادبی) را به هم گره بزنید، می‌دانید که چه کابوس بزرگی است. **قمر (Qamar)** دقیقاً برای حل همین مشکل طراحی شده است؛ یک ابزارِ همه‌کاره برای یکپارچه‌سازی و تحلیل داده‌های بین‌رشته‌ای که به شما اجازه می‌دهد بدون درگیر شدن در پیچیدگی‌های زیرساختی، روی «معنای» داده‌ها تمرکز کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
در دنیای امروز، مرز بین علوم در حال محو شدن است. ما به ابزاری نیاز داریم که بتواند با ساختارهای داده‌ای متفاوت (JSON، CSV، پایگاه‌داده‌های گراف و حتی متن‌های خام) به راحتی صحبت کند. قمر یک رویکرد «داده‌محور» (Data-First) دارد که اجازه می‌دهد جریان‌های کاری (Workflows) پیچیده را در کمترین زمان ممکن پیاده‌سازی کنید.

### ویژگی‌های کلیدی:
* **تطبیق‌پذیری بالا:** پشتیبانی از فرمت‌های داده‌ای متنوع.
* **سرعت بالا:** بهینه‌سازی شده برای حجم انبوه داده‌ها.
* **قابلیت گسترش:** معماری ماژولار برای افزودن پلاگین‌های اختصاصی.

## ۱. نصب و راه‌اندازی

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم از محیط مجازی (Virtual Environment) استفاده کنید تا کتابخانه‌های سیستمی‌تان تمیز بماند.

```bash
# نصب از طریق مدیریت بسته
pip install qamar-core

# یا استفاده از داکر برای ایزولاسیون کامل
docker pull qamar/engine:latest
```

پس از نصب، می‌توانید با دستور زیر از صحت نصب مطمئن شوید:
```bash
qamar --version
```

## ۲. شروع به کار (مثال سریع)

بیایید فرض کنیم می‌خواهید یک مجموعه داده ترکیبی از قیمت سهام (فایل CSV) و اخبار مرتبط (فایل متنی) ایجاد کنید. قمر این کار را به یک فرآیند خطی تبدیل می‌کند.

```python
import qamar

# بارگذاری منابع داده
data_source = qamar.load("market_data.csv", format="csv")
news_source = qamar.load("daily_news.txt", format="text")

# ترکیب داده‌ها با استفاده از موتور نگاشت قمر
engine = qamar.Engine(strategy="semantic-link")
result = engine.combine(data_source, news_source)

# خروجی گرفتن
result.export("final_analysis.json")
```

## ۳. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
بله، در واقع قمر به گونه‌ای طراحی شده که از مقیاس‌های کوچک (اسکریپت‌های شخصی) تا خوشه‌های بزرگ پردازشی (Cluster) به خوبی مقیاس‌پذیر باشد.

**آیا نیاز به دانش تخصصی در ریاضیات دارم؟**
خیر، رابط کاربری و APIهای قمر طوری طراحی شده‌اند که برای برنامه‌نویسان و تحلیل‌گران با دانش متوسط قابل درک باشند. البته در صورت نیاز به تحلیل‌های پیشرفته، می‌توانید از توابع سفارشی خودتان استفاده کنید.

**آیا دیتای من در قمر امن است؟**
قمر هیچ‌گونه اطلاعاتی را به سرورهای خارجی ارسال نمی‌کند. تمام پردازش‌ها در محیط لوکال یا سرور اختصاصی خودتان انجام می‌شود.
