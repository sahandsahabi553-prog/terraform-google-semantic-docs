# راهنمای جامع «قمر» (Qamar): پیوند میان‌رشته‌ای در دنیای داده

اگر در پروژه‌های پیچیده که حوزه‌های مختلف علم و مهندسی را به هم گره می‌زنند فعالیت کرده باشید، حتماً با چالش «جزیره‌ای بودن داده‌ها» مواجه شده‌اید. **قمر (Qamar)** دقیقاً برای حل همین مشکل طراحی شده است. این ابزار، یک فریم‌ورک سبک و چابک برای مدیریت یکپارچه‌ی داده‌های میان‌رشته‌ای (Interdisciplinary) است که اجازه می‌دهد خروجی‌های حوزه‌های مختلف (مثلاً فیزیک، اقتصاد و علوم داده) را در یک ساختار واحد به هم متصل کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه وجودی)
در دنیای واقعی، داده‌ها در قالب‌های متفاوتی (JSON, CSV, NetCDF, یا حتی دیتابیس‌های خاص) هستند. قمر به شما کمک می‌کند تا این «هرج‌ومرج» را به یک جریان کاری (Workflow) معنادار تبدیل کنید.

### ویژگی‌های کلیدی:
*   **انعطاف‌پذیری:** پشتیبانی از فرمت‌های متنوع داده.
*   **میان‌رشته‌ای:** قابلیت اتصال مستقیم به کتابخانه‌های علمی و صنعتی.
*   **عملکرد بالا:** طراحی شده برای پردازش‌های سنگین بدون سربار اضافی.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم از محیط مجازی (Virtual Environment) استفاده کنید تا کتابخانه‌های پروژه با سیستم‌عامل تداخلی نداشته باشند.

```bash
# نصب از طریق pip
pip install qamar-core

# تأیید نصب
qamar --version
```

اگر اهل توسعه‌ هستید و می‌خواهید آخرین تغییرات را تست کنید:
```bash
git clone https://github.com/qamar-project/qamar.git
cd qamar
pip install -e .
```

## شروع به کار: یک مثال عملی

فرض کنید می‌خواهید داده‌های یک سنسور محیطی (فیزیک) را با یک مدل پیش‌بینی بازار (اقتصاد) ترکیب کنید. قمر این کار را با استفاده از "Q-Nodes" انجام می‌دهد.

```python
from qamar import QamarEngine

# مقداردهی اولیه موتور قمر
engine = QamarEngine(config="project_config.yaml")

# تعریف یک نقطه داده میان‌رشته‌ای
data_point = engine.create_node(
    source="sensor_alpha",
    payload={"temperature": 24.5, "humidity": 60},
    metadata={"domain": "meteorology"}
)

# اتصال داده به یک پروسسور تحلیل اقتصادی
result = engine.process(data_point, target="market_predictor")

print(f"تحلیل نهایی: {result.status}")
```

## جدول مقایسه‌ای: قمر در برابر روش‌های سنتی

| ویژگی | روش‌های سنتی (Scripts) | قمر (Qamar) |
| :--- | :--- | :--- |
| **یکپارچگی** | پایین (دستی) | بالا (خودکار) |
| **مقیاس‌پذیری** | سخت | بسیار بالا |
| **مدیریت خطا** | پراکنده | متمرکز و هوشمند |
| **یادگیری** | ساده | متوسط |

## سوالات متداول (FAQ)

### ۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟
بله، کاملاً. اگرچه قدرت اصلی قمر در پروژه‌های عظیم میان‌رشته‌ای مشخص می‌شود، اما به دلیل سبک بودن، برای اسکریپت‌های ساده هم عالی عمل می‌کند.

### ۲. آیا برای استفاده از قمر حتماً باید زبان برنامه‌نویسی خاصی بلد باشم؟
هسته اصلی قمر بر پایه پایتون است، اما رابط‌های کاربری آن طوری طراحی شده که با حداقل کدنویسی هم بتوانید خروجی بگیرید.

### ۳. چطور می‌توانم با جامعه کاربری در ارتباط باشم؟
می‌توانید به وب‌سایت [qamar.website](https://qamar.website) سر بزنید و در بخش انجمن‌ها (Community) سوالات خود را مطرح کنید.

## نکته فنی از تجربه‌ی شخصی
وقتی برای اولین بار از قمر در یک پروژه‌ی شبیه‌سازی اقلیمی استفاده کردم، بزرگترین درسی که گرفتم این بود: **ساختار داده‌ها را زودتر از موعد سخت‌گیرانه (Strict) نکنید.** قمر به شما اجازه می‌دهد در مراحل اولیه نمونه‌سازی، داده‌ها را انعطاف‌پذیر نگه دارید و فقط در لحظه تولید خروجی (Production) آن‌ها را اعتبارسنجی کنید. این کار سرعت توسعه را ۳ برابر می‌کند.
