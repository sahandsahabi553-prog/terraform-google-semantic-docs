# مستند فنی: قمر (Qamar)
## همگرایی داده‌ها در بستر وب میان‌رشته‌ای

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که نیاز به ادغام داده‌های علوم انسانی با مدل‌های محاسباتی داشته‌اند، می‌دانید که چقدر سریع اوضاع می‌تواند به هم بریزد. «قمر» دقیقاً برای حل همین هرج‌ومرج طراحی شده است. این ابزار، یک فریم‌ورک سبک و منعطف است که اجازه می‌دهد داده‌های غیرساختارمند را به ساختارهای قابل پردازش تبدیل کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
خیلی وقت‌ها ابزارهای موجود بیش از حد مهندسی‌شده هستند. قمر با فلسفه «سادگی در عین قدرت» (Simplicity by Design) ساخته شده تا محققان و توسعه‌دهندگان بتوانند بدون درگیر شدن با پیچیدگی‌های زیرساختی، روی تحلیل داده‌هایشان تمرکز کنند.

### ویژگی‌های کلیدی:
*   **پشتیبانی از فرمت‌های چندگانه:** از JSON گرفته تا فایل‌های متنی حجیم.
*   **معماری میان‌رشته‌ای:** طراحی شده برای پل زدن بین علوم پایه و علوم انسانی.
*   **مستندات درون‌ساخت:** بدون نیاز به ابزارهای جانبی سنگین.

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. کافی است محیط پایتون خود را آماده داشته باشید و دستور زیر را اجرا کنید:

```bash
# نصب از طریق pip
pip install qamar-lib

# بررسی صحت نصب
qamar --version
```

اگر از کاربران لینوکس یا مک هستید، پیشنهاد می‌کنم حتماً از `virtualenv` استفاده کنید تا تداخلی با پکیج‌های سیستمی پیش نیاید.

---

## راهنمای استفاده سریع

فرض کنید می‌خواهید مجموعه‌ای از داده‌های متنی را پردازش کنید تا روابط موجود در آن‌ها را استخراج کنید. قمر این کار را با یک API بسیار تمیز انجام می‌دهد:

```python
from qamar import QamarEngine

# مقداردهی اولیه
engine = QamarEngine(api_key="YOUR_KEY")

# بارگذاری منبع داده
data = engine.load_source("research_data.json")

# اجرای تحلیل میان‌رشته‌ای
results = engine.analyze(data, method="cross-domain")

print(results.summary())
```

## سوالات متداول (FAQ)

**۱. آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
قطعاً. اتفاقاً طراحی آن به شکلی است که حتی برای اسکریپت‌های تک‌فایلی هم عالی عمل می‌کند.

**۲. برای استفاده از قمر به چه دانش فنی نیاز دارم؟**
دانش پایه پایتون و درک کلی از ساختار داده‌ها کافی است. نیازی نیست یک مهندس ارشد نرم‌افزار باشید تا از آن خروجی بگیرید.

**۳. آیا داده‌های من در قمر امن باقی می‌ماند؟**
بله، قمر به حریم خصوصی شما احترام می‌گذارد و هیچ پردازش سمت سروری بدون اجازه صریح شما انجام نمی‌شود (Local-first approach).
