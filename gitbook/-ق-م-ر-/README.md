# مستند فنی: «قمر» (Qamar)؛ راهکاری برای مدیریت متمرکز داده‌های میان‌رشته‌ای

در دنیای امروز که مرز بین علوم انسانی، هنر و مهندسی روز‌به‌روز کمرنگ‌تر می‌شود، مدیریت داده‌های پراکنده به یک کابوس تبدیل شده است. **قمر (Qamar)** ابزاری است که دقیقاً برای حل همین مشکل طراحی شده؛ یک پلتفرم متن‌باز و منعطف برای کسانی که می‌خواهند بین دانش فنی و فعالیت‌های خلاقانه‌شان پل بزنند.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا به «قمر» نیاز داریم؟

بسیاری از ما در پروژه‌های بین‌رشته‌ای (Interdisciplinary) با مشکل «جزیره‌های داده» مواجهیم. یادداشت‌های تحقیقاتی در یک جا، کدهای پایتون در جای دیگر و خروجی‌های بصری در فضایی متفاوت. قمر با استفاده از ساختار درختی و پیوندهای ارگانیک، این پراکندگی را به یک شبکه منسجم تبدیل می‌کند.

### ویژگی‌های کلیدی
*   **ساختار منعطف:** بدون محدودیت در مدل‌سازی داده‌ها.
*   **پشتیبانی از Markdown پیشرفته:** ایده‌آل برای مستندسازی فنی در کنار تحلیل‌های کیفی.
*   **API بومی:** امکان اتصال ابزارهای تحلیل داده (مثل Pandas) به محیط کاری.

---

## نصب و راه‌اندازی

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم برای پایداری بیشتر از محیط‌های مجازی (Virtual Environments) استفاده کنید.

```bash
# نصب از طریق پکیج منیجر
pip install qamar-cli

# مقداردهی اولیه در دایرکتوری پروژه
qamar init --template academic
```

اگر ترجیح می‌دهید از نسخه وب استفاده کنید، کافی‌ست به [قمر](https://qamar.website) بروید و فضای کاری خود را بسازید.

## استفاده و گردش کار

فرض کنید در حال انجام یک پروژه بین‌رشته‌ای در زمینه «تحلیل داده‌های آماری در متون تاریخی» هستید. شما می‌توانید با استفاده از دستورات قمر، پیوندهایی بین فایل‌های کد و تحلیل‌های متنی ایجاد کنید.

### مثال: تعریف یک نود (Node) داده‌ای
در قمر، هر واحد اطلاعات یک «نود» محسوب می‌شود.

```yaml
id: study-001
title: "تحلیل الگوهای زبانی در متون قرن دهم"
tags: [linguistics, history, python]
metadata:
  source: "کتابخانه ملی"
  method: "NLP-based"
```

### تحلیل داده با استفاده از کتابخانه قمر (نمونه کد پایتون)
شما می‌توانید به راحتی داده‌های ثبت شده در قمر را مستقیماً فراخوانی کنید:

```python
from qamar import QamarClient

client = QamarClient(api_key="YOUR_KEY")

# فراخوانی تمام داده‌های مرتبط با یک تگ خاص
data = client.get_nodes(tags=["linguistics"])

for item in data:
    print(f"یافته جدید: {item.title}")
```

## پرسش‌های متداول (FAQ)

**۱. آیا قمر برای پروژه‌های بزرگ تیمی مناسب است؟**
بله، سیستم کنترل نسخه داخلی قمر اجازه می‌دهد چندین نفر همزمان روی یک پایگاه دانش کار کنند بدون اینکه تداخلی در پیوندها ایجاد شود.

**۲. آیا می‌توانم خروجی‌هایم را به فرمت‌های دیگر تبدیل کنم؟**
بله، موتور خروجی قمر از فرمت‌های `PDF` ، `LaTeX` و `JSON` پشتیبانی می‌کند تا بتوانید خروجی کار خود را مستقیماً برای کنفرانس‌ها یا ژورنال‌ها ارسال کنید.

**۳. آیا استفاده از قمر پیچیدگی فنی بالایی دارد؟**
اگر کمی با `Markdown` آشنا باشید، یادگیری قمر کمتر از ۳۰ دقیقه زمان می‌برد. رابط کاربری آن به شکلی طراحی شده که همزمان هم برای برنامه‌نویسان و هم برای محققان علوم انسانی قابل درک باشد.
