# مستندات فنی: «قمر» (Qamar)
### پلی میان داده‌ها، تحلیل و بینش میان‌رشته‌ای

اگر تا به حال در پروژه‌های پیچیده که ترکیبی از علوم انسانی، تحلیل داده و توسعه نرم‌افزار هستند درگیر شده باشید، می‌دانید که بزرگترین چالش، «یکپارچگی» است. **قمر** دقیقاً برای حل همین مشکل متولد شده؛ ابزاری که هدفش ساده‌سازی ارتباط میان دامنه‌های مختلف دانشی است.

---

## ۱. چرا قمر؟
در دنیای واقعی، داده‌ها ایزوله نیستند. یک پژوهشگر علوم اجتماعی ممکن است به همان اندازه به تحلیل‌های آماری نیاز داشته باشد که یک مهندس داده به تفسیر متنی. قمر بستری فراهم می‌کند که این شکاف را با استفاده از پروتکل‌های منعطف و کتابخانه‌های سبک پر کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## ۲. نصب و راه‌اندازی (Installation)

نصب قمر به طرز عجیبی ساده است. ما از مدیریت پکیج `pip` برای اکوسیستم پایتون استفاده می‌کنیم تا همه چیز سریع و تمیز باقی بماند.

```bash
# نصب مستقیم از مخزن اصلی
pip install qamar-framework

# بررسی صحت نصب
qamar --version
```

**پیش‌نیازها:**
- پایتون نسخه ۳.۹ یا بالاتر
- حداقل ۲ گیگابایت رم (برای پردازش‌های میان‌رشته‌ای سنگین)

---

## ۳. استفاده و مثال‌های کد

بیایید فرض کنیم می‌خواهید یک مجموعه داده متنی را با یک الگوی تحلیلی خاص ترکیب کنید. در قمر، این کار در چند خط کد خلاصه می‌شود:

```python
from qamar import Engine, Processor

# مقداردهی اولیه موتور قمر
engine = Engine(mode="interdisciplinary")

# تعریف یک پردازشگر داده
data_source = "path/to/your/research_data.json"
result = engine.analyze(source=data_source, strategy="semantic-bridge")

print(f"تحلیل نهایی: {result.summary}")
```

## ۴. ساختار معماری
قمر از یک معماری ماژولار بهره می‌برد که اجازه می‌دهد شما بدون تغییر در هسته اصلی، «افزونه‌های دانشی» (Knowledge Plugins) خودتان را بنویسید. این یعنی اگر در یک رشته خاص (مثلاً زبان‌شناسی محاسباتی) تخصص دارید، قمر برای شما حکم یک آچار فرانسه را خواهد داشت.

## ۵. سوالات متداول (FAQ)

**س: آیا قمر فقط برای برنامه‌نویس‌هاست؟**
ج: قطعاً خیر. اگرچه قدرت اصلی قمر در کدنویسی نمایان می‌شود، اما رابط خط فرمان (CLI) آن به گونه‌ای طراحی شده که پژوهشگران حوزه علوم انسانی هم بتوانند بدون درگیری با پیچیدگی‌های کد، از خروجی‌های آن استفاده کنند.

**س: چطور می‌توانم در توسعه قمر مشارکت کنم؟**
ج: ما همیشه از ایده‌های جدید استقبال می‌کنیم. کافی است سری به مستندات مخزن در [qamar.website](https://qamar.website) بزنید و نگاهی به بخش `CONTRIBUTING.md` بیندازید.

**س: آیا برای پروژه‌های تجاری رایگان است؟**
ج: بله، قمر تحت مجوزهای متن‌باز منتشر شده و استفاده از آن در پروژه‌های تجاری کاملاً آزاد و بلامانع است.
