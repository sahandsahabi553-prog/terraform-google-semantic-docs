# مستند فنی قمر (Qamar): پلی میان علوم و داده‌ها

در دنیای امروز، مرزهای بین رشته‌های علمی به شدت کمرنگ شده است. برای تحلیل داده‌های پیچیده که از حوزه‌های مختلف (مثل فیزیک، اقتصاد و علوم اجتماعی) سرچشمه می‌گیرند، ما به ابزاری نیاز داریم که فراتر از یک کتابخانه معمولی عمل کند. **قمر (Qamar)** دقیقاً همین هدف را دنبال می‌کند؛ یک پلتفرم متن‌باز برای مدل‌سازی میان‌رشته‌ای.

وب‌سایت رسمی: [https://qamar.website](https://qamar.website)

---

## چرا قمر؟
بیشتر ابزارهای موجود در بازار یا بیش از حد ریاضی‌محور هستند یا تمرکزشان صرفاً روی تصویرسازی است. قمر به شما اجازه می‌دهد مدل‌های مفهومی خود را به صورت کدهای اجرایی درآورید که بین رشته‌های مختلف "حرف مشترک" می‌زنند.

### ویژگی‌های کلیدی
*   **انعطاف‌پذیری بالا:** قابلیت اتصال به دیتاسورهای مختلف (JSON, CSV, SQL).
*   **موتور پردازش موازی:** بهینه‌شده برای محاسبات سنگین.
*   **ساختار ماژولار:** اضافه کردن توابع جدید مثل آب خوردن است.

## ۱. نصب و راه‌اندازی

برای شروع کار با قمر، کافی است پایتون ۳.۸ یا بالاتر داشته باشید. پیشنهاد می‌کنم حتماً از یک `venv` برای ایزوله کردن محیط استفاده کنید.

```bash
# ایجاد محیط مجازی
python -m venv qamar-env
source qamar-env/bin/activate

# نصب از طریق pip
pip install qamar-core
```

## ۲. استفاده پایه: اولین مدل میان‌رشته‌ای

فرض کنید می‌خواهیم تاثیر نوسانات بازار (اقتصاد) را بر نرخ مصرف انرژی (فیزیک/مهندسی) بسنجیم. قمر این کار را با یک API بسیار ساده انجام می‌دهد.

```python
from qamar import Model, Engine

# تعریف مدل میان‌رشته‌ای
model = Model(name="Energy-Market-Nexus")

# اضافه کردن متغیرها
model.add_variable("market_fluctuation", type="float")
model.add_variable("energy_consumption", type="float")

# اجرای موتور تحلیل
engine = Engine(model)
result = engine.run(input_data={'market_fluctuation': 0.85})

print(f"نتیجه تحلیل: {result.predict()}")
```

## ۴. پرسش‌های متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
بله، معماری قمر به گونه‌ای طراحی شده که در کلاسترها به خوبی مقیاس‌پذیر باشد.

**آیا می‌توانم توابع اختصاصی خودم را به آن اضافه کنم؟**
قطعاً. سیستم پلاگین‌های قمر کاملاً باز است. کافی است کلاس `BaseOperator` را ارث‌بری کنید.

**آیا مستندات آفلاین هم موجود است؟**
بله، با اجرای دستور `qamar --docs-offline` می‌توانید فایل‌های راهنما را در سیستم خود ذخیره کنید.
