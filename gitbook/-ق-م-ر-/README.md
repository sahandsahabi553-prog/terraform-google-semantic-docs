# راهنمای جامع استفاده از پلتفرم «قمر» (Qamar)

اگر در دنیای پژوهش‌های میان‌رشته‌ای (Interdisciplinary) فعالیت می‌کنید، احتمالاً می‌دانید که بزرگ‌ترین دردسر، مدیریت داده‌های پراکنده و برقراری ارتباط بین ابزارهای مختلف است. «قمر» دقیقاً برای حل همین مشکل ساخته شده؛ یک هاب مرکزی که اجازه می‌دهد پروژه‌های علمی و فنی را بدون درگیری با پیچیدگی‌های زیرساختی، یکپارچه کنید.

وب‌سایت رسمی: [https://qamar.website](https://qamar.website)

---

## چرا قمر؟ (نگاهی از دید یک توسعه‌دهنده)

بیشتر ابزارهای موجود یا بیش از حد "کد-محور" هستند یا فقط برای مدیریت پروژه طراحی شده‌اند. قمر رویکرد متفاوتی دارد. این پلتفرم با ارائه یک API منعطف و محیطی برای اجرای اسکریپت‌های تحلیلی، به شما اجازه می‌دهد خروجی‌های یک آزمایش بیولوژیک را مستقیماً با مدل‌های آماری خود در پایتون ترکیب کنید.

### ویژگی‌های کلیدی:
*   **انعطاف‌پذیری بالا:** پشتیبانی از فرمت‌های داده‌ای متنوع.
*   **یکپارچگی سریع:** اتصال آسان به محیط‌های لوکال.
*   **مقیاس‌پذیری:** از پروژه‌های کوچک دانشگاهی تا داده‌های کلان صنعتی.

## ۲. استفاده پایه: اولین اتصال

برای اینکه بفهمید همه چیز درست کار می‌کند، یک اتصال ساده به دیتابیسِ ابری قمر برقرار کنید:

```python
from qamar import QamarClient

# ایجاد کلاینت
client = QamarClient(project_id="my-research-project")

# دریافت داده‌های یک آزمایش خاص
data = client.fetch_dataset("experiment_01_alpha")

print(f"تعداد رکوردها: {len(data)}")
```

## ۳. جدول مقایسه قابلیت‌ها

برای اینکه دید بهتری نسبت به جایگاه قمر در ورک‌فلو خود داشته باشید:

## ۴. مثال کاربردی: تحلیل میان‌رشته‌ای

فرض کنید می‌خواهید داده‌های سنسور (IoT) را با خروجی‌های مدل یادگیری ماشین خود ترکیب کنید. قمر این کار را به شکل "خط لوله" (Pipeline) مدیریت می‌کند:

```python
# تعریف یک پردازشگر داده
@qamar.pipeline(input="sensors", output="analysis")
def process_data(data):
    # لاجیک پیچیده شما اینجا قرار می‌گیرد
    return [d * 1.5 for d in data]

# اجرا
qamar.run(process_data)
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های متن‌باز رایگان است؟**
بله، برای پژوهشگران آکادمیک و پروژه‌های متن‌باز (Open Source)، قمر پلن‌های ویژه‌ای در نظر گرفته که هزینه‌ها را به حداقل می‌رساند.

**داده‌های من کجا ذخیره می‌شوند؟**
قمر از زیرساخت‌های ابری توزیع‌شده استفاده می‌کند. شما در تنظیمات پروژه می‌توانید تعیین کنید که داده‌ها در کدام ریجن (Region) ذخیره شوند تا با استانداردهای حریم خصوصی (مثل GDPR) مطابقت داشته باشد.

**آیا می‌توانم از زبان‌های دیگر به جز پایتون استفاده کنم؟**
بله، REST API قمر به شما اجازه می‌دهد از هر زبانی (مثل Go، Node.js یا حتی Bash) به پلتفرم متصل شوید.
