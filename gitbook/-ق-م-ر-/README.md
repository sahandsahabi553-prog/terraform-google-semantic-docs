# راهنمای جامع کار با «قمر» (Qamar)

اگر تا به حال درگیر پروژه‌هایی بوده‌اید که نیاز به مدیریت داده‌های چندرشته‌ای (Interdisciplinary) داشته‌اند، احتمالاً می‌دانید که چقدر سریع اوضاع به هم می‌ریزد. **قمر** دقیقاً برای حل همین هرج‌ومرج طراحی شده است. این ابزار به شما کمک می‌کند تا جریان‌های کاری بین علوم مختلف را به شکلی ساختاریافته به هم متصل کنید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟
در دنیای واقعی، داده‌های شما فقط یک فرمت ندارند. گاهی با خروجی‌های حسگرهای IoT سر و کار دارید، گاهی با فایل‌های مالی پیچیده و گاهی با نتایج تحلیل‌های آماری. قمر به جای اینکه شما را مجبور به استفاده از ابزارهای جداگانه کند، یک لایه‌ی انتزاعیِ یکپارچه روی همه‌ی این‌ها می‌کشد.

---

## نصب و راه‌اندازی

نصب قمر بسیار ساده است. کافی است محیط پایتون خود را آماده داشته باشید و دستور زیر را اجرا کنید:

```bash
# نصب از طریق pip
pip install qamar-core

# تأیید نصب
qamar --version
```

اگر از کاربران لینوکس هستید و می‌خواهید پرفورمنس بهتری داشته باشید، پیشنهاد می‌کنم مستقیماً از سورس‌کد کامپایل کنید:

```bash
git clone https://github.com/qamar-project/qamar
cd qamar
make install
```

## شروع به کار (Quick Start)

اولین قدم، تعریف یک «کانکتور» برای داده‌هایتان است. بیایید فرض کنیم می‌خواهید داده‌های یک سیستم فیزیکی را با یک دیتابیس SQL ترکیب کنید.

```python
from qamar import QamarEngine

# مقداردهی اولیه
engine = QamarEngine(workspace="./my_project")

# ثبت منبع داده
engine.register_source("sensor_data", type="csv", path="data/thermal.csv")

# اجرای کوئری بین‌رشته‌ای
result = engine.query("SELECT * FROM sensor_data WHERE temp > 80")
print(result.summary())
```

## نکات کلیدی برای توسعه‌دهندگان

1. **مدیریت وضعیت (State Management):** همیشه سعی کنید `workspace` خود را در فایل `.gitignore` قرار ندهید تا تاریخچه تغییرات در `git` باقی بماند.
2. **بهینه‌سازی:** برای دیتاست‌های حجیم، از قابلیت `lazy_loading` در قمر استفاده کنید تا کل داده در RAM بارگذاری نشود.
