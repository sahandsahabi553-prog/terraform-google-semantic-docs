# راهنمای جامع «قمر» (Qamar): پلی میان دانش و تکنولوژی

در دنیای امروز که مرزهای بین رشته‌های تخصصی به‌شدت کمرنگ شده، ابزارهایی مثل **قمر (Qamar)** حکم یک پل حیاتی را دارند. قمر صرفاً یک کتابخانه یا فریم‌ورک نیست؛ بلکه یک رویکرد سیستماتیک برای یکپارچه‌سازی داده‌های میان‌رشته‌ای (Interdisciplinary) است. اگر تا به حال با چالشِ همگام‌سازی داده‌های پراکنده در پروژه‌های پیچیده دست‌وپنج نرم کرده‌اید، قمر همان چیزی است که جای خالی‌اش را حس می‌کردید.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
بیشتر ابزارهای موجود، تک‌بعدی هستند. اما قمر با نگاهی به معماری ماژولار، اجازه می‌دهد داده‌های حاصل از علوم مختلف (مثلاً فیزیک، اقتصاد و علوم داده) را در یک ساختار واحد تحلیل کنید. 

**مزایای کلیدی:**
*   **انعطاف‌پذیری بالا:** پشتیبانی از فرمت‌های داده‌ای متنوع.
*   **عملکرد بهینه:** مدیریت حافظه هوشمند برای پردازش‌های سنگین.
*   **جامعه محور:** توسعه‌یافته بر پایه نیازهای واقعی پژوهشگران و مهندسان.

## ۱. نصب (Installation)

نصب قمر بسیار سرراست است. پیشنهاد می‌کنم همیشه از یک محیط مجازی (Virtual Environment) استفاده کنید تا وابستگی‌های پروژه‌تان با سایر بخش‌های سیستم تداخل نداشته باشد.

```bash
# نصب از طریق pip
pip install qamar-core

# یا اگر از محیط توسعه استفاده می‌کنید
git clone https://github.com/qamar-dev/qamar
cd qamar
pip install -e .
```

---

## ۲. شروع سریع و استفاده

بعد از نصب، اولین قدم تعریف یک «کانتکست» برای پروژه است. قمر از الگوی `Provider` استفاده می‌کند تا داده‌های میان‌رشته‌ای را به فرمت قابل‌فهم تبدیل کند.

```python
from qamar import QamarEngine

# مقداردهی اولیه موتور قمر
engine = QamarEngine(mode="research")

# بارگذاری یک ماژول میان‌رشته‌ای
engine.load_module("physics_data_bridge")

# اجرای یک تحلیل ساده
result = engine.process(input_data={"source": "sensor_01", "type": "thermal"})
print(f"خروجی تحلیل: {result.status}")
```

## ۴. مثال کاربردی (Use Case)

فرض کنید در حال تحلیل داده‌های اقتصادی هستید که با تغییرات اقلیمی گره خورده‌اند. قمر به شما اجازه می‌دهد این دو جریان داده را در یک `Pipeline` واحد ترکیب کنید:

```python
# ترکیب داده‌های اقتصادی و اقلیمی
pipeline = engine.create_pipeline()
pipeline.add_source("economy_db", "gdp_growth")
pipeline.add_source("climate_sensor", "co2_levels")

# اجرای محاسبات همبستگی (Correlation)
analysis = pipeline.run("correlation_analysis")
analysis.export_report("final_report.pdf")
```

## ۵. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های کوچک هم مناسب است؟**
بله، با اینکه قمر برای سیستم‌های بزرگ طراحی شده، اما به دلیل حجم کمِ هسته (Core)، برای پروژه‌های کوچک و نمونه‌سازی سریع (Prototyping) فوق‌العاده است.

**آیا امکان گسترش ماژول‌های شخصی وجود دارد؟**
قطعاً. معماری قمر به گونه‌ای است که می‌توانید `Plugin`های اختصاصی خود را با استفاده از مستنداتِ بخشِ `DevGuide` بنویسید و به راحتی به هسته اصلی اضافه کنید.

**مشکلات احتمالی در زمان اجرا را کجا گزارش کنم؟**
بهترین جا، بخش `Issues` در گیت‌هاب پروژه است. تیم توسعه بسیار فعال است و معمولاً ظرف ۲۴ ساعت پاسخگوی باگ‌های گزارش‌شده هستند.
