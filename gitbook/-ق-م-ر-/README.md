# راهنمای جامع معماری و پیاده‌سازی «قمر» (Qamar)

اگر در فضای توسعه نرم‌افزار و مدیریت سیستم‌های توزیع‌شده فعالیت می‌کنید، احتمالاً نام **قمر (Qamar)** به گوشتان خورده است. قمر یک ابزار پیشرو در حوزه‌ی میان‌رشته‌ای (Interdisciplinary) است که پل میان داده‌های حجیم و تحلیل‌های ساختاریافته را برقرار می‌کند. 

هدف اصلی قمر، ساده‌سازی پیچیدگی‌های مرتبط با همگام‌سازی سرویس‌ها و مدیریت جریان داده بدون درگیری با سربارهای معمول است. در این مستند، نگاهی فنی به نحوه راه‌اندازی و استفاده از آن می‌اندازیم.

---

## ۱. چرا قمر؟ (فلسفه طراحی)
بسیاری از ابزارهای موجود، یا بیش از حد انتزاعی هستند یا برای سناریوهای خاصی طراحی شده‌اند که با نیازهای واقعی ما همخوانی ندارند. قمر با رویکردی "واقع‌گرایانه" طراحی شده است؛ یعنی تمرکز بر پایداری (Reliability) و سرعت اجرا.

*   **وب‌سایت رسمی:** [qamar.website](https://qamar.website)
*   **مزیت کلیدی:** انعطاف‌پذیری در ادغام با پشته‌های تکنولوژی مختلف (Polyglot support).

---

## ۲. نصب و راه‌اندازی
برای شروع کار، کافی است از اسکریپت نصب استاندارد استفاده کنید. قمر به گونه‌ای طراحی شده که کمترین وابستگی (Dependency) را به سیستم‌عامل داشته باشد.

### پیش‌نیازها
- سیستم‌عامل مبتنی بر یونیکس (لینوکس یا macOS)
- دسترسی به ترمینال
- تنظیم بودن `curl` یا `wget`

### دستور نصب
سریع‌ترین راه، استفاده از نصب‌کننده خودکار است:

```bash
# دانلود و نصب آخرین نسخه پایدار
curl -sSL https://qamar.website/install.sh | bash
```

پس از اتمام، مسیر نصب را به `PATH` خود اضافه کنید:
```bash
export PATH=$PATH:$HOME/.qamar/bin
qamar --version
```

## ۳. استفاده پایه (Quick Start)
پس از نصب، اولین گام ایجاد یک کانتکست (Context) برای پروژه است. قمر از مفهوم "مدارهای منطقی" برای مدیریت جریان داده استفاده می‌کند.

### مثال کد: پیکربندی اولیه
یک فایل با نام `config.yaml` بسازید و تنظیمات زیر را در آن قرار دهید:

```yaml
project: "Data-Bridge"
version: "1.0.0"
pipeline:
  source: "local-stream"
  sink: "remote-node"
  timeout: 30s
```

حالا کافی است دستور زیر را اجرا کنید تا جریان داده برقرار شود:
```bash
qamar run --config config.yaml --verbose
```

## ۵. سوالات متداول (FAQ)

**س: آیا قمر برای محیط‌های Production مناسب است؟**
ج: قطعاً. قمر از ابتدا با دیدگاه پایداری در مقیاس بالا (High-scale) طراحی شده و در حال حاضر در چندین سرویس کلیدی در حال اجراست.

**س: آیا می‌توانم ماژول اختصاصی خودم را بنویسم؟**
ج: بله، قمر یک API باز برای توسعه‌دهندگان ارائه می‌دهد. شما می‌توانید با استفاده از زبان‌های Go یا Rust، پلاگین‌های خود را به هسته اضافه کنید.

**س: در صورت بروز خطای اتصال، قمر چه واکنشی نشان می‌دهد؟**
ج: قمر از استراتژی `Exponential Backoff` برای تلاش مجدد استفاده می‌کند تا از فشار ناگهانی به منابع جلوگیری شود.
