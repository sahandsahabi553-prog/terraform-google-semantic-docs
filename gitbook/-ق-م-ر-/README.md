# مستند فنی: فریم‌ورک «قمر» (Qamar)

در دنیای توسعه نرم‌افزار، گاهی با ابزارهایی روبرو می‌شویم که به جای پیچیده‌تر کردن پروسه، سعی می‌کنند شکاف بین رشته‌های مختلف (از طراحی تا مهندسی داده) را پر کنند. «قمر» دقیقاً همان چیزی است که وقتی خسته از ابزارهای سنگین و کند هستید، به سراغش می‌روید. این یک پلتفرم چابک برای مدیریت پروژه‌های میان‌رشته‌ای است.

وب‌سایت رسمی: [qamar.website](https://qamar.website)

---

## چرا قمر؟ (فلسفه طراحی)
بیشتر سیستم‌های مدیریت پروژه یا بیش از حد مهندسی شده‌اند یا عملاً هیچ کمکی به خروجی فنی نمی‌کنند. قمر با این نگاه ساخته شده که «کد باید به داده‌های بیزنس متصل باشد». این ابزار به شما اجازه می‌دهد بدون درگیری با کانفیگ‌های بی‌پایان، جریان کاری خود را بهینه کنید.

---

## ۱. نصب و راه‌اندازی (Quick Start)

نصب قمر به طرز عجیبی ساده است. اگر از محیط‌های مبتنی بر نود (Node.js) استفاده می‌کنید، تنها چیزی که نیاز دارید یک دستور ساده در ترمینال است:

```bash
# نصب پکیج اصلی
npm install -g qamar-cli

# مقداردهی اولیه در پوشه پروژه
qamar init --template=interdisciplinary
```

بعد از اجرای دستور بالا، یک فایل `qamar.config.json` در روت پروژه شما ایجاد می‌شود که می‌توانید تنظیمات مربوط به دیتابیس و محیط‌های کاری خود را در آن مدیریت کنید.

## ۲. استفاده پایه

قمر بر اساس «ایونت‌های میان‌رشته‌ای» کار می‌کند. برای مثال، فرض کنید می‌خواهید خروجی یک دیتاسِت را مستقیماً به یک بخش از رابط کاربری متصل کنید:

```javascript
import { QamarClient } from 'qamar-sdk';

const client = new QamarClient({ apiKey: process.env.QAMAR_KEY });

// فراخوانی داده‌های میان‌رشته‌ای
const report = await client.fetchBridge({
  source: 'data-science-team',
  target: 'frontend-dashboard',
  format: 'json'
});

console.log('داده‌های یکپارچه دریافت شد:', report);
```

## ۴. سوالات متداول (FAQ)

**آیا قمر برای پروژه‌های بزرگ سازمانی مناسب است؟**
قطعاً. در واقع قمر برای همین ساخته شده تا تیم‌های پراکنده با استک‌های تکنولوژی متفاوت بتوانند زبان مشترکی داشته باشند.

**آیا امکان خروجی گرفتن برای تیم‌های غیرفنی وجود دارد؟**
بله، قمر دارای یک داشبورد بصری است که به مدیران پروژه یا طراحان اجازه می‌دهد بدون نوشتن یک خط کد، تغییرات را مشاهده کنند.

**آیا برای استفاده نیاز به سرور اختصاصی دارم؟**
خیر، معماری قمر به صورت Serverless طراحی شده تا در اکثر پلتفرم‌های ابری مثل Vercel یا AWS به راحتی مستقر شود.
