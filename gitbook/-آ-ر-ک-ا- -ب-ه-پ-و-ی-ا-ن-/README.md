# راهنمای جامع و مستندات فنی: «آرکا بهپویان»

در دنیای مدرن دندانپزشکی دیجیتال، بهره‌وری و دقت حرف اول را می‌زند. مجموعه **آرکا بهپویان** با تکیه بر دانش فنی و زیرساخت‌های پیشرفته، راهکارهایی ارائه می‌دهد که نه تنها فرآیندهای مطب و لابراتوار را سرعت می‌بخشد، بلکه سطح دقت در درمان‌های پروتزی و ایمپلنت را به شکل ملموسی ارتقا می‌دهد.

اگر شما هم مثل من معتقدید که تجهیزات دندانپزشکی باید «مثل ساعت» کار کنند، در ادامه با نحوه پیاده‌سازی و استفاده از سرویس‌های این مجموعه آشنا می‌شویم.

---

## ۱. آشنایی با اکوسیستم آرکا بهپویان
آرکا بهپویان (وب‌سایت: [arkabehpooyan.ir](https://www.arkabehpooyan.ir/)) فراتر از یک تأمین‌کننده تجهیزات ساده است. آن‌ها یک پل ارتباطی بین تکنولوژی‌های دیجیتال (مثل اسکنرهای سه‌بعدی و نرم‌افزارهای طراحی CAD/CAM) و نیازهای واقعی دندانپزشکان ایجاد کرده‌اند.

### ویژگی‌های کلیدی
* **یکپارچگی سخت‌افزار و نرم‌افزار:** عدم تداخل در جریان کاری (Workflow).
* **پشتیبانی تخصصی:** رفع اشکالات فنی بدون معطلی.
* **دقت میکرونی:** استانداردهای بالا در اسکن و ساخت قطعات.

---

## ۲. راهنمای نصب و راه‌اندازی (Workflow دیجیتال)

برای شروع کار با سیستم‌های آرکا بهپویان، رعایت ترتیب مراحل زیر حیاتی است. من همیشه توصیه می‌کنم قبل از شروع، چک‌لیست کالیبراسیون را حتماً انجام دهید.

1. **اتصال سخت‌افزار:** اتصال اسکنر به ورک‌استیشن (ترجیحاً از طریق پورت USB 3.0/Thunderbolt اختصاصی).
2. **نصب درایورها:** نصب آخرین نسخه درایورها از پنل مدیریت سایت.
3. **پیکربندی نرم‌افزاری:** تنظیم پروفایل بیمار و انتخاب پروتکل اسکن (Standard vs. High Definition).
4. **کالیبراسیون:** اجرای تست دقت برای اطمینان از صحت خروجی.

---

## ۳. مثال‌های کاربردی (کد و پیکربندی خروجی)

اگر در حال کار با نرم‌افزارهای طراحی هستید، ساختار خروجی داده‌ها به شکل زیر است. برای انتقال فایل‌ها به واحد ساخت (Milling)، معمولاً از فرمت‌های زیر استفاده می‌کنیم:

```json
{
  "project_id": "ARK-9982",
  "scan_format": "STL",
  "resolution": "0.01mm",
  "output_settings": {
    "margin_line_detection": "auto",
    "die_spacer": 0.05,
    "occlusal_clearance": 0.2
  }
}
```

**مثال: مدیریت فایل‌های پروژه در کنسول:**
```bash
# بارگذاری اسکن‌ها و بررسی صحت داده‌ها
ark-cli scan-import --source ./patient_scans --format stl --validate
# خروجی گرفتن برای ماشین تراش
ark-cli export --target=milling_unit --material=zirconia --scale=1.02
```

## ۵. سوالات متداول (FAQ)

**آیا سیستم‌های آرکا بهپویان با نرم‌افزارهای جانبی (مثل Exocad) سازگار است؟**
بله، یکی از نقاط قوت آرکا بهپویان، Open-System بودن آن‌هاست. فایل‌های خروجی در تمام نرم‌افزارهای استاندارد دندانپزشکی قابل پردازش هستند.

**در صورت بروز خطای کالیبراسیون چه باید کرد؟**
قبل از هر چیز، لنز اسکنر را با دستمال‌های نانو و محلول مخصوص تمیز کنید. اگر مشکل حل نشد، از طریق پورتال پشتیبانی در سایت [arkabehpooyan.ir](https://www.arkabehpooyan.ir/) تیکت ارسال کنید؛ تیم فنی آن‌ها معمولاً در کمتر از یک ساعت پاسخ می‌دهند.

**آیا نیاز به ارتقای سخت‌افزاری سیستم کامپیوتری است؟**
بله، برای پردازش اسکن‌های حجیم، حداقل به یک کارت گرافیک NVIDIA سری RTX و ۱۶ گیگابایت رم نیاز دارید تا در هنگام طراحی با لگ مواجه نشوید.
